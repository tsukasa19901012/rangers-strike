# 確定仕様

Wiki 上で grnrngr 公式ルール・FAQ・atwiki 裁定ページが一致し、confidence HIGH と明記されている項目。カード個別効果は除く（後述）。

## フェイズ

| 項目 | 確定内容 | 出典 |
|------|----------|------|
| フェイズ構成 | スタート → チャージ → ラッシュ → バトル → エンド（5フェイズ） | `core-rules.md`, `phases.md` |
| 先攻1ターン目 | スタートフェイズ省略、チャージフェイズから開始 | grnrngr rule_phase1-2, FAQ |
| フェイズ内順序 | 各フェイズ内の行動順序に制限なし | FAQ |
| フェイズ遷移 | `end_phase` で次フェイズへ。必須バトル進入未完了時は battle で end 不可 | `core-rules.md`, `phases.md` |
| 勝利条件 | 相手に7ダメージ、または必須ドロー失敗（山札0のみでは即敗北しない） | `phases.md`, FAQ |
| スタート行程 | (1) 全ホールドリリース (2) バトル→ラッシュ戻し (3) 1枚ドロー — **任意順・各1回** | atwiki 264, FAQ |
| 追加ドロー | 手札 < ダメージなら追加1枚（任意、1ターン1回、手札同数までではない） | FAQ, `phases.md` |
| チャージ | 1ターン1枚、オモテ向き、スキップ可 | rule_phase1-2 |
| エンドフェイズ（基本） | バトルの次。「ターンを終えるとき」効果はここで処理。「自軍エンドフェイズ」はそれより先 | atwiki 155, FAQ |
| ターン修飾 | 「このターン」= 効果発動〜ターンプレイヤーのターンエンド。エンドで TurnModifiers / bpModifier 等クリア | FAQ, `timing.md` |

## ラッシュ

| 項目 | 確定内容 | 出典 |
|------|----------|------|
| ラッシュ手順 | ①必要パワー+追加条件確認 → ②コマンドホールド → ③追加条件実行 → ④ラッシュ | FAQ, atwiki 146 |
| 追加条件とパワー | 追加条件で必要パワーを満たすことは不可（パワー充足後に別途） | FAQ, atwiki Q3 |
| 手順中断 | 手順完了済み部分は、途中でコマンド/パワー変化しても続行可 | atwiki 146 |
| 効果ラッシュ | 特記なし限り必要パワー・追加条件・コマンド不要 | atwiki 146 |
| 「出したユニット効果なし」 | `ラッシュされたとき` タイミングのみ無効（全効果無効ではない） | atwiki 146 |
| 同名複数 | 同名ユニット複数場可 | FAQ |
| ゾードアップ素材 | rush/battle 上のユニットのみ。S→command はリリース状態 | FAQ, atwiki 584 |
| オペレーション | 通常オペ=捨札。常駐=各1枚、上書き時旧常駐捨札。非常駐使用で常駐は消えない | FAQ, atwiki 1296 |
| カウンター | 相手ターンのみ。コマンドホールド必要。相手にリリースコマンド必須 | atwiki 1295, 260 |
| RS-026 順序 | ラッシュ誘発効果 → その後 疾風カウンター窓（エラッタ確定） | `errata.ts`, `timing.md` |
| マルチカテゴリ使用 | 全カテゴリのコマンド存在 + いずれか1カテゴリホールド | atwiki 1559, FAQ |
| 敵コマンド上マルチ | 敵が自軍コマンドに置いたマルチ1枚 = 自軍パワー+1（カテゴリ数不問） | atwiki 110, 1559 |

## バトル

| 項目 | 確定内容 | 出典 |
|------|----------|------|
| バトル進入 | 左詰め配置。進入後アタック/ストライク/パス選択。パスでフェイズ終了可 | rule_phase4, FAQ |
| NC | 左からN番目 = comboNumber=N で発動。サイズ・カテゴリ混在可 | FAQ |
| NC再発動 | 進入時のみ。並び変化のみでは再発動しない | FAQ |
| NC欠番 | 途中離脱で詰め、右端は1番扱い | FAQ |
| アタック | 低BP撃破→捨札。同BP相討ち（同時撃破）。相手バトル空では不可（ウイング等例外あり） | rule_phase4, atwiki 1826 |
| 1ユニット1回 | battleActed — 1ユニット1ターン1回 | `battle.md` |
| レジスト | BP比較によるバトル撃破のみ。相討ち可。「勝っても撃破」vs レジスト不可 | FAQ |
| 代用・キャンセル | RS-006/018 エラッタ文面に準拠 | `errata.ts`, FAQ |
| BP計算 | 参照=修正後。「本来の値」=印刷値。「+」重複加算。「～になる」上書き、複数時低い方。順序: 指定値→+→- | FAQ |
| ジョイントコンボ（JC） | L/R 配置で発動。L=能力付加、R=自身発動。条件はカード文面依存 | `glossary/p266.md` |
| ライディングコンボ（RC） | RC付きユニットをビークルにライド→バトル進入。ライドオフ時のみ発動（効果ライドオフ不可） | `glossary/p228.md` |

## ダメージ

| 項目 | 確定内容 | 出典 |
|------|----------|------|
| ストライク | SP1以上、基本1ストライク=1ダメージ。7ダメージで勝利 | rule_phase4 |
| ストライク時 | 常駐オペ・NC 有効 | rule_phase4 |
| ダメージ支払い | N点 → 表パワーN枚裏返し。不足分は山札上から裏向きパワーへ | atwiki 105, FAQ |
| 裏返し選択 | 表パワーは自由選択。裏枚数は非公開 | FAQ |
| デッキアウト | ダメージ支払い中の山札引き失敗も敗北対象 | FAQ |
| パワー定義 | 自軍パワーゾーン枚数 + 敵コマンド上マルチ枚数。表裏不問。使用後も自軍パワー除去しない | atwiki 110, FAQ |

### ゾーン・デッキ（横断）

| 項目 | 確定内容 |
|------|----------|
| デッキ | 40枚以上、同名3枚まで（戦闘員等例外あり） |
| コマンド上限 | 5枚。超過捨札。満杯時入替は効果以外不可 |
| パワー | 枚数無制限。表=チャージ、裏=ダメージ |
| 手札 | 上限なし |
| 捨札 | 公開（オモテ） |

# 優先的に解決すべき未確定事項

実装着手前に、この順序で解消することを推奨する。

## 1. 即時（Block: HIGH / MEDIUM）

1. **I-01 敵マルチ→パワー加算** — ルール確定済みのままエンジンが誤ると対戦結果が変わる。`core-rules.md` / `state-mapping.md` でも HIGH リスク。
2. **I-02 + U-12 cards.json 突合** — RS-143 等5枚の効果文追加 → `verify-wiki-effects` 全弾実行。カード効果実装の前提データ。
3. **C-06 エラッタ統一** — grnrngr errata.html と errata.ts / cards.json の差分リスト作成・反映。

## 2. 短期（実装フェーズ1完了前）

4. **U-13 L3 効果文 UNKNOWN 40枚** — atwiki 再パースまたは grnrngr 画像参照で cards.json / wiki md 更新。
5. **I-04 同時効果順序** — BP「～になる」複数時等、FAQ 確定ルールに対する UI/自動解決方針を ADR 化。
6. **C-01 / C-02 ドキュメント整合** — core-rules 禁止カード・glossary 先攻記述を Wiki 確定内容に合わせる。

## 3. 中期（Legend 4-9 / EXP 前）

7. **I-05 ウイング / I-06 チェイス** — キーワード実装か、対象カードをプール外とするかをスコープ判断。
8. **I-07 JC/RC** — EXP（RK-*）カード実装に必須。combo.ts 設計レビュー。
9. **U-01 エンドフェイズ grnrngr 画像** — OCR または手動転記。現行 atwiki 155 で足りるか最終宣言。

## 4. スコープ外として確定可

10. **U-08 タッグストライク / U-09 XG / U-10 コマンダー** — Wiki 収集完了。本シミュレーター v1 スコープ外と明記済み。再議不要。
11. **U-04 / U-05** — grnrngr FAQ 追加取得は優先度 LOW。現行 FAQ + atwiki で足りる範囲を文書化。

### 結論

**コアゲームループ（フェイズ・ラッシュ・バトル・ダメージ）は Wiki 上ほぼ確定しており、Legend 1-3 のエンジン実装を開始できる。**

- 敵マルチ→パワー加算（I-01）の実装仕様確定
