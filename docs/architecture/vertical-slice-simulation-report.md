## 問題点と所見

### 1. 修正済み: `illegal_action`（VS-BUG-01）

修正前は 50/100 が `apply_failed: illegal_action`。  
原因は `effectStack` キャッシュと `pending*` の不整合。`buildEffectStack` 常時導出で解消。

### 2. バトル宣言が 0 試合（VS-AI-01）

CPU Lv1 はストライク・ラッシュ進入を優先し、ユニット同士の `battle` アクションを選ばない傾向。  
エンジン不具合ではなく **AI ヒューリスティックの問題**。

**影響:** コンボ・被アタック時効果・バトル時カウンターの実戦検証が不足。

**推奨:** Vertical Slice 用に「BP 有利なら battle を優先」ルールを Lv1 に追加、またはシミュレーション専用プロファイル。

### 3. デッキアウト勝利が多数（VS-AI-02）

59/100 が相手デッキ切れによる勝利。ドロー偏重・手札温存・ストライクのみのダメージルートが主因と推測。

**影響:** ダメージ勝利ルート（41試合）は確認できているが、バランス検証には不向き。

### 4. ストライクは 54/100 で発生

ストライク経路は動作。ダメージ勝利 41 試合と整合。

### 5. 試合長のばらつき

126–520 ステップ。スターター組み合わせ・先攻で差あり。異常な無限ループはなし。
