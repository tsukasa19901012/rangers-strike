                ハイパーゴーオンレッド

種類：Sユニット

カテゴリ：ミスティックアームズ／オーバーテクノロジー

BP：4000

SP：！

必要パワー：4+

追加条件：特徴「侍」を持つ自軍ユニットがある

CN：4

特徴：レッド／男／侍

テキスト：

※これは特徴「車両」を持つビークルにライドできる。 

【音速の赤き侍】「SP1」 敵軍バトルエリアから、ライドされている敵軍ビークルを1体選び、持ち主のパワーゾーンに送る。 （この効果は、ライドオフしたときナンバーに関係なく発動する） 

フレーバーテキスト

マッハ全開、天下御免の大暴れだぜ！

イラストレーター：SRI

レアリティ：シークレットレア

作品：侍戦隊シンケンジャーVSゴーオンジャー 銀幕BANG!!

収録：XG4 ザ・ジェットアクセル　自販：パック

カード評価

- 前年に続き、今度は恐竜ディスクの力を借りるカテゴリMAと特徴「侍」を得たゴーオンレッド。追加条件はあるが、ゲーム上はゴーオンレッドとは関係のないユニットである。

- ライドされたビークルを除去してしまう能力は、ハリケンウィンガーやマシンキバーのような乗りっぱなしで効果を発揮するビークルや、ビークルに乗せたまま使うことが多いチェイス持ちのユニットやギンガマン勢などにとって脅威となる。

- ビークルを除去できる数少ない能力。ライドされていないものを狙うにはバスオンでのライドオフ妨害や、レッカーが必要だがモグラ獣人を使うなど工夫が必要。

- 対象となるビークルのサイズは問わないため、現状ではバルジオン（2nd）やデカバイクなどのLビークルを除去できる数少ない手段である。

- ライドオフでナンバーに関係なくSPを得られる点が強力。デカブレイクと違い自身がライド能力を持っているため、乗るビークルの選択肢も豊富である。
