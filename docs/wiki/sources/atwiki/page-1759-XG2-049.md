                仮面ライダーギルス（XG2）

種類：Sユニット

カテゴリ：ミスティックアームズ

BP：3000

SP：1/3

必要パワー：4

追加条件：なし

CN：RC

特徴：仮面ライダー／男

テキスト：

※レジスト

【デモンズファングクラッシャー】敵軍山札の上から1枚をオモテにする。オモテにしたカードがSユニットのカードだったなら、敵軍バトルエリアに出してもよい（出したユニットの効果は発動しない）。出さなかったか、Sユニットのカード以外だったなら、オモテにしたカードを山札の上に戻す。 

フレーバーテキスト

なぜ戦うのか。問いに答える事無く彼はただ、雄叫びを上げて走り出す。

イラストレーター：K2商会

レアリティ：ノーマル

作品：仮面ライダーアギト

収録：クロスギャザー ザ・ドラゴンタイガー　自販：パック

カード評価

- 敵軍Sユニットを山札から強制的にラッシュさせるRCを持つSユニット。

- RCはラッシュ時に発動するモーフや仮面ライダー響鬼（XG2）の補助、トライゴウラムのようなバトルエリアを対象にする効果の対象を確保するのに便利。

- ザマス2弾の方と比べて、レジストを使用する機会が増えたので、愛機であるギルスレイダーとの相性は良くなった。

コメント

-  デッキトップからＳユニットをラッシュさせる効果は、単体ではただ敵の数を増やすだけなので、グリーンサイや仮面ライダー響鬼（ＸＧ２）と併せて使いたい。  -- 名無しさん  (2009-08-28 22:27:01)

-  処理順はラッシュエリアに出す、ラッシュに対する効果（モーフなど）の適応、バトルエリアに出す、の順？あと、コマンドがすべて寝ている状態でミラーモンスターなどバトルエリアに出られない場合は戻すほうを選ばなければならない、で良いよね？  -- 名無しさん  (2009-10-04 01:50:13)

-  こういう効果はバトルエリアに直接出してからラッシュに対する効果処理をする。後者はそれで正解。  -- 名無しさん  (2009-10-04 06:35:17)

-  直接バトルエリアに出されることもラッシュに変わりないからな。あと「バトルエリアに出るとき」ってタイミングの効果はラッシュエリア以外から出るときでも適用されるからホールド要るんだよな  -- 名無しさん  (2009-10-04 06:40:33)
