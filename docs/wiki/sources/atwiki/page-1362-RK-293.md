                センチピードオルフェノク

種類：Sユニット

カテゴリ：ダークアライアンス

BP：2000

SP：－

必要パワー：3

追加条件：なし

CN：なし

特徴：ラッキークローバー／オルフェノク／怪人／男

テキスト：

【捕縛する鞭】これが自軍バトルエリアにある間、敵軍ターン中、次の効果を発揮できる⇒敵軍ユニットがラッシュされたとき、自軍コマンドを1つホールドしてもよい。そうしたとき、相手は自分自身のコマンドを1つホールドするかしないかを選ぶ。ホールドしないことを選んだとき、そのユニットはそのターン中、バトルエリアに出られない。

フレーバーテキスト

せめて詩の一編を読むくらいの時間は楽しませてくださいよ。

イラストレーター：添田一平

レアリティ：ノーマル

作品：仮面ライダー555

収録:ザ・マスクドライダーEXP vol.4　自販：パック

カード評価

- コマンドの数が相手より多いほど有利になる能力。ユニットサイズも限定しないため、デンジイエロー等他のロックと組み合わせれば中々強力。効果を使うためにはバトルエリアに出なければならないが、BPに不安があるので特徴「怪人」等を上手く利用してしぶとく生き延びてもらいたい。混合ではブルースローワーが天敵になるだろう。

- ライ単ではブランウイングとのコンボを狙いたい。相手のラッシュとバトルエリアに出ることを妨害できる。ラッシュされたユニットをロブスターオルフェノクで撃破するのが理想的。
