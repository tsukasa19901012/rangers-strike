フレーバーテキスト

雷雲を割って飛ぶ深紅の龍を再び鏡の中に見るまで、彼は全てを忘れていた。だが、耳を刺すような音が“異界”の記憶を呼び覚まし、彼は吸い寄せられるようにその入口を潜った。しかし、そこはかつての悲しき戦場と何かが違っていた…。 

イラストレーター：F.M.U

レアリティ：シークレットレア

作品：仮面ライダー龍騎

収録：五龍の逆鱗　自販：パック

カード評価

- パワー4でBP500のSP・能力なし。相当使いづらいカードである。一応、ライダーEXPでミラーライダー用のカードが増えたのでマシになってはいる。
- 必要パワーの重さが幸いしてアドベントカードやボルキャンサーのようなミラーライダー専用の補助カードの恩恵を受けやすいので、一応使えないことはない。

- フレーバーが非常に長い。レンジャーズストライクのカードの中では一番長いフレーバーテキストである。
- 見ているのはもしかしてドラグレッダーではなくこれ？
