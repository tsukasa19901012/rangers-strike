※スクラム（これのＣＮより1多いＣＮを持つユニットがこれの次に並んでいる間、これはアタックされない）

【マスキーローター】「SP1」常駐しているオペレーションを1枚選んでもよい。そうしたとき、選んだオペレーションの上に重ねたカードがあれば、重ねたカードをすべて持ち主の山札に戻してシャッフルする。

フレーバーテキスト

忍の道は甘くはないわよ！ほらほら、学生さんは下がっていなさい！

イラストレーター：小城 崇志

レアリティ：レア

作品：光戦隊マスクマン

収録：七忍の炎陣　自販：パック

カード評価

- 他のマスクマンのメンバーとは一つ遅れて7弾目に収録されたユニット。特徴に忍者を持つ。

- マスクマン勢に良く見られた自軍ダメージの蓄積によるデメリットの消滅や強化は持っていないが、初めからデメリットを持ち合わせていないため問題無い。

- 自軍・敵軍両方の常駐を対象にできる。敵軍ならば、冥府神スレイプニル対策になったり、仮面ライダークウガUFのラッシュを阻止したりする。自軍を対象にするなら、アレに積み上げられたカードを山札に戻して再利用する、などが考えられる。
