                アバレブラックAM（アバレモード）

種類：Sユニット

カテゴリ：ワイルドビースト

BP：5500

SP：！

必要パワー：7-

追加条件：自軍「アバレブラック」1体を捨札にすれば必要パワー0になる

CN：1

特徴：ブラック／男／アバレモード

テキスト:

※これが撃破されて捨札になったとき、自軍捨札から「アバレブラック」のカードを1枚選び、自軍ラッシュエリアに出す。

【無敵の竜人魂】敵軍バトルエリアから、本来のBPが8000以下のLユニットを1体選び撃破してもよい。そうしたとき、撃破したユニットがDAを持っていたなら、このターン、これは「SP1」になる。

フレーバーテキスト

幸せの目前でそれを引き裂かれる辛さを、あの悲しみを、これ以上生み出させはしない！

イラストレーター：K2商会

レアリティ：スーパーレア

作品：爆竜戦隊アバレンジャー

収録：クロスギャザー ザ・ファーストエンカウント　自販：パック

カード評価

- アバレブラックからのゾードアップ、高BPとLユニットを撃破できる効果を得た。SPを得る事もできるが相手のデッキによって左右されるため安定はしない。

- 冥府神たちや巨大化爆弾で強化されたユニットへのメタとなる。メガヘラクレスやキングライナーのようにアタックで倒しにくい厄介なユニットの対策にもなるので、デッキに余裕があれば入れてもよいだろう。
