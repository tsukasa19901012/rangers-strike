                レッドマスク

種類：Sユニット

カテゴリ：ミスティックアームズ

BP：3000

SP：－

必要パワー：2

追加条件：なし

CN：4

特徴：レッド／男

テキスト：

※これは、ラッシュしたターンにバトルエリアに出られない (この制限は自軍ダメージが4点以上あれば無効になる)。 

【ゴッドハンド】敵軍バトルエリアから、BP4000の敵軍Sユニットを1体選び、持ち主のパワーゾーンにダメージにして置いてもよい。 

フレーバーテキスト

お主達、人もまた獣の一つと知れ。見よ、あの見事な功夫（クンフー）。あれぞ伝説にある神の拳じゃ。 

イラストレーター：小城 崇志

レアリティ：レア

作品：光戦隊マスクマン

収録：紅き六戦士の帰還　自販：パック

カード評価

- レッドに限らずマスクマンチームにはダメージが蓄積するとデメリットが解除される特徴がある。しかしどのユニットもデメリットが解除されてやっと人並みといった強さなので使い辛さだけが残ってしまう。

- 【ゴッドハンド】は除去とダメージを兼ね備えなかなか強力だが対象がBP4000ピッタリでなければならないのが難点。

- フレーバーはマスター・シャーフーがゲキレンジャー達に向かって言っていると思われる。
