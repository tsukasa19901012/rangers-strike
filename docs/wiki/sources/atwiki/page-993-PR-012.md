                隠流忍術（プロモーション）

種類：オペレーション

カテゴリ：ミスティックアームズ

追加条件：なし

※カウンター（これは敵軍ターン中にのみ使用できる）

自軍ユニットがアタックされたとき発動できる⇒アタックしてきたユニット以外のユニットをすべての場からユニットを1体選んで、かわりにバトルさせる。
