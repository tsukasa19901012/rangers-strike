                巨大邪神14

種類：Lユニット

カテゴリ：ダークアライアンス

BP：8000

SP：1

必要パワー：14-

追加条件：必要パワーの数字が5以上の自軍パワーを4枚捨札にすれば必要パワー0になる

CN：なし

特徴：ドラゴン

テキスト：

※これをラッシュしたとき、自軍Sユニットを1体選び、これの下にウラ向きで重ねる。 これがユニットでなくなるとき、これにウラ向きで重ねたカードは捨札になる。

【絶対的な最強の力】 このユニットの下にウラ向きで重ねたカードがあれば、これは次の能力を得る⇒敵軍ユニット1体につきBP+1000され、BP12000以上のときSP2になる。

フレーバーテキスト

4人の王と1つの命、滅びの鍵は統制者の手を離れ地上へと解き放たれた。

イラストレーター：Kotaro Maeda

レアリティ：ノーマル

作品：仮面ライダー剣 MISSING ACE

収録：クロスギャザー　ザ・ギガンティックタイタン

カード評価

- 名前と同様の、14という非常に高いパワーに目がいくユニット。

- 自軍パワーゾーンにあるカードを4枚捨札にすることによって最低パワー4でラッシュ可能だが、捨札にできるのは必要パワー5以上のカードという厳しい制限が設けられている。また、一気に自軍パワーが4も減るのはキツイ。
- レッドレーサー（2nd）でパワーゾーンにあるユニットカードの必要パワーを上げることで条件を満たしやすくすることが可能。

- 無限の使徒ヴォッファの効果を使えば厳しい追加条件を満たすこともなくパワー無視でラッシュ出来るため、相性は抜群。

- 【絶対的な最強の力】を最大限に生かすのなら、ガロア艦長やゴ・ガドル・バなどの相手のユニットを増やす効果と組み合わせると良い。また、ガオ・ソウルを使えば相手に関係なくSP2になれる。

- ラッシュ時効果を発動してBP9000以上になっても、仮面ライダーアギトでの裁定により、疾風流超忍法を喰らってしまうので注意が必要。
