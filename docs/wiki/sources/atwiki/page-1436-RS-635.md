ピンクの戦士…メガピンク以外に興味は無いがその色目障りだ。

カード評価

- ネジレンジャー唯一ダメージ源能力を持っていない代わりに単体でＮＣが発動できる。他のネジレンジャーと違い、デッキを選ばない扱い易いユニット。

- 特徴「ピンク」は厄介なカードが多い。デカピンクやマジピンクのような単純に強いユニット、「女」デッキの中核ミスアメリカ、パワーロックのキーカードピンクレーサー等、優秀なユニットは枚挙に暇がない。アクセントにデッキに1、2枚仕込んでおくと良いかもしれない。

- 必要パワー０でＢＰ２０００という性能は地味に優秀。序盤に出てきたロボコンなどの加速要員を殴り倒すことができる。序盤はアタッカーとして活躍できるうえで強力な効果が使えると考えれば強さが引き立ってくるだろう。

- 使わない場合はオロチになったりもできる。
