                シンケンゴールド

種類：Sユニット

カテゴリ：ミスティックアームズ

BP：4000

SP：1/3

必要パワー：5

追加条件：なし

CN：なし

特徴：ゴールド／男／侍

テキスト：

【サカナマル】これが自軍ラッシュエリアにある間、敵軍バトルフェイズ中、相手が自分自身のSユニットをバトルエリアに出すために選んだとき、これを自軍バトルエリアに出してもよい。そうしたとき、自分は1枚ドローしてから、自分の手札を1枚選び捨札にする。このとき、捨札にしたカードと相手の選んだユニットの特徴を比べて、同じ特徴が2つ以上あれば、そのユニットを持ち主のパワーゾーンにダメージにして置き、1つだけならそのユニットを撃破する。

フレーバーテキスト

黄金色に包まれて目にも留まらぬ太刀裁き。光の侍、ここに見参！

レアリティ：スーパーレア

Q&A

		Q1
		自軍ラッシュエリアに「XG-038 シンケンゴールド」があるとき、敵軍バトルフェイズ中、相手がラッシュエリアにある「RK-065 仮面ライダーカブトRF」をバトルエリアに出すために選びました。「RK-065 仮面ライダーカブトRF」には「これはアタックされる以外では相手に選ばれない」と書かれていますが、このとき「XG-038 シンケンゴールド」の【サカナマル】の効果を発動することはできますか？
		A1
		はい、できます。【サカナマル】の効果はユニットを選んで発動するのではなく、特定のタイミングに対して発動するからです。

カード評価

- パワーは重いが【サカナマル】が強力。相手がバトルエリアに出る前に発動するため相手のユニットのＮＣやバトルエリアに出たときの効果が発動する前に除去ができ、ダメージ送りとドロー効果まで併せ持っている。

- 捨札にするカードには特徴に男や女、仮面ライダーやメカを持ったカードを選べば大体のSユニットは撃破できる。
- 特に仮面ライダー・男であるユニットは数が多くデッキへの投入率も高いため、相手ターン中にダメージを取れる貴重な手段にもなりうる。

- 能力を使った後も敵ターンは続いているはずなので、アタックされそうになった時を考えて新体操アクションをデッキに入れたい。アタックを防ぐだけでなく、ラッシュエリアに戻れるのでもう一度能力を使用できるようになる等非常に相性が良い。

- 他のMAのユニットでは対処が困難な冥獣人ニンジャキリカゲ等のバトルエリアにいるだけで起動するロックカードも相手がバトルエリアに出ようとするタイミングで起動する為、問題なく対処できる。
- 効果の起動はビークルに乗せる処理より先である。その為、当然ながら除去された場合ビークルはバトルエリアに出ない。（あらかじめライドしてない限りライドすらされていない）

- 効果対象を選んでいるわけではないため、「（対象に）選ばれない」効果やブレイカー持ちのユニットも除去可能。

- 対策としてはバイモーションバスターやガオメインバスターなどの除去オペレーション、または水のエルなどバトルエリアに出らずに効果を発動できるもの。ゼクトマイザーでバトルエリアに出してしまうのも有効。

- 高いレアリティに対して優れた汎用性を持つ強力なカードだったためか、収録弾発売の３ヶ月後に公認大会の参加プロモになった。
