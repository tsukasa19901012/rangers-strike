カード評価

- コマンド送りとダメージ送りの除去を持つ。ストライカーとしても使え、攻めにも守りにも使える汎用性の高いユニット。

- バトルエリア限定ではあるが、自身より大きい相手を除去できる効果は強力。グリフォーザー、パワーマイナス系等にたいして後だしで一方的に除去できる。

- ダメージを狙うには相手のコマンドを増やしておく必要がある。コマンドが増えれば相手のユニットの展開も早くなるため、通常のビートダウンではゴーグリーンなどのコマンド埋めと併用して狙う。逆に速攻で使う場合は仮面ライダーイクサSMなどの軽くてコマンド送り能力を持つユニットと併用する必要がある。
