                ゲキバイオレット

種類：Sユニット

BP：2000

SP：！

必要パワー：3

テキスト：

※レジスト(これがバトルで撃破されたとき、捨札にするかわりにこれをホールドしてその場に留めてもよい)

※このユニットは、自軍ラッシュフェイズ中、特徴に「レッド」「ブルー」「イエロー」を追加される。

【狼狼蹴】「SP1」このユニットをホールドしてもよい。そうしたとき、敵軍バトルエリアのユニットを必要パワーの数字の合計が2になるまで好きな数選び、撃破する。

カード評価

- パワー3でレジスト持ち、ストライク可能でさらに強力なゲキウルフやゲキトージャウルフへゾードアップ可能と非常に優秀なユニット。能力のユニット除去もいざという時に役に立つ。3枚積んでも損は無いはず。

- 仮面ライダーアギトSFと同じく必要パワーを参照する除去なので花忍者ランと組めば敵軍バトルエリアのSユニットを一掃できる。

- 「レッド」「ブルー」「イエロー」の代わりにゲキトージャラッシュの材料にもなる点も良いが、何と言っても特筆なのが捨札が7枚以上になればこれ一枚を捨札にするだけでゲキトージャウルフがラッシュできる点。捨札に関してはJPカードなどで任意に捨てられる状況を作ればさらに呼びやすくなる。

- 特徴「レッド」「ブルー」「イエロー」が追加されるのはこれがユニットであり尚且つラッシュフェイズ限定。利用できるカードは案外少ない。
