                仮面ライダーギャレン

種類：Sユニット

カテゴリ：ワイルドビースト

BP：3000

SP：－

必要パワー：2

追加条件：なし

CN：RC

特徴：仮面ライダー／男

テキスト：

※レジスト（これがバトルで撃破されたとき、捨札にするかわりにこれをホールドしてその場に留めてもよい）

【ギャレンラウザー】自分の手札を3枚選び、相手に見せてもよい。そうしたとき、敵軍Sユニットを1体選びホールドする。その後、見せたカードの必要パワーの数字が番号順（例：0、1、2や3、4、5など）に揃うなら、敵軍Sユニットを1体選び撃破する。

フレーバーテキスト

心に潜む恐怖を克服し、戦士は覚醒した。この誇り、もう何者にも汚させはしない。

イラストレーター：K2商会

レアリティ：レア

作品：仮面ライダー剣

収録：ザ・マスクドライダーEXP vol.2　自販：パック

カード評価

- ストライクこそ出来ないものの、低パワー、ＲＣ、レジスト持ちと良性能。効果に関してはブレイドと同じく、特殊能力のホールドと撃破で選ぶ敵ユニットは別々でよく、さらにこちらは撃破するユニットはラッシュエリアから選んでもよい。除去条件である「必要パワーの数値が番号順～」はブレイドほどではないものの、案外揃えやすい。

- ＲＣは後半の効果を満たせなくても相手ユニットを１体ホールドすることができるので仮面ライダーラルクやブルースペイダーのようなホールドされたユニットを除去するカードと組み合わせたい。

- ライドオフ時のストライクの制限がないのでブレイバックルやロボタフを使えばライドオフして効果発動後にストライクが可能。

- 効果の発動には手札が３枚以上必要になるのでキャッスルドランや仮面ライダーXのような手札を確保する手段を用意しておかないと後半に引いた時に効果が発動できない可能性が高いので注意が必要。
