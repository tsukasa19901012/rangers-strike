                ブラックファング

種類：Sビークル

カテゴリ：ダークアライアンス

必要パワー：2

追加条件：なし

特徴：メカ／車両

テキスト：

【衝撃波】これがライドされている間、敵軍Sユニットは次の制限を受ける⇒ライドしてバトルエリアに出たとき、ホールド状態になる。

フレーバーテキスト

守る為に作られた筈だった。だが闇に染まりし咆哮は追う者達へと牙を剥いた。

イラストレーター：neji

レアリティ：ノーマル

作品：仮面ライダー剣

収録：クロスギャザー　ザ・ファーストエンカウント　自販：パック

カード評価

-  DAでは貴重なビークル。強力だがやや重い炎の騎馬やバルジオン（2nd）とは、必要パワーの低さで住み分けができるだろう。

-  単純にRC＋レジストを持つ事の多い仮面ライダー系に強いほか、ユガンデの能力を黒単で使えるようになると言うメリットも。

-  ただし「ライドされている間」が条件なので場持ちが課題。レジスト持ちを乗せる、乗せてからラッシュエリアに戻す、など工夫したいところだがDAはそう言った手段に乏しい。
