### 効果の解決 [部分編集](https://w.atwiki.jp/renst/pedit/1869/0-1 "部分編集")

- ある [タイミング](https://w.atwiki.jp/renst/pages/1828.html "タイミング (5715d)") 内に発動したユニット・ビークル・オペレーションなどの効果に従い、その内容を実行すること。
- 1つのタイミングに複数の効果が発動した場合、 [優先順位](https://w.atwiki.jp/renst/pages/1864.html "優先順位 (6070d)") の高い効果から順に解決する。同じ優先順位の効果はターンプレイヤーが自由に解決の順番を決められる。解決自体は持ち主あるいは [テキスト](https://w.atwiki.jp/renst/pages/587.html "テキスト (349d)") で指定されたプレイヤーが行う。
- 効果の解決は1つずつ行う。また複数のユニットやカードを操作する場合、1枚ずつ順に処理する。
- 効果の解決の途中で、同じタイミングでの効果を発動したユニットが場を離れたりしても「このユニットが自軍エリアにある限り」などと期限が指定されていない限りそのユニットにより発動した効果の解決は行われる。自身の効果解決中であった場合でも解決は続行される。
- 「好きなだけ○○する」「×回まで○○してよい」など任意で回数を決められる効果は、特に但し書きがない限りは効果の解決中に持ち主が回数を決めてよい。事前に宣言する必要はない。
- 適切な効果対象が存在しない状態で効果を使う、いわゆる「空撃ち」は可能。その場合は効果は不発となり、その効果の解決は行われない。
- ただし適切な対象が存在する状態で「0回やる」という行為は認められておらず「その効果を使わない」とみなされる。対象を「0枚選ぶ」ことは可能だが、対象が存在しないためその後の処理は中断される。強制効果の場合は対象があれば必ず選ばなければならない。
- [ゴーゴーファイヤー](https://w.atwiki.jp/renst/pages/403.html "ゴーゴーファイヤー (3097d)") と [バルパンサー（2nd）](https://w.atwiki.jp/renst/pages/527.html "バルパンサー（2nd） (1260d)")、 [幽魔王サラマンデス](https://w.atwiki.jp/renst/pages/1798.html "幽魔王サラマンデス (2353d)") と [ヘルサターン総統](https://w.atwiki.jp/renst/pages/576.html "ヘルサターン総統 (3096d)")、 [コピーベント](https://w.atwiki.jp/renst/pages/1608.html "コピーベント (2316d)") と [冥獣人ニンジャキリカゲ](https://w.atwiki.jp/renst/pages/819.html "冥獣人ニンジャキリカゲ (796d)") など、カードの組み合わせによっては意図的に止められない効果処理の無限ループが発生することがある。この場合はターンプレイヤーがどの効果を適用するのかを決めて処理することができる。
