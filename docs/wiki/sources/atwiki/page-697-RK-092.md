                狼男

種類：Sユニット

カテゴリ：ダークアライアンス

BP：6000

SP：1

必要パワー：5+

追加条件：自軍「ゾル大佐」1体を捨札にする

CN：なし

特徴：ショッカー／怪人／男／改造人間

テキスト：

【狼作戦】これが自軍エリアにある間、特徴「男」を持つ自軍SユニットはカテゴリにWBが追加される。

フレーバーテキスト

あらゆる状況に対応できる準備が整うのを待ち、狼作戦は、真の恐怖をもたらしはじめた。

イラストレーター：前河 悠一

レアリティ：レア

作品：仮面ライダー

収録：ザ・マスクドライダーEXP vol.2　自販：パック

カード評価

- ゾル大佐が正体を現した姿。BPやSPは申し分ない。また、この姿の時は特徴「怪人」が追加されるので、アポロガイストや巨大化爆弾での強化が出来る。

- 能力はレッドフラッシュやロボタフの効果対象を増やしたりと、どちらかというと混合デッキ向け。バルイーグル（2nd）などとも相性が良い。
