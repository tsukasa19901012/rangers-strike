※常駐 

特徴「侍」を持つユニットは、次の能力を得る⇒タクスMA、コールMA  

フレーバーテキスト

侍の技と心を受け継いで、己を剣に闇を断て。

イラストレーター：Masakazu Fukuda

レアリティ：ノーマルレア

作品：侍戦隊シンケンジャー

収録：蒼九の翼　自販：パック：スターター（12大ヒーロー）

カード評価

- 特徴「侍」持ちにタクスとコールを同時に付加する事が出来る。

- MAにはマジピンクや各種高性能なカウンター、ホウオウレンジャーのようなタクスやコールと相性の良いカードが多数存在する。タクス・コール共に単体では強くないので侍を持つユニットだけでなくそれらのカードを絡めて使うことで強力な効果を発揮する。

- 効果を最大限活かすには侍持ちのMAのSユニットであるシンケンジャー勢及びMAのSユニットを大量投入しなければならずデッキ構成が読まれやすい。相手の対策が始まる前に押し切ってしまおう。

- バードニックウェーブやクロスを使い、シンケングリーンやシンケンピンクのNCとタクスを同時に発動させて連続ストライクすることができる。
