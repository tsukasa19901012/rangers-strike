                スクーパー

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：4000

SP：－

必要パワー：3+

追加条件：自軍エリアに「高次元戦闘車ギャビオン」がある

CN：なし

特徴：メカ／車両

テキスト：

※これは、チェイスを持つ自軍ユニットがあるか、ライドされている間、Sビークルとして扱う。

【地中潜行】これをラッシュしたとき、敵軍パワーゾーンのオモテ向きのカードから1枚選び、捨札にしてもよい。そうしたとき、敵軍捨札からカードを1枚選び敵軍パワーゾーンにオモテ向きで置く。

フレーバーテキスト

ギャビオンのコンテナから飛び出すと、ドリルをフル回転させて地底基地を目指した。

イラストレーター：矢薙 じょう

レアリティ：ノーマル

作品：宇宙刑事ギャバン

収録：スペシャルメタルエディション　自販：パック

カード評価

- チェイス持ちがいるとＳビークルになるユニット。原作再現により高次元戦闘車ギャビオンがいないとラッシュできない。今のところは宇宙刑事を中心としたデッキ専用のカードといって差し支えないだろう。

- ラッシュに制約があるだけあって、チェイスとの相性は非常に良い。チェイス持ちが場にいない間は高いＢＰを活かしたアタックで活躍し、チェイス持ちが出ればビークルとなってチェイスを発動しやすくする。Ｓユニットなので、捨札から回収しやすいのも強み。しつこく使いまわしていこう。

- 宇宙警察によって、素でチェイスを持つカードが無いデッキでも使うことができる。
