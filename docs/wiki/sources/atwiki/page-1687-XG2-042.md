                仮面ライダーディケイドCF（コンプリートフォーム）

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：6000

SP：1/4

必要パワー：5+

追加条件：特徴「ディケイドライバー」を持つ自軍ユニット1体をパワーゾーンに送る

CN：1

特徴：仮面ライダー／男／ディケイドライバー

テキスト：

※これがユニットでなくなるとき、オモテ向きの自軍パワーから特徴「仮面ライダー」を持つカードを1枚選び捨札にすれば、その場に留まる。

【ファイナルアタックライド】オモテ向きの自軍パワーから特徴「仮面ライダー」を持つユニットカードを1枚選び、自軍ラッシュエリアに出してもよい。そうしたとき、この効果で出したユニットはナンバーに数字かRCを持っていれば、このターン、そのナンバーは「2」になり、自分がターンを終えるとき、自軍エリアにあれば捨札にする。

Q&A

		Q1
		「XG2-042 仮面ライダーディケイドCF」の【ファイナルアタックライド】の効果で出したユニットは、自分がターンを終えるとき、ナンバーに数字またはRCを持つユニットだけが捨札になりますか？
		A1
		いいえ、ナンバーに関わらず、出したユニットは自分がターンを終えるとき、自軍エリアにあれば捨札になります。
		Q2
		自軍エリアに「XG2-042 仮面ライダーディケイドCF」があり、特徴「仮面ライダー」を持つオモテ向きの自軍パワーあるとき、敵軍「RS-322 ベン・G」の【人身略取】が発動し、相手は追加条件に「自軍Sユニットを1体捨札にする」と書かれたMユニットのカードを捨札にしました。自軍Sユニット が「XG2-042 仮面ライダーディケイドCF」しかない場合、追加条件を満たす為に「XG2-042 仮面ライダーディケイドCF」を捨札にしなければなりませんが、このとき「XG2-042 仮面ライダーディケイドCF」のその場に留まる効果を発動することはできますか？
		A2
		はい、「XG2-042 仮面ライダーディケイドCF」の「その場に留まる」という効果を発動することは出来ます。ただし、その場合はまだ場に「XG2-042 仮面ライダーディケイドCF」がいるので、追加条件を満たすことは可能であるとして、「RS-322 ベン・G」の効果を続行して下さい。
		Q3
		「XG-034 害気大臣キタネイダス」が自軍エリアにある間、バトルフェイズ中に、「XG2-042 仮面ライダーディケイドCF」の「これがユニットでなくなるとき、オモテ向きの自軍パワーから特徴「仮面ライダー」を持つカードを2枚選び捨札にすれば、 その場に留まる」という効果は発動できますか？また、【ファイナルアタックライド】の効果は発動できますか？
		A3
		いいえ、どちらもパワーゾーンからカードが離れる処理を含むため、発動できません。

カード評価

- 先のストライク！賞のプロモ版とは性能が異なる。必要パワーが減り、BPも上がっている。

- 特徴「ディケイドライバー」持ちのユニットからモーフすることができ、各種最終フォームの中でも随一の出しやすさを誇る。たとえモーフを妨害されても、元々追加条件がかなり緩く仮面ライダーディケイドやディケイドライバー、仮面ライダーディエンドなど関連カードでパワーも簡単に貯まるため出しやすさは変わらない。さらにパワーに仮面ライダーを貯める行為はこのユニットの能力発揮への伏線にもなっている。
- 特にディエンドは後述のように効果で出したライダーの再利用と敵軍ユニットの除去も同時にでき、とても相性がいい。

- BPがSユニットとしては高く殴り負けすることは少ない上に、自軍パワーゾーンの仮面ライダーを捨てれば何度でも生き残れる強力な除去耐性を持つ。しかも効果名を持たない効果なので冥獣人ニンジャキリカゲの効果が効かないなど無効化されにくい。おまけにモーフでパワーやコマンドからも復活できるため、一度出れば排除は極めて困難。アカネタカなどでパワーの仮面ライダーを守ればさらに強固になる。

- 【ファイナルアタックライド】は本編の「隣にライダーを召喚して同時攻撃」のシチュエーションを再現したもの。仮面ライダーならば一切制限なしにパワーから呼べるため、状況に合わせて色々応用が利く。呼び出したユニットは使用後に仮面ライダー電王AF（2nd）や仮面ライダーディエンドで再びパワーに飛ばしてしまえば、使い減らすことなく再利用できる。
- 主にラッシュするユニットは強力なダメージ送り能力を持つ仮面ライダー装甲響鬼、ナンバー変更によって２番目でストライクできる仮面ライダー蛮鬼、毎ターンダメージと除去を行える仮面ライダーキバDGBKFなど。

- この効果で一度もう1体別の仮面ライダーディケイドCFを出し、出したディケイドCFの効果でさらに別の仮面ライダーをラッシュし、使用後に効果で出した2体を仮面ライダーディエンドでパワーに送れば、結果的にライダーやパワーが減らずに済む。ただしこの場合NCやRC効果は使えなくなる。

- 仮面ライダークウガUFをこの効果でラッシュした場合、【凄まじき戦士】のデメリット効果が発動してしまう。自軍ユニットが全て捨札になるため、ディケイドCFとは相性が悪い。XG4収録版もこの効果ではラッシュできない仕様になっている。皮肉にも本編でも最終フォーム中唯一召喚されていない。

- このように「出しやすさ」「打たれ強さ」「能力の汎用性」全てを高レベルで兼ね備えており、場の制圧力は相当なものである。

- 対策としては、除去耐性、ファイナルアタックライド、ディケイドCFを補助するカードに対応する形になる。このカードを使うなら、これらへの対策を考えておきたい。
- 耐性への対策としては超電子レーダーやゼロライナードリル、タイムレッドなどでパワーを削る、害気大臣キタネイダスで能力を無効にする、仮面ライダーアギトBFや爆竜バキケロナグルスの連続アタックで撃破し切る、レッドホーク（2nd）等ＢＰを下げる効果を複数使用してＢＰを０まで下げるなどが考えられる。確実性は劣るがベン・Gを使う手もある。

- 【ファイナルアタックライド】対策としては冥獣人ニンジャキリカゲや仮面ライダークウガRDのようなＮＣの発動そのものを妨害するか、シンケンゴールドやデカピンクで呼び出されたライダーを間接的に無力化するかになる。ゼクトルーパーも使い捨てだが効果の発動の妨害に役立ってくれる。

- 補助カード対策としては、トリプターなどで仮面ライダーディエンドとデカピンクをウイングで撃破する（ディエンドはSユニットへのアタック回避能力を持つので、Sユニット以外が望ましい）、シャドームーンなどでビークルを除去し、アクロバッターの除去や仮面ライダーディケイドと仮面ライダードレイクMFのＲＣを妨害するなど。

- マッドギャランやガオディアス等でラッシュエリアに戻せなくするのも有効。

- あまりにも強力であるためか、この後に登場したプロモーションカードや次弾のクロスギャザー ザ・Wインパクトには、明らかにこのカードの対策用と思われる効果を持ったカードが多数登場している。
- 特に仮面ライダーW・FJやロイヤルストレートフラッシュの持つ「効果名を持たないテキストを無効にする」能力の誕生はこのカードの影響抜きでは考えられないだろう。
