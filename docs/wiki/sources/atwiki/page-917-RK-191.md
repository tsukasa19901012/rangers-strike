カード評価

- 【ガライソード】の効果でラッシュしたターンのみだがSP1になれる。ただし、能力を使う場合はレジストが使えなくなる。他のSP1持ちの必要パワー５のDAと比べてラッシュしたターンしかストライクできないが、SP1以上のユニットにアタックされても撃破されないので、ストライクした後はアタッカーとして活躍できる。

- ウエイクアップ！などのリリース手段があればレジストを維持しつつSP1になれる。

- フォッグマザーをラッシュした際に手札に戻せるので再度【ガライソード】が使用可能。フォッグマザー自身もSP1なのでこの2体だけでもダメージが稼げる。

- 特徴に獣を持つのでファルコンサモナーでのラッシュが可能。タッチでこのカードを入れて打点を稼ぐのに使うこともできる。
