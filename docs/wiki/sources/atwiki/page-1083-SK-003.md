                仮面ライダーファム（2nd）

種類：Sユニット

カテゴリ：ワイルドビースト

BP：2000

SP：1/2

必要パワー：4

追加条件：なし

CN：なし

特徴：仮面ライダー／女／ミラーライダー／2nd

テキスト：

【復讐の女詐欺師】これが自軍バトルエリアにある間、敵軍バトルフェイズ中、ホールド状態の敵軍コマンドが1つ以上あれば、特徴「男」を持つ敵軍Sユニットは、次の制限を受ける⇒アタックもストライクもすることができない。

フレーバーテキスト

復讐の炎に焼かれ、戦いの泥に塗（まみ）れた。だがそれでも翼の白さは失わない。

イラストレーター：中北晃二

レアリティ：シークレットレア

作品：仮面ライダー龍騎 EPISODE FINAL

収録:ザ・マスクドライダーEXP vol.3　自販：パック

カード評価

- Sユニットは女よりも男のほうが圧倒的に多いのでこのユニットを出されるだけで何もできなくなる可能性もある凶悪なロックパーツ。

- ミラーワールドや冥府神ゴーゴンと組み合わせることによってそのロックはより確実なものとなる。

- バトルエリアに出られなくなるわけではないのでコンビネーションの発動は普通に可能。仮面ライダーパンチホッパーでラッシュエリアに戻されればロックから抜けられる他、ゴーオンレッドの強制バトルする能力やアナザーアギトのダメージ送りなどには特に注意。

- ミラーモンスターやイマジンは男を持たないので普通にアタックできる点にも注意が必要。

- 男でもコマンドをホールドしなければアタックが可能。
- そのままでは展開に差がつけられてしまうが、勇気の魔法やダッシュレオンでリリースする、コールやリードでコマンドをホールドせずにユニットのラッシュやオペレーションカードを使うという手もある。
