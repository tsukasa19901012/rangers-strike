- [蒼九の翼](https://w.atwiki.jp/renst/pages/1409.html "蒼九の翼 (2484d)") から登場した能力。 [バトルエリア](https://w.atwiki.jp/renst/pages/457.html "バトルエリア (2322d)") に出ずに、 [ラッシュエリア](https://w.atwiki.jp/renst/pages/147.html "ラッシュエリア (6057d)") からアタックを行う。
- [デンジイエロー](https://w.atwiki.jp/renst/pages/544.html "デンジイエロー (6068d)") のような [バトルエリア](https://w.atwiki.jp/renst/pages/457.html "バトルエリア (2322d)") に出ることを妨害する効果や、 [タイガーロイド](https://w.atwiki.jp/renst/pages/641.html "タイガーロイド (1943d)") のような [バトルエリア](https://w.atwiki.jp/renst/pages/457.html "バトルエリア (2322d)") に出ているユニットに効果を及ぼすカードの影響を受けずに [アタック](https://w.atwiki.jp/renst/pages/138.html "アタック (5654d)") を行うことができる事が強み。
- デメリットはユニットをホールドする点、発動したターンはバトルエリアに出られない点の２つ。
  - ただし、ユニットが先にバトルエリアに出てからそのバトルフェイズ中に何らかの効果でラッシュエリアに戻り、その後ウイングを使うことは可能。バトルエリアに出たときとウイングで2回アタックすることができる。
  - また、バトルフェイズ中にユニットをリリースする手段があれば、同じユニットのウイングを1ターンに複数回使うこともできる。
- 作中で空を飛ぶキャラクターや飛行する動物に関する能力・モチーフを持つキャラクターのユニットが持つことが多い。
