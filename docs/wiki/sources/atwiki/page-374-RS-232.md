                アバレイエローAM（アバレモード）

種類：Sユニット

カテゴリ：ワイルドビースト

BP：4500

SP：－

必要パワー：7-

追加条件：自軍「アバレイエロー」1体を捨札にすれば必要パワー0になる

CN：3

特徴：イエロー／女／アバレモード

テキスト：

※これが撃破されて捨札になったとき、自軍捨札に「アバレイエロー」のカードがあれば1枚選び、自軍ラッシュエリアに出す。

【アバレウィング】これがアタックするとき、これはBP+1000され、敵軍ユニットのBPをカードに表記された本来の値としてバトルする。

フレーバーテキスト

その羽ばたき、舞の如し。最大の欠点は、誰もそれを見られないことだ。…速すぎて。 

イラストレーター：K2商会

レアリティ：ノーマルレア

作品：爆竜戦隊アバレンジャー

収録：四雄の覚醒　自販：パック

再録：七忍の炎陣　スターター(type 2：激気デッキ)

カード評価

- 恐竜やのカレーでのBP強化でBPが最大7500まで上がる、特徴「イエロー」を持つユニットの有望株。

- ノーマル状態よりもBPがグンと上がり、BP上昇効果まで付いたため、素のBPでバトルできる能力の効果を十二分に発揮する事が出来るようになった。

- 強力なアタック能力を持つ代わりにストライク能力を持たないが、その弱点はエレハン・キンポーで補うことができる。
