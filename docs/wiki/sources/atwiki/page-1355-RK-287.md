                ゴルトフェニックス

種類：Sユニット

カテゴリ：ワイルドビースト

BP：8000

SP：－

必要パワー：6

追加条件：なし

CN：なし

特徴：ミラーモンスター／獣

テキスト：

※これは自軍コマンドを1つホールドしなければバトルエリアに出られない。 

※これは特徴「仮面ライダー」を持つユニット以外にアタックする事ができない。 

【瞬間の悪夢】 これをラッシュしたとき、敵軍コマンドゾーンから、モーフを持つユニットカードを1枚選び捨札にしてもよい。 

フレーバーテキスト

風と炎と時間を操り、再生と命の象徴は黄金に輝き現れる。

イラストレーター：回転急須

レアリティ：ノーマルレア

作品：仮面ライダー龍騎

収録：ザ・マスクドライダーEXP vol.4　自販：パック

カード評価

- パワー6は少々重いが追加条件なしでBP8000を誇るSユニット。ただし、特徴に仮面ライダーを持つユニットのみにしかアタックできないのでキングライナーやDAのユニットには手が出せない。花忍者スイレンや大帝ラー・デウスを使えばこのデメリットを解消して混合デッキでも使うことができる。

- Sユニットなので過信しているとあっさり除去されてしまう事が多々あるので注意。

- 【瞬間の悪夢】を活かす場合はバイモーションバスターや仮面ライダー新2号などでモーフ持ちをコマンドに飛ばす必要がある。
