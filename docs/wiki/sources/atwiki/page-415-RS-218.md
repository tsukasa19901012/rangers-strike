                タイムレッド

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：4000

SP：！

必要パワー：4

追加条件：なし

CN：4

特徴：レッド／男／加速

テキスト：

【アサルトベクター】「SP1」相手は自分自身のパワーゾーンのダメージ以外のカードを見て、カテゴリの数が2つ以上あれば、1つになるまでダメージ以外のカードを捨札にする。

フレーバーテキスト

未来は変えられなくても、自分の明日くらいは変えようぜ！

イラストレーター：Mitsuhiro Arita

レアリティ：スーパーレア

作品：未来戦隊タイムレンジャー

収録：四雄の覚醒　自販：パック

再録：リバイヴァ　自販：パック

カード評価

- 多色デッキに刺さるカード。相手のパワーゾーンに、２つ以上の色のカードがあれば１カテゴリになるまでパワーを減らしてしまう派手な能力を持つ。３色以上でやっていると一気にパワーがなくなるなんてことにも…。

- アバレブラック同様、敵軍パワーのカードがマルチカテゴリのみだった場合、「カテゴリの数を１つにする」ことができないため、捨てることはできない。ただし単色のパワーが混ざっていれば最優先で除去することができる。
