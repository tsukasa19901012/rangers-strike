                ギンガレッド

種類：Sユニット

カテゴリ：ワイルドビースト

BP：3000

SP：！

必要パワー：3

追加条件：なし

CN：2

特徴：レッド／男

テキスト：

【炎一閃】「SP1」「MA」の自軍コマンドを１つホールドして、次の効果を発動できる⇒敵軍バトルエリアからナンバーを持たないSユニットを1体選び、撃破する。

フレーバーテキスト

アーカイブと交信した知恵の木は、剣の使命を終えて生きる伝説の刃達に再び呼び掛けた。

イラストレーター：村上ヒサシ

レアリティ：スーパーレア

作品：星獣戦隊ギンガマン

収録：紅き六戦士の帰還　自販：パック

カード評価

- MAのコマンド使用を前提としたカードの一つ。ギンガマンは全員がこの条件を持っている。MAとの混色が気になるならギンガベリックを併用したい。

- 【炎一閃】の対象であるナンバーを持たないSユニットは、DAのユニットや仮面ライダーキバなど。コンビネーションが中心のゲーム性の関係上、あまり対象は多くないが、重いユニットにナンバーを持たないユニットが多いため、自身より大きいユニットの撃破も期待できる。

- 特徴「レッド」を持つため、アカレッドから効果を発動できるが、２枚のコマンドが必要になるため、相性はあまり良くない。

- XG3弾で獣装光ギンガレッドが参戦。ゾードアップ元として価値が高まった。
