                虎折神（トラオリガミ）

種類：Mユニット

カテゴリ：ミスティックアームズ

BP：4000

SP：－

必要パワー：4+

追加条件：特徴「侍」を持つ自軍ユニットがある

CN：なし

特徴：獣／折神獣

テキスト：

※これをラッシュしたとき、MAを持たないコマンドをすべてリリースする。

【侍武装】自軍ラッシュフェイズ中、DAを持たない自軍Lユニットを1体選び、このユニットに重ねてもよい。これは、ユニットが重ねられている間カードとして扱い、重ねたユニットがユニットでなくなるとき捨札になる。このカードに重ねたユニットは、次の能力を得る⇒このユニットの合体に必要なユニットの最大数を数えて、1体につきBP+1000される。

フレーバーテキスト

虎は走り噛み付き爪を立てる。だが立てた爪が回転するのは折神なればこそ。

イラストレーター：宮崎良平

レアリティ：ノーマル

作品：侍戦隊シンケンジャー

収録：クロスギャザー ザ・ファーストエンカウント　自販：パック

カード評価

- 侍が場にいることでラッシュが行えるＭユニット。テキストが作られたのがシンケンレッドが使用者になる前なので追加条件が兜折神・舵木折神とは違い色の特徴ではなく侍を参照する様になっている。

- 【侍武装】はBP8000以下の合体ユニットをBP8000以下を対象にした除去から守るのに適している。しかし、2~3体での合体ならツバサマルとBP上昇値がそれほど変わらない。

- 侍デッキのアタッカーとしては同じ追加条件とBPを持ち、必要パワーが2低い烏賊折神の方が優秀。

- ダイテンクウへの合体を狙わなくてもデッキに入れることは可能だが似通った性能を持ち、なおかつこれより使い勝手の良いカードがいるのでダイテンクウへの合体パーツとしての運用が無難だろう。
