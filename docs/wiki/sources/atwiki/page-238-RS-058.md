カード評価

- 初期のカードだけあって効果はシンプルである。エリアを問わない除去が豊富な現在では、地味な能力になってしまったか。

- ラッシュエリアにアタックできる能力は強力。恐竜やのカレーを合わせればBP5000になるのでバカにできない。

- 能力上、アタックとストライクの2択となるので、使い所が難しい。一応、ラッシュエリアに引き篭もるDA特有のデメリット持ちユニットへ自爆をすることで、三番目を空けさせる使い方もできる。

- 似たような効果を持つユニットとは何かと比較されがちである。しかし完全な上位互換が存在しない為、目的に合わせて使い分けることができる。
- 具体的な違いは、特徴にイエローと魔法があることと、ゾードアップユニットや合体ユニットの素体となることである。

- 相手を指定してアタックができる為、状況が整わなければ狙った相手にアタックが出来ない、といった確実性の欠けることはない。

- 他と比べると必要パワーが高い。ラッシュのし易さでは劣るが、パワー3以下を対象にした効果も多いため、これについては一長一短である。
