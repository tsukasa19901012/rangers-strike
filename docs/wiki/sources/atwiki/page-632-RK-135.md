                仮面ライダードレイクMF（マスクドフォーム）

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：1000

SP：－

必要パワー：1

追加条件：なし

CN：RC

特徴：仮面ライダー／男

テキスト：

※これはアタックされるときBP+4000される。

【潜行捜索】数字を1つ宣言してもよい。そうしたとき、自軍山札の下から1枚ひいてオモテにする。オモテにしたカードの必要パワーの数字が、宣言した数字と同じなら、自分の手札に加え、それ以外なら山札の下に戻す。

カード評価

- カブト勢のMFの中では仮面ライダーガタックMFに次いで使えるユニット。

- 能力はトライチェイサーからのコンビネーションで確実にドローが可能になる。相手よりドロー回数が多いのはそれだけ有利なことなので山札の残り枚数にさえ気を付けておけば強力。

- トライチェイサー以外にもビートチェイサー、パワードイクサー、親子の絆等で確実なドローが可能。

- 山札の下からドローする能力はレッドドラスやニンジャブラックの能力対策にもなる。飛ばされたユニットの必要パワーを覚えておきたい。

- 相手がラッシュしたときはアタックでは撃破しづらいので、ゲキバイオレット等で必要パワーの低さを突く、デスガロン、デカレッド等で本来のBPの低さを突くなどして対応したい。

- 単色であれば仮面ライダーNEW電王SFや仮面ライダーディケイドで表にしたカードを回収するギミックもよく使われる。特にNEW電王とはクライマックス刑事やシュリケンジャーFMもあわせて使うことでデッキトップに積み込んだ高パワーカードを何度も使い回すことで合体ロボすら毎ターン除去できる強力なコンボになる。
