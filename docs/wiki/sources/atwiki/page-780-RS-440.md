                バトルフィーバーロボ(2nd)

種類：Lユニット

カテゴリ：アーステクノロジー　

BP：6000

SP：1

必要パワー：6+

追加条件：自軍Sユニットを5体捨札にする

CN：なし

特徴：メカ／人型／2nd

テキスト：

※このカードの追加条件は、自軍捨札が7枚以上のとき、次のように変更される⇒特徴「母艦」を持つ自軍ユニットを1体捨札にする。

※これはナンバーに「L」または「R」を持つ自軍ユニット1体につきBP+1000される。

【武器換装】これが自軍バトルエリアにある間、自軍バトルフェイズ中、自軍コマンドを3つホールドしてもよい。そうしたとき、これをラッシュエリアに戻す。

フレーバーテキスト

母艦から降り立ったそれが剣を構えると、混沌とした戦場に一陣の風が吹き抜けた。

イラストレーター：森下直親

レアリティ：スーパーレア

作品：バトルフィーバーJ

収録：七忍の炎陣　自販：パック

カード評価

- 初代バトルフィーバーロボに比べて本来のBPが1000低くなったが、その分必要パワーと追加条件が満たしやすくなっている。また、ナンバーにLまたはRを持つ自軍ユニットが3体以上いれば疾風流超忍法や圧縮冷凍などによって除去されなくなるので、初代よりも安心して使用できる。

- 特に捨札が7枚以上になった後は母艦ユニット1体でラッシュ出来るようになるのでSユニットを残して戦力を維持したまま場に出せるのが大きい。捨札7枚という条件はJPカードやボウケンブラックを利用することで満たしやすくなる。

- 母艦はバトルシャークが最適。バトルフィーバーロボを強化するナンバーにLまたはRを持つ自軍ユニットもロボ自体もサーチで手札に引っ張ってこられる。

- それ以外にも元々の追加条件でもSユニット3枚でラッシュできるようにするキングピラミッダーPFも有効。

- 【武器換装】によってコマンド3枚でラッシュエリアに戻して再びバトルエリアに出られるので、勇気の魔法やダッシュレオンなど、コマンドをリリースするカードと組み合わせれば1ターン中に数回バトルエリアに出る事も可能。シュリケンジャー（XG4）と勇気の魔法のように複数のリリース手段を併用するのも有効。
