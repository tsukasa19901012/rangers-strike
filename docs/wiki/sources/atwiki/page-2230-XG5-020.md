                ボウケンレッド（XG5）

種類：Sユニット

カテゴリ：アーステクノロジー

BP：4000

SP：－

必要パワー：3

追加条件：なし

CN：1

特徴：レッド／男

テキスト：

※タクスET

【レッドゾーンクラッシュ】自軍コマンドを1つ選び手札に戻してもよい。そうしたとき、このターン、これはBP+2000され、戻したカードが特徴「メカ」を持つMユニットだったなら、さらにBP+2000される。

フレーバーテキスト

待たせたなお前達、冒険の始まりだ！

イラストレーター：Masakazu Fukuda

レアリティ：レア

作品：轟轟戦隊ボウケンジャー

収録：XG5 ザ・チケットブレイカー　スターター専用（ゾードアップロボデッキ）

カード評価

- オメデトロフィーと組み合わせれば、CN1でほぼ1ドロー的な効果を発揮できる。おまけにBPも上がりアタッカーとして申し分ない性能を発揮する。

- 特徴「メカ」持ちのMユニットならばさらにBPが上昇し、大物にも手が届く。除去にさえ気をつければ、合体デッキでのパーツ集めと場の維持が同時にこなせる。Mユニットをサーチするゴーライナーとは相性が良い。

- タクスで他ユニットにSPを付けることもでき、あらゆる状況に対応できるユニットといえる。
