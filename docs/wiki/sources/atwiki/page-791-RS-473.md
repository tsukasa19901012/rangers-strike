                タイムシャドウ

種類：Lユニット

カテゴリ：オーバーテクノロジー

BP：9000

SP：－

必要パワー：6+

追加条件：自軍「タイムシャドウSM」1体を捨札にする

CN：なし

特徴：メカ／人型／忍者

テキスト：

【ブルームーンスラッシュ】これが自軍バトルエリアにある間、敵軍ターン中、相手がパワーゾーンにカードを置かずにチャージフェイズを終えたとき、敵軍パワーゾーンのオモテ向きのカードから、必要パワーの数字が2以下のカードを1枚選び、ダメージにしてもよい。

フレーバーテキスト

過去、未来、現在…全ての時間に忍は存在する。

イラストレーター：As&#039;まりあ

レアリティ：スーパーレア

作品：未来戦隊タイムレンジャー

収録：七忍の炎陣　自販：パック

カード評価

- LサイズにしてOTでは数少ない忍者ユニット。
- 全カテゴリの忍者を要求する世界忍者戦を使う場合には、OTの枠は長らくこのカードしか選択肢がなかった。後により簡単にラッシュできる宇宙忍デモストが登場しており、この役割にはあちらの方が適している。

- BPは出しやすさから考えれば高い方。特に元となるタイムシャドウSMはパワーゾーンからのラッシュが出来るのでゾードアップもやり易い。

- 【ブルームーンスラッシュ】は相手のチャージ行動にプレッシャーを与えるちょっと変わった能力。相手のコマンドがすでに十分な数がある時はあまり意味が無くなってしまうので、ETのユニットと組んでコマンドを削ってパワーゾーンにチャージしづらい状況を作るなど工夫が必要になる。

- パワー2以下のカードがパワーゾーンに無いと効果が発動しないので、相手のカードをパワーに送る手段も用意しておきたい。便利なのはタイムシャドウSMとのシナジーがある電王AF（2nd）かダメージか除去の２択になるコーカサスあたりか。

- ゼロライナードリルで相手のパワーを操作すると、より強力。
