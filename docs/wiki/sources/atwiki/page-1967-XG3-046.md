※チェイス

※敵軍ターン中、これが撃破されて捨札になったとき、これを自軍パワーゾーンにダメージにして置いてもよい。そうしたとき、自分の手札から「仮面ライダーBLACK RX」のカードを1枚選び、自軍ラッシュエリアに出す。

【キングストーンフラッシュ】自分は1枚ドローしてから、自分の手札を1枚選び捨札にする。そうしたとき、捨札にしたカードの必要パワーの数字以下の必要パワーを持つ敵軍Sユニットを1体選び、持ち主の山札の下に戻す。

カード評価

- RCは手札の入れ替えと敵軍ユニットの除去を同時に行える。デッキ圧縮手段としても使い勝手は良い。除去効果も山札の下に送るので、回収手段がクルーザーや仮面ライダードレイクMF等、種類が少ないのも強み。

- 撃破されて捨て札になる際、ダメージを受ける代わりに仮面ライダーBLACK RXを手札からラッシュできる。

- 仮面ライダーBLACK RXがラッシュできなくてもダメージに送ることができる。ダメージ調整やパワー加速、デカブライトの効果の発動にも便利。

- メタルヒーロー・カテゴリOT以外で初のチェイスを標準で持つユニット。

- XG3弾で多数収録された「２体で一組のキャラ」の一つで、シャドームーン（XG3）と組絵になっている。
