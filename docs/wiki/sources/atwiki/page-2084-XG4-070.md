                クレイドール・ドーパント

種類：Sユニット

カテゴリ：ダークアライアンス

BP：3000

SP：－

必要パワー：1

追加条件：なし

CN：なし

特徴：怪人／女／ドーパント

テキスト：

【不死身のドーパント】敵軍ターン中、これが撃破されて捨札になるとき、捨札にするかわりに持ち主の山札に戻してシャッフルする。

フレーバーテキスト

またストーカー？どうして私を怒らせるのっ！

イラストレーター：yori

レアリティ：ノーマル

作品：仮面ライダーW

収録：XG4 ザ・ジェットアクセル　自販：パック

カード評価

- 標準的なＢＰと優秀なサポートがある特徴「怪人」と「女」を持つものの、【不死身のドーパント】の効果が使いづらい癖のあるカード。

- 【不死身のドーパント】は発動条件が受身なのに加え、山札に戻る効果は捨札が増づ、デッキの枚数が増えるなどデメリットが目立つ。効果の発動が強制で、「捨札にするかわりに」なので巨大化爆弾の恩恵を受けることができないのもネック。

- 一応、コピーベントで敵軍ユニットにこの効果を与えて、回収しづらい山札に戻して再利用しづらくするといった使い方はある。
