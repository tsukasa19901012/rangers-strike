                アルビノジョーカー

種類：Sユニット

カテゴリ：ダークアライアンス

BP：6500

SP：1

必要パワー：4+

追加条件：自軍｢仮面ライダーグレイブ｣1体を捨札にする

CN：なし

特徴：アンデッド

テキスト：

※これは自軍ラッシュエリアの特徴「アンデッド」を持つユニットを1体捨札にしなければバトルエリアに出られない。

【アンデッドを従える者】これが自軍エリアにある間、自軍ラッシュフェイズ中、自軍｢アルビローチ｣をラッシュしたとき次の効果を発動できる⇒自軍「アルビローチ」の数を数えて、その数と同じ必要パワーの数字を持つ敵軍ユニットを1体選び撃破する。

フレーバーテキスト

尋常でない強さ？当然だろう彼もまた“最強(ジョーカー)”なのだから。

イラストレーター：村山竜大

レアリティ：ノーマルレア

作品：仮面ライダー剣 MISSING ACE

収録:ザ・マスクドライダーEXP vol.3　自販：パック

カード評価

- 仮面ライダーグレイブからのパワーアップ。BPが大きく上昇してSP1になった。

- 能力はアルビローチをラッシュするたびに発動するので連続でラッシュしていけば一気に敵ユニットの数を減らせる可能性もある。アルビローチを大量展開する手段や、ミラーワールドなどによる枚数調整手段を用意しておきたい。

- 大量にラッシュしたアルビローチはバトルエリアに出るための捨札にしつつ、ピーコックアンデッドと組んでストライカーにするという方法もある。

- アンデッド系全般に言えることだが、BPの下三桁が500ばかりなのでこれを対象とした能力には十分気をつけたい。
