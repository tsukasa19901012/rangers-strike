                キハダガニ

種類：Sユニット

カテゴリ：ミスティックアームズ 

BP：1000

SP：－

必要パワー：1

追加条件：なし

CN：なし

特徴：ディスクアニマル

テキスト：

※このユニットは、リードMAを持つ自軍ユニットがあればBP+1000される。

【待ち伏せ】敵軍ターン中、これがSユニットとのバトルで撃破されて捨札になったとき、これとバトルしたユニットを、持ち主の山札の下に戻してもよい。

フレーバーテキスト

とってもキレイなカニがいたんだよ！黄色くてキラキラして…

イラストレーター：松野 トンジ

レアリティ：ノーマル

作品：仮面ライダー響鬼

収録：XG5 ザ・チケットブレイカー　自販：パック

カード評価

- 1対1交換を強制する、アタックを躊躇させる効果を持つ。そのためナンバー稼ぎには比較的優秀。また、BP上昇効果を持つためアタッカーとして使える可能性もある。

- 特徴「ディスクアニマル」を持つが、オペレーションではないため仮面ライダー天鬼の対象にはできない。仮面ライダー斬鬼（XG3）や変身音叉 音角の効果には問題なく使える。

- フレーバーは仮面ライダー龍騎の作中で金色のザリガニに夢中になった城戸真司＝仮面ライダー龍騎の発言か。
