                バイクロッサー・ギン

種類：Sユニット

BP：2000

SP：－

必要パワー：0

追加条件：なし

CN：RC

特徴：メカ／男

テキスト：

【ブレーザーカノン】これがライドしていれば、相手に1点ダメージを与える。

フレーバーテキスト

よし、見せてやろう僕達兄弟の力を！

イラストレーター：岩本佳浩

レアリティ：ノーマルレア

作品：兄弟拳バイクロッサー

収録：XG4 ザ・ジェットアクセル　自販：パック

カード評価

- 【ブレーザーカノン】は発動時にライドしていれば相手にダメージを与えられる効果。しかしＲＣ効果のためライドオフしなければ発動ができず、かといってライドオフして発動すればライドはしていないのでダメージは与えられない…と、悩ましい矛盾を抱えている。

- ライドオフせずに使わないと意味のないＲＣ効果を持つため、他のカードでのサポートが必須となる。
- カードデザインとしては、ギンクロンにライドさせてバイクロッサー・ケンからコンビネーションすることで全力が発揮できるようにして、原作の必殺技の再現を目指したものとなっている。

- 必要パワー0でBP2000と素のスペックは優秀。序盤のアタッカーとしても使える。
