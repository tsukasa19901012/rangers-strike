【人質と脅迫】これが自軍バトルエリアにある間、相手は次の制限を受ける⇒自分自身のバトルエリアにあるホールド状態のSユニットはラッシュエリアに戻せない。また、自分自身の手札を1枚選び捨札にしなければ、このユニットにアタックすることができない。

フレーバーテキスト

偉大なるサタンゴースは俺の父上だ！俺もサタンゴースとなる！

カード評価

- 何かしら相手のユニットをホールドする手段と組み合わせて使う能力。仮面ライダーワイルドカリスや蜂女などと一緒に出すといい。

- BPが非常に低いため、タイガーロイドやイカファイアで守るか、闇の戒律やスーパーレスキューなどで再利用することも考えよう。
