                仮面ライダーゼロノスZF（ゼロフォーム）

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：5000

SP：1

必要パワー：6+

追加条件：自軍「仮面ライダーゼロノスAF」1体をパワーゾーンに送る。

CN：なし

特徴：仮面ライダー／男

テキスト：

【デネビックバスター】これがストライクしたとき、次の効果を、自分が三回まで好きな回数行った後で、相手も同じ回数行う。

自分自身の山札の上から1枚をオモテにする。そして、オモテにしたカードの必要パワーの数値を見て、その数字と同じ必要パワーの数字を持つ自分自身のユニットがあれば、その中から1体選び撃破する。そうして撃破したなら、オモテにしたカードは捨札になり、撃破しなかったら手札に加える。

フレーバーテキスト

0（ZERO）にするのは、悲しい記憶。育んだ熱き友情が手に宿る時、その体は深紅に燃え上がった。

レアリティ：スーパーレア

作品：仮面ライダー電王

Q&A

		Q1
		「RK-141 仮面ライダーゼロノスZF」がストライクして【デネビックバスター】を発動させました。この効果で、山札の上のカードをオモテにする操作を繰り返す途中 で、オモテにしたカードの必要パワーの数字が6だったので、必要パワーの数字が6の「RK-141 仮面ライダーゼロノスZF」が撃破されて捨札になってしまいました。この場合、この効果の処理はその時点で終了ということになりますか？
		A1
		いいえ。「RK-141 仮面ライダーゼロノスZF」が捨札になっても、効果の処理は継続されます。基本的に一度条件を満たして発動した効果は、発動した元のユニットが捨札になっても、その効果を実行できる限り継続すると考えてください。

カード評価

- 仮面ライダーゼロノスAFの強化ユニットの一つ。追加条件の厳しさの違いか、デネブとの合体形態である仮面ライダーゼロノスVFと比較すると、純粋な戦闘力では若干劣る。ただし、ＳＰは同等となっている。

- ストライクしたときに強制発動する【デネビックバスター】は、サイズに関係なく最大で6体のユニットを撃破する可能性を秘めている。引いたカードによってはこのユニット自体を撃破してしまう可能性もあるが、デッキ構築の際にこのユニット以外をすべて必要パワー6以外のユニットで構成し、このユニットも1～2枚に留めておけばリスクを抑えることが出来る。

- また、【デネビックバスター】はその効果の特性上、自軍ユニットがこのユニットのみという危機的状況においてこそ利用価値があるといえる。カードを引いたとき、撃破できるユニットがいなければ手札に加えることになるので、ドロー加速ともいえる。

- 必要パワーの高さも含め、バトル終盤の秘密兵器としてデッキに忍ばせておくのが有効と思われる。
