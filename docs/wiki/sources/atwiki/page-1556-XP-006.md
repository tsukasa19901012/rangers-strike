                侍合体（プロモーション）

種類：オペレーション

カテゴリ：ミスティックアームズ

必要パワー：7

追加条件：なし

テキスト：

自分の手札から、合体が必要なLユニットのカードを1枚選び相手に見せる。見せたカードに表記された合体ユニットが、自軍エリアに3体以上（同名ユニットは1体と数える）あれば、自軍ユニットをすべて捨札にする。 このとき、見せたカードに表記された合体ユニット以外の自軍ユニットを2体捨札にするたび、相手は1枚ドローしてもよい。そして、捨札にしたユニットの本来のBPの合計が見せたカードのBP以上あれば、見せたカードを自軍ラッシュエリアに出す。

フレーバーテキスト

火、水、天、木、土、すべてが一つに。これぞ天下統一、侍合体。

イラストレーター：黒田 清桐

レアリティ：プロモーションカード

作品：侍戦隊シンケンジャー

収録：2009年6月～8月 ストライク！で必ずゲット！！

　　 　スペシャルプロモーションカードプレゼントキャンペーン　侍合体！コース

Q&A

		Q1
		自軍エリアに「XG3-006 ビクトリーウォーカー」１体とＢＰ４０００以上のユニットが１体あるとき、「XP-006 侍合体」を発動して「RS-382 ビクトリーロボ」をラッシュする事はできますか？
		A1
		はい、できます。

カード評価

- ＥＴのスーパーフォーメーション、ＯＴにおけるデンジ犬アイシーに続く、ＭＡの強力な合体補助カード。前二者とは違い4体以上の合体ユニットを必要とする合体Lユニットならばカテゴリや特徴に関係なく使用できるため、対応するユニットは多い。

- テキストには3体と書かれているが、3体合体ならばこのカードを使う必要は基本的に無いので、4体合体以上での使用となる。例外は部品と合体先のカテゴリが違うガオハンターイビルぐらいか。

- パーツが足りなくても合体できるという効果を持つ。Mユニット5体合体程度のLユニットならば、3体も素材がいれば後数体分のSユニットのBPで事足りる場合も多く、パワーは貯まっても素材が揃わない状況を解消できる。ＭＡを使う合体デッキならば入れておいて損はないだろう。

- しかしエンジンオーG9や天雷旋風神のようなBPも高い超重量級のLユニットをこれ頼みで出したい場合、流石にパワーとBPの確保がネックになってくる。いかに早くこれらの条件を揃えるかがデッキ構築の鍵となるだろう。ユニットのラッシュが出来るジャン・ボエール、仮面ライダーディケイドや天空大聖者マジエルのような出しやすい高BPのユニットなどで少しでも早く稼ぎたい。

- カテゴリに合わせてジャガーバルカンやキングピラミッダーPFなどの母艦でSユニットを温存しつつ素材をラッシュしていけば、母艦自体も含め多くのBPを確保でき無駄がない。

- 大神龍が出せればどんな合体ユニットも確実にラッシュできる。XLユニットなので安定したサーチ手段が存在せず、レアリティも大問題だが…。

- 使用後は手札枚数とエリアに大きなディスアドバンテージが生じてしまう。ラッシュした強力な合体ユニットで早めに決着をつけたい。
