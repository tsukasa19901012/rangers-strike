                カブトゼクター

種類：オペレーション

カテゴリ：オーバーテクノロジー

必要パワー：5

追加条件：なし

テキスト：

次の効果から1つ選び発動する。

◎自軍山札から「仮面ライダーカブトMF」のカードを1枚選び、自軍ラッシュエリアに出してもよい。その後、山札をシャッフルする。

◎このターン、特徴「加速」を持つBP2000以下のSユニットのカードは、追加条件を満たさなくてもラッシュできる。

フレーバーテキスト

全てはこの瞬間のために…。時空を寸断して飛来した力を掴んだ時、天の道は開かれた。

イラストレーター：Hiroshi Ayaragi  

レアリティ：プロモーションカード

作品：仮面ライダーカブト

収録：ザ・マスクドライダーエクスパンション ベルトコレクションボックス 

カード評価

- 仮面ライダーカブトMFのサーチ、またはカブト系RFユニットのラッシュを容易にするオペレーション。ラッシュ時に除去能力を発動する仮面ライダーガタックRFや仮面ライダーザビーRF、仮面ライダードレイクRFラッシュの為に利用すると有効。
