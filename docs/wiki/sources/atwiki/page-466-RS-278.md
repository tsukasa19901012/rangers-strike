                ブラックバイソン

種類：Sユニット

カテゴリ：アーステクノロジー

BP：2000

SP：！

必要パワー：2

追加条件：なし

CN：5

特徴：ブラック／男

テキスト：

【バイソンロッド】「SP1」必要パワーの数字に「－」のあるユニットを1体選び撃破する。（この効果は「グリーンサイ」からコンビネーションするときはナンバーに関係なく発動する）

Q&A

		Q1
		「RS-278 ブラックバイソン」は、「RS-279 グリーンサイ」からコンビネーションしたとき、並び位置にかかわらずストライクできますか？
		A1
		はい、ストライクすることができます。黒の下地に白抜きで書かれた効果名以降のテキストが、そのユニットの効果（ナンバーに数字を持つ場合はナンバーコンビネーションの効果）になります。

カード評価

- 基本的に5番ストライカーであるが、グリーンサイからのコンビネーションによりナンバーに関係のないストライカーへと変貌する。

- 【バイソンロッド】はギガンデスを含む強化ユニットを撃破するものであるがこれの前にグリーンサイの【サイカッター】を発動させておけば、強化ユニットが撃破された時にラッシュされる素体のユニットは大抵がBP4000以下なのでその場で撃破できる。

- 【バイソンロッド】は「撃破する」とあるので任意ではなく強制発動となるため、敵軍に「－」持ちユニットがおらず、自軍に「－」持ちのユニットがいる場合に発動させると自爆になってしまう。デッキタイプに合わせて投入を考えよう。
