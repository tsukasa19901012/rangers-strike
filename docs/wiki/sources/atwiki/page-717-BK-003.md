                ライドル

種類：オペレーション

カテゴリ：アーステクノロジー

必要パワー：3

追加条件：なし

テキスト：

次の効果から1つ選び発動する⇒

◎自軍山札から「仮面ライダーX」のカードを1枚選び、相手に見せてから手札に加えてもよい。その後、山札をシャッフルする。

◎自軍捨札からSユニットのカードを1枚選び、自軍山札の下に戻す。

フレーバーテキスト

穏やかな海が、大波の牙を剥くが如し。怒りのライドル引き抜く時に、銀の嵐が悪を撃つ。

イラストレーター：小松原 英 

レアリティ：ノーマル

作品：仮面ライダーX

収録：ザ・マスクドライダーエクスパンション　ベルトコレクションBOX 

カード評価

- 仮面ライダーX専用のサーチカード。もう一方の効果は手札ではなく、山札下へと戻す一風変わった捨札回収カードになっている。１ターン遅れるものの手札枚数を参照する効果や山札上関連のカードへの牽制として利用できなくもないが、仮面ライダードレイクMFなど、回収手段は用意しておきたい。

関連カード

- 仮面ライダーX

- 仮面ライダーX（XG4）
