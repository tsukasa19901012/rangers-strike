                Vマシーン（Vジェット）

種類：Sビークル

カテゴリ：アーステクノロジー

必要パワー：2

追加条件：なし

特徴：メカ／車両

テキスト：

【Vジェット】このビークルにライドしているユニットがモーフで置き換えられたとき、このビークルにライドしているユニットをラッシュエリアに戻してもよい。（ライドオフしない限り、ユニットとビークルは重ねたまま扱う）

フレーバーテキスト

主の悲しみと怒りを代弁するかのように、ジェット噴射の加速は激しさを増してゆく。

イラストレーター：JUN YAMAGUCHI

レアリティ：ノーマル

作品：仮面ライダースーパー1

収録：クロスギャザー　ザ・ファーストエンカウント　自販：パック

カード評価

- モーフを発動したＳユニットをラッシュエリアに戻すことでライドしているユニットを守ることができる。ただし、ライドしたままだとＲＣが使えないのでサイドバッシャーVMやミッションメモリーで補助する必要がある。

- ゴーグルレッドや仮面ライダー電王RFで自分ターン中にモーフを発動しても効果が発動する。

関連カード

- 能力に「モーフ」を持つユニット

- 特徴「メカ」関連

- 特徴「車両」関連
