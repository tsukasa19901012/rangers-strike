                ウルフアンデッド

種類：Sユニット

カテゴリ：ダークアライアンス

BP：2500

SP：－

必要パワー：2

追加条件：なし

CN：RC

特徴：アンデッド／獣

テキスト：

※これはライド中、BP+1000される。

【ワーウルフ化】ホールド状態のSユニットを2体選んでもよい。そうしたとき、選んだ2体でバトルさせる。ただし、特徴「男」を持つユニットを必ず1体選ぶこと。 

フレーバーテキスト

その爪に魂を引き裂かれた者は、人間としての死すらも奪われてしまう。

イラストレーター：小城 崇志

レアリティ：ノーマル

作品：仮面ライダー剣

収録:クロスギャザー ザ・ファーストエンカウント　自販：パック

カード評価

- ホールド状態のユニット同士でバトルを発生させるＲＣを持つ。組み合わせはエリア、自軍か敵軍かを問わないので使い道が広い。

- 相手のＢＰが高いユニット同士で自滅を狙うのはもちろん、ジャイアントローラーを使ったユニットを対象にしてダメージを狙うこともできる。

- 効果発動のためのホールド手段は蜂女やブラックファングが最適。
関連カード

- 特徴「アンデッド」関連

- 特徴「獣」関連

- 特徴に「男」を持つユニット
