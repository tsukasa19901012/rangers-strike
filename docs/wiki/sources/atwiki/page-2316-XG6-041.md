Q&A

		Q1
		「XG6-041 仮面ライダーエターナル」の【死神のパーティータイムだ】の効果で、「RS-394 タイムロボα」、「RS-395 タイムロボβ」、「RS-396 タイムジェットγ」はBP−1000されますか？
		A1
		いいえ、そのようにはなりません。【死神のパーティータイムだ】はA〜Z（またはa〜z）の26文字を対象とします。

カード評価

- 【死神のパーティータイムだ】は原作の旧世代ガイアメモリを無効化する能力の再現か、アルファベットが名前に含まれるユニットを弱体化させるという変わった妨害効果。
- フォームチェンジや強化フォームを持つ多くの平成ライダーは、フォーム名の省略で名前にアルファベットを含み、対象は非常に多い。特に大元の名前にもアルファベットを含む仮面ライダーWや仮面ライダーBLACK系のユニットはストライクまでも封じられてしまう。

- 対象となるのはAからZ(またはaからz)の26文字なので、タイムロボαやタイムジェットγなどは効果の対象外となる。

- 新能力「ブレイカー」により能力での除去がされず、アタックしようにも5000と高いBPに加え、相手のBPを下げてしまうためとても除去されにくい。複数出せないデメリットはあるものの、圧縮冷凍やバイモーションバスター等のオペでしか除去できないのはとても強力。
