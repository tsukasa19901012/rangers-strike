                仮面ライダーカブトHF（ハイパーフォーム）（XG5）

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：3000

SP：！

必要パワー：7

追加条件：なし

CN：なし

特徴：仮面ライダー／男／加速

テキスト：

※これは相手に選ばれない。

※これは、カード名に「カブト」「ザビー」「ドレイク」「サソード」を含むオモテ向きの自軍パワーがそれぞれあれば、SP1になる。

【天の道】これをラッシュしたとき、自軍パワーゾーンのオモテ向きのカードから、OTを持つ常駐オペレーションのカードを1枚選び自軍常駐置き場に配置してもよい。

フレーバーテキスト

姿は見えないが誰もが自覚した。絶対的な強者の存在を。

イラストレーター：F.M.U

レアリティ：スーパーレア

作品：仮面ライダーカブト

収録：クロスギャザー　ザ・チケットブレイカー　自販：パック

カード評価

- アタックだろうと能力だろうと問答無用で「相手に選ばれない」というすさまじい除去耐性を持つ。BPは高くはないが、耐性が得られないガタックエクステンダーの乗り手としては最適だろう。

- ラッシュ時に常駐オペレーションを配置できるが、OT限定でこれ自体の必要パワーも高いためタッチで使ったり早出しには使えない。

- カブト・ザビー・ドレイク・サソードがパワーにあるとSPを得るという、原作のパーフェクトゼクターをイメージした能力を持つ。カード名にそれぞれの文字列を含んでいればライダーでないカードでもOK。

- 加速デッキの場合、各RFはゾードアップ時にMFをパワーに送るので、普通にラッシュしていけば自然に条件は満たされる。ただしザビー系は微妙に加速デッキと噛み合いにくい能力が多く、XG以降のMFのキャストオフ能力も今のところないため組み込みづらい。

- 対策としては、仮面ライダーW・FJ等で「相手に選ばれない」能力を消す、シャドームーンの効果でビークルごと撃破する（ライド時限定）、仮面ライダーキバ（XG2）やシンケンゴールドやタイムベント等自分で対象を選ばない除去を使うなどが挙げられる。
