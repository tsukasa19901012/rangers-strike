                ユナイトベント

種類：オペレーション

カテゴリ：ワイルドビースト

必要パワー：5

追加条件：なし

特徴：アドベントカード

テキスト：

ライドしていない特徴「獣」を持つ自軍ユニットを1体選びターゲットとする。そして、このカードを自軍ラッシュエリアに置き、ターゲットをこのカードに重ねる。さらにターゲット以外のライドしていない特徴「獣」を持つ自軍ユニットを好きな数選び、このカードより下にウラ向きにして重ねる。ターゲットは、ウラ向きに重ねたカード1枚につきBP+2000され、BP10000ごとにSP+1される。ターゲットがユニットでなくなるとき、ターゲットの下に重ねていたカードはすべて捨札になる。

フレーバーテキスト

獣を多く飼うならば多くの餌が要るだろう?特にコイツは大喰らいなんだ・・・。

カード評価

- 特徴「アドベントカード」を持つオペレーションだが、対象はミラーライダーではなく獣。BPの大幅な増強とSPの付加ができ、ギガバイタスCMやゴルトフェニックスのような高BPの代わりにアタックに制限があるユニットやガオイーグルやギガライノスのように低コストのストライカーとは特に相性がいい。

- サイズの指定が無いため、ガオキングなど元々BPが10000以上のユニットに使えばそれだけでもSP+1なのもうれしい。

- ガオパンダなどラッシュしたときの効果目当てのユニットをみすみす腐らせずに活用できる。

- ターゲットに裏向きで重ねられているカードならば何によって重ねられたかを問わないため、サラマンデスドラゴンや白熱する実況、同じユニットに重ねられた2枚目以降のこのカード等でBPとSPの底上げをはかることができる。

- 2枚目、3枚目を同じユニットに重ねることで、BPとSPを爆発的にあげることが出来る。1ショットキルも夢じゃない。

- ゲゲルやクロックアップ等、ターゲットに重ねられていない裏向きのカードは参照しない。

- 仮面ライダーサガ等の効果でユニットに重ねられたこのカードだけが除去された場合でも、裏向きに重ねられたカードはそのままで残る。またその状態でユニットが除去された場合、このカードはすでに捨札になっていて効果が発動しないため重ねたカードが自軍エリアに残ってしまうことになるが、裏向きのカードが場にある状況はルール上おかしいため裏向きのカードも捨札になるとのこと。
