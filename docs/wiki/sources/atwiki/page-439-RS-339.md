                闇のヤイバ

種類：Sユニット

カテゴリ：ダークアライアンス

BP：4000

SP：－

必要パワー：4

追加条件：なし

特徴：ダークシャドウ／男／忍者

テキスト：

※これは敵軍ターン中、「SP1」以上のユニットとバトルしたときバトルに勝っても撃破される。

【闇への誘い】これが自軍エリアにある間、特徴「男」を持つすべてのユニットは、カテゴリに「DA」が追加される。

カード評価

- SP1以上のユニットとバトルすると相討ちになるというダークアライアンスによく見るデメリットを持っているが、バトル要因としてよりも能力を当てにした使い方が基本なので特に気にはならない。

- 【闇への誘い】でDAになった特徴「男」を持つ敵軍ユニットは、リュウレンジャーや気伝武人龍星王に料理させよう。良くてバトルエリアに出られなくなり、最悪全て撃破という運命が待っている。ボウケンブラックATや仮面ライダーアギトGFなども有効。

- 味方の男ユニットに対してはヘルサターン総統でのパワーアップを混色で使える、炎の騎馬にライドできるようになる、相手の冥獣人ニンジャキリカゲの効果を防ぐといった恩恵が考えられる。

- 気伝武人龍星王があれば、バトルエリア限定だがモーフを封じることもできる。
