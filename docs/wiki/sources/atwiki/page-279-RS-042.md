                デカレンジャーロボ

種類：Lユニット

カテゴリ：オーバーテクノロジー

BP：19000

SP：2

必要パワー：8+

追加条件：自軍合体ユニットを捨札にする

CN：なし

特徴：メカ／人型

テキスト：

合体―パトストライカー＋パトジャイラー＋パトレーラー＋パトアーマー＋パトシグナー

【ジャスティスフラッシャー】自軍パワーゾーンからダメージ以外のカードを5枚選び捨札にしてもよい。そうしたとき、このターン、このユニットは次の能力を得る⇒「SP3」

フレーバーテキスト

勝利の凱歌か、懺悔の時か。正義の閃光輝く前に、明暗分ける5カウント。

イラストレーター：獅子猿

レアリティ：スーパーレア

作品：特捜戦隊デカレンジャー

収録：英雄の再誕　自販：パック：スターター

再録：リバイヴァ　自販：パック

カード評価

- 5体合体のＬユニット。それだけに効果もド派手で、パワー5枚を捨てて一気に3ダメージを与えることが出来る。一見合体しづらいように見えるが、プロバイダーベースやデカベースクローラーの存在でＬユニットの中では比較的合体しやすい方である。

- オーバーテクノロジーなので巨獣特捜で上手くいけば一発ラッシュも可能。

- 合体ユニット5体中、4体が特徴「車両」を持つユニットなので、イエローアーマーやキングライナーを用いた車両デッキに組み込みやすい。

- 以下は車両デッキに組み込んだ場合の定石的動作である。参考にして欲しい。
- プロバイダーベースで車両を山札トップに積む。→乗車拒否でパワーに送る。→キングライナーでパワーゾーンから直接ラッシュする。

- 超電子頭脳の効果で捨札にする際、車両を優先的に捨札にする。→イエローアーマーでリアニメイトする。

- パワーゾーンのカードを捨札にするタイミングが明記されていないが、爆竜ティラノサウルスのQ&Aにて「ストライクポイントを得る効果は、自軍バトルフェイズに発動できます。それ以外のタイミングでは発動できません。」という裁定がされており、該当カードの例としてデカレンジャーロボも名指しされている。デカレンジャーロボ自身のQ&Aページには記載がないので要注意。
- 同様にタイミングが曖昧なテキストを持つ爆竜ティラノサウルスやパトストライカーは、クロスギャザー期での再録時に「自軍バトルフェイズ中、これがバトルエリアに出たとき」と発動タイミングを明確化するエラッタが行われている。しかしこのカードはリヴァイヴァ以降の再録がないため、このような不備のある古いテキストのまま放置されている。
