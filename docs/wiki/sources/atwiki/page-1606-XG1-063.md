                シャドーチェイサー

種類：Sビークル

カテゴリ：ワイルドビースト

必要パワー：0

追加条件：なし

特徴：メカ／車両

テキスト：

【トルネードチェイサー】これにライドしたユニットがある間、自分の手札からカードが1枚捨札に置かれるたび、次の効果を発動できる⇒敵軍コマンドを1つ選びホールドする。

フレーバーテキスト

封じられし風の力をその身に宿し、主と共に闇を駆ける疾風となる。

イラストレーター：二条忠則（MIC）

レアリティ：ノーマル

作品：仮面ライダー剣

収録：クロスギャザー　ザ・ファーストエンカウント　自販：パック

カード評価

- 手札を捨札に送った際に相手コマンドをホールドすることによって、カウンターを封じたりプテラレンジャーのコマンド除去に繋いだりできる。ブルースペイダー同様に効果はライドされた状態でないと使えない点には注意。

- 手札から捨札に送る手段は各種アンデッドやソルジャンヌ、オペレーションカードなど。

- ゴルゴムの仕業や疾風流超忍法のような、敵軍ラッシュフェイズに発動するカウンターと組み合わせて敵軍ラッシュフェイズに敵軍コマンドをホールドすることができる。
