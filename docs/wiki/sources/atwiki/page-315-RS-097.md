                ハリケンレオン

種類：Mユニット

カテゴリ：ミスティックアームズ

BP:5000

SP:－

必要パワー：5+

追加条件：自軍Sユニットを1体捨札にする

CN：なし

特徴：メカ

テキスト：

【カラクリ忍法・連獅子】これが自軍バトルエリアにあるとき、「SP1」以上または「SP！」のある敵軍ユニットはコマンドを1つホールドしなければバトルエリアに出られない。

フレーバーテキスト

唸りを上げる旋風の鬣が、これ以上の進軍を許さなかった。

Q&A

		Q1
		敵軍バトルエリアに「RS-097 ハリケンレオン」があるとします。その状態で、自軍バトルフェイズにSPが分数表記の自軍ユニットをバトルエリアに出すとき、SP1以上または「！」のあ る敵軍ユニットをバトルエリアに出すときと同じように、自軍コマンドを1つホールドしなければなりませんか？
		A1
		いいえ、その必要はありません。分数表記のユニットはラッシュエリアにある間は「SP1」でも「SP！」でもありませんので、「RS-097 ハリケンレオン」の効果を受けることはありません。コマンドをホールドすることなくバトルエリアに出ることができます。
		Q2
		敵軍バトルエリアに「RS-097 ハリケンレオン」がある状態で、自軍Lユニットが「パワーバズーカ」で撃破されたとします。このとき、捨札からバトルエリアに出す合体ユニットが 「SP1」以上か「SP！」なら「ハリケンレオン」の効果でコマンドを1つホールドしなければなりませんが、ホールドするコマンドが1つも無いとき、その ユニットはどうなりますか？
		A2
		バ トルエリアに出すためにホールドするコマンドが無いため、そのユニットはバトルエリアに出すことができず、捨札のままになります。ただし、ホールドできる コマンドが1つでもあれば、それをホールドして捨札から合体ユニットのカードをバトルエリアに出さなければなりません。
		Q3
		敵軍バトルエリアに「RS-097 ハリケンレオン」がある状態で、自分が「RS-090 レッドレーサー」を ラッシュするとき、ホールドできる自軍コマンドがあれば、コマンドを1つホールドしてバトルエリアに出さなければなりませんか？
		A3
		はい、その通りです。また、ホールドできる自軍コマンドがなければ、「ホールドできるコマンドが無いのでバトルエリアに出られない」と判断しますので、「RS-090 レッドレーサー」はラッシュエリアに置かれます。
		Q4
		敵軍バトルエリアに「RS-097 ハリケンレオン」がある状態で、敵軍「RS-049 グリーンレーサー」がナンバーコンビネーション「ピットインダイブ」を発動させました。この効果によって「ハリケンレオン」の効果の対象となるユニットがバトルエリアに出される場合、ホールドできるコマンドの有無による処理はどのようになりますか？
		A4
		「RS-049 グリーンレーサー」のナンバーコンビネーション「ピットインダイブ」のテキストには「出す順番は自分が選ぶ」とありますので、この場合は、効果を発動した 敵軍プレイヤーが1体ずつ選択します。そしてユニットが選択されるたび、リリース状態の自軍コマンドがあれば1つホールドして、選択されたユニットをバト ルエリアに出します。それを繰り返して、リリース状態のコマンドが無くなったら、それ以上のユニットをバトルエリアに出すことはできなくなるので、「ピッ トインダイブ」の効果は終了します。
		Q5
		敵 軍バトルエリアに「RS-097 ハリケンレオン」があるとき、「RS-041 タイガーレンジャー」などの「これは毎ターン、可能ならバトルエリアに出る」とある自軍ユニットは、ホールドできる自軍コマンドがあれば、コマンドを1つ ホールドしてバトルエリアに出なければなりませんか？
		A5
		は い、その通りです。ホールドできるコマンドがあれば、「バトルエリアに出ることは可能」と考えますので、コマンドを1つホールドしてバトルエリアに出さな ければなりません。逆に、ホールドできるコマンドが無ければ、「バトルエリアに出られない」と考えますので、ラッシュエリアに留まります。
		Q6
		敵軍バトルエリアに「RS-097 ハリケンレオン」がある状態で、自分が「RS-014 ファイブテクター」の効果で「SP1」以上または「SP！」のあるユニットをバトルエリアに出すとき、コマンドを1つホールドしなければなりませんか？
		A6
		はい、その通りです。
		Q7
		「RS-097 ハリケンレオン」の効果は重複しますか？　たとえば、「RS-097 ハリケンレオン」がバトルエリアに2体あるとき、相手が「SP1」以上または「SP！」のユニットをバトルエリアに出すためにホールドしなければならない コマンドは2つになりますか？
		A7
		はい、重複しますので、その通りになります。
		Q8
		敵軍バトルエリアに「RS-097 ハリケンレオン」があるとき、「SP1」以上または「SP！」のある自軍ユニットをバトルエリアに出そうとしました。「RS-097 ハリケンレオン」の【カラクリ忍法・連獅子】には「コマンドを1つホールドしなければバトルエリアに出られない」と書かれており、「自軍コマンド」とは書 かれていないため、リリース状態の敵軍コマンドがあればそれをホールドすることもできますか？
		A8
		いいえ、自軍コマンドをホールドして下さい。

カード評価

- 相手の展開をかなり遅らせることのできる優秀なMユニット。2体いれば効果が重複する。

- マジグリーン等でコマンドを削りながら使うとより強力。

- 分数のストライカーには効果がないので注意が必要。
