                仮面ライダークウガ

種類：Sユニット

カテゴリ：ミスティックアームズ

BP：3000

SP：1/3

必要パワー：3

追加条件：なし

CN：RC

特徴：仮面ライダー／男／アマダム

テキスト：

※レジスト

【笑顔の為に】自軍ラッシュエリアから特徴「警察」を持つSユニットを1体選び、持ち主の手札に戻してもよい。そうしたとき、このターン、これとバトルしたユニットは、撃破されて捨札になったとき、持ち主のパワーゾーンにダメージにして置く。

フレーバーテキスト

たとえ世界は違っても、その笑顔の尊さは変わらない！

イラストレーター：鈴眼依縫

レアリティ：ノーマル

作品：仮面ライダーディケイド

収録：クロスギャザー ザ・ドラゴンタイガー　自販：パック：（ファイナルフォームライド） 

カード評価

- プロモーションクウガの正式収録版。

- ディケイドに登場した方のクウガ。MFやPFなどのフォームの略称がカード名に付いていない。 

- 仮面ライダークウガMFとは名称の異なる別カードなので、両方ともデッキに導入できる。 

- 特徴「アマダム」を持つので、超変身で本家の別フォームにチェンジしたり、各種ライジングフォームの追加条件を満たす事も当然可能。

- 【笑顔の為に】はターン中、効果が続く。つまりこのユニットで倒せなくても他のユニットで倒せればダメージに送る事ができる。また、撃破したユニットが捨札にならないと効果が発動しないので相手がレジストやチェイスを持っている場合は注意。

- 必要なカードが多いため、あまり実用的ではないが
1.トライゴウラムに仮面ライダーG3等RCを持ち、特徴に警察と仮面ライダーを持つユニットをライドさせてバトルエリアに出してライドさせたままにする。
2.トライゴウラムにライドしたユニットをがんがんじいでラッシュエリアに戻す。
3.このカードのRCを発動させてトライゴウラムにライドしたユニットを手札に戻す。
4.ライドされていないトライゴウラムに別のRCを持ちをライドさせてバトルエリアに出す。
これによって、１枚のトライゴウラムの効果を1ターンに2回発動することができる。
