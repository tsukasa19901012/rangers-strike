カード評価

- バトルエリアを一掃できる効果は強力だが、相手がWBを主体に使っている場合は攻め負けることも。また、6体合体の手間を考えると、大獣神や剛龍神の方が出しやすく、使いやすい。実用的とは言い難いか?

- 【エンパイアアタック】は自軍にも効果を及ぼす。くれぐれもWB以外のユニットを並べないように。
