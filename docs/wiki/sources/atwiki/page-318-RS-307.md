                ハリケンイエロー

種類：Sユニット

【超忍法・舞獅子】これはアタックするかわりに次の効果を発動できる。自軍山札を見て「ハリケンイエロー」のカードを1枚選んで自軍バトルエリアに出してもよい。その後、山札をシャッフルする。

Q&A

		Q1
		「RS-100 ハリケンイエロー」のナンバーコンビネーション「超忍法・舞獅子」は、山札には「RS-100 ハリケンイエロー」が1枚もないと判明している状態でも発動できますか？
		A1
		はい、できます。
		Q2
		「RS-100 ハリケンイエロー」のナンバーコンビネーション「超忍法・舞獅子」は「アタックするかわりに」とありますが、相手のバトルエリアにユニットがなく、アタックすることができない時でも発動できますか？
		A2
		ルール整理前：
い いえ、その場合は発動できません。 相手のバトルエリアにユニットが存在していて、「RS-100 ハリケンイエロー」がアタックすることができる権利を得ているときに、それを失う事で発動できるのが「超忍法・舞獅子」の効果になります。 よって、相手のバトルエリアにユニットが存在しない場合は、この効果を発動させることは出来ません。

ルール整理後（※公式コラムvol44より抜粋）：
これまでは、敵軍バトルエリアにユニットが１体もなければこの効果を発動できませんでしたが、今後は敵軍 バトルエリアにユニットがいない（アタックする対象がいない）状態でも、アタックする権利を失う代わりに効果を発動することができることになります。

※注釈：公式コラムvol44で「Ａを行ってもよいタイミングであれば、Ａを行うことができなくても、Ａを行う権利を失うかわりに、Ｂを行うことができる」とルール整理されたため、相手のバトルエリアにユニットが存在しない場合でも効果を発動できるようになった

カード評価

- 【超忍法・舞獅子】は山札に2枚以下しかいないBP1000の非ストライカーユニットをサーチ&ラッシュするという悲しい能力。デッキ圧縮になり、タイムジェット2で並んだハリケンイエローをパワー送りにしたりできるがそのためだけに使う価値はないだろう。

- 恐竜やのカレーを食ってもBP3000と、どうしようもない落第忍者である。
