                ダブルブラザーパワー

種類：オペレーション

カテゴリ：アーステクノロジー

必要パワー：6

追加条件：なし

テキスト：

特徴「人型」を持つ自軍ユニットを2体選び、選んだ2体の本来のBPを合計する。そして、合計したBP以下の敵軍ユニットを1体選び、持ち主のコマンドゾーンにホールド状態で置く。置けなければ捨札にする。

フレーバーテキスト

光と熱のエネルギーが兄弟の絆によって奇跡を起こす力となる。

イラストレーター：ＮＡＫＡＧＡＷＡ

レアリティ：レア

作品：キカイダー01

収録：XG5 ザ・チケットブレイカー　自販：パック

カード評価

- ET版ダブルスナイパーといった感じのカードだが、特徴「人型」を持つユニットにはBPの高い合体ロボもいるため、理論上除去できるユニットの上限が無い。
