カード評価

- 素の状態でこれとコンビネーションしてBPが20000以上になるETのLユニットはダイボウケンとスーパーダイボウケン。ライブロボも能力発動で20000を超える。

- BPの上昇は自軍ターン中のみなので防衛には向かない。

- ダメージを与える能力が目当てなら聖剣ズバーンの方が使いやすい。どうしてもMAを混ぜたくない時や、ダイタンケンへの合体が目的のデッキ編成でなければ出番はあまり無い。
