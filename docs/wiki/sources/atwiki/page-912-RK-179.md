                ジャングラー

種類：Sビークル

カテゴリ：ワイルドビースト

必要パワー：4

追加条件：なし

特徴：メカ／車両

テキスト：

【体当たり攻撃】自軍ターン中、これがバトルエリアに出たとき、ライド中の敵軍Sユニットを1体選んでもよい。そうしたとき、選んだユニットの持つカテゴリと、選んだユニットがライドしているビークルの持つカテゴリが違うなら、そのビークルを捨札にした後で、選んだユニットを撃破する。

フレーバーテキスト

その荒々しい外見と爆発力、野生の暴れ馬が束になっても敵わないだろう。

イラストレーター：Masakazu Fukuda

レアリティ：ノーマル

作品：仮面ライダーアマゾン

収録：ザ・マスクドライダーEXP vol.3　自販：パック

カード評価

- ビークルとそれにライドしているユニットを除去できる強力な能力が魅力。敵ユニットがライドしていなくてもモグラ獣人と組み合わせれば強制ライドから除去に繋げられる。

- ハリケンウィンガーにライドした冥獣人ニンジャキリカゲも簡単に除去することができる。

- トライゴウラムのようなマルチカテゴリのビークルにライドしているユニットは、カテゴリが一つでも合っていれば【体当たり攻撃】の対象にならない。
