テキスト：

【ポイズンアンカー】これが自軍エリアにある間、自分も相手も次のようにする⇒自分自身のターンを終えるとき、特徴「男」または「女」または「獣」または「恐竜」を持つホールド状態のユニットを1体選び撃破する。

フレーバーテキスト

貴様らに倒された仲間達の仇を。これは俺の戦士としての意地だ。

レアリティ：ノーマル

収録:クロスギャザー ザ・ファーストエンカウント　自販：パック

カード評価

- 相手と自軍のターン終了時に、該当する特徴を持つホールド状態のユニットをエリア・サイズを問わず撃破できる。お互いに相手のユニットを選べるのでホールド手段があれば自分が撃破したい相手ユニットを確実に撃破できる。

- WBにはホールド手段が多い一方、レジスト持ちも多く自軍にも被害が出やすいのが難点。
