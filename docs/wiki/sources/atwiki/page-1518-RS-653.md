※ウイング

【後輩戦士への叱咤】このユニットからコンビネーションする特徴「イエロー」を持つSユニットは、このターン、次の能力を得る⇒BP+3000、「SP1」 

フレーバーテキスト

まだ恐れが抜けていないようだな。見せてみろ！お前の本当の剣を！

イラストレーター：小城 崇志

レアリティ：スーパーレア

作品：百獣戦隊ガオレンジャー VS スーパー戦隊

収録：蒼九の翼　自販：パック

カード評価

- 【後輩戦士への叱咤】はイエロー持ちの補助効果だが、恐竜やのカレーやエレハン・キンポーの方が使い勝手が良い。必要パワーが重いのもネック。

- 五色の戦士を使えば効果対象が広くなり、色々なユニットを補助できるようになる。しかし、WBのストライカーのナンバーと被るのであまり旨味は無い。

- アカレッドの効果でこの効果を使えば２番目以外に並んだユニットも強化できる。

- タクスMAを持つイエローであるニンジャイエローかイエローターボをコンビネーションさせてタクスの発動を同時に狙うことも可能。

- フレーバーテキストはガオイエロー（2nd）に向けたもの。これは『百獣戦隊ガオレンジャー VS スーパー戦隊』での修行シーンを再現している。
