                宇宙刑事ギャバン（XG2）

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：4000

SP：1/4

必要パワー：4

追加条件：なし

CN：RC

特徴：宇宙刑事／メカ／男／警察 

テキスト：

※チェイス

※これが自軍エリアにある間、特徴「宇宙刑事」を持つ自軍ユニットは、アタックされるとき、BP+1000される 

【銀河パトロール隊隊長】自軍ラッシュエリアから、RCを持つユニットを1体選んでもよい。そうしたとき、このターン、選んだユニットは、バトルエリアに出たとき、ライドオフしなくてもその効果を発動できる。

フレーバーテキスト

それが何処であったとしても、正義の光は必ず届く。

イラストレーター：funbolt

レアリティ：スーパーレア

作品：宇宙刑事ギャバン

収録：クロスギャザー ザ・ドラゴンタイガー　自販：パック

カード評価

- 以前収録のものとはうって変わり、仲間のサポートに特化した能力を持つ。特徴「宇宙刑事」持ちのユニットは宇宙警察でチェイスと共に増やせるので、このユニットを中心にかなり打たれ強い警察デッキを組める。

- 複数体いれば、各種MF並みの上昇幅を得られさらに安心。ただしこのユニット自体はサイクロン号などの強力なSユニット除去に引っかかってしまうBPであるため、チェイスで防ぐためにもライドさせておこう。

- 【銀河パトロール隊隊長】はダイアナレディと違いBP上昇効果はないがどのカテゴリでもライドオフせずに能力を発動させられる、ミッションメモリーに似た能力。仲間のチェイスを殺さずにRCで攻められる。

- ただし発動には自身がライドオフする必要があり、チェイスを使えない状況でバトルエリアに晒す不安がある。効果で自分自身も守れるとはいえ、確実に繰り返し利用するならサイバリアンなどでフォローしたい。
