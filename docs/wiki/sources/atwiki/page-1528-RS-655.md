                デカウイングロボ

種類：Lユニット 

カテゴリ：オーバーテクノロジー 

BP：9000

SP：1

必要パワー：7+

追加条件：自軍「パトウイング」、または自軍「デカウイングキャノン」1体を捨札にする 

CN：なし

特徴：メカ／人型／航空機

テキスト：

※ウイング

【パトマグナム】自軍捨札に特徴「スワット」を持つユニットカードが5枚以上あれば、これは「SP2」になる。

フレーバーテキスト

二丁拳銃が縦横無尽に火を噴いて、格闘と射撃の連続は途切れる事無く続いていく。

イラストレーター：As&#039;まりあ

レアリティ：スーパーレア

作品：特捜戦隊デカレンジャー

収録：蒼九の翼 自販：パック

カード評価

- ウイング持ちの合体ロボ。スワットが捨札に５枚以上あればＳＰ２になる。

- 合体手順を省略するデンジ犬アイシーや追加のラッシュが狙えるバラクティカ、このカードをサーチしてラッシュできる異次元からの翼など補助カードに恵まれている。

- SP2になるためにはスワットが必要不可欠。デカレンジャーのスワットは追加条件持ちなのが難点。ETと混ぜるなら、ブルースワットの面々が入れやすいか。
