                デカイエローSWAT

種類：Sユニット 

カテゴリ：オーバーテクノロジー 

BP：3500

SP：！

必要パワー：7-

追加条件：自軍「デカイエロー」1体を捨札にすれば必要パワー0になる

CN：4

特徴：イエロー／女／警察／スワット

テキスト：

※これが撃破されて捨札になったとき、自軍捨札から「デカイエロー」のカードを1枚選び、自軍ラッシュエリアに出す。 

【感知システム】「SP1」自軍パワーゾーンのオモテ向きのカードの中から、Sユニットのカードを1枚選び手札に加えてもよい。そうしたとき、自軍山札の上から1枚引いて自軍パワーゾーンに置いてもよい。

フレーバーテキスト

爆発物を確認したわ！解除はまかせて！

イラストレーター：Mitsuhiro Arita

レアリティ：スーパーレア

作品：特捜戦隊デカレンジャー

収録：蒼九の翼　自販：パック

カード評価

- デカイエローのパワーアップバーション。能力も強化され、パワーを減らさずにSユニットを回収できるようになった。
