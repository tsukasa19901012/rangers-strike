                炎神剣

種類：オペレーション

カテゴリ：オーバーテクノロジー

必要パワー：3

追加条件：なし

特徴：武器

テキスト：

お互いに山札の上から１枚をオモテにし、必要パワーの数字を比べる勝負を２回繰り返す。数字の大きい方を勝ちとして、自分が２回連続で勝ったなら、敵軍ユニットを１体選び撃破する。２回連続で負けたなら、相手に自軍ユニットを１体選ばせて、選ばれたユニットを撃破する。その後、オモテにしたカードは、好きな順番で持ち主の山札の下に戻す。（これが自軍コマンドゾーンにある間、OTを持つ自軍Lユニットがバトルエリアに出たとき、これをホールドしてもよい。そうしたとき、このカードの効果を発動する）

フレーバーテキスト

誰かの為に戦うと言うこと、俺達の正義は心と共にある！

イラストレーター：矢薙 じょう

レアリティ：レア

作品：炎神戦隊ゴーオンジャー BUNBUN!BANBAN!劇場BANG!!

収録：XG6 ザ・ギガンティックタイタン　自販：パック

カード評価

- エンジンオーの効果に似たギャンブル性の高い効果を持つ。こちらはSP付加ではなく除去能力を発動できる。

- OTのLユニットがいればサイズやエリア、BPを一切問わない除去を毎ターン行えるのは強力だが、失敗のリスクも大きい。クライマックス刑事やボウケンシルバー（2nd）で山札を操作するのが確実だが、毎ターンより確実な除去を狙うならシグナルキャノンで事足りるかもしれない。

- 一方で強力なLユニットを出された場合などの保険としての使用も考えられる。

- 手札からの使用の場合、XGシリーズ版の仮面ライダーカブト勢各RF(仮面ライダーザビーRF（XG） をのぞく)との相性がよい。7-なので勝ちやすく、また場のRFは「相手に選ばれない」能力で負けても除去対象にならないため。
