カード評価

- 並ぶ場所に関係なくラッシュエリアにアタックできる数少ないユニット。Ｍユニットなので簡単には除去できないのも強み。

- 忘れがちだが、Sユニット以外のサイズのユニットなら、バトルエリアでもアタックできる。

- BPはラッシュエリアにアタックする能力を持つユニットの中でも高い部類。シンケンゴールドやマジマザーのようなラッシュエリアに引きこもるユニットやゴーオンゴールド（XG4）のようなウイングへの殴り返しなど、活躍の機会は多い。

- 獣騎神キングブラキオンでレジストを付与すると強烈。
