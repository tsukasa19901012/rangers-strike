【ネコ達いじめたのお前？】これが自軍パワーゾーンでオモテ向きになっている間、自軍バトルフェイズ中、特徴「仮面ライダー」を持つ自軍ユニットがバトルエリアに出たとき、これを捨札にしてもよい。そうしたとき、自軍捨札にある特徴「獣」を持つユニットカードの枚数以下の必要パワーの数字を持つ敵軍ユニットを1体撃破する。

カード評価

- 能力はパワーゾーンにあれば発動出来るため、赤単などにタッチで入れてもまったく問題はない。対象もサイズや追加条件は関係無いので枚数によってはLユニットでも撃破出来るのはなかなか大きい。

- 超電子頭脳で特徴「獣」をどんどん捨札にすれば、大型ユニットの除去も夢ではない。

- 特徴「獣」のカードが0枚でも、必要パワー0のユニットは撃破できる。
