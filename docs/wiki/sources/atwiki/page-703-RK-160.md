                シザーズジャガー

種類：Sユニット

カテゴリ：ダークアライアンス

BP：2000

SP：－

必要パワー：5

追加条件：なし

特徴：ショッカー／怪人／男／改造人間

テキスト：

【ナノロボット散布実験】これが自軍エリアにある間、追加条件を持たない敵軍Sユニットがラッシュされたとき、そのユニットの必要パワーの数字と同じ必要パワーの数字を持つDAのユニットカードを自分の手札から1枚選び、ラッシュエリアに出してもよい。ただし、DAの自軍コマンドを1つホールドすること。そうしたとき、ラッシュされた敵軍ユニットを撃破する。

フレーバーテキスト

これは偉大なるショッカーが人類に示す踏み絵。さて…果たして何人選ばれるかな？

カード評価

- BPは低いが【ナノロボット散布実験】が強い。パワーが同じならば追加条件を満たさずともDAのカテゴリを持つあらゆるユニットを一発でラッシュでき、さらにはラッシュされた敵ユニットを即座に撃破するという黒単ならば面白い使い方が出来る1枚。手札が豊富ならば相手の行動をほぼ封じ込められる。

- 特徴に「改造人間」と「怪人」の二つを持っているので強化しやすいが、前述のとおりBPが低いのでバトルエリアには無理をして出ないように。

- 単体では効果の発動が受動的になってしまうが、ゴ・ガドル・バなどで強制的にラッシュさせれば能動的に効果が使える。さらに、相手ユニットのパワーを操作する花忍者ランがいれば意図したユニットをラッシュしやすくなる。

- DAコマンドをホールドするのはユニットのラッシュのためではなくあくまでも効果によるもの。ユガンデなどのコールDAでの代用は出来ない。
