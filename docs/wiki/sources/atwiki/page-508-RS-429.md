                マスター・シャーフー

種類：Sユニット

カテゴリ：ワイルドビースト

BP：4000

SP：－

必要パワー：0

追加条件：なし

CN：なし

特徴：男／拳聖／激気

テキスト：

※これは自軍ターン中バトルエリアに出られない。 

【暮らしの中に修行あり】これは自軍ラッシュエリアにある間、次の効果を発動する⇒すべてのSユニットの特徴に「激気」を追加する。また、自軍ターン中、「MA」の自軍コマンドをホールドする代わりに「WB」の自軍コマンドをホールドしてもよい。ただし、追加で自軍コマンドを1つホールドすること。

フレーバーテキスト

犬はボスで、猫が師匠で…。人間が一番なんて思い上がりだって事に気付かされるよな。 

イラストレーター：スミヒト 

レアリティ：ノーマルレア

作品：獣拳戦隊ゲキレンジャー

収録：紅き六戦士の帰還 　自販：パック

カード評価

- Sユニットに特徴「激気」を追加する事で、ゲキレッドたちのみならずレッド、ブルー、イエローの特徴を本来持っているユニットはゲキビーストたちをラッシュする事が出来るようになる。

- また、オペレーションの激気と組み合わせる事でWBのMユニットのラッシュを容易にし、ひいてはLユニットのラッシュを手助けする。

- 敵軍ユニットにも強制的に特徴を追加するので、一応モーフ対策として使うことができる。どうしてもモーフをされたくなければ1、2枚積んでみるのも一興か。
- 仮面ライダーディケイドCFの早期ラッシュを潰せるという点では、メタカードとして一考の余地がある。ただしバトルエリアに出られない割にBPが高いためクウガゴウラムの除去に引っ掛かってしまうのが難点。

- 姫忍　恵美破やサイドマシーンの補助もこなせる。

- MAのコマンドを肩代わりする能力でギンガマン勢や仮面ライダースーパー1やプロジェクトG4の能力を使用する事も可能。
