                カバドスSM（スペシャルモード）

種類：Sユニット 

カテゴリ：アーステクノロジー

BP：4500

SP：－

必要パワー：7-

追加条件：自軍「カバドス」1体をコマンドゾーンに送るか捨札にすれば必要パワー0になる

CN：なし

特徴：メカ／人型／スペシャルモード

テキスト：

※これが撃破されて捨札になったとき、自軍コマンドゾーンか自軍捨札から「カバドス」のカードを1枚選び、自軍ラッシュエリアに出す。

【マサカリホーク】自軍ターン中、このユニットはBP+3000される。

フレーバーテキスト

たまにはワイも良いとこ見せるドスよ！

イラストレーター：saku

レアリティ：ノーマル

作品：テツワン探偵ロボタック

収録：XG5 ザ・チケットブレイカー　自販：パック

カード評価

- 自ターンのみBPが強化されるアタッカー。冥府神ドレイクやセイントカイザー（XG6）など、序盤から出てくる高BPユニットをアタックで撃破できる。

- ゾードアップ元であるカバドスともどもアタッカー特化になっている。そのため、デッキのストライカーを入れる枠が小さくなってしまうのが難点。

- 撃破された際にカバドスをコマンドゾーンからラッシュできるので、ゴーゴーファイヤーの効果を能動的に発動することができる。
