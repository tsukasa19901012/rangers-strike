カード評価

- 特撮史上最も有名な戦闘員がついにカード化。

- 他の戦闘員ユニットと違い、特徴「男」を持つのがポイント。インフェルシアの花嫁で戦闘員増殖の種となってくれる。

- ゾル大佐と組ませたくなるが、単純にBPや必要パワーのことを考えると、ヒドラー兵やバーロ兵のほうが使いやすいかもしれない。
