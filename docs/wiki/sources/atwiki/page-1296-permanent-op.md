- [オペレーション](https://w.atwiki.jp/renst/pages/581.html "オペレーション (2330d)") カードの種類の一つ。
- テキスト左側のスペースに時計を模したアイコンが表記される。
- 常駐オペレーションカードを使用した場合、 [常駐置き場](https://w.atwiki.jp/renst/pages/149.html "常駐置き場 (5941d)") にそのカードを配置して、書かれてある効果を常に有効にし続ける事になる。
- その効果は常駐オペレーションカードが置き場においてある限り永続する。
- すでに [常駐置き場](https://w.atwiki.jp/renst/pages/149.html "常駐置き場 (5941d)") にカードがある時に新しい常駐オペレーションカードを使用した場合、置き場のカードを [捨札](https://w.atwiki.jp/renst/pages/1287.html "捨札 (2330d)") にしてから配置する。
- ライダー3弾から新しく2枚配置できる [タッグ](https://w.atwiki.jp/renst/pages/1297.html "タッグ（用語） (6066d)") 常駐オペレーションが登場。通常の常駐オペレーションとも併用可能。
