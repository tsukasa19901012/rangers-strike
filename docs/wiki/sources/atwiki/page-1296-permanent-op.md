                常駐

効果：場に配置して、離れるまで効果が有効になる（原文より） 

Q&A

		Q1
		すでに配置されている常駐オペレーションと同名のカードを、コマンドをホールドしたり手札を減らしたりすることを目的として上書きして配置することはできますか？
		A1
		はい、できます。
		Q2
		常駐オペレーションが場に配置されているとき、常駐ではないオペレーションを使用しても配置されている常駐オペレーションは捨札になりますか？
		A2
		いいえ。自分が常駐オペレーションを配置するとき、すでに配置している自分の常駐オペレーションがあれば、元々あったものを捨札にしてから配置します。常駐オペレーションは、各プレイヤーごとに1枚だけ配置できます。
		Q3
		常駐オペレーションの上に重ねられたカードは、重ねた後に情報を整理するために重ねている順番を持ち主が並べ替えることはできますか？
		A3
		いいえ、並べ替えることはできません。

- オペレーションカードの種類の一つ。

- テキスト左側のスペースに時計を模したアイコンが表記される。

- 常駐オペレーションカードを使用した場合、常駐置き場にそのカードを配置して、書かれてある効果を常に有効にし続ける事になる。

- その効果は常駐オペレーションカードが置き場においてある限り永続する。

- すでに常駐置き場にカードがある時に新しい常駐オペレーションカードを使用した場合、置き場のカードを捨札にしてから配置する。

- ライダー3弾から新しく2枚配置できるタッグ常駐オペレーションが登場。通常の常駐オペレーションとも併用可能。
