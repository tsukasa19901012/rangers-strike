テキスト：

※クロス1

※これは「仮面ライダーディケイド」または「仮面ライダークウガ」としてつかえる。

【ライダー大戦の世界】これが自軍エリアにある間、自分がターンを終えるとき、次の効果を発動できる⇒自軍山札の上から5枚をオモテにして、その中から1枚を選び手札に加える。その後、残りのカードとこのユニットを好きな順で山札の下に戻す。

ここはまるでライダー大戦の世界みたいだな…いや、それより性質が悪そうだ。

カード評価

- 効果が優秀で、スペックもパワー1でBP4000と序盤から使える良ユニット。

- 【ライダー大戦の世界】は優秀なサーチ効果。使用後は山札の下に任意の順番で送れるため、仮面ライダードレイクMFと組み合わせると効率的。
