                仮面ライダーディケイドCF（コンプリートフォーム）（XG3）

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：6000

SP：－

必要パワー：4+

追加条件：特徴「ディケイドライバー」を持つ自軍ユニット1体をパワーゾーンに送る

CN：なし

特徴：仮面ライダー／男／ディケイドライバー

テキスト：

※レジスト

【通りすがりの仮面ライダー】このターン中にＮＣまたはRCの効果を発動した、カテゴリにDA以外を持つSユニットからコンビネーションするとき、次の効果を発動できる⇒コンビネーションするユニットのNCまたはRCの効果を、このユニットの効果として発動する。

カード評価

- 三度目の収録となったコンプリートフォーム。前回より更に必要パワーが低くなりラッシュしやすくなった反面、分数SPと最大の特徴であった除去耐性テキストを失い、代わりにレジストを得ている。

- 能力は以前のカード以上に汎用性が高いコピー能力。戦士の魂に若干似てるが、こちらはDAを含むマルチカテゴリのカードからでもコピーが出来る。

- 戦隊ユニットなどのＮＣでSPを得る能力とあわせると簡単にSPを得られる上多段ストライクが容易にでき、デカブレイクや仮面ライダーギルスのようなダメージ能力もコピーできる為ノンストライカーデッキなどでも活躍が見込める。もちろんピンクレーサーのようなSPのつかない能力をコピーすることも可能。

- 特にWBのCN2番でSPを得るユニットからコンビネーションしてSPを得ることで、他のOTのストライカーと合わせて1ターンに合計3点のストライクが狙える。

- パワーが減りつつもBPは前回のCFから据え置きで6000と非常に高く、単純にアタッカーとしても十分な性能なのは相変わらず。SPが空欄である為、強化フォームの弱点になりやすいニンジャブラックの対象にもならない。

- 総合的に、カードパワーを引き出す為に専用の構築が必要だった以前のカードとは違い様々なデッキにタッチで入れても活用しやすくなったと言えるだろう。
