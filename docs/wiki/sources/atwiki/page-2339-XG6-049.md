                仮面ライダーオーガ（XG6）

種類：Sユニット 

カテゴリ：アーステクノロジー／ダークアライアンス

BP：7000

SP：-

必要パワー：4

追加条件：なし

CN：1

特徴：仮面ライダー／男／皇帝

テキスト：

※これはウイングを持つユニットとバトルしたときバトルに勝っても撃破される。

【オルフェノクの帝王】自分の手札を1枚選び自軍コマンドゾーンにホールド状態で置いてもよい。そうしたとき、そのカードの必要パワーの数字以下の必要パワーを持つ敵軍バトルエリアのSユニットを好きな数選び、持ち主のコマンドゾーンにホールド状態で置く。置けなければ捨札にする。

フレーバーテキスト

仲間を失い、理想を捨て、帝王と言う名の絶望がその身を支配する。

イラストレーター：鈴眼依縫 

レアリティ：レア

作品：仮面ライダー555 パラダイス・ロスト

収録:クロスギャザー　ザ・ギガンティックタイタン

カード評価

- マルチとはいえパワー4のBP7000と、ストライクは出来ないが強力なスペックを誇る。

- 【オルフェノクの帝王】はコマンド加速を行いながら相手のバトルエリアを一掃できる強力な効果。自軍コマンドが埋まってしまうと発動できなくなるので、アドベンチャーや獣人メレなど併せて使いたい。

- ウイング持ちとバトルをすると撃破されるデメリットは、本編での仮面ライダーファイズBFとの対決を意識したものと思われる。これは「SP1以上の～」と違い自軍ターン中も適用されるので注意。
