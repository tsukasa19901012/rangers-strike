                バルイーグル（2nd）

種類：Sユニット

カテゴリ：アーステクノロジー　

BP：4000

SP：！

必要パワー：5

追加条件：なし

CN：5

特徴：レッド／男／2nd

テキスト：

※これはバトルエリアにあるとき、カテゴリにWBが追加される。

【飛羽返し】「SP1」（この効果は、WBのユニットからコンビネーションするときは、ナンバーに関係なく発動する）

フレーバーテキスト

凛と鳴る鈴の音を風に乗せ、刃を纏う鷲を夕陽は身も心も紅く染めた。

イラストレーター：村上ヒサシ

レアリティ：スーパーレア

作品：太陽戦隊サンバルカン

収録：紅き六戦士の帰還　自販：パック

カード評価

- 1stのバルイーグルに比べて必要パワーが増えた代わりにBPが1000増えてワイルドビーストのユニットとなら誰とでもコンビネーションできるようになった。能力はBPの上昇が無くなっている。

- 1stバルイーグルの様にバルシャーク（2nd）とバルパンサー（2nd）とコンビネーションでも発動できるが、二人の1stカードではカテゴリが合わないのでコンビネーションは出来ない。

- カテゴリにWBが追加されることでロボタフなどの支援効果を受けられる。必要パワーが重い分、ＢＰ上昇も大きいのでアタッカーとしても活躍できる。

- 難点は重いという点。ストライカーとしてならボウケンシルバー（2nd）の方が使い易く、アタッカーとしても半端なのがつらい。

- バトルエリアに出るとWBのカテゴリが付与される能力は、サンバルカンが動物をモチーフにした技を使うところからきていると思われる。
