                ゲキチーター

種類：Mユニット

カテゴリ：ワイルドビースト

BP：5500

SP：！

必要パワー：0+

追加条件：特徴「激気」と「イエロー」を持つ自軍ユニット1体を捨札にする

CN：2

特徴：激気

テキスト：

【瞬瞬弾】「SP1」

フレーバーテキスト

瞬瞬弾の瞬は一瞬の瞬。瞬きする間に怒濤の連撃、刹那を刻む瞬間に、キラリ輝く旬な技。

イラストレーター：松島一夫

レアリティ：ノーマル

作品：獣拳戦隊ゲキレンジャー

収録：紅き六戦士の帰還　自販：パック

カード評価

- 必要パワー０でありながら高いＢＰとストライク能力を持つ。しかし、追加条件が厳しく、活躍の場はもっぱら、激気を使うデッキになるだろう。

- 必要パワーが０なので激気から出しやすい。ゲキチョッパーのような軽いユニットからラッシュして、序盤からストライクをしていくのが主な仕事。

- ゲキトージャの合体パーツだが、ゲキイエローで事足りる。そのため、合体パーツとして使用する機会はほとんど無いだろう。
