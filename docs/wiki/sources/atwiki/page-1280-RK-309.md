                ウラタロス（2nd）

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：1000

SP：1/4

必要パワー：1

追加条件：なし

CN：3

特徴：イマジン／2nd

テキスト：

【僕に釣られてみる？】自軍パワーゾーンのオモテ向きのカードから、必要パワーを満たしている特徴「女」を持つSユニットのカードを1枚選び、自軍ラッシュエリアに出してもよい（ただし追加条件は満たすこと）。この効果でラッシュしたユニットは、このターン、バトルエリアに出られない。 

フレーバーテキスト

先輩、僕の釣る分を残しておいてくださいよ。

イラストレーター：F.M.U

レアリティ：ノーマル

作品：仮面ライダー電王 俺、誕生！

収録：ザ・マスクドライダーEXP vol.4　自販：パック

カード評価

- コマンドをホールドせずに特徴女を持ったユニットをラッシュできるので、タッチで他の色のカードを使うことができるのが強み。

- BPが低く、エリアに長く留まるのは難しいか。

- DAにはロブスターオルフェノクやズー等女のカードが多く、タイガーロイドでこのカードのBPの低さもある程度補えるので相性が良い。

- 単純にパワー1の1/4ストライカーとしても使い道はある。速攻デッキには女持ちも入りやすく、分数なのでコロンやクウガRD等が居ても普通にストライク可能と詰めの場面において安定した仕事をこなしやすい。
