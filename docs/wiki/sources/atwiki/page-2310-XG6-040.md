                仮面ライダージョーカー

種類：Sユニット

カテゴリ：ダークアライアンス

BP：4000

SP：！

必要パワー：3

追加条件：なし

CN：RC

特徴：仮面ライダー／男／ロストドライバー

テキスト：

※リードET

【ライダーキック】これ以外の自軍Sユニットが１体もなければ、相手は自分自身のSユニットを１体選び撃破する。そうしたとき、これはSP1になる。

フレーバーテキスト

たった一枚でも勝負を賭けられる。だからこその切札(ジョーカー)なのさ。

イラストレーター：ＪＵＮ　ＹＡＭＡＧＵＣＨＩ

レアリティ：スーパーレア

作品：仮面ライダーＷ　ＦＯＥＶＥＲ　ＡｔｏＺ/運命のガイアメモリ

収録：クロスギャザー ザ・ギガンティックタイタン

カード評価

- DAでありながらリードETを持つ。

- DAの必要パワー３のユニットとしては標準的なスペックを持つが、SPの条件が厳しいのでストライカーとしては不安定。

- 効果の発動条件さえ満たせばストライクと敵軍ユニットの除去も同時に行うことができる。積極的に狙うならSユニット以外をメインにしてデッキを構築するか、ゴレムカード等で他のユニットのサイズを変更するなどの工夫が必要になる。

- いっそのこと無理にRCを使おうとはせず、リードを活かすように使うのもいいかもしれない。
