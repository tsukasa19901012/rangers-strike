                ライドベンダー

種類：Sビークル

カテゴリ：アーステクノロジー

必要パワー：2

追加条件：なし

特徴：メカ／車両

テキスト：

※これにライドしているユニットはBP+1000される。

【ベンダーモード】自軍ラッシュフェイズ中、このビークルを捨札にして次の効果を発動できる→自軍山札を見てオペレーションカードを1枚選び、自軍コマンドゾーンにホールド状態で置く（置けなければ自軍コマンドを1つ選び、捨札にしてから置く）。その後、山札をシャッフルする。

フレーバーテキスト

欲望の欠片を飲み込んで、それは力を吐き出し速度を上げる。

イラストレーター：Masakazu Fukuda

レアリティ：ノーマル

作品：仮面ライダーオーズ

収録：クロスギャザー　ザ・ギガンティックタイタン

再録：クロスギャザー　ザ・ベストパートナー　アニバーサリーセット（仮面ライダーオーズ&Wデッキ）

カード評価

- 使い捨てだがオペレーションサーチ能力を持つビークル。単純にコマンド加速の他、バイクルやボウケンレッド（XG5）などと組み合わせて回収することができる。

- これの登場で、デネブなどのOTが入らないデッキでもオペレーションのサーチができるようになった。あちらと比べると手札に加えるまで少々手間がかかるが、相手にアドバンテージを与えることがない。準備が整うまでビークルとして活用しておくこともできる。

- ダブルドライバーやシグナルキャノンなどのコマンドで効果を発揮するオペレーションは、回収せずとも次のターンから使えるため相性がいい。

- 同作品のタカカンはコマンドに置かれたとき自力で手札に戻ってくる効果を持ち、実質的に手札へのサーチができるようになっている。
