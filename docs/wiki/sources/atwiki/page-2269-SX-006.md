                仮面ライダーG電王

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：4000

SP：1/4

必要パワー：3

追加条件：なし

CN：なし

特徴：仮面ライダー／男／GDEN-O／警察

テキスト：

【時間警察の使者】これをラッシュしたとき、必要パワーを満たしていないSユニットとSビークルを可能な限りすべて選び、捨札にする。

フレーバーテキスト

白か黒か―どれだけ時を経ようとも、正義を行使する者にこれほど相応しい姿は無い。

イラストレーター：回転急須

レアリティ：シークレットレア

作品：仮面ライダー×3超・電王トリロジー

収録：XG5 ザ・チケットブレイカー　自販：パック

カード評価

- 必要パワーを満たしていないSユニットとSビークルを、敵味方関係なくすべて捨札にする強烈な効果を持つ。パワー3・BP4000・分数SP持ちとスペックも高水準。

- 仮面ライダー電王RFやゴーオンゴールド（XG4）で相手のパワーを削ってからラッシュすると、ラッシュしたときは必要パワーを満たしていた敵軍ユニット・ビークルも捨札に出来る。

- すべての7-ユニットの天敵。大抵の場合必要パワーは満たせておらず、撃破ではないので素体も帰ってこない。
- ただし、パワー加速が得意でそもそも選ばれないカブト系ユニットは別。

- 選ぶ→捨札にするの順番で処理するので、サバイブなどで1度耐えられれば捨札にはされずに済む。G電王はSユニットであり、効果もラッシュ効果なので再使用が容易な為油断は禁物だが。

- 仮面ライダーシザース以来久々に登場した特徴「仮面ライダー」と「警察」を併せ持つユニット。一人共同戦線が出来る。
