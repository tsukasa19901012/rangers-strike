                マシンキバー

種類：Sビークル

カテゴリ：ミスティックアームズ

必要パワー：3

追加条件：なし

特徴：メカ／車両／魔皇力

テキスト：

※特徴「魔皇力」を持つ自軍Sユニットは、RCを持っていなくてもこのビークルにライドできる。

【シャドウベール】自分がターンを終えるとき、これにライドしているユニットがホールド状態ならば、そのユニットをリリースしてもよい。

フレーバーテキスト

背に跨（またが）る主の声に応え、真紅の鉄馬は激しく嘶（いなな）き走り出す。

イラストレーター：古賀マサヲ

レアリティ：ノーマル

作品：仮面ライダーキバ

収録：ザ・マスクドライダーEXP vol.4　自販：パック

カード評価

- ホールド状態のユニットのリリースが可能なビークル。ギルスレイダーとの違いはリリースするタイミングと必要パワー。あちらはライドした時点で発動するが、こちらはターンの終了時になっている。ライドオフした場合はリリースされないのでRC持ちのユニットとは相性が悪い。

- 仮面ライダーキバに代表される特徴「魔皇力」持ちのユニットにとって必須ともいえる能力を持っており、乗りっぱなしにすることで毎ターン能力の発動が可能になる。

- また、自軍ターン終了時にリリース状態に戻れるため、レジスト持ちのユニットを乗せて自軍ターン中にバトルで相討ちしてでも敵ユニットを倒し、敵軍ターンが始まる前に再度レジスト発動を可能にするという戦い方もできる。

- ライド中のユニットの天敵であるシャドームーンや仮面ライダーサガには注意。
