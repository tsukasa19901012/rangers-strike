【疾風流の継承】これが自軍ラッシュエリアにある間、特徴「忍者」を持つユニットがストライクしたとき、そのユニットの持ち主は1枚ドローしてもよい。また、これが撃破されて捨札になったとき、このカードの持ち主は、特徴「忍者」を持つ自軍ユニットの数と同じ枚数までドローしてもよい。

-  マジパンチ等の「ストライクされたとき」の効果による無効であれば、おっしゃる通り一度ストライクが成立し「ストライクしたとき」のタイミングが発生しているのでドローは可能でしょう。ですがファイブテクターはストライクの成立よりも早い「ストライクされるとき」のタイミング（アタックorストライクの行動権を消費して、プレイヤーが「ストライクします」と宣言してから、そのストライクが成立するまでの間）で、成立前のストライクを未然に無効にしてしまう効果なので「ストライクしたとき」のタイミングは発生しなくなるのではないか、と考えました。  -- 名無しさん  (2020-05-30 16:05:12)

-  もしかしてストライクの指す言葉の意味がお互い違ってるのでしょうか?行動やタイミングの流れは『「ストライクします」と宣言する→ストライクするとき→ストライクされるとき→[実際の行動ストライク］→ストライクしたとき→ストライクされたとき→ダメージを与える処理』となりますが、『』内の一連の処理全体を指してストライクと表現しているため、「無効にされてもその時点ですでに『ストライク（全体）』の一部は行われているので、ストライクしたことになる」という意見でしょうか?こちらの書くストライクは上記のうち、[]内の実際の行動の部分だけになります。なので無効になると[実際の行動ストライク]が無いこと・無かったことになり、それを存在の根拠にしている上記の流れが、無効になったタイミングの時点で中断・強制終了される。それまでに「ストライクしたとき」のタイミングを経過していればハムスター館長の効果を受けられ、経過していなければ受けられない、という意見です。  -- 名無しさん  (2020-06-06 13:55:30)
