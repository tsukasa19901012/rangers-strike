                トリックベント

種類：オペレーション

カテゴリ：ワイルドビースト

必要パワー：4

追加条件：なし

特徴：アドベントカード

テキスト：

自軍山札の上から3枚をオモテにする。その中から特徴「ミラーライダー」を持つユニットカードをすべて自軍ラッシュエリアに出す。ただし、追加条件は満たすこと（必要パワーは満たさなくてもよい）。その後、それ以外のオモテにしたカードはすべて捨札になる。

フレーバーテキスト

現れたのは虚像でも、その攻撃は現実。真の撹乱とは虚実が入り乱れてこそ物を言う。

イラストレーター：Mitsuhiro Arita

レアリティ：ノーマル

作品：仮面ライダー龍騎

収録：マスクドライダーEXP vol.2　自販：パック：スターター 

カード評価

- コマンドをホールドせず、パワーに関係なくミラーライダーを最大3体ラッシュできる。

- 必要パワーの重い仮面ライダー龍騎サバイブや本来ならラッシュするのにDAのコマンドが必要な仮面ライダーアビスもラッシュできる。

- 山札から出すため単体では不安定。クライマックス刑事などでデッキトップを操作すれば必要なユニットを確実にラッシュできる。

- ミラーライダーデッキならユニットを一掃された後の場の立て直しに使うことができる。

- 追加条件は無視出来ないので仮面ライダーオーディンの追加条件が満たせなかった場合、そのまま捨札になってしまう。デッキに投入しているなら注意して使う必要がある。

関連カード

- 特徴「アドベントカード」関連

- 特徴に「ミラーライダー」を持つユニット

コメント

-  JPカードでW･CJを捨てて捨札から２枚山札に戻せる。更にクライマックス刑事も合わせれば最大限に活用でき、運に頼らず３体ラッシュできる。  -- 名無しさん  (2009-10-19 15:56:04)
