                仮面ライダー電王SF（ソードフォーム）（2nd）

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：3000

SP：1/4

必要パワー：4

追加条件：なし

CN：RC

特徴：仮面ライダー／男／DEN-O／2nd

テキスト：

※モーフ（敵軍ユニットがモーフ以外でラッシュされたとき、特徴がこのユニットと完全一致するオモテ向きのユニットカードを自軍ゾーンから1枚選びこれと置き換えてもよい）

【俺の必殺技特別編】敵軍コマンドを2つ、1つずつ順番に選びリリースしてもよい。そうしたとき、本来のカテゴリが1つ目にリリースしたコマンドと同じで、本来の必要パワーが2つ目にリリースしたコマンドと同じ敵軍Sユニットをすべて撃破する。

Q&A

		Q1
		敵軍エリアに「RK-305 仮面ライダー電王SF」があり、敵軍コマンドゾーンに「RK-306　仮面ライダー電王AF」がある状態で、相手の手札が3枚あったとします。この状態 で、自軍ターンに「RK-193 ズー」をラッシュし【パームニードル】を発動しようとしたところ、相手は「モーフ」の能力を使い「RK-305　仮面ライダー電王SF」と「RK-306 　仮面ライダー電王AF」を入れ替えました。「RK-306 仮面ライダー電王AF」はBP4000なので、上記の状態では【パームニードル】の効果は及びませんが、効果が同時発動しているのでターンプレイヤーを優 先し「モーフ」の発動前まで巻き戻した上で【パームニードル】の効果を使用することはできますか？
		A1
		いいえ。「ラッシュしたとき」とある「RK-193 ズー」の【パームニードル】の効果が先に発動し、「RK-305　仮面ライダー電王SF」は「ラッシュされたとき」とある「モーフ」が発動する前に撃破され捨札になります。
		Q2
		自軍エリアに「RS-352 ダイデンジン」があるとき、敵軍ユニットのラッシュに対して《モーフ》を使い自軍エリアの「RK-305 仮面ライダー電王SF」と自軍パワーゾーンの「RK-304 仮面ライダー電王RF」を入れ替えました。このとき「置き換え」によってカードがパワーゾーンを離れますが、「RS-352 ダイデンジン」の効果【ダイデンジンブーメラン】は発動できますか？
		A2
		はい、発動できます。「置き換え」であっても、それまでオモテ向きであったカードがパワーゾーンを離れているので、【ダイデンジンブーメラン】の効果が発動します。

カード評価

- 【俺の必殺技特別編】はエリアを問わず一気に敵軍Sユニットを除去できる非常に強力な効果だが、発動には相手コマンドのカードが２枚ホールドされている必要があり、条件を満たすにも相手がコマンドゾーンに置いたカードに依存するので使いやすいとは言えない。
- 相手のコマンドをホールドするWBやカードをコマンド送りにする効果が多いETとの混色にすることで効果を活かし易くできる。

- 使い勝手の良い「※これはアタックされる以外では相手に選ばれない。」持ちである仮面ライダーカブトRF（XG2）やブレイカーの登場で、対象を選ばずに撃破するという点が強みとして活きるようになってきた。

- SP1ストライカーという点で1stやXG5弾の方がデッキに投入されやすい。こちらを入れるなら上記のようなサポート手段を用意して積極的に効果の発動を狙いたい。

- 「俺の必殺技特別編」は原作ではフルチャージを２回行う（通常は１回）特殊なもので、カードゲーム内ではコマンドを２枚リリースすることで効果が再現されている。
