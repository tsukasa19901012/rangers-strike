                仮面ライダーオーズ・サゴーゾコンボ（プロモーション）

種類：Sユニット

カテゴリ：ワイルドビースト

BP：4000

SP：-

必要パワー：5

追加条件：なし

CN：なし

特徴：仮面ライダー／男／オーズドライバー

テキスト：

※モーフ

※レジスト

※これはホールド状態なら、アタックするときBP+2000される。

【打ち抜く剛腕】自軍ターン中、これをラッシュしたとき、敵軍コマンドを1つ選びホールドしてもよい。

フレーバーテキスト

欲望の戦場で何かを求めるならば、力がそれの鍵となるだろう。

イラストレーター：石川ヒデキ

レアリティ：プロモーション

作品：仮面ライダーオーズ/OOO

収録：2010年11月～　クロスギャザー公認大会参加賞

カード評価

- レジスト・バンプアップ効果など、アタックに特化したフォーム。

- ホールド状態でアタックすればMユニット並みのBPを得られる。素のBPも4000と高く、レジストも持つので殴り合いには強い。

- 【打ち抜く剛腕】は自軍ターン中限定だが敵軍コマンドをホールドすることができる。
- リードがあるため過信はできないが、相手のカウンターを防ぐことができる。

- 守護獣プテラノドンのようなホールドされたコマンドを対象にする効果とも相性が良い。

- 必要パワーが高いのがネック。幸い軽いモーフ元は多いのでモーフからのラッシュを積極的に狙っていきたい。

- BP4000なのでモーフオルゴールをすることができる。モーフオルゴールにはリードETを持つ仮面ライダーオーズ・ガタキリバコンボの方が適しているが、あちらはSRなので集めるのが難しい。こちらで代用する手も十分考えられる。
