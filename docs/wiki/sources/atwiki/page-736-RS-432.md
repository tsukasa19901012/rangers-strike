                隠流マキビシ

種類：オペレーション

カテゴリ：ミスティックアームズ

必要パワー：2

追加条件：なし

テキスト：

※カウンター（これは敵軍ターン中にのみ使用できる）

ストライクされたとき発動できる⇒相手がバトルフェイズを終えるとき、そのバトルフェイズ中に自分の受けたダメージが2点以上なら、敵軍バトルエリアのSユニットをすべて撃破する。

フレーバーテキスト

去る忍、追うべからず。

イラストレーター：西野 幸治

レアリティ：ノーマル

作品：忍者戦隊カクレンジャー

収録：七忍の炎陣　自販：パック:スターター(忍者、炎神)

再録:クロスギャザー ザ・ベストパートナー　スターター（スーパー戦隊シリーズ35作品記念）

カード評価

- 連続ストライク対策カード。スペックに対して必要パワーの低い優秀なカウンターであり、Sユニット中心のウィニー系デッキの展開に十分に間に合わせることが出来る。

- 相手が自身のターン中1回目のストライクをしてきた時に発動する事で後続のストライク阻止、2回目以降のストライクをしてきた時に発動する事でバトルエリアの敵Ｓユニット全滅という2通りの使い方ができる。

- このカウンターはストライクされた時にのみ発動できるので、それ以外の方法でダメージを受けた時には発動できない点に注意。

- 仮面ライダーキバGFのようなダメージ送り、デカブレイクのような間接ダメージで２点ダメージになれば効果が発動する。相手のストライクに発動すればこれらの効果への牽制になる。

- メディテーションを発動していれば、一回のストライクでも２点ダメージとなるのでこのカードの効果を発動できる。
