                ゴーカイオー（プロモーション）

種類：Lユニット

カテゴリ：オーバーテクノロジー

BP：7000

SP：1/4

必要パワー：6+

追加条件：特徴「レッド」または「宇宙海賊」を持つ自軍ユニット1体を捨札にする

CN：なし

特徴：メカ／人型

テキスト：

※これは、自軍パワーの数5につきBP+2000される。

【レジェンドを求めて】自軍ターン中、これがバトルエリアに出たとき、次の効果を発動できる⇒自軍山札を見て、Sユニット以外のユニットカードを1枚選び、自軍パワーゾーンに置いてもよい。その後、山札をシャッフルする。

フレーバーテキスト

未来は地図なき大海原。平和という名の宝（トレジャー）を手に入れるため、いざ出航!

イラストレーター：キクチヒラメ

レアリティ：プロモーション

作品：海賊戦隊ゴーカイジャー

収録：2011年3月～　クロスギャザー公認大会参加賞 

カード評価

- サーチできるユニットカードはSサイズ以外なのでダイカイオー以外のモーフ補助には使えないが、キングライナーやグレートタイタンなどのパワーゾーンの大型ユニットカードを利用するOTのユニットとの組み合わせが考えられる。

- BP上昇のために参照するのは「パワーの数」であるためマルチカテゴリのパワー増加分を含み、ラッシュすればほぼ確実にBP9000以上からの開始となる。追加条件は軽いので、OTのアタッカーとして悪くない。
