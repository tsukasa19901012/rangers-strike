テキスト：

【ビッグ・バトン】これは、自軍コマンドゾーンにあるカードの特徴を見て、それぞれの特徴ごとに次の能力を得る⇒特徴「レッド」があればレジストを得る。特徴「ブルー」があればタクスETを得る。特徴「グリーン」があればBP7000になる。特徴「ピンク」があればSP1になる。

フレーバーテキスト

私はジャッカー電撃隊行動隊長ビッグワン！これはその挨拶代わりさ。

イラストレーター：タカヤマトシアキ

レアリティ：シークレットレア

作品：ジャッカー電撃隊

収録：蒼九の翼　パック：自販機

カード評価

- ETらしくコマンドゾーンに置かれてあるカードに応じて様々な能力を付加する事ができる。

- ワンパーを1枚コマンドゾーンに置くだけで特徴「レッド」以外の全ての恩恵を受けることが出来る。
