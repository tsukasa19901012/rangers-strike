                リボルギャリー

種類：Mユニット

テキスト：

【リボルバーハンガー】自軍ターン中、これがバトルエリアに出たとき、次の効果を発動できる⇒自軍コマンドゾーンから、カテゴリを2つ以上持つビークルカードを1枚選び、カテゴリを2つ以上持つ自軍ビークル1体と置き換える。ただし、必要パワーと追加条件は満たすこと。

フレーバーテキスト

「フィリップ！」「もう呼んでいる」

イラストレーター：宮崎良平

レアリティ：ノーマルレア

作品：仮面ライダーW

収録：XG4 ザ・ジェットアクセル　自販：パック：スターター（ライディングデッキ）

再録：クロスギャザー　ザ・ベストパートナー　アニバーサリーセット（仮面ライダーオーズ&Wデッキ）

カード評価

- 追加条件を持たないMユニット。必要パワーは低く、BPもそれ相応の値である。

- ETでは貴重な追加条件無しのMユニット。Mユニットなので除去手段が限られる。BPも必要パワー3の標準値となっているため、場に残しやすい。長く場に残ってナンバー稼ぎやアタッカーとして活躍することができる。

- 多色のビークルを交換する効果はそのまま使う場合、トライゴウラムのラッシュが主な狙いになる。

- 害地大臣ヨゴシュタインやタカカンでカテゴリを追加すれば、単色のビークルをタッチで使用することができる。
