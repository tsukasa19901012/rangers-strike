カード評価

- ユニット名を参照するＪＣを持つOTの数少ないJC持ちユニット。条件さえ合えばSユニットともJC発動させる事ができる。

- コンビネーションする相手はSユニットではBPの高いゴーオンレッドやゴーオンゴールドが最適。

- ガンバルオーやセイクウオーでは発動できないので注意。

- 効果で参照するコンビネーションするユニットのBPは本来の値ではない。そのためガオ・ソウルでBPを上昇させることで、大きなユニットも除去できる。

- コンビネーションするユニットとはサイズが合っていなくても構わないので、天空大聖者マジエルなど軽いLユニットをラッシュしておいてBPを底上げするとともにサイズを変えておけば、撃破や除去をされづらくなる。

- ナンバーがRなので、コンビネーションするユニットをダイアナレディ等で強化できる点も強み。
