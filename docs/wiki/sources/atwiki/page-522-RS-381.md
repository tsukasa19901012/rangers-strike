                ガレオパルサー

種類：Sビークル

カテゴリ：ワイルドビースト

必要パワー：4

追加条件：なし

特徴：ギンガの光／車両

テキスト：

※特徴「レッド」を持つSユニットは、自軍コマンドを1つホールドすれば、ＲＣを持っていなくてもこのビークルにライドできる。

【獅子の装光】自軍ターン中、これにライドしたユニットをライドオフさせるかわりに次の効果を発動できる⇒ライドされていない敵軍Sビークルを1体選び捨札にする。その後、これを捨札にする。

フレーバーテキスト

現れたもう一人の赤き獅子。彼が仲間であることは、言葉を交わさずともすぐに分かった。

イラストレーター：二条忠則

レアリティ：ノーマル

作品：星獣戦隊ギンガマン

収録：紅き六戦士の帰還　自販：パック

カード評価

- ビークル除去効果を持つSビークル。

- 同じビークル除去のサイコローダーと比べて、追加条件が無いため手軽にデッキに組み込める。RCを持たなくても特徴にレッドを持つユニット誰でもライドできるのも強み。

- 効果を使うと、自身も捨札にされるのが難点。通常のビークルとして運用して、相手のRCを牽制するのが関の山か。

関連カード

- 特徴「車両」関連
