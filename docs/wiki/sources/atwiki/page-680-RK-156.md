                マシンデンバード

種類：Sビークル

カテゴリ：オーバーテクノロジー

必要パワー：1

追加条件：なし

特徴：メカ／車両

テキスト：

【デンライナー搭乗】これがバトルエリアからラッシュエリアに戻るとき、これがライドされていれば次の効果を発動できる⇒自軍山札から特徴「車両」を持つMユニットのカードを1枚選び、相手に見せてから自分の手札に加えてもよい。その後、山札をシャッフルする。

フレーバーテキスト

ギガンデスの暴走を食い止める手段は一つ、デンライナーが、真の力を見せる時は来た。

イラストレーター：Kakoi Kazuhiko

レアリティ：ノーマル

作品：仮面ライダー電王

収録：ザ・マスクドライダーEXP vol.2　自販：パック：スターター 

カード評価

- 車両をサーチする効果を持つビークル。相手ターンに撃破されづらい仮面ライダードレイクMFなどに乗せるか、がんがんじいでラッシュエリアに戻して使うと効果が発動させやすい。

- ライ単では車両の種類が少なく他のビークルに見劣りがちだが、混合では車両の種類が豊富なので使い易い。

- ライ単では主にデンライナーゴウカかデンライナーイスルギがサーチされる。

関連カード

- 特徴に「車両」を持つユニット
