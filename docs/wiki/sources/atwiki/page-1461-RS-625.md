                メガウインガー・フライヤーモード

種類：Lユニット 

カテゴリ：アーステクノロジー 

BP：4000

SP：！

必要パワー：4+

追加条件：特徴「シルバー」を持つ自軍Sユニット1体を捨札にする 

CN：なし

特徴：メカ／航空機

テキスト：

※ウイング

【シルバー専用機】 これをラッシュしたとき、この追加条件で捨札にしたカードを見て、SPが空欄でなかったなら、このターン、これは次の能力を得る⇒BP+2000、「SP1」 

フレーバーテキスト

彼は急いで休暇届を書き上げると基地から飛び出した。彼らに翼を届けるために。

イラストレーター：R-AREA

レアリティ：ノーマル

作品：電磁戦隊メガレンジャー

収録：蒼九の翼　自販：パック：スターター（ウイング）

カード評価

- Sユニット1枚でラッシュ出来るのが魅力のLユニット。ただしラッシュに必要なシルバーは数が非常に少なく、全体的に重いものが多いのがネック。ゴーオンシルバーのいるOTとの混色デッキで使うのが無難か？

- 条件を満たせばラッシュしたターンのみSP1になれるがBP6000で前線に出すのは不安が付きまとう。ファイターモードにゾードアップするのが目的なら無理せずに留まりたい。
