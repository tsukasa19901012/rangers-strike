【第六世代コンピューター】これが自軍バトルエリアにあり、ユニットにライドされていなければ、敵軍ターン中、自軍バトルエリアのSユニットがホールド状態になったとき、そのユニットをこのビークルにライドさせてから、ラッシュエリアに戻してもよい。

フレーバーテキスト

それは危険な任務に就く彼が「いこうぜ」と言える貴重な存在だった。

イラストレーター：キクチヒラメ

レアリティ：ノーマル

作品：機動刑事ジバン

収録：クロスギャザー ザ・ドラゴンタイガー　自販：パック

Q&A

		Q1
		「XG2-090 レゾン」の【第六世代コンピューター】の効果でライドさせることができるユニットは、RCを持つユニットだけですか？
		A1
		はい、その通りです。

カード評価

- レジストを持つRCユニットの生存率を高めてくれるビークル。

- 原作の乗り手である機動刑事ジバンや仮面ライダーデルタなどETにはレジスト持ちのRC持ちが多いので効果を発動する機会は多い。

- 他のカテゴリではMAがレジスト持ちのRCが多い。逆にOTとWBにはレジストを持つRC持ちが少ないので相性は悪い。

- レジスト持ちのユニットとこれを用意してファイブテクターを組み合わせれば、発動回数を増やせる。
