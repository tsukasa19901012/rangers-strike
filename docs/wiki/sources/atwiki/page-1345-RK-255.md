                電波人間タックル（2nd）

種類：Sユニット

カテゴリ：アーステクノロジー

BP：1000

SP：1/5

必要パワー：2

追加条件：なし

CN：RC

特徴：女／改造人間／2nd 

テキスト：

※特徴「仮面ライダー」を持つユニットが自軍バトルエリアにあれば、これは敵軍Sユニットにアタックされない。 

【ウルトラサイクロン】このユニットを捨札にして、次の効果を発動してもよい⇒敵軍バトルエリアから必要パワーの数字が3以下のユニットを1体選び、持ち主のコマンドゾーンにホールド状態で置く。置けなければ敵軍コマンドを1つ選び、捨札にしてから置く。

フレーバーテキスト

いつか悪い怪人が居なくなって世の中が平和になったら…。約束忘れてないわよね？

イラストレーター：横田 守

レアリティ：ノーマル

作品：仮面ライダーストロンガー

収録：ザ・マスクドライダーEXP vol.4　自販：パック

カード評価

- ザマス1弾に収録された電波人間タックルの2ndカード。

- 1stに比べてパワーが2増えたが、特徴「仮面ライダー」を持つユニットが居ればアタックされなくなり、RC能力は自分を犠牲にする代わりにユニットの除去とコマンドの強制埋めが同時にできる等、大幅に強化された。

- 【ウルトラサイクロン】は原作同様自分を犠牲にする自爆技だが、サイズの指定が無く、コマンドがすでに埋まっていても強制的に置き換えることができる強力な効果。特に強制コマンド埋めは多色デッキに対して強いアドバンテージが持てる。
