                ゼクロスベルト

種類：オペレーション

カテゴリ：アーステクノロジー

必要パワー：2

追加条件：なし

テキスト：

次の効果から1つ選び発動する⇒

◎自軍山札から「仮面ライダーZX」のカードを1枚選び、相手に見せてから手札に加えてもよい。その後、山札をシャッフルする。

◎自軍コマンドゾーンから、特徴「改造人間」を持つSユニットのカードを1枚選び、自軍ラッシュエリアに出す。ただし、必要パワーと追加条件は満たすこと。

フレーバーテキスト

語られた九つの戦いが、新たな戦士に道を示す。今こそ、天昇る龍となって駆け抜ける時。 

イラストレーター：二見敬之  

レアリティ：ノーマル

作品：仮面ライダーZX

収録：ザ・マスクドライダーエクスパンションベルトコレクションボックス 

カード評価

- 効果は改造人間専用のランドバルカン。他の違いはパワーと出せるユニットの数。そして、ホールドされていても選ぶことができること。場合によってはランドバルカンより効果を発揮する場合も。もう一方の効果はおまけと考えよう。

関連カード

- 仮面ライダーZX

- 仮面ライダーZX（XG）

- 仮面ライダーZX（XG4）
