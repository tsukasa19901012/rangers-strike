                ダイナピンク

種類：Sユニット

カテゴリ：アーステクノロジー

BP：2000

SP：－

必要パワー：0

追加条件：なし

CN：2

特徴：ピンク／女

テキスト：

【フラワーカーニバル】敵軍コマンドゾーンのリリース状態のカードをすべて持ち主の手札に戻す。その後、自分がターンを終えるとき、相手は自分自身の手札から好きな枚数を自分自身のコマンドゾーンに置く。

フレーバーテキスト

艶やかに乱れ飛ぶ幻惑の花吹雪。トゲを持つのはバラか、それとも…。 

イラストレーター：Takeshi Mohri

レアリティ：ノーマル

作品：科学戦隊ダイナマン

収録：四雄の覚醒　自販：パック

再録：リバイヴァ　自販：パック

カード評価

- コマンドを一時的に全て除去させる効果はカウンターオペレーションや、気力を完全に防ぐ事ができる。ただし、その後は相手がコマンドゾーンを自分が有利になるように置けるので状況によってはデメリットの方が大きいか。

- エラスモテリウムオルフェノクや仮面ライダーキバGFなど、相手の手札を参照する能力とはシナジーがある。
