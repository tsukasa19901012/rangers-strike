カード評価

- エリアを問わない、BP下三桁500のSユニット除去能力を持つ。同じ効果を持つ仮面ライダーカイザと比べて、BPが下がった代りに、デメリットが無くなった。

- 仮面ライダーファイズとして扱えるため、仮面ライダーファイズの代わりとしてアクセルフォーム等、各種ユニットへのゾードアップももちろん可能。

- ディケイドライバー持ちで唯一のET。ETのデッキで、他のカテゴリのディケイドライバー持ちにモーフする場合は、このカードを経由することになる。
