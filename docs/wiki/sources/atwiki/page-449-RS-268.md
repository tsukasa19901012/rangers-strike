                グリーンフラッシュ

種類：Sユニット 

カテゴリ：オーバーテクノロジー 

BP：5500

SP：！

必要パワー：1

追加条件：なし 

CN：5 

特徴：グリーン／男

テキスト：

※このユニットは、自分と相手のコマンドゾーンにある「OT」以外のコマンド1つにつき「BP-1000」され、BP0以下のとき撃破される。

【プリズムカイザー】自軍ラッシュエリアから、「ET」のユニットを1体選び自軍パワーゾーンに送ってもよい。そうしたとき、このターン、これは「SP1」になる。

		「RS-266 レッドフラッシュ」は「このユニットは、自分と相手のコマンドゾーンにあるＯＴ以外のコマンド１つにつきＢＰ−１０００され、ＢＰ０以下のとき撃破され る。」というテキストを持ちますが、ＯＴを含むマルチカテゴリのコマンドであっても１つにつきＢＰ−１０００されますか？
※注釈：対象カードがレッドフラッシュなのは元の公式QAの原文そのままです
		A1
		はい、その通りです。「ＯＴ以外」とは「ＯＴではないカテゴリを持つ」という意味です。

カード評価

- 原作終盤の悲壮感を再現した能力。本来のBPは5500とかなり高めだがOT以外のコマンドが複数あると撃破されてしまうので工夫が必要。

- それを補うための能力がピンクフラッシュ。ホールドされたコマンドのカテゴリをOTに変えてくれるのでBPの減退が軽減される。

- また、ファイブイエローや仮面ライダー新1号のようなBPの値が「～になる」効果を使えば、BPの減退を一時的に無効化することができる。

- フラッシュマンの中でCNは5と一番最後。コマンド操作の得意なETと組めるのは利点だがBPは5500と少し低めになっている。

- 赤青デッキならば呉越同舟で他のユニットカテゴリを変えればETを入れなくても【プリズムカイザー】が使用できる。
