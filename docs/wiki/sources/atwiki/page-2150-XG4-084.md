                仮面ライダー幽汽HF（ハイジャックフォーム）

種類：Sユニット

カテゴリ：ダークアライアンス

BP：5000

SP：1

必要パワー：5

追加条件：なし

CN：なし

特徴：仮面ライダー／男

テキスト：

※コールDA 

※これは自軍ユニットがホールドされたターンにしかバトルエリアに出られない。

【乱れ独楽】これが自軍ラッシュエリアにある間、自軍エンドフェイズ中、次の効果を好きなだけ発動できる⇒自分の手札を1枚選び捨札にする。そうしたとき、敵軍バトルエリアからSユニットを1体選び撃破する。

フレーバーテキスト

死んだ筈の者が甦るだと･･･本当ならば私の宿願も叶うと言うものだ。

イラストレーター：鈴眼依縫

レアリティ：スーパーレア

作品：劇場版 さらば仮面ライダー電王　ファイナル・カウントダウン

収録：XG4 ザ・ジェットアクセル　自販：パック

カード評価

- 仮面ライダー幽汽SFの別形態だが、ゲーム上は特に繋がりはない。

- 撃破デメリットなしでBP5000・SP1という強力なスペックを誇る。仮面ライダーネガ電王と同様のバトルエリアに出る際の制限があるが、自身がコールDAを持つため手札にDAのユニットさえあれば事実上いつでもバトルエリアに出られる。ただし宏のオルゴール時計には注意。

- 仮面ライダー斬鬼（XG3）があればコールの再利用とユニットのホールド稼ぎが同時にできる。

- バトルエリアに出られなくとも、今度は手札を捨ててバトルエリアのSユニットを無条件に撃破という除去効果を何度でも発動できるというフォローがある。キャッスルドランと組み合わせれば失った手札を即座に補充できるため相性がいい。

- がんがんじいやバトルダンスがあれば1ターン中にアタックorストライクと効果の発動の両方をすることもできる。ただし今の環境ではクウガゴウラムの存在でそこまで場持ちは良くないのが残念。
