種類：Sユニット

テキスト：

【エンジンブレード】これをラッシュしたとき、特徴「加速」を持たない敵軍Sユニットを1体選び、持ち主のコマンドゾーンにホールド状態で置く。置けなければ捨札にする。 

フレーバーテキスト

翔太郎、また新しい仮面ライダーの噂が街に流れている。興味深いと思わないか？

イラストレーター：中北晃二

レアリティ：スーパーレア

カード評価

- 【エンジンブレード】はほとんどのSユニットを除去できる、擬似バイモーションバスターのような能力。必要パワーが3とラッシュしやすくスペックも上々で使いやすいため、色々なタイプのデッキに採用できる。

- 効果がラッシュ時に発動するので、カウンターやシンケンゴールドで妨害されず、モ－フされる前にユニットを除去することができる。
- 特徴に加速を持つユニットは対象にすることができないが、それらのユニットは元々各種RFや仮面ライダーアクセルトライアル（XG6）のように「これはアタックされる以外では相手に選ばれない」という効果を持っていることが多く、あまり気にならないかもしれない。

- 原作では現役の刑事だが、なぜか特徴「警察」は持っていない。フレーバーも本編と噛み合っておらず、最速収録の弊害の最たる例として挙げられる。
- なおこれ以降に収録されたプロモーション版や仮面ライダーアクセルトライアルには「警察」が付いている。
