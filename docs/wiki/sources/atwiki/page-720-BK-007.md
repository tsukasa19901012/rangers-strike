                サイクロード

種類：オペレーション

カテゴリ：アーステクノロジー

必要パワー：4

追加条件：なし

テキスト：

次の効果から1つ選び発動する⇒

◎自軍山札から「仮面ライダースーパー1」のカードを1枚選び、相手に見せてから手札に加えてもよい。その後、山札をシャッフルする。

◎自軍捨札から特徴「改造人間」を持つSユニットのカードを1枚選び、自軍コマンドゾーンにホールド状態で置く。（コマンドゾーンに置けるカードは通常5枚まで）

フレーバーテキスト

硬い蕾（つぼみ）から大輪の花が咲くように、厳しい修行の果てにベルトは真の力を解放した。 

イラストレーター：小松原 英  

レアリティ：ノーマル

作品：仮面ライダースーパー1

収録：ザ・マスクドライダーエクスパンション　ベルトコレクションBOX 

カード評価

- 本人よりずいぶん前に収録されていたカードだが、クロスギャザー 1stでついに本人が参戦した。

- 登場に間が空いてしまったため、特徴「ファイブハンド」を持つスーパー1の他形態には対応しておらず、サーチすることができない。ただし2番目の効果で捨札の他形態をコマンドに置けばスーパー1のモーフの補助になるので、完全にシナジーが無いわけでもない。

- 仮面ライダーXやバイクルと合わせれば捨札から手札への回収も可能。

関連カード

- 仮面ライダースーパー1

- 特徴に「改造人間」を持つユニット
