                タイムシャドウSM（ステルスモード）

種類：Lユニット

カテゴリ：オーバーテクノロジー

BP：3000

SP：－

必要パワー：4

追加条件：なし

CN：なし

特徴：メカ／航空機

テキスト：

※これが自軍パワーゾーンでオモテ向きになっている間、自軍ラッシュフェイズ中、自軍捨札の枚数がこれの必要パワーの数字以上あれば、これを自軍ラッシュエリアに出してもよい。

※自軍ターン中、これがバトルエリアに出たとき、自軍パワーゾーンからオモテ向きのカードを1枚選び捨札にする。

【ステルスモード】これは敵軍ユニットにアタックされない。

フレーバーテキスト

刻（とき）を渡り、闇を裂き、月輪(がちりん)の光を浴びて未来からの使者が舞い降りる。

イラストレーター：F.M.U

レアリティ：ノーマルレア

作品：未来戦隊タイムレンジャー

収録：七忍の炎陣　自販：パック

カード評価

- 条件を満たせばパワーゾーンから直接ラッシュが可能なLユニット。【ステルスモード】のお陰で生存率は高いが、BPが低く、バトルエリアに出るためのデメリットが痛いのでラッシュエリアに篭ってタイムシャドウにチェンジできるまで待つ事の方が多いだろう。

- パワーゾーンからラッシュできることを利用して仮面ライダー電王AF（2nd）でパワーゾーンに送るカードとして使うとことも出来る。

- 能動的にパワーゾーンから捨札を作ることができる。イエローアーマーなどリアニメイト狙いや、ゲキトージャウルフなどの捨札枚数を参照するカードに使うと良い。コマンドなしでラッシュも可能なので、極論を言えばどんな色のデッキにも入れられる。
