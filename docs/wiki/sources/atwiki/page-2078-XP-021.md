                ファイナルカメンアタックフォームライド

種類：オペレーション

カテゴリ：オーバーテクノロジー

必要パワー：25

追加条件：なし

テキスト：

※これは特徴「仮面ライダー」を持つユニット1体ごとと、特徴「仮面ライダー」を持つゾーンのオモテ向きのカード1枚ごとと、特徴「仮面ライダー」を持つ捨札1枚ごとにつき、必要パワーの数字が1減る。

◎敵軍ユニットを1体選び撃破する。

フレーバーテキスト

なし

イラストレーター：EGC WORKS

レアリティ：リミテッドレア

作品：劇場版 仮面ライダーディケイド オールライダー対大ショッカー

収録：XG4 ザ・ジェットアクセル　自販：パック

カード評価

- フレーバーテキストを持たない初めてのカード。ちなみに前回のリミテッドレアにはフレーバーがあった。

- 1号からディケイドまでの歴代ライダーの人数にちなんだ桁違いの必要パワーにまず目が行くオペレーション。そのかわり効果はエリアやサイズを問わない非常に汎用的な除去と、リターンもそれなりに大きい。

- お互いのエリア・ゾーン・捨札にある仮面ライダーの数だけ必要パワーは減るので、積極的にライダーを使えば使うほど使いやすくなる。合計で20体は欲しいところ。ライダー限定大会などでは発動できる機会もあるだろう。
- ただし、ビークルである仮面ライダーアクセル バイクフォームはエリアにあるときはパワーが減らない。ゾーンや捨札にあるときとは扱いが変わるため、数えるときは注意。

- とはいえライダー単だとエリア無視の除去は仮面ライダーアクセルや仮面ライダーキバーラで十分事足りるのも確か。混合でもよほど大型のユニット相手でない限りBPやパワー参照の除去で済む。ライダーシンドロームとどちらが実用的かは意見の分かれるところ。

- ストレンジベントを使いパワーを無視して発動する手もある。
