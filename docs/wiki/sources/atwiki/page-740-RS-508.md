カード評価

- パワー1でBP4000と相当コストパフォーマンスが良いように思えるが、単体だと何も出来ないという重いデメリットを持つ。このカードが真価を発揮するのはこのコンビネーションを発動させたときである。アタックを省略してバトルが行えるうえ、ストライクも同時にすることが可能。

- また、アタックではなくバトルという点にも注目。隠流忍術などに影響されずユニットを撃破できる。

- ＢＰが高いため序盤のナンバー稼ぎとしても活躍できる。毎ターンバトルエリアに出なくてはいけないデメリットがあるため終盤にラッシュするタイミングには注意が必要。

- アカレッドの効果での使用も強力。アカレッドのＢＰ上昇効果とこのカードの効果の相性が良い。
