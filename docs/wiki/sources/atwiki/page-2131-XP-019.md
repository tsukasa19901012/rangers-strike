                仮面ライダー1号（プロモ）

種類：Sユニット

カテゴリ：アーステクノロジー

BP：4000

SP：1/5

必要パワー：4

追加条件：なし

CN：RC

特徴：仮面ライダー／男／改造人間

テキスト：

【技の1号】「SP1」これがアタックするとき、敵軍ユニットのBPをカードに表記された本来の値としてバトルし、自分が次の行動の宣言をするまで相手はカウンターを発動できない。

フレーバーテキスト

何度戦ったとて同じ事、勝利は正義を背負う者の手にこそ輝くのだ。

イラストレーター：Ｋ２商会

レアリティ：プロモーション

作品：仮面ライダー

収録：2010年4月～レンジャーズストライク公認大会　優勝賞品 

カード評価

- ライダーEXP vol.1に収録された1号が、クロスギャザーで待望のプロモーションカード化。
- ちなみに、以前収録されていたものはファンから「桜島1号」と呼ばれる姿で、コチラは「旧1号」と呼ばれる番組最初期の姿である。

- 公式HPの画像ではRCがついていないが、実物にはちゃんと通常のものと同様にRCがついている。
