                仮面ライダーV3（XG）

種類：Sユニット

カテゴリ：アーステクノロジー

BP：4000

SP：！

必要パワー：4

追加条件：なし

CN：RC

特徴：仮面ライダー／男／改造人間 

テキスト：

※レジスト

※これが自軍コマンドゾーンにある間、自軍ラッシュフェイズ中、自軍捨札に「仮面ライダー1号」のカードと「仮面ライダー2号」のカードがあれば、これを自軍ラッシュエリアに出してもよい。

【V3反転キック】敵軍バトルエリアからSユニットを1体選び、持ち主のコマンドゾーンに置いてもよい。置けなければ捨札にする。このとき選んだユニットのSPが1以上だったなら、これはSP1になる。 

フレーバーテキスト

お前と同じ悲しみや苦しみを俺達も抱えている。だから一緒に来い。

イラストレーター：矢薙じょう

レアリティ：ノーマルレア

作品：仮面ライダーV3

収録：クロスギャザー ザ・ファーストエンカウント　自販：パック：スターター（10人ライダー）

Q&A

		Q1
		「XG-044 仮面ライダーV3]の【V3反転キック】の効果で、敵軍の「SK-004 仮面ライダークウガUF」を選びましたが、「SK-004 仮面ライダークウガUF」は【凄まじき戦士】の効果でその場に留まりました。このとき、「XG-044 仮面ライダーV3]のSP1になる効果は発動しますか？
		A1
		はい、発動します。「このとき、選んだユニットのSPが1以上だったなら」とありますので、コマンドゾーンに送る、または捨札にすることができなくても、選ぶだけでSP1になります。

カード評価

- ストライク能力に目がいきがちだが、単純明快にどんなSユニットも除去できる【V3反転キック】は強力無比。除去能力の点で見れば、似た役割を持つ仮面ライダー新2号よりも優秀。分数ＳＰを持っていないのでストライクはやや苦手。

- ＳＰの獲得についてはストライクポイントの項目を参照。ユニットの状態を参照するので、効果によりSPを得ているユニットを除去した場合も有効。選んだ時点でSPを得るので相手に除去耐性があってもよい。

- RCからSPが得られるユニットとしては、同パワーの仮面ライダー1号や仮面ライダーストロンガーと比べて、相手がユニットをバトルエリアに出した次の自軍ターンしかSPが得られない点で劣る。他の2枚にはない除去効果による場の制圧力を活かしたい。

- 一号と二号が捨て札にあればコマンドから直接ラッシュできるようになる。ソルジャンヌやボウケンブラックで直接捨て札に送れば、必要パワーを無視してのラッシュも可能。新一号などでも条件を満たせるので、そちらを使っても問題ない。仮面ライダー新2号×仮面ライダー新1号は1号か2号のどちらか1枚としてカウントできるので、他のカードよりもある程度融通が利く。

- このカードの効果でコマンドに置かれる場合、リリース状態で置かれる。間違えやすいので注意。

- 出典は「仮面ライダーV3」になっているがイラストは「仮面ライダーZX」に登場したときの状況で、フレーバーもおそらくZXに向けて。
