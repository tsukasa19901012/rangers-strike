                仮面ライダーディエンド（XG3）

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：3000

SP：1/4

必要パワー：4

追加条件：なし

CN：なし

特徴：仮面ライダー／男／ディエンドライバー

テキスト：

【カメンライド】これが自軍エリアにある間、自軍ラッシュフェイズごとに1度だけ、自軍パワーゾーンのオモテ向きのカードから特徴「仮面ライダー」を持ち追加条件を持たないユニットカードを2枚まで選び、自軍ラッシュエリアに出してもよい。この効果で出したユニットは、このターン、アタックもストライクもできず、このターンを終えるとき、自軍エリアにあれば捨札になる。

Q&A

		Q1
		「XG3-069 仮面ライダーディエンド」の【カメンライド】の効果で ラッシュした「XG3-061 仮面ライダーガタックMF」は【キャストオフ】の効果を発動することはできますか？また、このとき「この効果で出したユニットは、このターン、アタックも ストライクもできず、このターンを終えるとき、自軍エリアにあれば捨札になる。」というテキストの処理はどうなるのでしょうか？
		A1
		はい、【キャストオフ】の効果を発動することは可能です。【キャスト オフ】の効果で「仮面ライダーガタックRF」をラッシュする際に、「XG3-061 仮面ライダーガタックMF」を追加条件でパワーゾーンに送った場合は、「仮面ライダーガタックRF」は「XG3-069 仮面ライダーディエンド」の効果でラッシュされたユニットではないので、「この効果で出したユニットは、このターン、アタックもストライクもできず、この ターンを終えるとき、自軍エリアにあれば捨札になる。 」という制限の影響は受けません。また、「XG3-061 仮面ライダーガタックMF」は自軍エリアにないので、ターンを終えるときに捨札になることもありません。

カード評価

- パワーゾーンから仮面ライダーをラッシュできるSユニット。

- ラッシュフェイズにパワーから仮面ライダーをラッシュできるが、ラッシュされたユニットは、アタックもストライクもできない。そのため、ディケイド キバや仮面ライダーブレイド（XG2）のような強力な効果を一時的に使うという使い方が基本になる。

- 仮面ライダーカブトMF（XG2）のような各種MFと相性が良い。効果でラッシュして、各種RFへのゾードアップが狙える。また、オルタフォース等による置き換えや、デンライナーイスルギ等へのゾードアップを狙うのにも便利。
