                仮面ライダー威吹鬼（イブキ）

種類：Sユニット 

カテゴリ：ミスティックアームズ 

BP：3000

SP：1/3

必要パワー：4

追加条件：なし

CN：RC

特徴：仮面ライダー／男／猛士

テキスト：

【音撃射・疾風一閃】自軍山札の上から3枚をオモテにしてもよい。そうしたとき、敵軍山札の上から3枚をオモテにする。そして、オモテにしたカードの中から「SP1」を持つSユニットのカードをすべて捨札にし、それ以外を持ち主の山札に戻してシャッフルする。（この効果は、特徴「猛士」を持つユニットからコンビネーションする時、ナンバーに関係なく発動する）

フレーバーテキスト

罪なき人々の前に邪なる影が迫った時、その間に割って入る様に一陣の風が吹いた。

イラストレーター：funbolt

レアリティ：スーパーレア

作品：仮面ライダー響鬼

収録:ザ・マスクドライダーEXP vol.3　自販：パック

カード評価

- 素でSP1のSユニットはドラゴンレンジャーやシャドームーンなど一部のユニットのみだが、どれも強力なカードが多いので相手に効果が決まった時のアドバンテージはなかなかのもの。猛士からコンビネーションすることでも発動できるのも強み。

- 必要パワーの重さ、レジストが無い、重さの割にＢＰが低いなど難点が地味に多い。使うからにはがんがんじいなどで保護しつつできる限り効果を発動させていきたい。

- 仮面ライダー龍騎サバイブ（XG4）のような、ユニットでない時にSP1になるカードは、SP1になる条件を満たしていれば効果の対象になる。
