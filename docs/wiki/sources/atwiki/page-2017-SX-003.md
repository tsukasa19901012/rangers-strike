                仮面ライダーW・FJ（ファングジョーカー）

種類：Sユニット

カテゴリ：ダークアライアンス

BP：3000

SP：－

必要パワー：4+

追加条件：特徴「獣」または「恐竜」を持つ自軍コマンドがある

CN：なし

特徴：仮面ライダー／男／ダブルドライバー

テキスト：

※モーフ

※自軍ターン中、これが自軍バトルエリアにある間、敵軍バトルエリアにあるユニットの効果名を持たないテキストは無効になり、発動もできない。

【アーム・ファング】これはバトルするとき、BP+3000される。

フレーバーテキスト

風は様々な顔を持つ。時として逆風になり激しく牙を剥く事だってあるだろう。

イラストレーター：funbolt

レアリティ：シークレットレア

作品：仮面ライダー×仮面ライダーW＆ディケイドライダー大戦2010

収録：クロスギャザー ザ・Wインパクト　自販:パック

Q&A

		Q1
		自軍ターン中、自軍バトルエリアに「SX-003 仮面ライダーW・FJ」があるとき、敵軍バトルエリアのレジストは無効になっていますが、本来の記述にレジストを持つユニットを「レジストを持たない」と して扱い、「RM-057 レッドル」の【スティンガープラズマ】の効果でホールドすることはできますか？
		A1
		いいえ、それはできません。無効になっているだけであり、テキスト自体を失っているわけではないからです。
		Q2
		敵軍バトルエリアに「XG3-060 仮面ライダー天鬼」の効果でラッシュされた特徴「ディスクアニマル」を持つ敵軍ユニットがあります。自軍ターン中、自軍バトルエリアに「SX-003 仮面ライダーW・FJ」があるとき、その特徴「ディスクアニマル」を持つユニットの『本来の特徴に「猛士」を持つ自軍ユニットがユニットでなくなるとき、 これを捨札にして、そのユニットをその場に留める。』というテキストは無効になりますか？無効になるなら、その状態で「XG3-060 仮面ライダー天鬼」を撃破した場合、特徴「ディスクアルマル」を持つユニットはどうなりますか？
		A2
		特徴「ディスクアニマル」を持つユニットのテキストは無効になります。無効になった状態で「XG3-060 仮面ライダー天鬼」が撃破されて場からいなくなっても、特徴「ディスクアニマル」を持つユニットは、そのまま場に残り続けます。

カード評価

- 仮面ライダーディケイドCFに対するメタカード。レジストやスクラム、各種MF・RFの能力、仮面ライダー電王LFの効果まで無力化する。

- Wのカードだが、追加条件の都合上ダブルドライバーのみではラッシュできない。獣や恐竜をデッキに入れるかモーフに頼ろう。
- 獣・恐竜持ちはDA単色ならアンデッド勢や比較的優秀なガライ、WBやETを混ぜるのならばHMやCMにも使えるギガバイタスCMやライジンゴーがよい。

- DA特有のデメリット、「これはSP1以上のユニットとバトルしたとき～」も消してしまうのは注意。

- 素のBP3000はメリットにもデメリットにも働くが、クウガゴウラム・宏のオルゴール時計といったBP4000以上のユニットを対象にした効果が環境に蔓延している現状を考えるとメリットと言っていいだろう。
- ただし、仮面ライダースーパー1やデスガロンといった致命的なカードは各色に存在する上に、Sユニットなので簡単に除去されるため、結局は使い捨てかもしれない。
