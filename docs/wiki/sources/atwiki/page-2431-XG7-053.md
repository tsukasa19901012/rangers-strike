                仮面ライダーオーズ・シャウタコンボ

種類：Sユニット

カテゴリ：ワイルドビースト

BP：500

SP：なし

必要パワー：5

追加条件：なし

CN：なし

特徴：仮面ライダー／男／オーズドライバー

テキスト：

※モーフ

※リードET

※これは、自分と相手の手札1枚につきBP+500される。

【水中からの強襲】自軍ターン中、これをラッシュしたとき、自軍捨札からナンバーにRCを持つカードを1枚選び、ゲームから除外してもよい。そうしたとき、そのカードのRCの効果を、このユニットの効果として発動する。

フレーバーテキスト

この姿は、欲望の渦にも呑まれぬ意志の強さの顕れか。

イラストレーター：松島一夫

レアリティ：スーパーレア

作品：仮面ライダーオーズ/OOO

収録：クロスギャザー ザ・ベストパートナー　パック／自販機

カード評価

- 5パワーと重めの必要パワーに対してSPなし・BP500と素のスペックがかなり低め。BP上昇効果はあるものの、上昇値が+500ずつと若干物足りない。うまく活用するなら、ガンマジンなどのドローソースを豊富に用意してBPを上昇しやすくする、リードETを活かすなど工夫が必要。

- 【水中からの強襲】は捨札になった仮面ライダー1号などの強力な効果を使用できるが、発動条件が自軍ターン中にラッシュした時なので通常発動できるのは1度きり。そのためラッシュのタイミングは慎重に見極める必要がある。
- ラッシュフェイズ中に効果が発動するため、仮面ライダードレイクMFや仮面ライダーディケイドの効果を即ラッシュに活かすことができる。

- 【水中からの強襲】で仮面ライダーディケイド（XG2）、仮面ライダーW・CJ（XG6）、仮面ライダーオーズ・タトバコンボの能力を使用すると、それぞれに対応するライダーの内、RCの効果を持つユニットの能力を1ターンに2度使うことができる。
- 仮面ライダーオーズ・タトバコンボを使う場合、単色でできるため特に狙いやすい。
