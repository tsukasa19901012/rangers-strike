                激気（プロモーション）

種類：オペレーション

カテゴリ：ワイルドビースト

必要パワー：0

追加条件：なし

テキスト：

※常駐（場に配置して、離れるまで効果が有効になる）

自軍バトルフェイズ中、特徴「激気」を持つ自軍Ｓユニットがバトルエリアに出たとき、次の効果を発動できる

⇒バトルエリアに出たユニットの必要パワーの数字よりも、必要パワーの数字が小さいワイルドビーストのMユニットのカードを、自分の手札から1枚選び、自軍ラッシュエリアに出す。

フレーバーテキスト

この身に滾(たぎ)る獣の力は、真の強さへの第一歩。鍛えて掴め、ゲキ的勝利！

レアリティ：プロモーションカード

-  このカードの効果はWBを含むマルチカテゴリ(ゲキペンギン等)も出せるのでしょうか？「WBの」だから無理でしょうか？  -- 名無しさん  (2010-07-20 00:03:37)

-  ↑「WBの」なのでWBを含んでいれば出せます。余談ですが、仮にカテゴリにWBのみを持つものしか出せない場合は、鉄面臂張遼の効果のように「WBのみを持つ」といった表記がされるはずです。  -- 名無しさん  (2010-07-20 00:28:43)

-  返信ありがとうございます。わかりやすい説明、感謝です。  -- 名無しさん  (2010-07-20 00:58:18)

-  この効果ってXGゲキレッドとかゲキバイオレット、ゲキチョッパー達の能力とどっちが先に発動するんですか？  -- 名無しさん  (2010-07-23 01:58:39)

-  ↑バトルエリアに出た時の効果がNCよりも先に発動するので、激気の効果発動→並び順確定のちゲキレッド等のNC効果発動という流れになります  -- 名無しさん  (2010-07-23 02:03:20)
