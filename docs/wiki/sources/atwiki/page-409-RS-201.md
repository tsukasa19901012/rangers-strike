                イエローフォー

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：1000

SP：－

必要パワー：1

追加条件：なし

CN：3

特徴：イエロー／女

テキスト：

【超電子ホログラフィー】自軍山札を見る。そして、オペレーションのカードがあれば1枚選び、自軍パワーゾーンに置く。その後、山札をシャッフルする。

フレーバーテキスト

カメラを知り尽くした彼女ならではの撹乱戦法。ただの静止画が頼もしい増援に変わる。

イラストレーター：森下直親

レアリティ：ノーマル

作品：超電子バイオマン

収録：四雄の覚醒　自販：パック

再録：リバイヴァ　自販：パック

カード評価

- 低パワーでデッキの圧縮とパワー加速を同時にこなす。サーチしたオペレーションの回収は超電子レーダーやゴーオンブルーで回収する

- 同じくオペレーションのサーチするデネブと比べて、重いオペレーションを多用するデッキ向きのカードと言えるだろう。

- 2色になるが、重力忍者オモ・カルを使えば1番目でNCを発動させることができる。そこにゴーオンブルーが続けば、オペレーションをサーチをしつつストライクができるので無駄がない。
