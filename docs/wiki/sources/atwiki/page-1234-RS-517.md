                バードニック反応炉

種類：オペレーション

カテゴリ：アーステクノロジー

必要パワー：1

追加条件：なし

テキスト：

※常駐 

自軍コマンドゾーンにスクラムを持つユニットカードがあれば、そのカードと同じＣＮを持つBP2000以下の自軍Sユニットは次の能力を得る⇒これはアタックされない。

フレーバーテキスト

人類の英知を宿した胸を張り、受け継いだ心と共に大空へ。

イラストレーター：雨宮慶太 

レアリティ：ノーマル

作品：鳥人戦隊ジェットマン

収録：究極の八神　自販：パック

カード評価

- 条件さえ満たせば、サイズに関係なくアタックされなくなる。能力除去が増えているとは言え、アタックできないという状況は相手にとって相当つらい。

- 同じETのCN5のストライカ－を守るには、唯一のCN5のスクラム持ちである仮面ライダー西鬼が必須であり、単色での使用は難しい。SP1/5と5番以外のCNを持つブルースワットなどがいれば解消できるが、数は少ない。

- イエローオウルやメガイエローに注意。

関連カード

- スクラムを持つユニット

コメント
