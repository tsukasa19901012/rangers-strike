                仮面ライダークウガPF（ペガサスフォーム）

種類：Sユニット

カテゴリ：ミスティックアームズ

BP：500

SP：1/3

必要パワー：2

追加条件：なし

CN：なし

特徴：仮面ライダー／男／アマダム

テキスト：

※自分がターンを終えるとき、自軍常駐置き場に配置されている「超変身」の上に、このユニットを重ねて置いてもよい。

【ブラストペガサス】これは、特徴「警察」を持つ自軍ユニットからコンビネーションするときBP+3000され、敵軍ラッシュエリアのユニットにアタックできる。

フレーバーテキスト

警察官が銃を預けると言う意味―託された思いが、極限の集中力を更に鋭く研ぎ澄ました。

イラストレーター：村上ヒサシ

レアリティ：ノーマルレア

作品：仮面ライダークウガ

収録：ザ・マスクドライダーEXP vol.2　自販：パック：スターター

再録：ザ・マスクドライダーEXP vol.4　スターター（クウガ）

カード評価

- BPこそ低いがストライク可能で、「警察」ユニットと組ませることで大きくパワーアップする。共同戦線の併用もおすすめ。

- 超変身を使うデッキなら置き換える効果でビークルに乗れるようになる。ハリケーンに乗れば打たれ弱さをある程度克服できる。

- ザマス4弾で追加された各種ライジングフォームは特徴「アマダム」を持つユニットであればどのユニットを捨札にしても追加条件を満たすことができるので、他のフォームよりパワーの少ないこのユニットは素体として向いている。

- ターン終了時にこのカードを超変身に重ねる効果は単純に見れば、自軍ユニットが１体減るため使い勝手が悪いが、仮面ライダークウガUFのラッシュを狙うデッキなら、ストライクなどをしつつクウガUFラッシュの肥やしになる。
