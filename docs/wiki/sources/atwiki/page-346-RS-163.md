                ガオブラック

種類：Sユニット

カテゴリ：ワイルドビースト

BP：3000

SP：－

必要パワー：1

追加条件：なし

CN：4

特徴：ブラック／男

テキスト：

【アイアンブロークン】自軍ターン中、このユニットはBP+3000される。

フレーバーテキスト

うおおっ！ネバギバぁっ！―がっぷり四つの土俵際。狙え、逆転大金星！

イラストレーター：Mitsuhiro Arita

レアリティ：ノーマル

作品：百獣戦隊ガオレンジャー

収録：三界の獅子　自販：パック

再録：リバイヴァ　自販：パック

カード評価

- ガオブルーよりもBP増加幅は小さいが、こちらは敵ユニットのサイズに関係なく自軍ターン終了時までBPが6000にまで強化される。コストパフォーマンスも優秀。

- CNが少し重いが、大半のMユニットを叩き潰してしまう戦闘能力は魅力。ガオ・ソウルと併用すれば、軽量のLユニットを撃破しうるBP10000に強化することも可能。
