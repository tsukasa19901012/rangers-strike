                シンクレッダー

種類：Sユニット

カテゴリ：アーステクノロジー

BP：4000

SP：！

必要パワー：4

追加条件：なし

CN：5

特徴：メカ／レッド／男／警察／スワット

テキスト：

※レジスト

※これがリリース状態で自軍コマンドゾーンにある間、相手にストライクされたとき、これを捨札にしてそのストライクを無効にしてもよい。

【ヘビーサイクロン】SP1

（この効果は「ドラフトブルース」または「ドラフトキース」からコンビネーションするときはナンバーに関係なく発動する）

フレーバーテキスト

欲望の闇に飲まれた街に立って、彼はかつて倒した悪魔の気配を感じていた。

イラストレーター：鈴眼依縫

レアリティ：スーパーレア

作品：特捜エクシードラフト

収録:クロスギャザー ザ・ベストパートナー　自販：パック

カード評価

- アーステクノロジーお得意のストライク妨害効果を内蔵したユニット。ゴーゴーファイヤーとグリーンホバーを組み合わせることでストライクを完全に防ぎきる。

- 戦闘力も十分に高いのでラッシュしても活躍できるのも大きい。
