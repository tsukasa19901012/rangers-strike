                ドン・ホラー

種類：コマンダーカード

カテゴリ：ダークアライアンス

テキスト：

ゲーム開始時、一度だけ次の効果を発動できる⇒自軍山札の上から3枚を捨札にする。

フレーバーテキスト

目障りなヤツめ、魔空空間に引きずり込め！

イラストレーター：W.AIAI

レアリティ：ノーマル

作品：宇宙刑事ギャバン

収録：クロスギャザー ザ・Wインパクト　スターター専用（仮面ライダーW）

カード評価

- ゲーム開始前から捨札を増やす事が可能なコマンダーカード。

- 開始時に発動するので他のカードとの併用は当然できず、捨てるカードが完全に運任せになってしまう点には注意。

- 一見使い道が無さそうだが、捨札の枚数によってラッシュ条件が変更されるダイナブラック、ゲキトージャウルフ等をより早く場に展開する事が可能になる。

- 同一スターターに収録される闇の戒律とも合わせて使える。
