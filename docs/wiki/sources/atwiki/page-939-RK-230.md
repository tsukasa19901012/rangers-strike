【音撃響・偉羅射威】敵軍ユニットの下にオモテ向きで重ねたオペレーションカードを1体選んでもよい。そうしたとき、選んだカードを持ち主の山札に戻してシャッフルする。

カード評価

- ユニットに重ねられたオペレーションを山札に戻すＮＣを持つ。

- 仮面ライダーサガと比べてサイズを問わないため巨大化爆弾やJパワーを除去できる点で優れている。逆にあちらはダメージと発動の容易さで優れている。

- 唯一のナンバー５のスクラム持ち。ナンバー６のユニットがほとんどいないためこのユニット自体がスクラムを発動する機会はあまりないが、バードニック反応炉を使うデッキではETのナンバー５のストライカーを守るため、コマンドとして重宝される。
