                スティラコサウルス

種類：Lユニット

カテゴリ：ワイルドビースト

BP：7000

SP：－

必要パワー：6+

追加条件：特徴「スティライザー」を持つ、自軍ユニットまたは自軍コマンドがある

CN：なし

特徴：恐竜

テキスト：

※これは自軍コマンドを1つホールドしなければバトルエリアに出られない。 

【ファイヤーボールクラッシュ】これをラッシュしたとき、敵軍バトルエリアからBP3000以下のユニットを3体まで選び撃破してもよい。

フレーバーテキスト

伝説の爆竜は炎の車輪を牽き、己を目覚めさせた戦士を探し走り続ける。

イラストレーター：宮崎良平

レアリティ：ノーマルレア

作品：爆竜戦隊アバレンジャー

収録：クロスギャザー ザ・Wインパクト　自販：パック

カード評価

- 特殊な追加条件を持ち、必要パワーも重いためラッシュは少々難しい。【ファイヤーボールクラッシュ】も低BPのユニットしか選択できない、バトルエリア限定など使いづらさが目立つ。

- 単体では使いづらく、マックスオージャへのゾードアップ元としての活躍がメインになる。

- 疾風流超忍法で山札に戻されても再ラッシュが容易なので、カウンターを使われない状況ではなく、【ファイヤーボールクラッシュ】を活かせるタイミングでのラッシュを狙いたい。
