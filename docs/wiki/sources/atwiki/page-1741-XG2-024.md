                剣将ブドー

種類：Sユニット

カテゴリ：ダークアライアンス

BP：5000

SP：－

必要パワー：4

追加条件：なし

CN：1

特徴：宇宙海賊／男／侍

テキスト：

【一騎打ち】敵軍バトルエリアのユニットが1体だけなら、これのBPを+4000してもよい。そうしたとき、自軍バトルフェイズ終了時にこれを撃破する。

フレーバーテキスト

散ればこそ残る物もあろう。さぁ存分に戦おうぞ。

イラストレーター：Kakoi Kazuhiko

レアリティ：ノーマル

作品：星獣戦隊ギンガマン

収録：クロスギャザー ザ・ドラゴンタイガー　自販：パック

カード評価

- 条件付きでＢＰが9000にまで上昇する。DAでは数少ない合体ロボを撃破できるＢＰが得られるユニット。

- とはいえ【一騎打ち】の発動条件の厳しさがネック。倒したいユニットだけがバトルエリアに出てくるとは限らないため効果の発動が難しい。そのため他のカードの補助は必須。

- 重力忍者オモ・カルでナンバーを変更したり、仮面ライダーパンチホッパーの自爆で相手バトルエリアにいるユニットの数を操作することで効果の発動がしやすくなる。

- さらに重力忍者オモ・カルでナンバーを変更してデカグリーンのようなレッカーからの効果発動も狙える。
