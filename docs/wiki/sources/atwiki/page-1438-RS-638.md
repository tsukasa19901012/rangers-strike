                ネジブルー

種類：Sユニット

カテゴリ：ダークアライアンス　

BP：2000

SP：！

必要パワー：2

追加条件：なし

CN：4

特徴：ブルー／男

テキスト：

※ホールド状態のコマンドがあるとき、これはストライクできない。

【ネジトマホーク】「SP1」特徴「ブルー」を持つ敵軍Sユニットを1体選び、撃破してもよい。

フレーバーテキスト

お互いターゲットは決まっているんだから、邪魔は無しにしようよ？

イラストレーター：小城 崇志

レアリティ：ノーマル

作品：電磁戦隊メガレンジャー

収録：蒼九の翼　自販：パック

カード評価

- ネジレンジャーのブルー担当。ネジブラックとほぼ同じスペックだが、CNが4と遅いせいか、こちらの方がパワーは1少なくなっている。

- ネジブラックと違い、特徴追加は花忍者スイレンを頼るしかないが、特徴「ブルー」は色の特徴の中で特徴「レッド」「イエロー」に匹敵するほど多く、BSフォーメーションなど、専用のオペも存在する。ストライクできる可能性も視野に入れて、OT以外との混色では1、2枚入れても面白いかも知れない。

- ネジブラックやネジレッドと同様に、ストライク条件を満たしやすいメレスラスターでは使い勝手の良い軽量ストライカーとして使える。
