                グランナスカ・コンバットフォーメーション

種類：XLユニット

カテゴリ：オーバーテクノロジー

BP：9000

SP：－

必要パワー：5+

追加条件：カード名に「グランナスカ」を含む自軍ユニット1体を捨札にする

CN：なし

特徴：メカ／人型

テキスト：

【ナックルボンバー】自軍ターン中、これがバトルエリアに出たとき、敵軍バトルエリアからMユニットを1体選び、持ち主のパワーゾーンに送ってもよい。

フレーバーテキスト

戦艦か銃かロボットか？　気付いたときには、拳の一撃を食らっていた。

イラストレーター：キクチヒラメ

レアリティ：ノーマルレア

作品：時空戦士スピルバン

収録：XG5 ザ・チケットブレイカー　自販：パック

カード評価

- 追加条件と必要パワーの割にBP9000でアタック制限なし、効果も使いどころがあるという高スペックなユニット。素体の超時空戦闘母艦グランナスカがデッキに入れやすいため、いざという時のアタッカーとしてこれを入れておくのも良い。

- 【ナックルボンバー】はイエローアーマーやオロチなど通常倒しにくいユニットも除去することができる。特に合体デッキ相手に対しては非常に有効。
