Q&A

		Q1
		「RK-312 仮面ライダーキバDF」は、「RK-316 キバットバットIII世」の【フエッスル】の効果で与えられた「モーフ」によってバトルエリアに出る際にもコマンドをホールドする必要がありますか？
		A1
		はい、コマンドをホールドしてください。

カード評価

- モーフの恩恵を最も受けられるのが仮面ライダーキバEF。パワー2つ分と追加条件を省いてラッシュすることが出来る。

- シュードランがいれば捨札のカードにもモーフが出来るようになる。ガルル獣人態のような各種フエッスルを使うことの多い魔皇力ユニットと相性が非常にいい。

- 仮面ライダーキバはラッシュ時にホールドしてしまうのでモーフする際には注意。

- 理屈の上では特徴に「魔皇力」のみが追加されていれば他作品のライダーからキバ系ヘ、仮面ライダーラルクから仮面ライダーキバーラへなどの変則的なモーフもできるが、任意の特徴の単独での追加は敵軍の花忍者スイレンの効果でしか実現しないため、あくまでも夢である。
