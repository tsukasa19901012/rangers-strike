テキスト：

【血に飢えた予言者】これが自分の手札にある間、必要パワーに「＋」を持つ敵軍Sユニットがラッシュされたとき、DAを持つ自軍コマンドを1つホールドしてからこれを自軍ラッシュエリアに出してもよい。そうしたとき、ラッシュされた敵軍ユニットを撃破する。

静かに両手の鎌を振り上げる。アギトに関わる者の未来を切り裂く為に。

カード評価

- カウンターオペレーションのような使い方ができる1枚。

- 【血に飢えた予言者】は「＋」の追加条件持ちに対してカウンターのように使える除去。対象になるユニットはいずれも強力で、デッキの中核を占めるものが多いため決まれば強力。

- 追加条件を満たしてのラッシュである必要はないので、モーフからラッシュされた仮面ライダーキバEFも撃破できる。

- ユニットカードなのでカーナビックに引っかからないので安心して手札に留めておける。

- 派手な効果に目がいきがちだが、基本的なスペックも優秀。１ターン目からラッシュができ、相手の加速要員を潰しやすい。序盤にきてもアタッカーとして腐りづらい。

- 効果が相手依存なので汎用性が低いのがネック。序盤はアタッカーとして運用して、中盤は手札で温めて対象のラッシュに備えるように使うといいだろう。

- サイズ制限があることに注意。相手が戦隊、メタル主体のデッキにはあまり効果を発揮しない。
