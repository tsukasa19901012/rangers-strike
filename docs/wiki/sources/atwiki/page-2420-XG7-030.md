                ゴセイヘッダー

種類：オペレーション

カテゴリ：ワイルドビースト／ミスティックアームズ

必要パワー：2

追加条件：なし

テキスト：

ウイング、タクス、レジスト、リードのどれかを持つ自軍ユニットを1体選ぶ。このターン、選んだユニットはBP+1000され、ホールド状態ならリリースする。（これが自軍コマンドゾーンにある間、カード名に「ゴセイ」を含む自軍ユニットがバトルエリアに出たとき、これをホールドしてもよい。そうしたとき、このカードの効果を発動する）

フレーバーテキスト

天使達の危機に召喚された彼等は、文字通り頭だけで飛び出した。

イラストレーター：松本 エイト

レアリティ：ノーマル

作品：天装戦隊ゴセイジャー

収録：クロスギャザー　ザ・ベストパートナー　自販：パック

カード評価

- 対象にとれる範囲が広くサイズも問わないため、仮面ライダーキバやファイヤーカイザー（2nd）の効果を繰り返し使うことができる。使うなら勇気の魔法などのコマンドリリース手段を用意しておきたい。
- ツバサマルを使えばすべてのLユニットを対象にとれるため、舵木折神などの強力な効果も使いまわすことができる。
