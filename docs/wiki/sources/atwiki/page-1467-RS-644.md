                分身獣ギガウイング

種類：SCユニット 

カテゴリ：ワイルドビースト

BP：4000

SP：－

必要パワー：4+

追加条件：特徴「母艦」を持つ自軍ユニットがある

CN：なし

特徴：メカ／獣／航空機

テキスト：

※ウイング

フレーバーテキスト

人々はそこに疾駆する赤い獣と、飛翔する青い巨鳥を見たという。

イラストレーター：矢薙じょう

レアリティ：ノーマル

作品：星獣戦隊ギンガマン

収録：蒼九の翼　自販：パック

カード評価

- BPが高めのウイング持ち。

- 追加条件は同カテゴリのギガバイタスCMで満たすのが楽。航空機を活かしてDAのバラクティカで満たすのも面白い。

- ギガフェニックスにゾードアップできる。ゾードアップを目指す際にもウイングでこのユニットを危険に晒さずにアタックできる。
