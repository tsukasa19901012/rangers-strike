                仮面ライダーキックホッパー（2nd）

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：2000

SP：1/4

必要パワー：4

追加条件：なし

CN：1

特徴：仮面ライダー／男／加速／2nd

テキスト：

【ライダーキック】敵軍バトルエリアのユニットを、必要パワーの数字の合計が2になるまで好きな数選んでもよい（自軍Sユニットが「仮面ライダーキックホッパー」と「仮面ライダーパンチホッパー」だけなら、4になるまで好きな数選んでもよい）。そうしたとき、選んだユニットを持ち主のパワーゾーンに送る。

フレーバーテキスト

闇の中だとしても俺たちに掴める光がある…一緒に来い。

イラストレーター：JUN YAMAGUCHI 

レアリティ：レア

作品：仮面ライダーカブト

収録：ザ・マスクドライダーEXP vol.4　自販：パック

カード評価

- ナンバーの関係で花忍者ランとのシナジーはまったく無い。タイムピンクを使えば、シナジーを得ることも出来るが、そこまでして使うこともないだろう。

- 必要パワー２までのユニットを単独で毎ターン除去できるのは優秀だが若干重いのが気になる。ガタックエクステンダーがあれば大きいユニットの除去には困らないのでカブトエクステンダーの乗り手として使うのもあり。

- 自軍のＳユニットが仮面ライダーパンチホッパーとこのカードだけになる状況を作るには炎神のようなＳユニット以外のカードが中心になるデッキでないとなかなかできないだろう。
