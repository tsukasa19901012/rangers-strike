                ネジレッド

種類：Sユニット

カテゴリ：ダークアライアンス　

BP：3000

SP：！

必要パワー：4

追加条件：なし

テキスト：

※ホールド状態のコマンドがあるとき、これはストライクできない。

【ネジセイバー】「SP1」特徴「レッド」を持つ敵軍Sユニットを1体選び、撃破してもよい。

フレーバーテキスト

今度こそ俺は奴を倒して手に入れる…永遠の命をな！！

イラストレーター：小城 崇志

レアリティ：レア

収録：蒼九の翼　自販：パック

カード評価

- 特徴「レッド」を持つユニットを撃破する効果と制限付きのストライク能力を持つ。

- 自軍と敵軍両方のコマンドが全てリリースされていないとストライクできない。ユガンデのようなコールや敵軍のコマンドをリリースできる能力での補助が必要。

- 特徴「レッド」を撃破する能力は相手依存。花忍者スイレンと組み合わせれば対象が増える。

- メレスラスターでは獣人メレとアバレブラックのコンボで両軍のコマンドが一掃した所でストライクが狙えるため相性が良い。

- ストライクの制限が厳しいためメレスラスター以外のデッキでは使いづらい。相手コマンドの操作にたけたETと組み合われば使えないわけではない。
