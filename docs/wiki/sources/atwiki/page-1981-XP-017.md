                仮面ライダーディケイド激情態

種類：Sユニット

カテゴリ：オーバーテクノロジー／ダークアライアンス

BP：4000

SP：1/4

必要パワー：4

追加条件：無し

CN：RC

特徴：仮面ライダー／男／ディケイドライバー

テキスト：

※これは手札からしかラッシュできない。

【世界の破壊者】自分と相手のパワーゾーンのカードの枚数をくらべ、枚数が多いパワーゾーンの持ち主は次のようにする⇒自分自身のパワーゾーンのカードの枚数が対戦相手と同じになるまで、自分自身のオモテ向きのパワーを可能な限り選び捨札にする。

フレーバーテキスト

激情が世界の破壊を叫ぶ。その声は戦士達を戦いの渦へと導くだろう。

イラストレーター：ケン・ナガサキ

レアリティ：プロモーションカード

作品：仮面ライダー×仮面ライダーW&ディケイドMOVIE大戦2010

収録：2010年1月～レンジャーズストライク・ライダー単大会　参加賞 

Q&A

		Q1
		「XP-017 仮面ライダーディケイド激情態」を「XG2-055 変身一発」や「RK-160 シザーズジャガー」などの手札から選んで出す効果でラッシュすることはできますか？
		A1
		はい、できます。

カード評価

- 初のラッシュ方法に制限を持つユニット。手札以外からのラッシュができないので、他の特徴「ディケイドライバー」持ちユニットからのモーフや仮面ライダーディケイドCFでのラッシュはできない。

- 【世界の破壊者】は、やり方次第でパワーの枚数を一気に減らすことが出来る恐ろしい効果。仮面ライダー電王AFなどであらかじめパワーを捨てておけば敵軍パワーを確実に全滅に追いやることができる。

- さらに効率的にパワーを削るなら、変身一発でパワーが少なめのときにラッシュしたり、ラジエッカーなど自軍パワーを大量にコストとして消費するカードを併用したい。せっかくならパワー2以下程度を目標に。ダメージが溜まると効率が落ちるので注意。

- RC効果なので手軽に発動でき、さらにCFデッキそのものでは採用しにくい効果であることからも、まさに仮面ライダーディケイドCFへのメタカードといえるだろう。

- 「手札からしかラッシュできない」というテキストは、モーフなどでラッシュできなくなるデメリットだが、仮面ライダー電王RFや仮面ライダーストロンガー（XG3）の効果でラッシュされないというメリットでもある。
