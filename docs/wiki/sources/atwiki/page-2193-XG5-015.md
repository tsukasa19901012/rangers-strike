                スティライザー

種類：オペレーション

カテゴリ：ワイルドビースト

必要パワー：5

追加条件：なし

特徴：スティライザー

テキスト：

自軍Sユニットを1体選ぶ。そして、このカードを自軍ラッシュエリアに置き、選んだユニットをこのカードに重ねる。自軍バトルフェイズ中、このカードに重ねたユニットがバトルエリアに出たとき、自分の手札から特徴「恐竜」を持つユニットカードを1枚選び、自軍ラッシュエリアに出してもよい（ただし、追加条件は満たすこと）。重ねたユニットがユニットでなくなるとき、このカードは捨札になる。

フレーバーテキスト

剣だけでなく鎧すらも託すその信頼。爆竜は必ず答えてくれるはず。

イラストレーター：Ishibashi Yosuke

レアリティ：ノーマル

作品：爆竜戦隊アバレンジャー

収録：XG5 ザ・チケットブレイカー　自販：パック

カード評価

- 恐竜持ちのラッシュ補助としてはVコマンダーの方が使い勝手は良い。特徴「スティライザー」やカテゴリ等、あちらにはない特性を活かした使い方が必要。

- 特徴に「スティライザー」を持つのでスティラコサウルスの追加条件を満たすのに使う事が出来る。ただし、効果で重ねてもユニットにはこの特徴がつかないので、このカードの効果でスティラコサウルスをラッシュするのは難しい。

- カテゴリがWBなので青以外との混色ができる。特にマックスオージャにとっては、ETのバトルシャークやコマンド操作の恩恵を受けることができるのは大きい。

- 効果がバトルフェイズに発動するので、守護獣ティラノザウルスをラッシュして２番目のユニットを除去して連続ストライクを狙うこともできる。

- 仮面ライダーカブトHF（XG5）のような強力なアンタッチャブル能力を持つユニットに装着させると効果的。
