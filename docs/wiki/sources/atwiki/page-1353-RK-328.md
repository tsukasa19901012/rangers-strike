                ドッガ怪人態

種類：Sユニット

カテゴリ：ダークアライアンス

BP：4000

SP：－

必要パワー：3

追加条件：なし

CN：なし

特徴：フランケン／怪人／男

テキスト：

【ドッガフエッスル】自軍ラッシュフェイズ中、このユニットを捨札にして次の効果を発動できる⇒自軍山札を見て「仮面ライダーキバDF」のカードを1枚か、自軍捨札に「ガルル獣人態」と「バッシャー獣人態」があれば「仮面ライダーキバDGBKF」のカードを1枚選び、自軍ラッシュエリアに出してもよい。その後、山札をシャッフルする。

フレーバーテキスト

人間…ガブリと…喰う…

イラストレーター：小城 崇志

レアリティ：ノーマル

作品：仮面ライダーキバ

収録：ザ・マスクドライダーEXP vol.4　自販：パック

カード評価

- 山札から直接仮面ライダーキバDFか仮面ライダーキバDGBKFをラッシュできる。仮面ライダーキバDFの必要パワーより1つ低いパワーでラッシュができ、デッキ圧縮にもなる。

- 自身のBPが高めで、特徴に怪人を持っているのでアポロガイストで強化が可能。単体でも十分にアタッカーとして活躍できる。仮面ライダーキバDFはバトルエリアに出る条件が厳しいので状況に合わせて使いたい。

- 山札からしかラッシュができないので手札に仮面ライダーキバDFがくると効果が腐ってしまう。親子の絆と一緒に使うなどして補いたい。

- 【ドッガフエッスル】はアンデッドの効果と違いユニットの状態である時に発動するためブルースペイダーとのシナジーはない。
