                ガオメインバスター

種類：オペレーション

カテゴリ：ワイルドビースト

必要パワー：5

追加条件：なし

テキスト：

敵軍Sユニットを1体選び撃破する。

フレーバーテキスト

牙吠ッ！牙吠ッ！牙アァッ！ 

イラストレーター：K2商会

レアリティ：ノーマル

作品：百獣戦隊ガオレンジャー

収録：五龍の激鱗　自販：パック：スターター

再録：七忍の炎陣　スターター(type 2：激気デッキ)

カード評価

- 今までにありそうでなかった、シンプルな除去オペレーション。必要パワーが5と若干重めだが、Sユニットを問答無用に葬り去れるのが強み。ジークとのコンボでMユニットも撃破できる。

- この手のシンプルな除去は、特に外す理由が無ければとりあえず入れておいてあまり損はない。NCを使わずに除去する事でスムーズにストライクへと繋いだり、土壇場でSユニットによるロックを食らった時の保険にできたりと活用の幅は広い。
