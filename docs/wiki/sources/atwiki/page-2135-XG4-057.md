                仮面ライダー龍騎サバイブ（XG4）

種類：Sユニット

カテゴリ：ワイルドビースト

BP：6000

SP：1/2

必要パワー：7

追加条件：なし

CN：RC

特徴：仮面ライダー／男／ミラーライダー／サバイブ

テキスト：

※これは常駐置場にカードが1枚もなければ、「SP1」になる。 

【叶えたい願い】上にカードが重なっている常駐オペレーションをすべて捨札にしてもよい。そうしたとき、ウラ向きの自軍パワーを1枚選び捨札にしてもよい。

フレーバーテキスト

たった一つの願いの為に、全てを犠牲にする―それで何が残るんだよ！

イラストレーター：村上ヒサシ

レアリティ：レア

カード評価

- 常駐オペレーションをプレイヤーを問わず除去した上、自分は回復した上にSPも獲得できるという常駐破壊ユニット。かなり相手を選ぶが、相手が合った場合はかなりのアドバンテージを得られる。

- 相手がそう都合良く該当する常駐を使ってくれるとは限らないので、基本的には闇の戒律やミラーワールドを使うデッキで自軍常駐の除去をしつつ回復する使い方となるだろう。

- 上にカードを重ねない常駐を使われてしまうとSP1を得ることはできない。どうしても得たいならレッドワンなど他の常駐除去を併用しなければならない。

- 上にカードを重ねた常駐を捨てる効果は、「ミラーワールドを閉じて戦いを止める」という彼の最後に見つけた「叶えたい願い」に由来するものだろうと思われる。
