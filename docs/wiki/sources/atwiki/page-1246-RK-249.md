                アドベント

種類：オペレーション

カテゴリ：ワイルドビースト

必要パワー：4

追加条件：なし

特徴：アドベントカード

テキスト：

※常駐

自軍ラッシュフェイズごとに1度だけ、特徴「ミラーライダー」を持つ自軍ユニットを1体選んでもよい。そうしたとき、このターン、選んだユニットは次の能力を得る⇒※コールWB（このユニットはWBのユニットをラッシュするためのコマンドとしてホールドできる） 

フレーバーテキスト

召喚されし力の象徴は、契約ある限り主と共に。そう契約がある限り…

イラストレーター：回転急須

レアリティ：ノーマル

作品：仮面ライダー龍騎

収録：ザ・マスクドライダーEXP vol.4　自販：パック

カード評価

- コマンドをホールドせずにミラーモンスターをラッシュし、バトルエリアに出し易くするためのカードなのだが、他のコールを付加する常駐と違いコールが１ターンに一回しかつかえない。これを使うならコマンドにチャージしたほうが良い。

- これを使う主な利点としてはコマンドを増やさずに済むためガオレッド（2nd）などの効果が使い易くなる、ミラーライダーを能動的にホールドすることによってユイ・イブキなどの恩恵を受けられるようになる等だが、ミラーライダーしか対象に取れないため他のカードを増やすとコールそのものが使いづらくなる。

- ラッシュフェイズごとに使えるので、無理やり使おうと思えばキリンレンジャーの【天時星・時間返し】で再度コールWBを利用できる。だがそこまでして使う効果でもない。

- XGシリーズにて自前でコールを持った仮面ライダー龍騎（XG4）・仮面ライダーナイト（XG5）が登場し、ますます使われないカードに。

関連カード

- 特徴「アドベントカード」関連

- 特徴に「ミラーライダー」を持つユニット

コメント

-  龍騎サバイブとナイトサバイブはＲＣを持っているのでコールＷＢでホールド状態になった後はギルスレイダーでリリース状態に戻しておいて再度コールＷＢを使用するというプレイングも面白いかもしれない。  -- 名無しさん  (2011-01-31 18:33:11)
