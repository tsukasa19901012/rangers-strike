                仮面ライダー電王超CF（クライマックスフォーム）

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：4000

SP：1/4

必要パワー：5+

追加条件：自軍「仮面ライダー電王SF」1体をパワーゾーンに送る

CN：なし

特徴：仮面ライダー／男／DEN-O

テキスト：

※ウイング

【超ボイスターズキック】自軍ターン中、これがバトルエリアに出たとき、自軍パワーゾーンから、オモテ向きのカードとウラ向きのカードをそれぞれ1枚ずつ選び捨札にしてもよい。そうしたとき、このターン、これは「SP1」になる。

フレーバーテキスト

終わりを越え、再び始まるその伝説は何処へゆくのか…

イラストレーター：EGC WORKS

レアリティ：シークレットレア

作品：超・仮面ライダー電王&ディケイド NEOジェネレーションズ 鬼ヶ島の戦艦

収録：クロスギャザー ザ・ファーストエンカウント　自販：パック

カード評価

- ストライクとダメージ回復を同時に行えるが、パワー2枚を消費と代償も大きい。仮面ライダー電王SFも1st・2nd共に強力なユニットなので、ゾードアップさせるかどうかは状況を見て冷静に判断したい。

- さりげなくスカイライダーに続き、ライダー環境で数少ないウイングを持つユニット。
