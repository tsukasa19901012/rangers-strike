                激気

種類：オペレーション

カテゴリ：ワイルドビースト

必要パワー：0

追加条件：なし

テキスト：

※常駐（場に配置して、離れるまで効果が有効になる）

自軍バトルフェイズ中、特徴「激気」を持つ自軍Sユニットがバトルエリアに出たとき、次の効果を発動できる

⇒バトルエリアに出たユニットの必要パワーの数字よりも、必要パワーの数字が小さいWBのMユニットのカードを、自分の手札から1枚選び、自軍ラッシュエリアに出す。

フレーバーテキスト

燃え立つ激気は正義の証！獣を心に感じ情熱を沸き上がらせるのだ！

イラストレーター：回転急須

レアリティ：ノーマル

作品：獣拳戦隊ゲキレンジャー

収録：七忍の炎陣　自販：パック

Q&A

		Q1
		「RS-436 激気」の効果でWBのMユニットをラッシュエリアに出すとき、その追加条件を満たす必要はありますか？
		A1
		いいえ、その場合は追加条件を満たす必要はありません。
		Q2
		「RS-436 激気」の効果でWBのMユニットをラッシュエリアに出したとき、そのMユニットのラッシュしたときの効果は発動しますか？
		A2
		はい、発動します。

カード評価

- 激気持ちのユニット主体デッキ専用のオペレーション。自軍バトルフェイズにWBのMユニットの追加条件を無視してラッシュすることが出来る。コマンドをホールドする必要もない為、WBのMユニットの多くが持つ「自軍コマンドを1つホールドする」を満たすためのコマンドも同時に確保することができるのは大きい。

- この効果で出せるWBのMユニットは、バトルエリアに出た激気を持つSユニットの必要パワーの数字より少なくなければならない点に注意。しかし特徴「激気」を持つユニットは追加条件持ちを除いて必要パワー4までのユニットしかいないので、このままではゲキタイガーのようなパワーの軽いMユニットしかラッシュできない。

- このカードが真価を発揮するには追加条件「－」で出しやすく、特徴に激気を初めから持っているスーパーゲキレッドなどが必要になる。パワー7もあれば大抵のMユニットをラッシュできるようになり使い道が大きく広がるだろう。

- また、マスター・シャーフーや大帝ラー・デウスで激気持ちを増やしたり、ガンツ先生で激気持ちユニットのパワーを上げる事でも使い勝手を上げる事が出来る。
