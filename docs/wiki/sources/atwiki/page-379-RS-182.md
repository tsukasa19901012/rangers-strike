                ジャイアントローラー

自軍Sユニットを1体選ぶ。このターン、選んだユニットとバトルしたユニットは、撃破されて捨札になったとき、持ち主のパワーゾーンにダメージにして置く。

Q&A

		Q1
		「RS-182 ジャイアントローラー」の効果で選んだ自軍ユニットが敵軍ユニットを撃破した際、敵軍ユニットがカウンターなどの効果で捨札に送られなかった場合でも、その敵軍ユニットのカードは敵軍パワーゾーンにダメージにして置かれますか？
		A1
		いいえ。その場合は「撃破されて捨札になったとき」の条件を満たさないため、ダメージとしては置かれません。
		Q2
		敵 軍のラッシュエリアに「RS-089 レスキューファイター」がある状態で、「RS-182 ジャイアントローラー」で指定した自軍ユニットが、ワイルドビーストの敵軍Mユニットを撃破しました。そのとき、撃破されたユニットは敵軍パワーゾーンに ダメージとして置かれますか？
		A2
		い いえ、撃破されたユニットはダメージにはならず、持ち主のパワーゾーンにオモテ向きに置かれます。「RS-182 ジャイアントローラー」の効果を実行するには「撃破されて捨札になったとき」という条件を満たす必要があるのに対し、「RS-089 レスキューファイター」の効果には「撃破されたとき捨札にするかわりに」とあります。つまり、撃破されたユニットは捨札を経由せずに持ち主のパワーゾーン に置かれてしまうため、「RS-182 ジャイアントローラー」の効果は適用されないということになります。
		Q3
		「RS-182 ジャイアントローラー」で指定した自軍ユニットが、ワイルドビーストの敵軍ユニットを撃破したとき、相手は自分自身の「RS-052 爆竜トリケラトプス」をかわりに捨札にすることを選択しました。このとき、「RS-052 爆竜トリケラトプス」は敵軍パワーゾーンにダメージとして置かれますか？
		A3
		い いえ、その場合は「RS-052 爆竜トリケラトプス」が捨札になるだけです。「RS-182 ジャイアントローラー」の効果は、その効果で選んだユニットとバトルしたユニットが、撃破されて捨札になることが条件であるため、かわりのユニットが捨札 になっても効果は適用されません。

カード評価

- 能力でBP10000を超える事が出来るオーレッドのようなユニット向けのオペレーションであるが、オーブルー、オーグリーンのNCとも重複しないので、彼等に適用すれば1度に2点ダメージを与えることも可能になる。連続アタックが可能な仮面ライダーファイズAFや仮面ライダーZO、仮面ライダーアギトBFとの相性も良い。
- 必ずしも選んだユニットで撃破する必要はない。

- ユニットが「撃破されたとき」ではなく「撃破されて捨札になったとき」の発動であることに注意。ダイノガッツやダイノ伝記、レジスト、チェイスを発動したユニットにはまったく無意味となってしまうので、アタックする相手には気をつけよう。
- 効果の対象が「バトルしたユニット」で持ち主の記載がないため、隠流忍術を使われて自軍ユニットを撃破してしまった場合は、当然自分がダメージを受ける。

- パワーの重さが泣き所。入れるならフィニッシャーとしての運用が主になるだろう。

- フレーバーのセリフは激走戦隊カーレンジャーのレッドレーサーが言っていると思われる。

-  ↑ジャイアントローラーの使用対象に選んだ自軍ユニット（A）で敵軍ユニット（B）とバトルする。
⇒AがBにバトルで負けても、Bは「選んだユニットとバトルしたユニットは、撃破されて捨札になったとき、持ち主のパワーゾーンにダメージにして置く。」の効果が残る。
Bを、Aとのバトル以外の何らかの方法で撃破しても、ダメージ効果は発動する。
という意図かと思います。Mサイズ以上でBPの高いユニットがいる場合や、何らかの撃破効果を持つユニットがいる場合に役立ちます。  -- 名無しさん  (2014-10-11 12:53:30)
