特徴：恐竜

テキスト：

※これは自軍コマンドを2つホールドしなければバトルエリアに出られない。

【守護獣の使徒】これが自軍エリアにある間、WBを持つ自軍Mユニットは、『※レジスト（これがバトルで撃破されたとき、捨札にするかわりにこれをホールドしてその場に留めてもよい）』を得る。ただし、そのユニットが持つ「ラッシュしたとき」の効果を発動したときは、そのユニットをホールドする。 

フレーバーテキスト

護るべきモノがある。故に我が地を侵すものには容赦をしない。 

イラストレーター：黒田 清桐

レアリティ：ノーマルレア

作品：恐竜戦隊ジュウレンジャー

収録：究極の八神　自販：パック

カード評価

- WBのMユニットにレジストを付加してやられにくくする。ラッシュ時の効果を発動する際にホールドしなければいけないため守護獣とは相性が悪い。

- ガオエレファントのようなＪＣのユニットや、ガオバイソンのようなバトルエリアに積極的に出したいユニットを守るのにつかいたい。

- ガオシャークやガオハンマーヘッドのような優秀なアタッカーの補助としても使える。
