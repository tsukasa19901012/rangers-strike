                仮面ライダーオーズ・タカキリーター

種類：Sユニット

カテゴリ：ワイルドビースト

BP：500

SP：－

必要パワー：2

追加条件：なし

CN：なし

特徴：仮面ライダー／男／オーズドライバー

テキスト：

※モーフ

【カマキリソード】これは敵軍Sユニットにアタックするとき、BP+5000される。

フレーバーテキスト

風のようにすばやく、走り抜けざまに敵を斬る。その眼、その腕、その脚でこそ成せる技。

イラストレーター：funbolt

レアリティ：ノーマル

作品：仮面ライダーオーズ/OOO

収録：クロスギャザー ザ・チケットブレイカー　自販：パック

カード評価

- 必要パワーが2と軽く、同値のタカトラーターと比べて強制的にバトルエリアに出るデメリットもないためモーフの基点として使いやすい。

- 「アタックするとき」に発動する効果はアタック宣言した後に発動する。なので、仮面ライダーオーズ・ラトラーターコンボや仮面ライダーオーズ・タカトラーターのような、「※これは BP3000以上 のユニットにアタックされない。 」というテキストを持つユニットにアタックすることができる。
