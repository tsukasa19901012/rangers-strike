                リボルバーマンモス

種類：XLユニット

カテゴリ：ミスティックアームズ

BP：5000

SP：－

必要パワー：5

追加条件：なし

CN：なし

特徴：メカ／母艦

テキスト：

※これは自軍コマンドを2つホールドしなければバトルエリアに出られない。

【カラクリボール発射】自軍ターン中、これがバトルエリアに出たとき、自軍山札の上から1枚をオモテにしてもよい。そうしたとき、オモテにしたカードがMAのMユニットのカードだったなら、追加条件を持たない敵軍ユニットを1体選び、持ち主の手札に戻す。その後、オモテにしたカードを手札に加える。

フレーバーテキスト

演奏が激しさを増すほどに、撃ち出される弾の数も増えてゆく。

イラストレーター：ケン・ナガサキ

レアリティ：ノーマルレア

作品：忍風戦隊ハリケンジャー

収録：XG4 ザ・ジェットアクセル　自販：パック

カード評価

- バトルエリアに出るためのデメリットがやや辛いものの、【カラクリボール発射】でオモテにしたカードは必ずドローでき、うまくいけばバウンスまで狙えるため、発動する価値は大いにある。

- コマンドの増加と山札の1番上のカードを確認できるオメデトロフィーと共に使うのがよいか。
