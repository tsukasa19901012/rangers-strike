### スタートフェイズ [部分編集](https://w.atwiki.jp/renst/pedit/264/0-1 "部分編集")

- ゲームが開始された時や、相手のターンが終了してこちらのターンに回ってきた時をスタートフェイズという。
- 先攻側は１ターン目のみ、この [フェイズ](https://w.atwiki.jp/renst/pages/69.html "フェイズ (2328d)") を飛ばして [チャージフェイズ](https://w.atwiki.jp/renst/pages/145.html "チャージフェイズ (6774d)") からの始まりとなる。
- スタートフェイズでは次の３つの行程を好きな順に必ず行う。
  - ホールド状態の自軍 [コマンド](https://w.atwiki.jp/renst/pages/151.html "コマンド (381d)") を [リリース](https://w.atwiki.jp/renst/pages/158.html "リリース (6409d)") する。
  - [バトルエリア](https://w.atwiki.jp/renst/pages/457.html "バトルエリア (2328d)") に出ている自軍 [ユニット](https://w.atwiki.jp/renst/pages/137.html "ユニット (6057d)") 及び [ビークル](https://w.atwiki.jp/renst/pages/141.html "ビークル (347d)") を [ラッシュエリア](https://w.atwiki.jp/renst/pages/147.html "ラッシュエリア (6063d)") に戻す。
  - [山札](https://w.atwiki.jp/renst/pages/154.html "山札 (2328d)") から手札を一枚だけ [ドロー](https://w.atwiki.jp/renst/pages/123.html "ドロー (2328d)") する。
    - この時、 [ドロー](https://w.atwiki.jp/renst/pages/123.html "ドロー (2328d)") したカードを手札と合わせて、枚数が自軍 [ダメージ](https://w.atwiki.jp/renst/pages/105.html "ダメージ (6327d)") の数値未満ならばもう一枚だけ続けて [ドロー](https://w.atwiki.jp/renst/pages/123.html "ドロー (2328d)") することも出来る。
    - 二度目のドローに関しては強制ではないので引かない事も出来る。
- これらが済んだらスタートフェイズは終了し、 [チャージフェイズ](https://w.atwiki.jp/renst/pages/145.html "チャージフェイズ (6774d)") に進む。
