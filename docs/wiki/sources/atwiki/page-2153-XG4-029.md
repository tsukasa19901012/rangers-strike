                ゲキバイオレット（XG4）

種類：Sユニット

カテゴリ：ワイルドビースト／ミスティックアームズ

BP：3000

SP：1/3

必要パワー：5

追加条件：なし

CN：2

特徴：バイオレット／男／激気

テキスト：

【天地転変打】「SP1」特徴「激気」を持つ自軍MユニットのBPを合計して、その合計以下のBPを持つ敵軍ユニットを敵軍バトルエリアから1体選び撃破する。 

フレーバーテキスト

俺はこの拳で必ず俺達の友情を果たしてみせる！

イラストレーター：matsudanozomu

レアリティ：レア

作品：獣拳戦隊ゲキレンジャー

収録：XG4 ザ・ジェットアクセル　自販：パック

カード評価

- 以前と比べるとBPとパワーが増えた。特に必要パワーが上がったことにより、激気の効果でラッシュできるWBのMユニットがより多くなった。

- 場を整えればかなりの大物を撃破できる効果。特徴:激気を持つMユニットは元からBPは高いものが多く、参照する際にはエリアを問わないのでラッシュエリアに引き篭もらせることもできる。
- しかし効果は強力であるが、このユニット自身が打たれ弱い為、何回も使えることはないだろう。

- BP5000以下の除去を主とするのなら、レジストを持つゲキレッド（XG）の方が使い易いか。

- 前のゲキバイオレットもWBを代表する優秀なユニットである為、使い易さではこちらはやや劣る。しかし効果自体は優れた性能を持っているので、積む割合を変えたりしてデッキに合った調整をしよう。
