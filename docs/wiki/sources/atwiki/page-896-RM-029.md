                ジャスピオン

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：4000

SP：－

必要パワー：2

追加条件：なし

CN：ＲＣ

特徴：メカ／男

テキスト：

※SPが空欄ではない自軍Sユニットがあれば、これはバトルエリアに出られない。 

【コズミックハーレー】敵軍山札の上から1枚をオモテにする。オモテにしたカードがWBを持つユニットカードなら、それを持ち主のラッシュエリアに出す。違うなら、そのカードを持ち主のパワーゾーンに送ってから、相手に1点ダメージを与える。

フレーバーテキスト

巨大な獣に一人敢然と立ち向かう。正義に輝く魂を持つ彼を、人は銀河狼（スペースウルフ）と呼んだ。

イラストレーター：村上ヒサシ

レアリティ：スーパーレア

作品：巨獣特捜ジャスピオン

収録：スペシャルメタルエディション　自販：パック

カード評価

- きつい制限と少々ギャンブル的な効果の【コズミックハーレー】を持つユニット。【コズミックハーレー】自体はワイルドビースト以外が引ければ良いので案外決まりやすい。

- 問題はSPが空欄ではない自軍ユニットがいるとバトルエリアに出られない点。SPが空欄でもダメージを与えられるユニットたちと組む、MやLのユニット主体のデッキで運用する、SPが空欄のユニットでもジャイアントローラーを使ってダメージを与えられるようにする、等でフォローしたい。
