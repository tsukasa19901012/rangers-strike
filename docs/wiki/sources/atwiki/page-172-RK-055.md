                仮面ライダーパンチホッパー

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：3000

SP：1/4

必要パワー：2

追加条件：なし

CN：1

特徴：仮面ライダー／男／加速

テキスト：

【ライダーパンチ】敵軍バトルエリアからSユニットを好きな数選び、ラッシュエリアに戻してもよい。

フレーバーテキスト

アニキを笑った奴は、俺の敵だ…。悪いが、タダじゃあ帰さないぜ！

イラストレーター：小城 崇志

レアリティ：ノーマル

作品：仮面ライダーカブト

収録：ザ・マスクドライダーEXP vol.1　自販：パック

カード評価

- 敵軍Ｓユニットを無制限で押し戻せる【ライダーパンチ】は強力。敵軍ラッシュエリアにあるＳユニットの数を調節し、仮面ライダーキックホッパーの【ライダーキック】に繋げることや、敵軍バトルエリアのユニットを一掃し仮面ライダー電王SFのストライクに貢献できる。

- 加速持ちでありながらBPが3000あるのも強み。カブトエクステンダーにライドした仮面ライダーカブトRF（XG2）や仮面ライダーサソードRF（XG3）と相討ちができる。

- また自身も特徴に加速を持つので、カブトエクステンダーやクロックアップの恩恵を得ることができ、打たれ弱さある程度カバーできる。

- タイガーロイドやイカファイア、シノビドグラーおよびキンタロス（2nd）などのバトルエリアで効果を発揮するユニットに対しても有効。ドラグレッダーやスクラム等といったコンビネーションの妨害もできたりと、幅広く使える。

- 能力を置いておいても低パワーの「仮面ライダー」である点を生かしてモモタロスと共に速攻デッキに組み込まれることも多い。分数ストライカーであるため妨害されづらいのも強み。
