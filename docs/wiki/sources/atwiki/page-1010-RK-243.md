【ドラゴンライダーキック】特徴「ドラゴン」を持つユニットからコンビネーションしたとき発動できる⇒敵軍バトルエリアから、ナンバーを持たない敵軍Sユニットを1体選び撃破する。

カード評価

- 【ドラゴンライダーキック】は条件がやや厳しいがドラゴンからコンビネーションすればどこからでも発動できる。

- ライダー環境ではナンバーを持たないユニットは一部を除くミラーライダー、ゾードアップユニット等が多い。
