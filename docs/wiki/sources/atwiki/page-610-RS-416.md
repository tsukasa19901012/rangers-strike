                冥府神トード

種類：Lユニット

カテゴリ：ダークアライアンス

BP：5000

SP：－

必要パワー：2+

追加条件：自軍コマンドを1つ捨札にする

CN：なし

特徴：冥府神／五武神／男／人型

テキスト：

※これは自軍ラッシュエリアのSユニットを1体捨札にしなければバトルエリアに出られない。

【魂のコレクション】自軍ターン中、これがバトルエリアに出たとき、敵軍パワーゾーンにダメージになっているカードがあれば1枚選び捨札にしてもよい。そうしたとき、敵軍Sユニットを1体選び、持ち主のパワーゾーンにダメージにして置く。

フレーバーテキスト

この世界はマニア垂涎のコレクションアイテムだらけ。神罰執行なんて二の次、三の次。

レアリティ：ノーマル

Q&A

		Q1
		「RS-416 冥府神トード」の効果【魂のコレクション】によって、敵軍Sユニットを持ち主のパワーゾーンにダメージとして置いたとき、「撃破」したものとして扱われますか？
		A1
		いいえ。バトルで勝って撃破するか、「撃破する」という効果の対象にする以外では、「撃破」という扱いにはなりません。
