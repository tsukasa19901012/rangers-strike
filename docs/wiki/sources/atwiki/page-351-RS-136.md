                ランドライオン

種類：Mユニット

カテゴリ：アーステクノロジー

BP：5000

SP：なし

必要パワー：5+

追加条件：自軍Sユニットを1体コマンドゾーンに送るか捨札にする

CN：なし

特徴：メカ

テキスト:

【強襲】これをラッシュしたとき次の効果を発動できる。敵軍バトルエリアからBP8000以下のユニットを1体選び、持ち主のコマンドゾーンにホールド状態で置く。置けなければ捨札にする。

フレーバーテキスト

地上部隊の位置を掴んだ事で、闇の同盟が押えた航空基地への強襲作戦が実行された。

イラストレーター：中北晃二

レアリティ：ノーマル

作品：超獣戦隊ライブマン

収録：三界の獅子　自販：パック

再録1：五龍の激鱗　スターター

再録2：リバイヴァ　自販：パック

カード評価

- ライブロボの合体材料になる前に【強襲】で相手のバトルエリアにいるBP8000以下のユニットをコマンド送りにできる。
- ジェットファルコンのフレーバーテキストは地上部隊を炙り出した事が書かれているが、こちらは地上部隊の位置を掴んだ事で航空基地への強襲作戦が行われた事が書かれている。両者の能力もラッシュエリアからバトルエリアに引きずり出す物と、バトルエリアからコマンドゾーンに送る物でシナジーがある。

- ＢＰも５０００あるのでそのままアタックで相手のユニットを撃破していくこともできるので単体でも十分活躍が見込める。
