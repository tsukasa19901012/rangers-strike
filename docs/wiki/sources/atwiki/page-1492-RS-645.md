                ビクトリーマーズ

種類：Lユニット 

カテゴリ：アーステクノロジー 

BP：11000

SP：1

必要パワー：7+

追加条件：自軍「マーズマシン」1体を捨札にする

CN：なし

特徴：メカ／人型

テキスト：

※これは敵軍常駐置き場のカード1枚につきSP+1される。

【マーズフレア】 自軍ターン中、これがバトルエリアに出たとき、相手は自分自身の常駐置き場からカードを1枚選び（ウラ向きのカードはウラ向きのまま選ぶ）、自分自身のコマンドゾーンにホールド状態で置く。置けなければ捨札にする。

フレーバーテキスト

小惑星が地球に激突？そんな未来は俺達が砕いてやるぜ！

イラストレーター：F.M.U

レアリティ：レア

作品：救急戦隊ゴーゴーファイブ

収録：蒼九の翼 自販：パック

カード評価

- 一見すると敵軍常駐が溜めるタイプのオペレーションであれば、SPが一挙に上昇する強力ユニットであるかのようだが、【マーズフレア】の効力により、相手は常駐置き場からカードを捨札にすることができるため、実際は敵常駐オペレーションを破棄させる能力と捉えても差し障りない。

- SPが上昇する効果が期待されるのはタッグオペレーションを相手が使用している場合か。【マーズフレア】で破棄できるのは1枚だけのため、SP+1が約束される。

- 相手によりSP調整が可能のため、ブラストを警戒する必要もある。この手のユニットに共通して言えることだが、ラッシュしたターンに勝負を決めるよう場を調整したい。
