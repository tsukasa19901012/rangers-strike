                デンライナーレッコウ

種類：Mユニット

カテゴリ：オーバーテクノロジー

BP：5000

SP：－

必要パワー：4+

追加条件：自軍Sユニットを1体パワーゾーンに送る。

CN：なし

特徴：メカ／車両

テキスト：

【フロントアックス】自軍ターン中、これがバトルエリアに出たとき、敵軍バトルエリアからMユニットを1体選び、敵軍ラッシュエリアに戻してもよい。そうしたとき、戻したユニットが特徴「メカ」を持っていなければ、持ち主のパワーゾーンへ送る。

フレーバーテキスト

何や、えらい遠くまで飛んだのう。もっとがっぷり、四つでケリつけたかったんやけどな。

イラストレーター：EGC WORKS

レアリティ：ノーマル

作品：仮面ライダー電王

収録：ザ・マスクドライダーEXP vol.2　自販：パック

カード評価

- キンタロスが担当するデンライナー。パワーもBPもそこそこでラッシュしやすい。

- 【フロントアックス】は相手のＪＣを崩したり、特徴にメカを持たないWBのMユニットに対して効果があるのだが、ライダー環境では対象が少ない。他のデンライナーと違ってライダー環境よりも混合環境の方が活躍出来るユニット。
