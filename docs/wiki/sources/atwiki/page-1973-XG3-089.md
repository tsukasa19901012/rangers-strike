- フレーバーテキストにある「お前」とはブラックビートの事。

- ビーファイターカブトと同様に、マルチカテゴリになって再登場した。1stと比べるとパワーが上がっているが、ロボタフによる効果が強化される他、デンジイエローのロックから抜けられるようになった等、悪いことばかりではない。
