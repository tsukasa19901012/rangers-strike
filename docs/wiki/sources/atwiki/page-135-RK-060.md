                デンライナーゴウカ

種類：Mユニット

カテゴリ：オーバーテクノロジー

BP：6000

SP：－

必要パワー：5+

追加条件：自軍Sユニットを1体パワーゾーンに送る

CN：なし

特徴：メカ／車両

テキスト：

【戦闘モード】これは必要パワーの数字に「－」のあるユニットにアタックするときBP+5000される。

フレーバーテキスト

今回は、随分と大きく遡（さかのぼ）りますねえ―その紳士は、スプーンを動かす手を休めずに言った。

イラストレーター：EGC WORKS

レアリティ：ノーマル

作品：仮面ライダー電王

収録：ザ・マスクドライダーEXP vol.1　自販：パック

再録：ザ・マスクドライダーEXP vol.4　スターター（電王）

カード評価

- ライダー環境では珍しいMユニット。BP6000はライダー環境では強いが混合環境になるともっと強いユニットがいるため埋もれてしまいがち。

- 能力を発動しないと倒せないほどBPが高いユニットは現時点ではギガンデスヘブンやデカマスター（2nd）、レジェンドマジグリーンRAなどが挙げられるが、「－」付きユニットの除去ならば混合ではブラックバイソンがいるため活躍は難しい。良くも悪くもライダー環境でしか活躍が見込めそうにないユニットと言える。
