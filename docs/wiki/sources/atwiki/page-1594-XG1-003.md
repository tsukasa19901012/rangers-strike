                バルイーグル（XG）

種類：Sユニット

カテゴリ：アーステクノロジー

BP：3000

SP：！

必要パワー：2

追加条件：なし

CN：5

特徴：レッド／男

テキスト：

※ウイング

【新飛羽返し】SP1これがバトルで敵軍ユニットを撃破したとき、これが撃破したユニットと同じカード名の敵軍ユニットをすべて撃破する。（この効果はこれがウイングでアタックするときはナンバーに関係なく発動する） 

フレーバーテキスト

気高き鷲がその翼を翻（ひるがえ）すたび、周囲の闇は切り払われ光が射してゆく。

イラストレーター：矢薙じょう

レアリティ：ノーマル

作品：太陽戦隊サンバルカン

収録：クロスギャザー ザ・ファーストエンカウント　自販：パック

Q&A

		Q1
		「XG-003 バルイーグル」はウイングの効果でアタックするときNCの効果をナンバーに関係なく発動することができますが、「これはNCもRCも発動していないSユ ニットにアタックされない」というテキストを持つ「XG-096 ビーファイタークワガー」に対して、ウイングの効果でアタックすることはできますか？
		A1
		いいえ、それはできません。「XG-003 バルイーグル」の「この効果はこれがウイングでアタックするときナンバーに関係なく発動する」とは【新飛羽返し】に書かれた効果を発動するものであり、NC自体は発動していないからです。

カード評価

- ウイング持ちのストライカー。ＢＰも３０００と標準の数値を持っており、ウイング持ちの中では使い易い。ＮＣは戦闘員や「～として使える」というテキストを持つユニットに対して強力な効果を発揮する。

- ＮＣの効果で撃破する同名ユニットを一気に撃破できる。ウイング発動時に効果が発動するので、ラッシュエリアから単体で効果が使えるのが強み。同時にＳＰも付くのでシャドームーンのようなＳＰ持ちとのバトルで強制的に撃破されるユニットとの相打ちも狙える。

- NCを発動した状態でレジスト持ちを撃破しても、直接アタックで撃破されたカードはＮＣの効果で撃破できない。ＮＣの効果が発動するのはレジストを発動する前であり、効果処理の時点では撃破されたカード本人は「撃破された」状態にっているためＮＣの効果による撃破を免れることになる。詳しくはXG公式コラムNO.8を参照。
