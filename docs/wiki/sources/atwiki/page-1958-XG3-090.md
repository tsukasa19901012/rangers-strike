                スーパーブルービート

種類：Sユニット

カテゴリ：ワイルドビースト／アーステクノロジー

BP：5500

SP：1/2

必要パワー：7-

追加条件：自軍「ブルービート」1体を捨札にすれば必要パワー0になる 

CN：なし

特徴：メカ／昆虫／ブルー／男

テキスト：

※レジスト

※これが撃破されて捨札になったとき、自軍捨札から「ブルービート」のカードを1枚選び、自軍ラッシュエリアに出す。 

【スーパーファイナルブロー】 これをラッシュしたとき、次の効果を発動できる⇒ユニット1体につきBP2000として、特徴「昆虫」を持つ自軍ユニットの数分のBPを計算し、そのBP以下の敵軍ユニットを1体選び撃破する。

フレーバーテキスト

俺は変わる！成長、進化する！

イラストレーター：funbolt

レアリティ：スーパーレア

作品：重甲ビーファイター

収録：クロスギャザー　ザ・Wインパクト　スターター専用（インセクトライド）

カード評価

- ブルービートのゾードアップユニット。ラッシュと同時に「ＢＰ（２０００×特徴「昆虫」を持つ自軍ユニット数）の敵軍ユニット」を撃破するという昆虫版ライダーシンドロームとも言える効果を発動出来る。老師グルなどで効果の範囲を広げておきたい。

- 効果の対象となるユニットはサイズを指定されていないため、場に特徴「昆虫」を持つユニットが大量に展開してあればＬユニットすら破壊出来る可能性を持つ。

- また、ユニットの回収能力に優れるETが必然的に必要になるため、自身のブルービートを再ラッシュする能力、レジストなどと組み合わせると非常に場持ちの良いユニットになる。

- ただし、効果の発動はラッシュ時に限られるため、恒久的な場の制圧という点ではブルービートに劣る。ブルービートは現在二種類存在し、それぞれが違う対象を撃破する能力を持つため上手く使い分けたい。

- 上記に関してはバトルコサックとバトルダンスを併用することで効果を恒久的に使うことが出来るようになるが、コマンドが３つ必要になるため多少使いづらい。プロジェクトG4で戻すのも有効。呉越同舟で条件を入れ替えれば、コマンド１枚で効果が使える。

- 余談ではあるが、『ブルービート（XG3）が捨札に存在する時、場のブルービートを捨札にこのカードをラッシュ→効果発動後、何らかの手段でこのカードを撃破する→このカードの効果で捨札のブルービート（XG3）をラッシュする』という手順を踏みブルービートを交換することが出来る。実用的とは言い難いコンボではあるが、参考にしてもらいたい。
