                仮面ライダーサソードRF（ライダーフォーム）

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：2000

SP：！

必要パワー：3+

追加条件：自軍「仮面ライダーサソードMF」1体をパワーゾーンに送る

CN：1

特徴：仮面ライダー／男／加速

テキスト：

※これはバトルエリアの1番目に並んでいないときアタックもストライクもできない。

※これはアタックされる以外では相手に選ばれない。

【頂点に立つ男】このターン、これは自軍パワーゾーンのカード枚数が敵軍パワーゾーンのカード枚数よりも1枚多いごとにBP+1000され、BP5000以上のとき「SP1」になる。

フレーバーテキスト

俺はあいつらとは違う。真にライダーの頂点に立つ男だ！

イラストレーター：K2商会

レアリティ：ノーマル

作品：仮面ライダーカブト

収録：ザ・マスクドライダーEXP vol.4　自販：パック

カード評価

- 【頂点に立つ男】は打点を増やせるため一見強力だが、除去で相手のパワーが増え易いOTの特性上、何も考えずに使うと中々ストライクできない。

- 仮面ライダーパンチホッパー（2nd）などのパワー除去や仮面ライダー電王AF（2nd）のパワー加速を行うなどのテコ入れが必要。BPが低いのでカブトエクステンダーが欲しいか。

- ライダーフォームの中で唯一ナンバーを持っているため、バードニック反応炉の恩恵を受けることができる。

- 相手が仮面ライダーディケイドを使ってパワーを加速させたり、コロンやゼクトルーパーなどで妨害されると、さっぱり仕事ができなくなる。
