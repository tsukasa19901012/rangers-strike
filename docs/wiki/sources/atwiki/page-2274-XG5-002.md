                ゴーグルブラック

種類：Sユニット

BP：3000

SP：－

テキスト：

※タクスET

【ブラックシャドウ】自軍コマンドゾーンから、「ゴーグルブラック」以外の特徴「ブラック」を持つユニットカードを1枚選び、自軍ラッシュエリアに出してもよい。ただし、追加条件は満たすこと。そうしたとき、これを自軍コマンドゾーンにホールド状態で置く。

フレーバーテキスト

暗闇の戦場を走り跳べ、愛を伝える戦士達よ！

イラストレーター：獅子猿

レアリティ：レア

作品：大戦隊ゴーグルファイブ

収録：XG5 ザ・チケットブレイカー　自販：パック

カード評価

- 戦隊ヒーロー初のブラックの名を冠するカードが遂にカード化。色、演者が共通しているダイナブラックと同様、レアでの収録となる。

- 【ブラックシャドウ】は端的に言えば、自身とコマンドゾーンにある特徴ブラック持ちを入れ替える能力。必要パワーを無視できるため、同じETで性能の高いブラックであるボウケンブラックATを引っ張り出すのが適当か。また、他カテゴリのブラック持ちをタッチで入れて運用する事も可能。

- タクスETを持っている点も見逃せない。

- 効果のラッシュはサイズも問わないので、今後ブラック持ちのM・Lユニットが出た場合、活躍の幅は広がると思われる。

- 同じくブラック持ちをゾーンからラッシュする効果を持つゴーカイグリーンと併用する場合はあちらでもラッシュができるカードを採用したい。主にゴセイブラック（XG5）やブラックビート等、打点を増やせる追加条件を持たないカードのラッシュが狙い目になる。
