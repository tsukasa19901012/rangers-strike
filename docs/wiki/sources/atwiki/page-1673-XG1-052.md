                仮面ライダーアギトTF（トリニティフォーム）

種類：Sユニット

カテゴリ：ミスティックアームズ

BP：3500

SP：1

必要パワー：7-

追加条件：自軍「仮面ライダーアギトGF」1体を捨札にすれば必要パワー0になる

CN：なし

特徴：仮面ライダー／男／賢者の石

テキスト：

※これが撃破されて捨札になったとき、自軍捨札から「仮面ライダーアギトGF」のカードを1枚選び、自軍ラッシュエリアに出す。

【ファイヤーストームアタック】これが自軍エリアにある間、相手がターンを終えるとき、次の効果を発動できる⇒そのターン中にホールド状態になった敵軍ユニットを、すべて持ち主の山札に戻してシャッフルする。

フレーバーテキスト

風が炎を巻き上げ、炎が風をより強くする。

イラストレーター：前河 悠一

レアリティ：レア

作品：仮面ライダーアギト

収録：クロスギャザー ザ・ファーストエンカウント　自販：パック

カード評価

- 三位一体の形態のためか、効果もSFの得意とした除去とFFの得意としたストライクの両方ができる。

- 【ファイヤーストームアタック】は主にウイングや仮面ライダーキバGFのようなホールドして発動する効果へのメタとなる能力。ブラックファングや蜂女で相手をホールドすることによって積極的に効果を発動することができる。

- ＳＰ１をもつがＢＰが低めに設定されており、殴り倒され易いのが難点。【ファイヤーストームアタック】はラッシュエリアからでも発動できるので、状況を良く見て使いたい。カウンターやがんがんじいなどを使って守りつつストライクを狙うべきか。
