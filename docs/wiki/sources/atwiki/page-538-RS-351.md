カード評価

- 【ニューレッドビュート】は敵軍ユニットが増えてしまうがバトルエリアに出てくるので使い勝手は悪くない。リリースされているコマンドも対象にとれるのも強み。

- 優秀な能力を持ちながらも、ラッシュしたターンにバトルエリアに出られないデメリットと重いナンバーがネックとなっている。

- アカレッドの効果で使うカードとしてはかなり優秀。どこからでもコマンド除去ができる。
