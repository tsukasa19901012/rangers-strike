カード評価

- 特徴「警察」と「仮面ライダー」を同時に持つユニットの一つ。共同戦線を張れば相手のアタックを封じる事が出来る。また、「メカ」も持っているため、アールジーコとコンビでユニット除去も可能。

- 【バッテリー交換】はトライチェイサーから発動すればコマンドに置いて良いカードなのか判別してから選べるので安心してコマンド加速が出来る。

- ロボコンやオメデトロフィーの登場によりお株を奪われてしまっている。特徴は優秀だが、それだけなら仮面ライダーG3や仮面ライダーG3-Xがいるので、最近ではライダー単環境でなければ活躍はできないか。
