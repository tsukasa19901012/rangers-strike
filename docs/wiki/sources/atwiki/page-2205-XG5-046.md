カード評価

- 条件を満たすまでがやや厳しいものの、条件のSユニットには自身も含まれるため、実質はSユニット4体とLユニット1体でよい。コールMAを持つのでユニットを展開しやすいのも強み。マーフィーK9やゴールドプラチナムなどでSユニットを増やしたり、天空大聖者マジエルや各種冥府神などの追加条件がゆるく必要パワーのかるいLユニットと合わせて早い段階から効果発動を狙っていきたい。

- キリンレンジャーの効果でラッシュフェイズに戻せばもう一度ドロー契機が来る。大量ドローを狙うなら入れる価値あり。「天時星・時間返し」の発動条件である、手札に戻すユニットに、データス自身が当てはまるものの、他のユニットを戻しすぎてSユニット5体が維持できなくては本末転倒なので、再ラッシュに必要な残りコマンドにも注意。
