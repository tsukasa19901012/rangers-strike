種類：Sビークル

特徴：メカ／車両

テキスト：

【サイバリアンレーザースピード】自軍ターン中、これがバトルエリアに出たとき、OTを持つ自軍コマンドを2つホールドしてもよい。そうしたとき、これにライドしているユニットは、このターン、ライドオフしなくてもＲＣの効果を発動できる。

フレーバーテキスト

射出されたサイバリアンに飛び乗ると、彼はそのまま異空間へと飛び込んだ。

イラストレーター：F.M.U

レアリティ：ノーマル

作品：宇宙刑事ギャバン

収録：スペシャルメタルエディション　自販：パック

カード評価

- コマンドをホールドすることでライドオフせずとも能力が使える効果はチェイスを持つ宇宙刑事たちにおあつらえ向きの能力。チェイス発動のために予備のビークルを用意したい。
