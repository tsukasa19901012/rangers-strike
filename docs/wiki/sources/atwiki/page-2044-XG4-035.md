                シンケンゴールド（XG4）

種類：Sユニット

カテゴリ：ミスティックアームズ／アーステクノロジー

BP：4000

SP：1/3

必要パワー：4

追加条件：なし

CN：なし

特徴：ゴールド／男／侍

テキスト：

【モヂカラのプログラム】これが自軍エリアにある間、自軍ラッシュフェイズ中、 ETを持つ自軍コマンドを1つホールドしてもよい。そうしたとき、自軍山札の上から1枚をオモテにし、オモテにしたカードが「特徴」を持つMAのカードなら手札に加え、それ以外なら山札の上か下に戻す。

フレーバーテキスト

おいおい！兄妹揃って言いたい放題言いやがって…見てろよ！

イラストレーター：W.AIAI

レアリティ：スーパーレア

作品：侍戦隊シンケンジャーVSゴーオンジャー 銀幕BANG!!

収録：クロスギャザー ザ・ジェットアクセル　スターター専用（ゾードアップデッキ）

カード評価

- 電子モヂカラを表現したのか、なんとマルチカテゴリでの登場。

- 【モヂカラのプログラム】はドロー能力だが、コマンドのホールドが必要な上にカテゴリ的にも能力発動もETとの混色前提のため、確実性はどうしてもマジブルーなどに劣る。山札の上と下を操作確認できるカードと見ることもできるが、特徴持ちのMAのカードならばドローしなければならず、こちらも確実性に欠ける。

- 一方でコマンドさえあれば何度でもドローまたは山札操作ができる点がこのユニットの旨み。MAの合体ユニットを集めるときなどには関係ないカードをどんどん山札下に送って疑似的な山札圧縮ができるため、たとえ直接ドローできずとも目当てのパーツを引く確率を高められる。

- ただし前のシンケンゴールドが非常に優秀なユニットであるため、そちらを削ってでも入れたいかと言われると微妙なところ。

- フレーバーは同弾収録のゴーオンゴールド（XG4）とゴーオンシルバー（XG4）の兄妹のフレーバーを受けての発言。金属色繋がりか、天空勇者マジシャイン（XG4）もその場にいるようだ。
