カード評価

- 低パワーのレジスト持ち。BPは低いものの、契約モンスターであるボルキャンサーと組めばストライカーにもなる。

- 特徴「警察」を持つのが特徴。このカードの登場で、今までに緑が必要だった共同戦線を使ったロックが赤黄でも可能になった。

- 共同戦線以外にも、仮面ライダークウガPFや仮面ライダークウガなどとのシナジーを赤黄で狙える。使用する際には、これらのシナジーを目当てで使うことが多くなるだろう。
