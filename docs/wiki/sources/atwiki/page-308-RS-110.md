Q&A

		Q1
		「RS-110 デカピンク」の「ゼニボム」が発動したあとで、その「RS-110 デカピンク」が撃破されたり、コンビネーションが崩されたとき、「ゼニボム」の効果は無効になりますか？
		A1
		いいえ、効果は無効になりません。「ゼニボム」の効果は「次の相手ターン」と指定されていますので、一度発動してしまえば、「RS-110 デカピンク」が撃破されても、そのコンビネーションが崩されても、効果は有効になります。
		Q2
		「RS-090 レッドレーサー」は「これはラッシュするとき可能ならバトルエリアに置く」とありますが、「RS-110 デカピンク」の「ゼニボム」の効果でユニットがバトルエリアに出られないときは、ラッシュエリアに置きますか？
		A2
		いいえ、そのようにはなりません。「RS-090 レッドレーサー」の「これはラッシュするとき可能ならバトルエリアに置く」とは、バトルエリアに直接ラッシュする効果なので、【ゼニボム】の「新しく ラッシュエリアに出たユニット」にはあたりません。ですので「RS-090 レッドレーサー」はバトルエリアに置かれます。（2010/10/25修正）

カード評価

- 【ゼニボム】は非常に強力なロック効果。相手がラッシュしたユニットを見てからでもこちらで対策を立てられる余裕が出るのでプレイングが非常に有利になる。

- 倒したいユニットだけデカグリーンなどで引っ張り出したり、ラッシュエリアに留まらせる効果を利用し、仮面ライダーキックホッパーやハリケンブルーの効果の補助を行う事も出来る。

- 9弾でロック効果がさらに強化されたデカピンクSWATが収録された。

- パワー0から使える軽さ故に手軽にロックをかけられ、初期のカードでありながら未だに現役で頻繁に使われ続ける優秀なユニット。特にOT絡みのコントロールデッキでは、このカードで相手の反撃を防ぎつつ上記のようにレッカーやラッシュエリアのユニットを撃破できるカードでユニットを撃破していく戦術がよく取られる。

- ウイングの登場でラッシュエリアからこのカードにアタックできるようになったのでロックから抜け易くはなったが、依然として強力なカードである。
- 仮面ライダー龍騎（XG2）や変幻鎧将ビーザックなどである程度はウイングに対抗することができる。
