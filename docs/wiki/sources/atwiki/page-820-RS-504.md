カード評価

- 自軍のコマンドを操作する効果を持つシステムユニット。

- 自軍コマンドを減らす効果は黒獅子リオやアバレブラックのようなコマンドが無い状態で強力な効果を発揮するユニットと相性が良い。強制的にコマンドを埋められた時の救済にも使える。
- 自軍コマンドがあるとストライクできない黒獅子リオのストライクを補助できる。

- アバレブラックと組む事で相手のコマンドを一掃可能。気力やダッシュレオンの能力の効果をフルで活用しづらくするほか、多色で組んでいる相手にはかなりキツイ制限となる。

- 捨札で発動する効果を持つ仮面ライダーG4（XG6）のサポートにも使える。あちらの効果で減ったコマンドをこちらで補充することができるので相性は良い。

- 自軍コマンドが無い状態だと捨て札からリリース状態のコマンドを補充できる。黒獅子リオなどの補助を行うためにコマンドを空にした後やコマンドを捨て札にする追加条件を持つ冥府神をラッシュした後にコマンドを回収するのに使える。

- 自軍のコマンドの数が０～１枚の状態になるため２色デッキだと片方のカテゴリのコマンドしか残せない。マルチカテゴリをコマンドに置きたい。

- コマンドを０～１枚しか置けないため独自のプレイングが求められるがそれを補ってアバレブラックや黒獅子リオとの強力なシナジーを持つためメレスラスターと呼ばれるデッキの中核となっている。
