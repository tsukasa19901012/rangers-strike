カード評価

- メタルエディションからの新ルール「チェイス」を持つ元祖宇宙刑事。

- ストライク面でのデメリットによって他のユニットとは異なるプレイングを強いられることになるが、Mサイズ以上のユニットが中心のデッキに組み込んだり、味方のSユニットが除去されてから使用を開始するといったように相応の工夫をすれば、バトル後半にかけてかなりの強ユニットへと化ける。

- ナンバーに関係なくストライクが可能な上に、何よりチェイスの能力によって自軍のビークルの数だけ除去を逃れる事ができる為、実際のバトルではかなりしぶとく生き残る。

- また、高BPのSユニットを除去するRCの能力も強力である。原作のパートナーである電子星獣ドルに乗ればライドオフするだけでダメージを与える事ができるので、味方のSユニットがいる間のストライクの代わり、またはギャバンがストライク可能となった状態でライドオフ＞ダメージ1点＞RC効果で除去＞ストライクと一気に打点と除去をこなすこともできる。

- 電子星獣ドル（XG2）の登場でチェイスを発動させることで、敵軍ターン中に除去が狙えるようになった。これによって、電子星獣ドル（XG2）によるこのカードへの除去に対しての抑止力を活かしてのプレイングも可能になった。

- ライド状態を解除できる上に、BPで相打ちを取られる可能性のあるメタルゲラスに注意。
