                ダイアナレディ

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：1000

SP：1/4

必要パワー：3

追加条件：なし

CN：なし

特徴：メカ／女

テキスト：

【レディスナイパー】このユニットからコンビネーションするOTを持ち特徴「男」を持つSユニットは、このターン、次の能力を得る⇒BP+2000され、ナンバーにＲＣを持っていれば、ライドオフしなくてもその効果を発動できる。

フレーバーテキスト

たった二人の力だが、互いの絆がそれを何倍にも強くする。

イラストレーター：Mがんぢー

レアリティ：ノーマル

作品：時空戦士スピルバン

収録：クロスギャザー ザ・ファーストエンカウント　自販：パック

カード評価

- BP上昇と同時にRC発動をサポートするユニット。OTの男限定だが相棒のスピルバンや電王勢、チェイス持ちの宇宙刑事たちなど強力なユニットとの相性が良いのであまり気にならない。呉越同舟でOTを追加すれば他のカテゴリのユニットでも当然可能。

- 反面、自身の性能は低いので一度サポートした後はすぐに敵ターンでやられてしまう事も多い。潔く玉砕覚悟で出すべきか。

- 使い捨てたくない場合はミスアメリカやプロジェクトG4の効果で守るなり、撃破された後で捨札から回収する手段が必要。

関連カード
