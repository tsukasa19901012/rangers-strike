                ベン・G

種類：Sユニット

カテゴリ：ダークアライアンス

BP：3000

SP：－

必要パワー：4

追加条件：なし

特徴：メカ／男

テキスト：

【人身略取】自軍ターン中、これがバトルエリアに出たとき、自分の手札から追加条件を持つMユニットのカードを1枚選び捨札にしてもよい。そうしたとき、相手は自分自身がそのカードの持ち主であるかのように、そのカードの追加条件を可能なら満たす。

カード評価

- 【人身略取】は通常の除去と違い追加条件扱いなのがミソ。仮面ライダーディケイドCFなどが除去耐性を発揮してエリアに留まった場合、条件は満たされていないので効果を解決したことにできない。そのため相手は再び対象を選ばなければならず、結果耐性に関係なく除去を行うことができる。

- ETやOTのMユニットを捨札にすると相手にアドバンテージを与えることになる。また、条件を満たすためのユニットは相手が選ぶので、使いどころはかなり慎重に選ぶ必要がある。

- バイオジェット2号を捨札にする事で一気に3体除去できる。
