                アバレブルーAM（アバレモード）

種類：Sユニット

カテゴリ：ワイルドビースト

BP：4500

SP：！

必要パワー：7-

追加条件：自軍「アバレブルー」1体を捨札にすれば必要パワー0になる

CN：2

特徴：ブルー／男／アバレモード

テキスト：

※これが撃破されて捨札になったとき、自軍捨札から「アバレブルー」のカードを1枚選び、自軍ラッシュエリアに出す。

【アバレタックル】「SP1」

フレーバーテキスト

もう好きにしろ。こっちも好きにやらせてもらう！―ひと皮剥けば、似た者同士。 

イラストレーター：K2商会

レアリティ：ノーマルレア

作品：爆竜戦隊アバレンジャー

収録：四雄の覚醒　自販：パック

再録：リバイヴァ　自販：パック

再録2：クロスギャザー ザ・ファーストエンカウント　スターター（パワーアップ）

カード評価

- ＢＰが高く序盤に出せれば相手にストライクするために出したユニットへのアタックを躊躇させる事ができる。

- アバレブルーを捨札にして序盤に出せれば強いが、手札にこれしか来ないとどうしても腐ってしまう。チャージにまわすか揃うのを待つかはあらかじめ考えておきたい。
