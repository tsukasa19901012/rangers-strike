※常駐（場に配置して、離れるまで効果が有効になる）

カテゴリを2つ以上持つSユニットのうち、MAを持つSユニットは次の能力を得る⇒このユニットは敵軍ターン中BP+1000され、MAのオペレーションカードを使用するためのコマンドとしてホールドできる。

強き魂と清き心を持つ者達よ、今こそ天使の技を見せる時！

カード評価

- マルチカテゴリかつMAのSユニットに2つの能力を追加する常駐オペレーション。自分だけでなく相手も効果の対象になっている。

- ｢敵軍ターン中にBP+1000され、」と｢MAのオペレーションカードを使用するためのコマンドとしてホールドできる。｣は独立した効果である事が公式のコラムで明言されている。よって、これの対象になっているSユニットは、自軍ターン中もオペレーションカードを使用するためのコマンドとしてホールドできる。

- 闇のヤイバと併用すれば特徴「男」を持つMAのSユニット全てを対象に出来る。ただし敵軍ユニットの対象も広げてしまう点に注意。

- このカードで与えられる効果はリードMAと同じ物だが、リードそのものではないため、リードを参照する効果には使えないので注意。
