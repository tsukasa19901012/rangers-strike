                メガヘラクレス

種類：Lユニット

カテゴリ：ワイルドビースト

BP：6000

SP：！

必要パワー：5

追加条件：なし

CN：なし

特徴：メカ／昆虫

テキスト：

※これは自軍コマンドを1つホールドしなければバトルエリアに出られない。 

【メガビートフォーメーション】これは、自軍エリアに「ビートルーダー」があれば「SP1」になり、「スタッガータンク」があればBP+3000され、「レッドジャイロ」があればレジストを得る。 

フレーバーテキスト

地響きと共に現れた巨大な角を持つ甲虫は、悠然と戦場へ歩を進めた。

イラストレーター：矢薙 じょう

レアリティ：ノーマルレア

作品：重甲ビーファイター

収録：スペシャルメタルエディション　自販：パック

再録：クロスギャザー ザ・ジェットアクセル　スターター（ライディングデッキ）

カード評価

- ラッシュの追加条件が無い割に強力なLユニット。ビートルーダーなどビートマシンありきの環境でしか活躍出来ないが、ビートマシンが全て揃った時のその強さと使い勝手はかなりの物。LユニットなのでＪＣが出来るのも強み。

- パワーアップの源のビートマシンがMビークルなので、除去によるパワーダウンはまずない。どのビートマシンと組んでも強力で、どの組み合わせが最適なのかプレイヤーによって意見が分かれるほど。
- スタッガータンクが2枚以上いてもBPは9000なので注意。

- 各種ビートマシンはソルインジケーターで、このカードはバトルシャークでサーチできる。複数のメガヘラクレスが並ぶ状況も作りやすい。

- バトルエリアに出るときのデメリットがあるためコマンド除去には弱い。コマンド加速や獣奏剣、ゴーゴーファイヤーがあると安定して活躍できる。
