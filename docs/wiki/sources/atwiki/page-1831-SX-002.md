                仮面ライダークウガRU（ライジングアルティメット）

種類：Sユニット 

カテゴリ：ミスティックアームズ／ダークアライアンス

BP：7000

SP：1

必要パワー：7+

追加条件：カード名に「クウガ」を含む自軍ユニット1体を捨札にする

CN：なし

特徴：仮面ライダー／男／アマダム／ライジング

テキスト：

※レジスト

【黒い瞳に映るもの】これが自軍バトルエリアにある間、特徴「仮面ライダー」を持つユニットは、アタックかストライクを選ぶとき、可能ならアタックを選ぶ。

フレーバーテキスト

その瞳は究極の闇に染まり、もはや光を飲み込むのみ。

イラストレーター：K2商会

レアリティ：シークレットレア

作品：劇場版 仮面ライダーディケイド オールライダー対大ショッカー

収録:クロスギャザー ザ・ドラゴンタイガー　自販：パック 

カード評価

- 仮面ライダークウガUFと違い特に除去耐性はないが、追加条件は緩く各種ライジングフォームからモーフすることもできるため、格段に出しやすい。BPも7000でアタック制限なしとSユニットとしては破格の値。

- 【黒い瞳に映るもの】は仮面ライダー限定でストライクを強制的にアタックに変更する効果。ただし敵軍バトルエリアにユニットがあると自身もストライクできないため注意。
- 効果はあくまでも「アタックかストライクを選ぶとき」なので、シノビドグラーやキンタロス（2nd）とは違い「何もしない（＝アタックもストライクも行わない）」という選択が可能。

- 前述のように耐性がないが、パワーやコマンドに飛ばされてもモーフで再利用でき、黄黒であることを生かしてシュードランと組めばやられてもライジングフォームのクウガがいるかぎり延々と使い続けられる。
