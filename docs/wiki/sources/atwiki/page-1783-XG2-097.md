                ビーファイターゲンジ

種類：Sユニット

カテゴリ：ワイルドビースト／アーステクノロジー

BP：3000

SP：－

必要パワー：2

追加条件：なし

CN：3

特徴：メカ／昆虫／男

テキスト：

【ライトニングキャノン】自軍コマンドゾーンから、カテゴリを2つ以上持つカードを1枚選び、自分の手札に戻してもよい。そうしたとき、戻したカードの持つカテゴリと同じカテゴリを1つ以上持つ敵軍Sユニットを1体選び撃破する。

フレーバーテキスト

機械の力も素晴らしいが…それは人間の力と心があってこそだ。

イラストレーター：Nottsuo

レアリティ：ノーマル

作品：ビーファイターカブト

収録:クロスギャザー ザ・ドラゴンタイガー　自販：パック

カード評価

- マルチカテゴリのコマンド回収とSユニット除去の効果を持つSユニット。

- コマンドにあるマルチカテゴリの回収が主な使い方。コマンド加速と組み合わせることでドローソースとしても使える。

- コマンドを回収した際に同じカテゴリを一つ以上持つSユニットを撃破できるが、ETとWBのマルチカテゴリなので、主に撃破できるのはWBとETになるだろう。他のカテゴリのユニットを撃破したいなら、モーフからラッシュできる仮面ライダーW・LJやパワーから直接ラッシュできる宇宙忍デモストをタッチで入れよう。
