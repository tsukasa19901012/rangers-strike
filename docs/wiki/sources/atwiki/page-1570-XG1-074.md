                仮面ライダーザビーRF（ライダーフォーム）（XG）

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：3000

SP：1/4

必要パワー：3+

追加条件：自軍「仮面ライダーザビーMF」1体をパワーゾーンに送る

CN：なし

特徴：仮面ライダー／男／加速

テキスト：

※レジスト

※これはアタックされる以外では相手に選ばれない。

【俺はもっと大事なものを見つけた】これが自軍エリアにある間、これ以外の自軍ラッシュエリアのユニットはアタックされない。

フレーバーテキスト

彼は気付いてしまった。組織に囚われていては守れないモノがある事に。

カード評価

- 【俺はもっと大事なものを見つけた】はラッシュエリアのユニットをグリフォーザーなどから守る能力。ただし現状ラッシュエリアにアタックできるユニットは非常に限られており、またアタック以外の対象には選ばれてしまうため、各種RFの保護以外の用途には向いていない。
