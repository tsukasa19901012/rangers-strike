                ピンクエイダー

種類：Mユニット

カテゴリ：アーステクノロジー　

BP：4000

SP：－

必要パワー：3+

追加条件：自軍Sユニットを1体コマンドゾーンに送るか捨札にする

CN：なし

特徴：メカ／車両

テキスト：

【緊急車両誘導】これをラッシュしたとき、ライドされていないSビークルがあれば、すべて持ち主の山札の下に好きな順で戻してもよい。

フレーバーテキスト

それが救急車の仕事かどうかはともかく、大渋滞を一気に解消する手際に拍手が起こった。

イラストレーター：キクチヒラメ

レアリティ：ノーマル

作品：救急戦隊ゴーゴーファイブ

収録：紅き六戦士の帰還　自販：パック

カード評価

- ラッシュ時にライドされていないビークルを全て除去する効果を持つ。

- ＲＣやチェイスを主軸にしたデッキへのメタカード。ビークル除去のできるカードの中ではサイコローダーと並んで最も軽い。追加条件もSユニット１体をコマンドに送るだけなのでデッキに組み込みやすく、他のビークル除去と違いラッシュ時に効果が発動するため使い勝手は良い。

- 当然相手がビークルを使ってなければ腐ってしまうがそれでも刺されば相手の展開を大きく遅らせることができる。周りのメタ次第では十分な活躍が見込めるだろう。
