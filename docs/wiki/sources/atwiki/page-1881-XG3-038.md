                イカダイカイオー

種類：Lユニット

カテゴリ：ミスティックアームズ

BP：10000

SP：1

必要パワー：7+

追加条件：自軍合体ユニットを捨札にする

CN：なし

特徴：侍／人型／ 電子モヂカラ

テキスト：

合体―ダイカイオーヒガシ+烏賊折神

【槍烏賊突貫】これをラッシュしたとき、BP5000以下の敵軍ユニットを1体選び、持ち主の手札に戻してもよい。そうしたとき、相手は自分自身の手札を1枚選び捨札にする。

フレーバーテキスト

法螺貝の音も勇ましく、天下無双の槍捌き。

イラストレーター：JUN YAMAGUCHI?

レアリティ：スーパーレア

作品：侍戦隊シンケンジャー

収録：クロスギャザー ザ・Ｗインパクト

カード評価

- ラッシュ時に敵軍ユニットの除去と手札破壊の効果を発動するLユニット。

- 合体ロボであるが各種ダイカイオー（ヒガシ、ニシ、ミナミ）からモーフすることで、追加条件を無視してラッシュすることができる。

- 【槍烏賊突貫】はラッシュ時に敵軍ユニットの除去と手札破壊が行える。モーフで敵軍ユニットのラッシュに対応してラッシュできるので、カウンターのような使い方ができる。

- ただしこれ自体はモーフを持っておらず一方通行になるので、使いどころは慎重に。
