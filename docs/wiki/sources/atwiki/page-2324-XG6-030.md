                ネオショッカー大首領

種類：Lユニット

カテゴリ：ダークアライアンス

BP：4000

SP：1

必要パワー：5

追加条件：なし

CN：なし

特徴：ネオショッカー／獣／ドラゴン

テキスト：

※これは自軍コマンドを1つホールドしなければバトルエリアに出られない。

※これは敵軍ターン中、ウイングを持つユニットとバトルしたときバトルに勝っても撃破される。

【唯一の弱点】これは自軍コマンドがすべてホールド状態なら、敵軍Sユニットにアタックされない。 

フレーバーテキスト

邪悪な気配の中心へとたどり着いた時、彼らは爛々と赤く輝く瞳に地獄の炎を見た。

イラストレーター：K2商会

レアリティ：レア

作品：仮面ライダー（新）

収録：クロスギャザー ザ・ギガンティックタイタン

カード評価

- 必要パワー5でSP1かつLユニットなのでクウガゴウラムなどの対象にならないという高スペックなユニット。シャドームーン等同パワーのDAユニットと比べるとBPはやや低めだが、制限やデメリットが格段に緩く、ストライカーとして用いるなら気にならない。

- 【唯一の弱点】は自身やWBのMユニットの持つデメリット、ヘルサターン総統の効果などで発動を容易にできる。
- 当然のことながら、自軍コマンドが0枚のときは効果を発動できない。

- 特徴に「獣」と「ドラゴン」を持つため参照するカードは多い。ファルコンサモナー、ユナイトベント、仮面ライダー龍騎、チェンジドラゴンあたりは活用できる。
