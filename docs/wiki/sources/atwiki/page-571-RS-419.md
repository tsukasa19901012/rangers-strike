                聖剣ズバーン

種類：Sユニット

カテゴリ：ミスティックアームズ

BP：4000

SP：－

必要パワー：5+

追加条件：自軍｢大剣人ズバーン｣を1体捨札にする

テキスト：

※これはSユニットかLユニットからコンビネーションしなければバトルエリアに出られない。

【ゴールデンクラッシュ】これがDA以外のユニットからコンビネーションするとき、次の効果を発動できる⇒コンビネーションしたユニットよりもBPの低い敵軍ユニットを1体選び、持ち主のパワーゾーンにダメージにして置く。

Q&A

		Q1
		「RS-419 聖剣ズバーン」はナンバーに「R」を持ちますが、その効果を「RS-263 タンクコマンド」の効果で発動させなくすることができますか？
		A1
		数字のコンビネーションは「ナンバーコンビネーション」、RCを持つ ユニットのコンビネーションは「ライディングコンビネーション」、LやRを持つユニッ トのコンビネーションは「ジョイントコンビネーション」というように分けられますが、「RS-263 タンクコマンド」で発動できなくなるのは「ナンバーコンビネーション」ですので、それ以外のコンビネーションは問題なく発動することができます。
		Q2
		「RS-419 聖剣ズバーン」のコンビネーションしたSユニットまたはLユニットが、ダークアライアンスとそれ以外のカテゴリの両方を持っていた場合、「ゴールデンクラッシュ」の効果を発動することはできますか？
		A2
		は い、できます。この場合、コンビネーションしたユニットのカテゴリは、「ダークアライアンスであり、DA以外でもある」ことになりますが、「ダークアライ アンス以外のユニットからコンビネーションした」として、その効果を発動できることになります。また、レンジャーズストライクでは、「できる」という効果 と「できない」という効果では否定文である「できない」とある効果を優先するルールがありますので、例えば「ダークアライアンスのユニットからコンビネー ションするときは、次の効果を発動できない」と書かれていたなら、その効果を発動できないことになります。

※注釈：公式コラムvol44により以下解説の内容でルール整理
「ＤＡ以外の」ということは、「ＤＡを持たない」ことが条件になりますので、例えばこのユニットが「ＤＡ」と「ＭＡ」の２つのカテゴリを持っている「RS-166 ガインガイン」からコンビネーションしても、この効果を発動できません。

カード評価

- ジョイントコンビネーション持ちのユニットであるにも拘らず、DA以外のカテゴリとならどこでもよく、なおかつSユニットともコンビネーションできる変わったユニット。
- ちなみにコンビネーションするユニットがDAとそれ以外のカテゴリを持つ場合は発動不可。

- 聖剣と名前にあるように武器なので一人でバトルエリアにも出られずアタックも出来ない。その代わり、コンビネーションしたユニットよりBPが低い敵ユニットをダメージに出来るので、一つ前に並んだユニットが追加でアタック+ストライクを行ったような感じになる。

- SユニットなのでタクスMAを持ったSユニットを2番目、これを3番目に持ってくれば更にストライクも可能。

- 前述したとおり、DA以外ならカテゴリを問わずSユニットからでもコンビネーションできるし、ダメージ送りにするユニットもエリアを問わないので使い勝手は良好。問題はラッシュに少々手間がかかる点だが、そこで同作品のゴーゴージェットの出番。追加条件を無視して山札から直接ラッシュできるため、とても相性がいい。
