                バトルジャパン（XG）

種類：Sユニット

カテゴリ：アーステクノロジー

BP：3000

SP：！

必要パワー：2

追加条件：なし

CN：5

特徴：レッド／男

テキスト：

【空手技】「SP1」レジストを持つ敵軍Sユニットを1体選び、持ち主のコマンドゾーンにホールド状態で置く。置けなければ捨札にする。

フレーバーテキスト

混沌とした戦場を舞い踊るかの身軽さで潜り抜け、繰り出す技は一撃必殺。

イラストレーター：タカヤマトシアキ 

レアリティ：ノーマル

作品：バトルフィーバーJ

収録：クロスギャザー ザ・ファーストエンカウント　自販：パック

カード評価

- 【空手技】は同じくＳユニット除去のＮＣを持つゴーイエローと比べて対象は限られてくるが、ラッシュエリアに届くのが強み。

- アントロードで特徴「女」の敵軍ユニットにレジストを付与して除去するというコンボが可能。
