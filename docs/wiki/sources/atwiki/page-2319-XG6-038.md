                仮面ライダーアクセルトライアル（XG6）

種類：Sユニット 

カテゴリ： アーステクノロジー

BP：2500

SP：1

必要パワー：7－

追加条件：「仮面ライダーアクセル」を１体コマンドゾーンに送るか捨て札にすれば必要パワー0になる

CN：なし

特徴：仮面ライダー／男／警察／アクセルドライバー／加速

テキスト：

※これはアタックされる以外では相手に選ばれない

【マシンガンスパイク】自軍ターン中、これがバトルエリアに出たとき、自軍山札の上から3枚まで捨て札にしてもよい。そうしたとき、捨札にしたカードの必要パワーの数字の合計が10未満なら、その数字以下の必要パワーの数字を持つ敵軍バトルエリアのユニットを１体選び撃破する。10以上なら、これを撃破する。

フレーバーテキスト

復讐の闇を振り切って手に入れたのは、大切な者を守る為の１０秒間。

イラストレーター：ASATOSHI(Layup)

レアリティ：レア

作品：仮面ライダーW

収録：クロスギャザー　ザ・ギガンティックタイタン

Q&A

		Q1
		「XG6-038 仮面ライダーアクセルトライアル」の効果【マシンガンスパイク】を実行する際、山札の上からカードを捨札にする前に、何枚捨札にするのか宣言しておく必要はありますか？
		A1
		いいえ、その必要はありません。

カード評価

- 各種RFと同じアタック以外で相手に選ばれない効果を持つ。特徴に恵まれており、カブトエクステンダーにライドできるだけでなく、共同戦線の維持にも最適。組み合わせてかなりのアタックを封殺できる。

- 【マシンガンスパイク】は自滅の危険がある能力だが、捨てる枚数を宣言する必要はないため、パワーの合計が危なければ1枚目や2枚目を捨てた時点で処理を止めることもできる。
