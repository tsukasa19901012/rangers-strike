                ビクトリーロボ

種類：Lユニット

カテゴリ：アーステクノロジー　

BP：12000

SP：1

必要パワー：7+

追加条件：自軍合体ユニットを捨札にする

テキスト：

合体―レッドラダー＋ブルースローワー＋グリーンホバー＋イエローアーマー＋ピンクエイダー

【人の命は地球の未来】これはストライクするとき、このターン中に自軍捨札から手札に加えたSユニットのカード1枚につきSP+1される。

（1）「XG2-041 スーパーシンケンイエロー」をバトルエリアの1番目に出し、【真・土煙の舞い】を発動。
（2）「XG2-041 スーパーシンケンイエロー」を敵軍ユニットにアタックさせ、故意にバトルで敗北させる。
（3）撃破されて捨て札となった「XG2-042 スーパーシンケンイエロー」を【真・土煙??を再度ラッシュ。
この（1）〜（3）を繰り返す事により、「RS-382 ビクトリーロボ」は【人の命は地球の未来】によりSP＋1の効果を繰り返し得ることができますか？
		A1
		はい、できます。
		Q2

		A2

カード評価

- Sユニットを回収すればするほどSPが高くなるぶっ飛んだカード。ゲームエンド級の最大ダメージも期待できるが、そこまでするならゴーレッド、ゴーブルー、ゴーピンク、スーパーレスキューあたりを揃える必要がある。出るのはゲーム終盤なので、そんなに頑張る必要はないが。

- レッドラダーのラッシュからでも十分なダメージが期待できる上に手軽なのでそちらをオススメ。

- ライフバードを張って他のユニットでストライクしつつ捨札を回収し、トドメにビクトリーロボが締めるという戦法もありか。

- マーズマシンを特攻させれば、SP+5という破格のSPを取得できる。あくまで夢やロマンの類のコンボだが……。

- スーパーシンケンイエローが自爆特攻を繰り返すことで無限にSPを上げることができる。ビクトリーウォーカーの登場でスーパーフォーメーションによる合体もより行いやすくなり、あながち夢でも無くなってきた。
