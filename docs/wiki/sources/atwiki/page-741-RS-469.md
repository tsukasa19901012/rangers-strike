                ギンガベリック

種類：Mビークル

カテゴリ：ワイルドビースト　

必要パワー：2

追加条件：なし

特徴：獣

テキスト：

※特徴「イエロー」を持つSユニットは、自軍コマンドを１つホールドすれば、ＲＣを持っていなくてもこのビークルにライドできる。

【雷の星獣】これにライドしたユニットがある間、次の効果を発動する⇒自軍バトルフェイズ中、MAの自軍コマンドを1つホールドするかわりに、敵軍コマンドを1つ選びホールドしてもよい。

フレーバーテキスト

轟音と破壊そして一瞬の静寂。まるで稲光のようなその獣は一瞬で走り去った。 

イラストレーター：矢薙じょう

レアリティ：ノーマルレア

作品：星獣戦隊ギンガマン

収録：七忍の炎陣　自販：パック

再録：蒼九の翼　スターター(type 2：合体ロボデッキ)

カード評価

- 自軍MAコマンドの変わりに相手のコマンドをホールドすることができる。自軍コマンドをホールドする効果が使い易くなる。相手のコマンドを使う事で気力やカウンターを封じることもできる。

- MAコマンドに限らず、自軍バトルフェイズ中にコマンドをホールドする必要のある効果は、カテゴリが特定されていない限り全て相手に肩代わりさせることができる。

- コマンドをホールドする様々なカードとのコンボが狙える。
- メタルゲラスを自軍コマンドのホールド無しでバトルエリアに出せるようになる。

- ギンガイエローや仮面ライダースーパー1のようなMAコマンドのホールドをMA無しで使用できるようになる。

- プテラレンジャーなどのホールドされたコマンドを対象にした効果の発動。

- 2008/07/30のルール改定より前はMAのコマンドが必要だった。ルール改定により「～するかわりに」という効果は「～」が実行不可能でも使用可能になったので、MAコマンドが自軍に存在しなくてもこの効果は発動できるようになった。
