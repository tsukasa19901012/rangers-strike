テキスト：

【BILLGOLDY FOR EVIL】自軍ターン中、これがバトルエリアに出たとき、自軍ゾーンのオモテ向きのカードがすべてDAを持つなら、本来のBPが5000以下の敵軍ユニットを1体選び撃破する。 

フレーバーテキスト

これは心を捨てて得た力だ。中途半端なお前が勝てると思っているのか？

イラストレーター：中北晃二

レアリティ：スーパーレア

作品：特捜ロボジャンパーソン

収録：クロスギャザー ザ・ジェットアクセル　自販：パック

カード評価

- 【BILLGOLDY FOR EVIL】は黒単のデッキでないと発動が難しいがエリア・サイズを問わない除去効果は強力。マジマザーのようなラッシュエリアに引きこもるユニットやキングライナーのようなアタックでの撃破が難しいユニットの撃破に活躍する。
- 強制効果なので、条件を満たしていれば必ず発動しなければならない点には注意。

- 混色デッキの場合は害地大臣ヨゴシュタインでコマンドにDAを追加すると使いやすくなる。パワーゾーンにDA以外のカードが行ってしまった場合はダメージで上手く調節しよう。

- 除去効果だけでなく素のスペックも優秀。加えて特徴「メカ」を持っているので凱聖バルスキーで使いまわせる。

- ジャンパーソン（XG4）と組絵になっている。
