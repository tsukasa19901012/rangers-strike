                リュウキドラグレッダー

種類：Sユニット

カテゴリ：ワイルドビースト

BP：5000

SP：－

必要パワー：5+

追加条件：自軍「仮面ライダー龍騎」1体を手札に戻す

CN：なし

特徴：獣／ドラゴン／FFR

テキスト：

※自分が「仮面ライダー龍騎」をラッシュしたとき、自軍エリアに「リュウキドラグレッダー」があれば1体選んで手札に戻す。

【ファイナルアタックライド】このユニットからコンビネーションする、「仮面ライダーディケイド」または「仮面ライダーディエンド」は、次の能力を得る⇒BP+3000

フレーバーテキスト

独りで戦っているのでは無い。それに気が付いたとき、彼は龍へと姿を変えた。

イラストレーター：JUN YAMAGUCHI

レアリティ：ノーマルレア

作品：仮面ライダーディケイド

収録：クロスギャザー ザ・ドラゴンタイガー　自販：パック

カード評価

- 姿は似ているが、ドラグレッダーとは別のユニット。特徴「ミラーモンスター」も持っていないので、ミラーライダー達とは特にシナジーがない。

- 追加条件がある代わりに、本物のドラグレッダーとは違いコマンドをホールドしなくてもバトルエリアに出られる。BPもアタッカーとして申し分ない。必要パワーが重いのが難点か。

- 能力は本家と比べ仮面ライダーディケイドまたは仮面ライダーディエンド専用になった代わりに、上昇幅は大きくなっている。ディケイド 龍騎からでもゾードアップできるので、ディケイドメインのデッキにも採用は可能。

- XG2までは直接的なアタックには向かない性能の両ライダーだったが、XG3に収録されたディケイドとディエンドでなら噛み合うようになった。BP上昇のためだけにわざわざ入れる価値があるかは微妙なところだが、以前よりは活躍できるだろう。

- ドラグレッダーと違い、自軍ターンしかＢＰが上がらなくなってしまっているのも地味に痛い。
