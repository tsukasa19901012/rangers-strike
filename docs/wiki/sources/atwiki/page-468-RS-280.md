                レッドホーク

種類：Sユニット

カテゴリ：アーステクノロジー

BP：2000

SP：！

必要パワー：2

追加条件：なし

CN：5

特徴：レッド／男

テキスト：

※これは、自軍バトルフェイズを終えるときのバトルエリアでの並び順が、カードに表記された本来のナンバーと違うなら、自分がターンを終えるとき、手札に戻す。

【ウィングガントレット】「SP1」自軍ターン中、これはBP＋2000される。

フレーバーテキスト

男から全ての迷いが消えた時、拳には真実の愛を貫く強さが宿っていた。

イラストレーター：小城 崇志

レアリティ：レア

作品：鳥人戦隊ジェットマン

収録：五龍の逆鱗　自販：パック

カード評価

- ジェットマン勢全員に言えることだが、素のBPが低くやられやすい欠点があるため、使用するならバードニック反応炉やバードニックウェーブを使用してやられにくい環境を整える必要がある。

- 5番以外に並んでいると手札に帰る特性を利用して、毎ターン安全にオメデトロフィーを発動するというコンボがある。

コメント

-  バードニックウェーブと似た効果を持つ能力・クロスの登場でNCを使いつつ手札に戻るのが簡単に出来るようになった。  -- 名無しさん  (2011-04-29 10:26:07)

-  自軍ターン中BPが上昇する効果がガオレッドと同じ。  -- 名無しさん  (2011-04-29 17:32:04)

-  タイミングの項目にもありましたが、これがバトルエリアに二体いて、それぞれ並び順がナンバーと違うなら、どちらか一体しか戻せないのですか？処理の仕方を教えて下さい。  -- 名無しさん  (2020-02-29 10:35:00)

-  ↑その場合、どちらか1体しか戻せないということはありません。バトルフェイズ終了時の並び順を確認して、ナンバーと並び順が違えば2体とも手札に戻します。
タイミングの項目で触れられているのは、並び順がナンバーと違うレッドホーク（Aとする）と、並び順がナンバーと同じレッドホーク（Bとする）の2体がいる場合に、Aを効果で戻した後にBの並びがずれても並び順を参照するタイミングは終わっているため、Bが手札に戻ることはないということを言っています。  -- 名無しさん  (2020-02-29 12:08:56)

-  確定してズレたレッドホークのことだったのですね。ありがとうございます。  -- 名無しさん  (2020-02-29 13:19:30)
