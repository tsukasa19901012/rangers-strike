                ダイナブラック

種類：Sユニット

カテゴリ：アーステクノロジー　

BP：4000

SP：！

必要パワー：5

追加条件：なし

CN：5

特徴：ブラック／男／忍者

テキスト：

※これが自軍コマンドゾーンにある間、自軍ラッシュフェイズ中、自軍捨札の枚数がこれの必要パワーの数字以上なら、これを自軍ラッシュエリアに出してもよい。 

【忍術の備え】「SP1」　自軍捨札からカテゴリにMAを持つオペレーションカードを1枚選び手札に加えてもよい。

フレーバーテキスト

星空を見上げ、抱き続けた夢。この戦いが終わるまで、今は心に忍ばせる。 

イラストレーター：Takeshi Mohri

レアリティ：レア

作品：科学戦隊ダイナマン

収録：七忍の炎陣　自販：パック

カード評価

- ETの貴重な忍者ユニット。パワーは5と重めだが、能力によってコマンドゾーンからラッシュが出来るのであまり気にはならない。

- MAのオペレーションのサルベージが出来る珍しい能力を持っている。コマンドゾーンからのラッシュができるので、MA単色のデッキにもタッチで入れて使うことができる。ストライクの打点を増やしつつカウンターを使いまわそう。

- ラッシュのコストとしてSユニットをコマンドに送るETのMユニットと組み合わせ、再ラッシュを繰り返して一気に展開する戦法をとることもできる。同時にリリース状態のコマンドも手に入るので、ダイナブラックが２体いればコマンドのダイナブラックＡをホールド→追加条件でラッシュエリアのダイナブラックＢをコマンドゾーンに→ＥＴのＭユニットをラッシュ→ホールドしたダイナブラックＡを効果でラッシュ→ＡとＢを入れ替え以上を繰り返すことで、実質コマンドの消費も追加条件も一切なしに展開が可能。
- 現在は同様のラッシュ能力を持ち、よりパワーや条件が軽く入手しやすい仮面ライダーZX（XG4）が登場したので、この用途のみでの使用例は少なくなった。
