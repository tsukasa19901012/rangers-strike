※これは敵軍ターン中、特徴「女」を持つユニットとバトルしたときバトルに勝っても撃破される。

【変身の妨害】これが自軍バトルエリアにある間、カテゴリにDAを持たず、本来の特徴に｢男｣または「女」を持つSユニットは、次の制限を受ける⇒効果名を持つテキストは無効になり、発動もできない。

Q&A

		Q1
		「XG-078 コピーベント」を発動し、自軍ラッシュフェイズ中、敵軍バトルエリアにある、カテゴリにDAを持たず、本来の特徴に「男」または「女」を持つSユニットを 1体目に、自軍ラッシュエリアの「RS-497 冥獣人ニンジャキリカゲ」を2体目に選びました。このとき、1体目に選んだユニットは自身が「RS-497 冥獣人ニンジャキリカゲ」からコピーされた【変身の妨害】の対象となります。この場合、敵軍ユニットの効果を無効にした『敵軍ユニット自身の効果』が無効 になりますが、それにより敵軍ユニットの効果が有効となり、再び敵軍ユニット自身の効果を無効にする、と言うループ状態になります。この場合の処理はどち らが優先されますか？
		A1
		ターンプレイヤーが効果の優先順を選択して処理してください。
		Q2
		敵軍バトルエリアに「RS-497 冥獣人ニンジャキリカゲ」と「XG-096 ビーファイタークワガー」があるとき、自軍バトルフェイズ中、RCを持つユニットをライドオフさせてから「XG-096 ビーファイタークワガー」にアタックすることはできますか？
		A2
		はい、できます。「RS-497 冥獣人ニンジャキリカゲ」により効果名を持つ効果は無効になり発動もできなくなりますが、ナンバーは消えていないので、RCを持つユニットはライドオフすることでRCを発動しているとみなします。

カード評価

- パワー3でBP5000という性能もさる事ながら、一番恐ろしいのはほとんどのSユニットの効果名のあるテキストを封じてしまう【変身の妨害】。特にSP「！」のSユニットはNC発動はおろかストライクすら出来なくなってしまうというSユニットが主力のデッキが多い現状では恐ろしいユニット。DAの入ったデッキを相手にする際には、対処法を考えておかなければならない。

- 効果は自軍にも及ぶ点に注意。自軍ターンは最後にバトルエリアに出すようにすれば影響は少なくて済むが、シンケンゴールドのような相手ターン中に効果を発揮するユニットとは相性が悪い。また、数合わせには向かないため、自軍ユニットが少ないときは味方ユニットのNC発動の邪魔になってしまい使いづらい事もある。

- ハリケンウィンガーにライドさせ、数少ない弱点である女ユニットからのアタックを困難にする「キリカゲウィンガー」と呼ばれるギミックが有名。天空神・飛行モードも加われば更に撃破が難しくなる。

- DA単色で守る手段としてはタイガーロイドや、リスクが大きいが暗黒の鎧が使われる。怪人なので巨大化爆弾や芋長の芋ヨーカンも使えるが、ハリケンウィンガーにライドできなくなる欠点がある。

- キリカゲ及びキリカゲウィンガー対策は、圧縮冷凍など除去オペレーションやサイクロン号やクウガゴウラムのようなビークルによる除去、Mサイズ以上のユニットでのアタック、メタルゲラスなどでライドオフさせる、闇のヤイバで自軍ユニットにDAを付けるなどの方法がある。
