                プットオン

種類：オペレーション

カテゴリ：オーバーテクノロジー

必要パワー：3

追加条件：なし 

テキスト：

カード名に「RF（ライダーフォーム）」を含む自軍ユニットを1体選び、手札に戻してもよい。そうしたとき、自軍パワーゾーンのオモテ向きのカードから、カード名に「MF（マスクドフォーム）」を含むユニットカードを1枚選び、自軍ラッシュエリアに出す。その後、このカードを自軍パワーゾーンに置く。

フレーバーテキスト

敵の増援に、彼らはアーマーを再構成し低く身構えた。

イラストレーター：矢薙じょう

レアリティ：ノーマル

作品：仮面ライダーカブト

収録：ザ・マスクドライダーEXP vol.3　自販：パック

カード評価

- キャストオフしたライダー達をマスクドフォームに戻すオペレーション。パワーから回収するユニットカードの代わりにこのカードがパワーに置かれるのでパワーの減少はない。

- 仮面ライダーザビーRFや仮面ライダーガタックRFのようにラッシュした時に能力を発動するようなユニットを戻して、もう一度能力を使用する事が出来る。

- 手札に戻すRFとラッシュエリアに出すMFは同じユニットのものでなくてもいいのでガタックRFを手札に戻しつつ、パワーゾーンからザビーMFをラッシュエリアに出すような真似も出来る。

- 超電子レーダーを組み合わせるとパワーに置かれても回収しやすい。ただし、ラッシュ→パワーに置くの順番なので、パワーに置きつつ回収、という動きは同カードが2枚必要になる。
