                シンケンレッド（XG7）

種類：Sユニット 

カテゴリ：ミスティックアームズ

BP：4000

SP：1/3

必要パワー：1

追加条件：なし

CN：―

特徴：レッド／男／侍

テキスト：

※レジスト

【影武者】これが自軍エリアにある間、特徴「レッド」を持つユニットがラッシュされたとき、これを捨札にする。

フレーバーテキスト

戦いの予感は確信へと変わり、遠く空を見つめ夢を追う仲間を想う。

イラストレーター：西野 幸治

レアリティ：ノーマル

作品：侍戦隊シンケンジャー

収録：クロスギャザー　ザ・ベストパートナー　自販：パック

カード評価

- パワー1でBP4000にレジスト、ストライクも可能と高いスペックを持つが、他のレッドが登場すると捨札になるやや厳しいデメリットを持つ。

- 相手が特徴「レッド」持ちをラッシュしても除去されてしまう。ダークウイングで特徴を消したり冥獣人ニンジャキリカゲで【影武者】を無効にすることである程度回避は可能。

- 必要パワーが1と非常に軽いため、かなり早い段階からスーパーシンケンレッドやハイパーシンケンレッドをラッシュ可能。
