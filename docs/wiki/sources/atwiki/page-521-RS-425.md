                ゲキジャガー

種類：Mユニット

カテゴリ：ワイルドビースト

BP：5500

SP：－

必要パワー：2+

追加条件：特徴「激気」と「ブルー」を持つ自軍ユニット1体を捨札にする

CN：なし

特徴：激気

テキスト：

【転転弾】これをラッシュしたとき、敵軍ユニットを1体選んで撃破してもよい。ただし、必要パワーの数字が敵軍ダメージの点数以下のユニットしか選べない。

フレーバーテキスト

転転弾の転は転回の転。華麗な見切りで危機は一転、敵は手玉よ、くるり転がれ掌の上。

イラストレーター：松島一夫

レアリティ：ノーマル

作品：獣拳戦隊ゲキレンジャー

収録：紅き六戦士の帰還　自販：パック

カード評価

- サイズ、エリア無視の強力な除去能力を持つMユニット。

- 追加条件は素で満たせるユニットが少なくて満たしづらいので、激気を使ってラッシュしたい。

- 同じくラッシュ時に除去が行えるゲキウルフよりも、必要パワーが軽いため激気でラッシュしやすいのも利点。
