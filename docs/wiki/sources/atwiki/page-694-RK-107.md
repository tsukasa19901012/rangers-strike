                マシントルネイダー

種類：Sビークル

カテゴリ：ミスティックアームズ

必要パワー：1

追加条件：なし

特徴：メカ／車両

テキスト：

【硬化装甲】これにライドしているユニットは、敵軍ターン中、リリース状態の自軍コマンド1つにつきBP+1000される。

フレーバーテキスト

オルタフォースが紅の鎧を形成し、力は更に加速する。カウントゼロ。今、走り出す時！ 

イラストレーター：PLEX（鈴木 和也）

レアリティ：ノーマルレア

作品：仮面ライダーアギト

収録：ザ・マスクドライダーEXP vol.2　自販：パック 

カード評価

- ビークル版気力カード。その気力と併用することで効果は2倍になる。

- 今ではコマンド操作能力が多く万全とは言えないが、コマンドをリリースする手段を用意した上で超力と併用させることで、このビークルにライドしているユニットを敵軍ターン中はこのビークルの効果で守り、自軍ターンに超力の効果で強力なアタッカーにさせるという戦法が可能。

- ライド中のユニットを狙ってくるジャングラーやシャドームーンには注意。

- 同パワー・同カテゴリで、コマンドの状態に左右されずにユニットを守れる分こちらより使い勝手の良いハリケンウィンガーに立場を奪われがち。一応、こちらはSユニット以外へのアタック耐性も付くが、そのためにこちらを使うことは少ないだろう。

-  しかしこのマシントルネイダーって、使い勝手が悪くないだろうか。気力には対象範囲で負けているし、似た効果の鬼の鎧もあるし。RCがあるユニットならライドできるけど、そうするとRCが発動できないし。ライドしているとシャドームーン1stに潰される可能性もでてくる。下に重ねたカードとしてサガにも潰されるし。（これは鬼の鎧にも当てはまるけど）俺に考えられるのは「気力と鬼の鎧とマシントルネイダーを併用して極限までBPアップ」ってくらいなのだけど、そんなものに正直価値は見出せない。ビークルとして使うとしても微妙。気力代わりに使うとしても微妙。としたら、このカードってどういう時に使うのだろうか。それとも、使い道ないカードなのだろうか。このカードの価値について聞きたい。  -- 名無しさん  (2009-12-10 00:28:53)
