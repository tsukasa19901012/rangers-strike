【トロピカルダンス】特徴「獣」を持つ自軍ユニットを3体まで選び、ラッシュエリアに戻してもよい。ただし、戻したユニットはこのターン、再びバトルエリアに出ることはできない。

荒々しい野生を感じさせるその動きは、駆け跳ねる獣のようだ。

作品：バトルフィーバーJ

収録：七忍の炎陣　自販：パック
