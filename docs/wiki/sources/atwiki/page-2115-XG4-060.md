                仮面ライダーファイズBF（ブラスターフォーム）（XG4）

種類：Sユニット

カテゴリ：アーステクノロジー

BP：4000

SP：1/5

必要パワー：5

追加条件：なし

CN：RC

特徴：仮面ライダー／男／ブラスターフォーム 

テキスト：

※ウイング

【フォトンブレイカー】これがBPの下三桁が500のユニットにアタックしてバトルに勝ったとき、追加でアタックしてもよい。（この効果はこれがウイングでアタックするときはナンバーに関係なく発動する）

フレーバーテキスト

全身を満たす真紅の光が、果ての無い闇を切り裂いてゆく。

イラストレーター：F.M.U

レアリティ：ノーマルレア

作品：仮面ライダー555

収録：XG4 ザ・ジェットアクセル　自販：パック

Q&A

		Q1
		自軍「XG4-060 仮面ライダーファイズBF」が【フォトンブレイカー】の効果を発動して、BPの下三桁が500のユニットにアタックしました。このとき、相手は「RS- 018 隠流忍術」を発動して、BPの下三桁が500でないユニットを選び、そのユニットをバトルで撃破しました。「XG4-060 仮面ライダーファイズBF」は追加でアタックをすることはできますか？
		A1
		いいえ、それはできません。【フォトンブレイカー】の効果は、BPの下三桁が500のユニットを撃破したときのみ有効です。
		Q2
		自軍「XG4-060 仮面ライダーファイズBF」がウイングの効果でBPの下三桁が500のユニットにアタックしました。通常、ラッシュエリアからはアタックが行えませんが、 「XG4-060 仮面ライダーファイズBF」は【フォトンブレイカー】の効果でラッシュエリアから追加でアタックすることはできますか。
		A2
		はい、【フォトンブレイカー】の効果により、追加でアタックできます。

カード評価

- ウイングの効果でアタックした場合このユニットはラッシュエリアにあるが、効果によるアタックなので問題なく敵軍ユニットに追加アタックすることができる。
