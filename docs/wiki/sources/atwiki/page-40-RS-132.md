テキスト：

※これは、自軍ラッシュエリアのSユニットを1体捨札にしなければバトルエリアに出られない。

【反バイオ粒子砲】これがバトルエリアに出るとき、捨札にしたSユニットが「バイオハンター・シルバ」ならこのターン、これは次の能力を得る。⇒「SP1」「BP+5000」

フレーバーテキスト

心持たぬ非情のハンターと出会った時、悪夢が再びこの世界を蹂躙する。

イラストレーター：森下直親

レアリティ：レア

作品：超電子バイオマン

収録：三界の獅子　自販：パック

カード評価

- バイオハンター・シルバを捨札にすることで性能が大幅に上がるユニット。凱聖バルスキーで捨札にしたシルバを回収すれば、毎ターン強化したまま使うことが出来る。

- セイクウオーやメガヘラクレスのような強力なＬユニットが増えてきたことにより、黒単のＬユニットの撃破手段として活躍が見込めるようになった。バイオハンター・シルバの使い勝手が良いのも嬉しい。
