特徴：イマジン

テキスト：

※このユニットからコンビネーションする「仮面ライダーNEW電王SF」は、ナンバーにRCを持っていればライドオフしなくてもその効果を発動できる。また、このコンビネーションが成立している間BP+2000される。 

【危険の排除】これをラッシュしたとき、自軍山札の上から1枚を見て、そのカードを自軍パワーゾーンのオモテ向きのカード1枚と置き換えるか、山札の上に戻す。 

フレーバーテキスト

契約は終わっても、関係は終わらない。当たり前だけど大切なコト。

レアリティ：ノーマル

収録：クロスギャザー ザ・ギガンティックタイタン　自販：パック 

カード評価

- 仮面ライダーNEW電王SFを補助する能力を持ったイマジン。

- 仮面ライダーNEW電王SFのRC発動を補助する能力と山札操作はXG2、XG6両方の効果と相性が良い。BP上昇効果はXG6の方のSP1の条件を満たすことができる。

- 山札操作の効果はクライマックス刑事の読み替えテキストのように、山札を参照するカードの補助に使う事が出来る。
