                ディケイド ブレイド

種類：Sユニット

カテゴリ：ワイルドビースト

BP：3000

SP：－

必要パワー：2

追加条件：なし

CN：RC

特徴：仮面ライダー／男／ディケイドライバー

テキスト：

※モーフ 

※これは「仮面ライダーブレイド」としてつかえる。

【アタックライド】自分の手札を3枚選び、相手に見せてもよい。そうしたとき、敵軍Sユニットを1体選びホールドする。その後、見せたカードの持つカテゴリがすべて同じなら、敵軍バトルエリアからSユニットを1体選び撃破する。

フレーバーテキスト

仲間と共に励まし助け合い一緒に進化していく。それがこいつの強さだ。

イラストレーター：Matsuda nozomu

レアリティ：ノーマル

作品：仮面ライダーディケイド

収録：XG1 ザ・ファーストエンカウント　自販：パック

再録：XG5 ザ・チケットブレイカー　スターター（カードヒーローデッキ）

カード評価

- 本家ブレイドと比べて必要パワーが軽くなった反面、ストライク能力を失っている。ディケイドライダーの中ではディケイド本人と並んで一番パワーが軽いのでモーフの起点になれる。

- ブレイドJFやブレイドKFへのゾードアップも当然可能。

- 【アタックライド】は仮面ライダーディケイドのアタックやニンジャイエローのようなホールドされたユニットを対象にするカードと相性が良い。

- ストライク能力を失っているものの、代わりに本家にあったストライクの制限も無くなっている。その為ギャレンのようにライドオフからのモモタロスやロボタフを使ったストライクは可能。
