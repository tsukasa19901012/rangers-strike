※ウイング

【メガトマホーク】自軍コマンドが3つ以下なら、自分の手札からカードを1枚選び、自軍コマンドゾーンにホールド状態で置いてもよい。そうしたとき、このターン、これは次の能力を得る⇒SP1 

フレーバーテキスト

おいおい、レッド１人を先に行かせていいのかよ？

イラストレーター：funbolt 

レアリティ：ノーマル

作品：電磁戦隊メガレンジャー

収録：蒼九の翼　自販：パック：スターター（ウイング）

カード評価

- 【メガトマホーク】を発動させればETのユニットでありながら3番目でストライクができる。ただし、手札を1枚コマンドに送る必要があるので注意が必要。

- 自軍コマンドが3つ以下でないと能力を発動できないため、多すぎる分のコマンドはメガイエロー等を使って回収しておこう。

- メガピンクからのコンボで相手のコマンドを削る事が出来る。
