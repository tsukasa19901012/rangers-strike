                セイクウオー

種類：Lユニット

カテゴリ：オーバーテクノロジー

BP：9000

SP：1

必要パワー：6+

追加条件：自軍合体ユニットを捨札にする。

CN：なし

特徴：人型／航空機／炎神

テキスト：

合体―トリプター＋ジェットラス＋ジャン・ボエール

※ウイング

【セイクウインパルス】これがストライクしてダメージを与えたとき、敵軍パワーゾーンのオモテ向きのカードから、必要パワーの数字が3以下のユニットカードを1枚選び捨札にしてもよい。

フレーバーテキスト

高速で空を舞い豊富な武装で圧倒する、空を制するその名に偽り無し。

イラストレーター：As&#039;まりあ

レアリティ：レア

作品：炎神戦隊ゴーオンジャー

収録：蒼九の翼　スターター専用

Q&A

		Q1
		「RS-605 異次元からの翼」を使って「RS-686 セイクウオー」をラッシュする時、追加条件を満たすために「RS-359 デンジ犬アイシー」の効果【最後の手段】を使うことはできますか？
		A1
		はい、できます。１つの効果の解決中に新たな効果が発動した場合、新しい効果を即時解決した後、もとの効果の解決を再開してください。

カード評価

- パーツとなる炎神たちがウイング持ちのトリプター、ジェットラス、そして炎神ユニットのサーチが強力なジャン・ボエールとあって使い勝手は上々。

- 前述したジャン・ボエールによるパーツのサーチに加え、異次元からの翼で必要パワーを無視してラッシュできる。その代わりに、同じく３体合体のエンジンオーなどと比べてＢＰが低めに設定されている。それでも、圧縮冷凍に引っかからない程度のBPはあるので十分及第点。

- 【セイクウインパルス】はラッシュが早いほど活かし易い効果。早めにラッシュできれば、相手のパワーへの牽制にも役立つ。ピンクレーサーのようなパワーを減らさせるカードと組み合わせるとより強力。

- 特徴航空機を持つため、バラクティカの効果で２体同時にラッシュすることも可能。本来の必要パワーを満たす必要はあるが、効果はかなり大きい。
