                ゴセイナイト

種類：Sユニット

カテゴリ：ミスティックアームズ 

BP：3000

SP：！

必要パワー：4

追加条件：なし

CN：3

特徴：魔法／獣／人型

テキスト：

※ウイング

※タクスMA

※レジスト

※これは「グランディオン」としてつかえる。

【ナイトダイナミック】「SP1」OTまたはETまたはDAを持つ敵軍Sユニットを1体選び撃破する。その後、自分の手札が1枚以下なら、これをリリースする。

フレーバーテキスト

破壊必要レベル８…お前達を星の汚染源と認識した。断罪する！

イラストレーター：中北晃二

レアリティ：スーパーレア

作品：天装戦隊ゴセイジャー

収録：XG6 ザ・ギガンティックタイタン　自販：パック

カード評価

- ウイング・タクスMA・レジストといった有用な能力、それなりに優秀な特徴、及第点のスペック、強力な効果と非常に恵まれたユニット。

- 【ナイトダイナミック】はエリアを問わず対象も広い強力な効果。加えて手札が1枚以下ならリリースできるため、レジストやウイングを再び使えるようにしたりウエイクアップ！の条件に充てたりするなど応用も効く。
- 1番目にクロス持ちを並べれば、NCとタクスMAを同時に発動させることができる。
