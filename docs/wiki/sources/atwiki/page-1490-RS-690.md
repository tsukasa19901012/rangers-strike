                スペードエース

種類：Sユニット 

カテゴリ：アーステクノロジー

SP：－

必要パワー：4

追加条件：なし

CN：2

特徴：メカ／レッド／男

テキスト：

※タクスET

【スペードアーツ】敵軍バトルエリアと敵軍ラッシュエリアから、同じBPを持つSユニットを1体ずつ選んでもよい。そうしたとき、選んだユニットを持ち主のコマンドゾーンにホールド状態で置く。置けなければ捨札にする。

フレーバーテキスト

燃え滾る赤い闘志を矢に変えて、悪を貫けアトム射ち！

イラストレーター：JUN YAMAGUCHI

レアリティ：レア

作品：ジャッカー電撃隊

収録：蒼九の翼　スターター専用（12大ヒーロー）

カード評価

- ラッシュエリアとバトルエリアの同じＢＰを持つＳユニットをコマンド送りにするＮＣを持つ。条件がやや特殊だが、複数のＳユニットを除去できる可能性があるのは魅力的。

- ＢＰが高く、場に残り易いためタクスを活かしやすいのも強み。
