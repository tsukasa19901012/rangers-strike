                リンカメレオン

種類：Mユニット

カテゴリ：ダークアライアンス

BP：2500

SP：－

必要パワー：2+

追加条件：特徴「臨気」と「女」を持つ自軍ユニットがある

CN：R

特徴：臨気

テキスト：

※これは自軍バトルフェイズ中、カテゴリにWBが追加される。

※これは敵軍ユニットにアタックされない。 

【リンギ・がんじがため】これが同カテゴリのLユニットからコンビネーションするとき、次の効果を発動できる⇒敵軍ユニットを1体選ぶ。そうしたとき、選んだユニットがリリース状態ならホールドし、ホールド状態なら撃破する。ただし、必要パワーの数字が、自軍捨札にあるカテゴリを2つ以上持つカードの枚数以下のユニットしか選べない。 

フレーバーテキスト

アンタ達、弱いからってボヤボヤしてるとぶっ飛ばすよ！

イラストレーター：A.t.Factory

レアリティ：ノーマル

作品：電影版 獣拳戦隊ゲキレンジャー ネイネイ！ホウホウ！香港大決戦

収録：クロスギャザー ザ・ギガンティックタイタン　自販：パック

カード評価

- 【リンギ・がんじがため】はサイズ・エリアを問わずに、ホールドか除去が行える。しかし、対象に取れるカードが自軍捨札のマルチカテゴリの枚数に依存するので、大きいユニットを狙うのは難しい。

- 仮面ライダーW・CJX（XG6）やリンライオンなど、自軍バトルフェイズに捨札でマルチカテゴリになるカードを使えば、デッキに入るマルチカテゴリのカード枚数を抑えることができる。

- 自軍バトルフェイズ中にWBのカテゴリが追加される。なので、WBのユニットから【リンギ・がんじがため】を発動したり、激気でラッシュすることができる。
- ただし、マルチカテゴリのユニットからコンビネーションする場合は、WBとDAの両方を含まなければ、他方がもう一方のカテゴリを全て含まないため、両者は同じカテゴリとみなされない。カテゴリを追加する効果関連も参照。
