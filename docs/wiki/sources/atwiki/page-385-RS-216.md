※自分がターンを終えるとき、特徴「車両」を持つ自軍ユニットがなければ、このユニットを自軍山札に戻してシャッフルする。

【大宇宙ハイウェイ計画】これが自軍エリアにある間、特徴「車両」を持つすべてのユニットは、毎ターン、可能ならバトルエリアに出る。

Q&A

		Q1
		自軍「RS-580 絶対神ン・マ」が、敵軍「RS-216 暴走皇帝エグゾス」にアタックされ、お互いに撃破されました。「RS-580 絶対神ン・マ」には『これがユニットでなくなるとき、自分も相手も自分自身の捨札をすべて山札に戻してシャッフルする。』と書かれています。『ユニットで なくなったとき』ではなく『ユニットでなくなるとき』とあるので、このとき「RS-580 絶対神ン・マ」と「RS-216 暴走皇帝エグゾス」が捨札になる前に「RS-580 絶対神ン・マ」のテキストが実行され、その後「RS-580 絶対神ン・マ」と「RS-216 暴走皇帝エグゾス」がお互いの捨札になりますか？
		A1
		はい、その通りです。
		Q2
		「XG3-103 ライジンゴー」が【噛みつき】の効果でSユニットになっているとき、自軍「RS-216 暴走皇帝エグゾス」は自分がターンを終えるとき自軍山札に戻りますか？
		A2
		いいえ、そのようにはなりません。「自分がターンを終えるとき」と 「Sユニットとして扱いが切れる」タイミングは異なります。「RS-216 暴走皇帝エグゾス」の「自分がターンを終えるとき」の処理は「XG3-103 ライジンゴー」のSユニットとして扱いが切れる前に行います。このとき、「XG3-103 ライジンゴー」はまだSユニットですので「RS-216 暴走皇帝エグゾス」は山札に戻ることはありません。

カード評価

- パワーの割りにサイズが大きいユニット。ラッシュさせて敵ユニットを襲っても、ストライカーとしても十分な脅威になるサイズを持っている。その分、車両がないと飽きて山札に帰ってしまうデメリットがある。マスクドライダーEXP vol.2で車両を参照するカードが大量に登場したため、それらを混ぜて使うのがいい。その場合、二つ目の能力もデメリットになり得る。

- 自軍に車両持ちのユニットがいなければ延々と山札に帰り続けるため、山札操作が行われなければ山札切れで負けることはない。

- 能力的に、車両と合わせ常駐させるよりも、毎回山札に帰るヒット&アウェイストライカーとして使われることが多い。そういった用途の場合、ルナジェルによって無効化される。
