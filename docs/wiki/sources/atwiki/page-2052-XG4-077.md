カード評価

- 効果名を持つテキストはないが、捨札が3枚以上あればラッシュする事が出来る。

- ラッシュのコストとしてSユニットをコマンドに送るETのMユニットと組み合わせ、再ラッシュを繰り返して一気に展開する戦法をとることが出来る。同じ事が出来るダイナブラックと比べラッシュ条件が楽なので、MAのオペ回収を考えないならこちらの方が優秀。ETのMユニットをメインとするデッキなら最大限に活かすことができる。
- スカイエースや仮面ライダーイクサBMの効果でデッキから直接コマンドに持ってくる事が出来る点も優秀。

- タッチで入れて5番ストライカーとしての運用も可能。
