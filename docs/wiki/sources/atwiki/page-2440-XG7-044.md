                仮面ライダーアクセル×仮面ライダーW・CJ

種類：Sユニット

カテゴリ：アーステクノロジー 

BP：4000

SP：1/5

必要パワー：2+

追加条件：追加で自軍コマンドを1つホールドする

CN：なし

特徴：仮面ライダー／男／警察

テキスト：

※クロス1

※リードET

【風都の護り手】これがリリース状態で自軍コマンドゾーンにある間、相手の手札以外から敵軍Sユニットがラッシュされたとき、これを自軍ラッシュエリアに出してもよい。そうしたとき、ラッシュされた敵軍ユニットを持ち主のコマンドゾーンにホールド状態で置く。置けなければ捨札にする。

フレーバーテキスト

俺に質問する暇があったら先に行け。すぐに追いつく。

イラストレーター：Masakazu Fukuda

レアリティ：レア

作品：仮面ライダーW

収録：クロスギャザー ザ・ベストパートナー　自販：パック

カード評価

- 手札以外からラッシュされたＳユニットを除去する効果を持つＳユニット。

- 異次元からの翼やラジエッカーなど、手札以外からのラッシュされたユニットをラッシュされた直後に対処できる。
- 対象をとらない効果なので、「※これはアタックされる以外では相手に選ばれない。 」やブレイカーを無視して除去することができる。

- 効果は自軍ターン・敵軍ターンを問わず発動可能。

- ＢＰが高くリードＥＴを持つので、効果発動と同時に宏のオルゴール時計を発動することもできる。

- 自軍ターン中でも発動することができるのでバットショットやボウケンイエローといったカードの補助にも使える。

- メタルダーやＥＴのＭユニットでコマンドに送ることで、効果を使いまわすことができる。

- 仮面ライダーと警察を持っているため、特徴関連のサポートカードも充実している。
