                スカイエース

種類：Mユニット 

カテゴリ：アーステクノロジー 

BP：4000

SP：！

必要パワー：5+

追加条件：自軍Sユニットを1体コマンドゾーンに送るか捨札にする

CN：なし

特徴：メカ／航空機

テキスト：

※これは特徴「メカ」を持つ自軍コマンドが4つ以上あればSP1になる。

【スカイコンテナ】これをラッシュしたとき、自軍コマンドを好きな数選び捨札にしてもよい。そうしたとき、自軍山札を見て、特徴「メカ」を持つSユニットのカードを、捨札にしたコマンドの数まで好きな枚数選び、自軍コマンドゾーンにホールド状態で置く。その後、山札をシャッフルする。

フレーバーテキスト

ミサイルの援護を受けて地上部隊は突入を開始。電光石火の強襲劇の幕が上がった。

イラストレーター：K2商会

レアリティ：ノーマルレア

作品：ジャッカー電撃隊

収録：蒼九の翼　自販：パック：スターター（12大ヒーロー）

カード評価

- プロジェクトG4を中心とした特徴にメカを持つＳユニット中心のデッキで使われる。ラッシュ時に捨札に置いたカードはウォルターやソルジャンヌで、コマンドに置いたカードはバイクルで回収できるので必要なカードを簡単に補充できる。

- メカのSユニットをコマンドへサーチして持ってこられるので、コマンドからラッシュできる仮面ライダーライジングイクサや仮面ライダーZX（XG4）と相性が良い。 

- ロボタックSMや前述の仮面ライダーライジングイクサなどは、ゾードアップ元とゾードアップ先をサーチして、ランドバルカンで追加条件を満たしてのラッシュが狙える。
