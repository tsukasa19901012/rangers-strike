                ギャラクシーメガ

種類：Lユニット 

カテゴリ：アーステクノロジー 

BP：9000

SP：1

必要パワー：7+

追加条件：自軍「メガシップ」1体を捨札にする

CN：なし

特徴：メカ／人型

テキスト：

【メガシールド】敵軍ターン中、これが撃破されたとき、次の効果から1つ選び発動できる⇒

◎敵軍ユニットを1体選び撃破する。

◎自軍捨札からウイングを持つSユニットのカードを5枚まで選び、自軍ラッシュエリアに出す。

フレーバーテキスト

大気圏に突入するその姿は、燃え上がる流星となって地上にいる者達を奮い立たせた。

イラストレーター：Hiroshi Ayaragi

レアリティ：スーパーレア

作品：電磁戦隊メガレンジャー

収録：蒼九の翼 自販：パック

カード評価

- 素材であるメガシップが、状況次第ではコマンドをホールドするだけでラッシュできるので非常に出しやすいLユニットと言える。
- メガシルバー（XG4）の補助を受ければ、メガシップのラッシュを省くことができる。

- このカードと素材のメガシップはともにLユニットなのでバトルシャークの恩恵が大きい。

- 「メガシールド」の効果を持っているため、破壊されることは少ないであろう。BPが8000を超えているためマジパンチや疾風流超忍法を受け付けないのは大きなメリット。

- 撃破される際に発動する効果は強力ではあるが、このカード自体が撃破されづらく、発動する機会は少ない。能動的にこの効果を活かすのは難しいだろう。
関連カード
