                戦闘ワンセブン

種類：Lユニット

カテゴリ：アーステクノロジー

BP：8000

SP：1

必要パワー：5+

追加条件：自軍「要塞ワンセブン」１体を捨札にする

CN：なし

特徴：メカ／人型

テキスト：

※これがユニットでなくなったとき、自軍捨札から「要塞ワンセブン」のカードを１枚選び、自軍ラッシュエリアに出す。

【グラビトン攻撃】これが自軍エリアにある間、自分がターンを終えるとき、このユニットのBP以下のBPを持つ敵軍ユニットを１体選び撃破してもよい。そうしたとき、このユニットを捨札にする。

フレーバーテキスト

人類が地球を救うと判断すればこそ、己は人類を守ると立ち上がる。

イラストレーター：As&#039;まりあ

レアリティ：スーパーレア

作品：大鉄人１７

収録：クロスギャザー ザ・ギガンティックタイタン　自販：パック 

カード評価

- 追加条件と必要パワーに対してスペックが非常に高く、効果も強力。ETのLユニットの中ではトップクラスの使いやすさを誇る。ユニットでなくなった時に素体の要塞ワンセブンが返って来るため、捨札になっても要塞ワンセブンの効果で回収して何度も使いまわすことが可能な点も非常に優秀。

- 【グラビトン攻撃】はエリアを問わず最低8000以下を除去できる非常に強力かつ使い勝手のいい効果。除去対象を広げるなら同カテゴリのゴーゴードリルやサブマシーンなどでサポートしたい。
