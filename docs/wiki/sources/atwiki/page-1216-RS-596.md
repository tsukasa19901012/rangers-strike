                炎神大将軍

種類：Lユニット

カテゴリ：オーバーテクノロジー

BP：13000

SP：1

必要パワー：7+

追加条件：自軍合体ユニットを捨札にする

CN：なし

特徴：人型／炎神

テキスト：

合体―レツタカ＋シシノシン＋ツキノワ 

【炎神剣】自軍ターン中、これがバトルエリアに出たとき、自軍山札の上から1枚をオモテにしてもよい。そうしたとき、オモテにしたカードが特徴「炎神」を持つユニットカードなら、このターン、これは「SP2」になる。その後、オモテにしたカードは山札の下に戻す。 

フレーバーテキスト

今、命の炎を燃やし、炎神大将軍、堂々出陣！！

イラストレーター：R-AREA

レアリティ：レア

作品：炎神戦隊ゴーオンジャー BUNBUN！BANBAN！劇場BANG！！

収録：究極の八神　自販：パック

カード評価

- 他の炎神に比べて合体パーツの能力が使いやすいため、合体できなくてもそれなりに戦える。合体後は、BPが13000あるため百獣アニマルハートなどのBPを参照する除去に引っかかりにくく、【炎神剣】でSP2まで狙えるのでストライカーとしても十分活用できる。突出した能力はないが堅実なユニットと言える。

- 【炎神剣】はクライマックス刑事と相性がよい。表にしたカードが山札の下に戻ることを利用して、同じOTカテゴリの仮面ライダードレイクMFを使うのもよい。
