-  必要パワー７－の中では珍しい弱体化するユニットといっても良いと思う。確かにBPは５００上がるが、そのためにファイズとかの効果に引っかかり、特徴も４つに増えるのでサイドマシーンに引き殺されるし・・・  -- 名無しさん  (2011-01-13 17:03:14)

-  ↑NEW電王みたいなパワー参照系の除去には引っかかりにくくなるし、撃破されても素体が帰ってくるのは耐久力が上昇してるも同じ。BP3000と相打ちしなくてすむのは非常に大きいし、クウガゴウラムには相変わらず引っかからない。パワーアップしてるよ  -- 名無しさん  (2011-01-13 18:20:32)
