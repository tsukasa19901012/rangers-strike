                電子星獣ドル

種類：Lユニット

カテゴリ：オーバーテクノロジー

BP：5000

SP：－

必要パワー：4+

追加条件：自軍｢超次元高速機ドルギラン｣1体を捨札にする

CN：なし

特徴：メカ／獣／ドラゴン

テキスト：

※これは、チェイスを持つ自軍ユニットがあるか、ライドされてる間、Lビークルとして扱う。 

【ドルファイヤー】自軍ターン中、本来の特徴に「宇宙刑事」を持つユニットがこのビークルからライドオフしたとき、相手に1点ダメージを与える。

フレーバーテキスト

頭に乗った宇宙刑事の叫びに応え、激しくうねり近寄る戦闘機達を打ち払った。

イラストレーター：Mitsuhiro Arita

レアリティ：ノーマルレア

作品：宇宙刑事ギャバン

収録：スペシャルメタルエディション　自販：パック

再録：クロスギャザー ザ・ファーストエンカウント　スターター（メカニカル）

カード評価

- チェイス持ちが自軍にいるとビークルになる。【ドルファイヤー】はビークルの状態でないと発動できない。

- ＢＰ５０００を持つのでユニットの時でもアタッカーとして活躍することができる。とはいえ、このカード真髄は【ドルファイヤー】による追加ダメージなので無理はしないように。

- 【ドルファイヤー】はダメージを与える効果。宇宙刑事デッキでは優秀なダメージ源として活躍する。この効果を発動するとチェイスができないのでダメ押しがしたい時や、撃破されても問題無い時に使いたい。

- 【ドルファイヤー】のためにいるユニットのようなものなので宇宙刑事ギャバンや宇宙刑事シャリバンと一緒に使うのが基本。

- メタルエディションが出た当時は使いづらかったが、XG1で宇宙刑事シャイダーが追加された事によって使い易くなった。

- XG1のスターターで再録されたが、ラッシュに必要な超次元高速機ドルギランが再録されなかったため素のスターターのままではラッシュが出来なくなってしまっていた。
