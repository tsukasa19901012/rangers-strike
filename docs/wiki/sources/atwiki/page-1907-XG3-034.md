                恐竜折神（キョウリュウオリガミ）

種類：Mユニット

カテゴリ：ミスティックアームズ

BP：5000

SP：－

必要パワー：4+

追加条件：特徴「侍」を持つ自軍ユニットがある

CN：L

特徴：恐竜／折神獣

テキスト：

【キョウリュウマル】このユニットからコンビネーションする特徴「侍」を持つユニットは、次の能力を得る⇒アタックするかわりに、敵軍バトルエリアのユニットを、BPの合計がこのユニットのBP以下になるように好きな数選び、撃破してもよい。

フレーバーテキスト

あれは爆竜では無いブラ。ダイノガッツとは違う力を感じるブラ。

イラストレーター：村山竜太

レアリティ：ノーマル

作品：侍戦隊シンケンジャー

収録：クロスギャザー ザ・Wインパクト　自販：パック

		敵軍バトルエリアに、レジストを持たないＢＰ３０００以下のユニットだけがいるとき、「XG3-034 恐竜折神」からコンビネーションした「XG4-046 腑破十臓」は【キョウリュウマル】の効果を発動することはできますか？
		A1

		A2
		はい、できます。

カード評価

- 特徴「侍」を持つユニットならサイズに関係なく発動できる変わったJCを持つユニット。

- 【キョウリュウマル】は敵軍バトルエリアの複数のユニットを撃破できる強力な除去能力。これ自体も高いBPを持ち、状況次第では一気にバトルエリアの制圧が可能。

- BP上昇効果やアタックされない効果を持つユニット、レジスト持ちのユニットなどを始末したいときにも便利。同じBPのユニットが相手のときも相打ちせずに一方的に倒すことができる。

- JCを持つのでゴーゴージェットやバトルシャーク、特徴に恐竜を持つのでVコマンダーと、他カテゴリばかりだがサーチ手段にも恵まれている。
