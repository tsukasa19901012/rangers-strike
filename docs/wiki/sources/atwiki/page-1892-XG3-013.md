                ガオポーラー

種類：Mユニット

カテゴリ：ワイルドビースト

BP：1000

SP：－

必要パワー：2

追加条件：なし

CN：L

特徴：獣

テキスト：

※これは自軍コマンドを1つホールドしなければバトルエリアに出られない。

※これは自軍「ガオベアー」があればBP+3000される。 

【冷凍光線】「ガオベアー」か特徴「人型」を持つLユニットがこのユニットからコンビネーションするとき、次の効果を発動できる⇒コンビネーションしたユニットのBP以下のBPを持つ敵軍ユニットを1体選びホールドする。 

フレーバーテキスト

敵に囲まれた彼等を救ったのは、二頭の獣が放つ冷気と炎の奔流だった。

イラストレーター：キクチヒラメ

レアリティ：ノーマル

作品：百獣戦隊ガオレンジャー

収録：クロスギャザー ザ・Wインパクト　自販：パック：スターター（アニマルジョイント）

カード評価

- 敵軍ユニットをホールドするJCを持つMユニット。

- JCはLユニットだけでなく、ガオベアーをコンビネーションさせても発動できる。ガオベアーをコンビネーションさせれば、あちらのJCも同時に発動させることができる。

- ガオベアー共々、カテゴリが一致していなくてもJCが発動できるのも強み。JパワーでLサイズにしたSユニットや冥府神でも呉越同舟なしに使える。

- ガオベアーがいるとBPが4000まで上昇する。ガオベアーとJCすることでBP4000までのユニットをあちらの効果で撃破できるので、合体素材としてでなくても、ガオベアーとセットでの運用でも強い。

- ガオベアーとのJCを狙う際は、コマンドを２つホールドしなければいけない。あらかじめコマンドを多めに用意したり、コマンドのリリースが得意なMAとの混色にするなどでフォローしたい。
