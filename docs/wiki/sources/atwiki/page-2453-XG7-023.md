                獣拳巨神サイダイオー

種類：XLユニット

カテゴリ：ワイルドビースト／ミスティックアームズ

BP：13000

SP：1

必要パワー：5+

追加条件：自軍「獣拳神サイダイン」1体を捨札にする

CN：なし

特徴：拳聖／激気／人型

テキスト：

※ブレイカー

【大大砕大斬】自軍ターン中、これがバトルエリアに出たとき、敵軍バトルエリアからユニットを1体選んでもよい。そうしたとき、選んだユニットがリリース状態ならホールドする。その後、選んだユニットとこのユニットでバトルする。

フレーバーテキスト

重く！大きく！強い！これが獣拳の神。激気の源流を見せてやるぜ！

イラストレーター：K2商会

レアリティ：スーパーレア

作品：獣拳戦隊ゲキレンジャー

収録：ザ・ベストパートナー　自販：パック

カード評価

- ブレイカー・BP13000・XLユニットで除去されにくく、SP1と強力な効果の【大大砕大斬】でバトルとストライクを同時にこなせる。シンプルだが、まさにフレーバーの通り「重く！大きく！強い！」ユニット。

- 必要パワー5かつ素体の獣拳神サイダインの追加条件も緩いため、ラッシュは比較的容易。出してしまえばそうそう止められない。
- ラッシュ後の2枚目以降は、操縦者のゲキチョッパーの効果に使えば無駄がない。

- 【大大砕大斬】はレジストを潰してからバトルできるため、相手の耐性がなければ実質的な除去効果。イナズマンなどの効果も防げる。もちろん効果発動後に通常のバトルをすることも可能。
