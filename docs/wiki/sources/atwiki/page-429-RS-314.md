フレーバーテキスト

&quot;中身&quot;が無数の虫と分かった時にあがった、女性たちの悲鳴の方が怖かったです…。

カード評価

- 忍者はサポートカードの多い特徴ではあるが、戦闘員と相性が良いかというと少々疑問もある。

- アレの上に重ねる目的なら割と使いやすい。BPが低いため倒してもらいやすく敵軍ターンに倒されることを期待できる。問題は逆に弱すぎて放置されてしまうパターンだが…

- ネコマルの餌としても優秀。戦闘員デッキのキーカードとも言えるゾル大佐等をさがして来やすくなる。
