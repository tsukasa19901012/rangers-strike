                龍折神（リュウオリガミ）

種類：Mユニット 

カテゴリ：ミスティックアームズ

BP：4000

SP：－

必要パワー：3

追加条件：なし 

CN：4

特徴：獣／折神獣／ドラゴン

テキスト：

【押し寄せる水流】敵軍ラッシュエリアのホールド状態のユニットをすべて持ち主の山札に戻してシャッフルしてもよい。

フレーバーテキスト

巨大な身体が波打つ様は、まさに海の荒波そのものであった。

イラストレーター：宇井戸 雨樋

レアリティ：ノーマル

作品：侍戦隊シンケンジャー

収録：蒼九の翼 自販：パック

再録：クロスギャザー ザ・ドラゴンタイガー　スターター（ドラゴンストライク）

再録2：クロスギャザー　ザ・ギガンティックタイタン 自販：パック

カード評価

- デメリットなしの必要パワー3、BP4000は優秀な部類に入る。しかもMユニットなので除去する手段が限られるのも嬉しい。優秀なアタッカーとして活躍してくれるだろう。

- 特徴「ドラゴン」を活かす場合、XG2環境までではWBとの混色になりやすい。WBはユニットをホールドする手段が豊富なのでNCを活かす機会も多くなるだろう。
