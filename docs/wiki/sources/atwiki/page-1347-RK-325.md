                パワードイクサー

種類：Sビークル

カテゴリ：アーステクノロジー

必要パワー：4

追加条件：なし

特徴：メカ／ドラゴン

テキスト：

※これにライドしているユニットは、「仮面ライダーイクサBM」なら「SP1」になる。

【イクサポッド】自軍ターン中、これがバトルエリアに出たとき、自軍コマンドゾーンからカードを1枚選び、自軍山札の上か下に戻してもよい。そうしたとき、戻したカードの必要パワーの数字と同じ必要パワーの数字を持つSユニットを敵軍バトルエリアから1体選び、持ち主のコマンドゾーンにホールド状態で置く。置けなければ捨札にする。

フレーバーテキスト

見なさい！これがイクサの新しい力！

イラストレーター：F.M.U

レアリティ：ノーマル

作品：仮面ライダーキバ

収録：ザ・マスクドライダーEXP vol.4　自販：パック

カード評価

- 【イクサポッド】は追加条件も無視して除去を行える強力な効果。また、コマンドのカードを山札の上か下に戻すという点も様々なカードとシナジーがあるため使いどころが多い。
- 同じ必要パワーという条件なので、デッキの構築次第では狙いたい相手を除去しにくいという問題もある。

- オメデトロフィーやクルーザーなどコマンド操作の手段を用意しておけば無駄が少ない。また仮面ライダードレイクMFやマジブルーで手札に戻せばコマンド回収要員としても使える。

- 山札の上を操作できるので、山札上を参照する効果を持つ仮面ライダーNEW電王SF等と相性がいい。

- 欄外能力で仮面ライダーイクサBMをSP1にできる点も優秀。

- 特徴｢ドラゴン｣を持つが、ビークルなので参照する機会は少ない。
