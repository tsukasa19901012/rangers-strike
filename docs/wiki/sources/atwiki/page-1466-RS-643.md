種類：SCユニット

BP：5000

SP：－

追加条件：特徴「母艦」を持つ自軍ユニットがある

CN：なし

特徴：メカ／獣／車両

テキスト：

なし

レアリティ：ノーマル

カード評価

- 追加条件持ちではあるが、必要パワーに対してＢＰが非常に高いスクランブルユニット。追加条件は同カテゴリのギガバイタスCMで満たすのが一番か。

- 単体でも高ＢＰのアタッカーとして活躍できるが、ギガライノスにゾードアップするのがこのカードの目的。ギガライノス自体が非常に優秀なカードなので是非一緒に組み込みたい。
