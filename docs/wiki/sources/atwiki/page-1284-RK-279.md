                仮面ライダーナイトサバイブ

種類：Sユニット

カテゴリ：ワイルドビースト

BP：5500

SP：1/2

必要パワー：10-

追加条件：自軍「仮面ライダーナイト」を1体捨札にすれば必要パワー0になる

CN：ＲＣ

特徴：仮面ライダー／男／ミラーライダー／サバイブ

テキスト：

※これが撃破されて捨札になったとき、自軍捨札から「仮面ライダーナイト」を1体選び、自軍ラッシュエリアに出す。

【ダークバイザーツバイ】 自軍捨札から特徴「アドベントカード」を持つカードを2枚まで選んでもよい。そうしたとき、敵軍バトルエリアからSユニットを好きな数選び撃破してもよい。ただし、選んだユニットの特徴の数の合計が、捨札から選んだカードの必要パワーの数字の合計以下になるように選ぶこと。

フレーバーテキスト

俺の願いを諦めるわけにはいかない。だが今はお前と…俺はそう望んでいる！

イラストレーター：獅子猿

レアリティ：スーパーレア

作品：仮面ライダー龍騎

収録：ザ・マスクドライダーEXP vol.4　自販：パック

カード評価

- 【ダークバイザーツバイ】はバトルエリア限定ではあるが強力な除去手段。素で使うと撃破できる数が相手に依存しがちだが、ダークレイダーを使えば問題ない。

- 龍騎サバイブと比べて撃破の条件が限定されているが、対象が複数に広がり王蛇のストライクを補助しやすくなっている。その代わり、キングライナーの除去がガードベント頼りになるため車両デッキを相手だと思うように活躍できない。

- 効果の発動にアドベントカードが最低1枚捨札にある必要があるため、ミラーライダー中心のデッキでないと効果が発動し辛い。混色のデッキに組み込み辛いのも地味なネック。
