                アギト

種類：Sユニット

カテゴリ：ダークアライアンス

BP：4000

SP：－

必要パワー：3

追加条件：なし

CN：なし

特徴：男／獣

テキスト：

【アギトファング】これをラッシュしたとき、レジストを持つ敵軍Sユニットを1体選んでもよい。そうしたとき、そのユニットとこのユニットでバトルする。

フレーバーテキスト

凶悪な牙で獲物を襲う姿はトカゲというより恐竜のそれであった。

イラストレーター：西野 幸治

レアリティ：ノーマル

作品：仮面ライダーJ

収録:ザ・マスクドライダーEXP vol.3　自販：パック

カード評価

- ラッシュ時にレジスト持ちとバトルする。

- ラッシュしたときに一度、バトルフェイズにもう一度と、ラッシュしたターンのみ二回バトルが可能。

- 特徴に獣と男の両方を持つ数少ないユニット。

- 劇中では仮面ライダーJが最初に戦った相手。このカードの効果である【アギトファング】はレジストを持つ仮面ライダーJを奇襲するシーンを意識していると思われる。また、同じアギトでも彼らとの関係はまったく無い。
