※カウンター

敵軍Sユニットがラッシュされたとき発動できる⇒自軍ラッシュエリアから、MAを持つ自軍Sユニットを1体選ぶ。そうしたとき、選んだユニットより必要パワーの数字が大きい、追加条件を持たない敵軍Sユニットを1体選び撃破する。

カード評価

- 敵軍ユニットがラッシュされたときに発動するが、効果の対象は自分で選ぶ。既にラッシュされているユニットも対象にすることができるため、疾風流超忍法と比べて、効果の発動タイミングをある程度自由に決められる。

- 効果の発動には自軍ラッシュエリアに必要パワーの低いSユニットが必要になる。マジマザーやハムスター館長のようなシステムユニットやウイング持ち等バトルエリアに出ずに使うことができるユニットと併用していくことが望ましい。
- このカードの収録された弾では、このカードと相性の良いシステムユニットが再録されている。
