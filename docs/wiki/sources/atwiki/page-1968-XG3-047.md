                シャドームーン（XG3）

種類：Sユニット

カテゴリ：ダークアライアンス

BP：5000

SP：1

必要パワー：5

追加条件：なし

CN：RC

特徴：男／改造人間／世紀王

テキスト：

※これは敵軍ターン中、SP1以上のユニットとバトルしたときバトルに勝っても撃破される。

【シャドーフラッシュ】自分の手札からユニットカードを1枚選び、捨札にしてもよい。そうしたとき、捨札にしたカードのBP以下の本来のBPを持つ敵軍ユニットを1体選び撃破する。

フレーバーテキスト

甘いな、俺は既に創世王の力を宿している。その甘さごと貴様を、世界を焼き尽くす！

イラストレーター：JUN YAMAGUCHI

レアリティ：スーパーレア

作品：仮面ライダーBLACK

収録：クロスギャザー　ザ・Wインパクト　自販：パック

カード評価

- ザマス1弾版と完全に同スペック。単純に高BPかつアタックやストライクに制限のない強力なユニットとして運用するのもいいが、RCを発動できる構築なら環境やデッキコンセプトを考慮して使い分ける必要がある。

- 【シャドーフラッシュ】はサイズ・エリアを問わず本来のBPを参照するという非常に強力な効果で、マジマザーなどBPの低いシステムユニットから大型の合体ロボまで幅広く撃破可能。大神龍を捨札にすれば、単純にBPの数値だけで考えると現状撃破できないユニットはない。

- 効果の発動が手札破棄なので連続発動するのはやや厳しい。マジブルーのようなドローソースを入れるなど手札を確保する手段を用意しておきたい。特に同カテゴリの闇の戒律は複数で効果を発動しやすく相性が良い。

- 仮面ライダーBLACK（XG3）と組み絵になっている。
