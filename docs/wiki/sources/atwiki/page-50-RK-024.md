                サイクロン号

種類：Sビークル

カテゴリ：アーステクノロジー

必要パワー：5

追加条件：なし

特徴：メカ／車両

テキスト：

※これにライドしているユニットはBP+1000される。

【サイクロンクラッシャー】自軍ターン中、これがバトルエリアに出たとき、追加条件を持たないBP4000以上の敵軍Sユニットを1体選び、持ち主のコマンドゾーンにホールド状態で置く。置けなければ捨札にする。

フレーバーテキスト

その時、戦士とマシンは運命の邂逅を果たした。エンジンが回り、伝説が走り始める。

イラストレーター：廣岡政樹

レアリティ：ノーマル

作品：仮面ライダー

収録：ザ・マスクドライダーEXP vol.1　自販：パック

再録：クロスギャザー ザ・Wインパクト　スターター（インセクトライド）

Q&A

		Q1
		「RK-024 サイクロン号」は、その効果の対象となる「追加条件を持たないBP4000以上の敵軍Sユニット」が存在しなくてもバトルエリアに出ることができますか？
		A1
		はい、ライドされていればバトルエリアに出ることができます。

カード評価

- 能力が強力で、高BPのユニットを手軽に除去することができる。

- 仮面ライダー2号やシャドームーン等のアタックでの撃破が難しい、高BPユニットをエリアを問わずに除去できるため、使い勝手は非常に良い。

- ビークルなので繰り返し使うことができるのも強み。

- ビークル除去の方法は少ないので、置いておくだけでもかなりのプレッシャーを相手に与えられる。

- パワーは5と少々重く感じるが、その能力を考えるとお釣りが来るほど。

- 最近は仮面ライダーレイのような一時的にBPを上昇させるアタッカーや、仮面ライダーキバのような除去に特化したユニットが増えてきたので相対的に弱体化したが、それでも強力な除去能力を持ったビークルであることに変わりはない。

- 参照するBPは本来の値ではない為、気力に対しても有効。

- ETでは標準的な値ではあるがBP+1000も強力。ETの高BPユニットがライドしていればバトルでの撃破は困難になる。
