                カブトライジャー（XG3）

種類：Sユニット

カテゴリ：ミスティックアームズ

BP：3000

SP：－

必要パワー：4

追加条件：なし

CN：3

特徴：男／忍者

テキスト：

※レジスト

【迅雷流剣技・カブト雷撃破】 敵軍バトルエリアから、DAを持つSユニットを1体選び撃破してもよい。そうして撃破したユニットが捨札になったとき、選んだユニットの本来のSPが1以上だったなら、敵軍捨札からカードを1枚選び、持ち主のパワーゾーンにダメージにして置く。 

フレーバーテキスト

一鍬、あまり油断するな。あの赤い奴…かなり強いぞ。

イラストレーター：K2商会

レアリティ：レア

作品：忍風戦隊ハリケンジャー

収録：クロスギャザー ザ・Wインパクト　自販：パック

カード評価

- DAを持つSユニット撃破・与ダメージの効果を持つNCを持つSユニット。

- NCはバトルエリア限定だが、ダメージを与える事が可能。ナンバーは３だが、タクスを使うことで２点ダメージを狙うこともできる。

- クワガライジャー（XG3）との相性が良く。カテゴリの追加によるNC補助とタクスによるストライク補助を同時に行うことができる。このカードを使うなら出来る限り一緒に使いたい。

- クワガライジャー（XG3）と組絵になっている。
