カード評価

- サンバルカンロボやダイナロボ、チェンジロボ、ライブロボ、サイレンビルダーと3体合体までのLユニットが出しやすくなる母艦ユニット。

- コマンドゾーンから引っ張り出せるので、ラッシュするタイミングを待って手札にMユニットカードをじっと持っておくような事をせずとも、序盤からコマンドとして活用できるので便利。

- 必要パワーが重めなのが難点だが、合体ロボのラッシュを前提に考えるならば、あまり問題ではないだろう。
