                雷鳴剣ヒカリマル

種類：オペレーション

カテゴリ：ミスティックアームズ

必要パワー：5

追加条件：なし

テキスト：

ウイングを持つ自軍ユニットを1枚選びリリースしてもよい。そうしたとき、リリースしたユニットのBPを見て、そのBP以下のBPを持つユニットを敵軍バトルエリアから1体選び、持ち主のパワーゾーンにダメージにして置く。

フレーバーテキスト

雷鳴に紛れて忍び寄る影ひとつ。閃光瞬いて倒れる影ひとつ。

イラストレーター：古賀マサヲ 

レアリティ：ノーマル

作品：忍者戦隊カクレンジャー

収録：蒼九の翼　自販：パック

カード評価

- 強力な効果のウイングを再度使用可能にしながらさらに敵ユニットをダメージ送り。これで使えないはずが無い。混色でもMAを混ぜるのであればデッキに入れても損は無い。

- ウイング持ちのリリースと敵ユニットのダメージ送りを行う。サイズを問わないので、バリブルーンのような大きいユニットと併用すると強力。

- 難点はウイングを発動してから１ターン後にならないとこのカードが使えないこと。

- ウイング持ちは主にETのカテゴリに多い。バルイーグル（XG）やメガレッドなどがあれば、このカードの効果も発動しやすくなる。

関連カード

- 能力に「ウイング」を持つユニット
