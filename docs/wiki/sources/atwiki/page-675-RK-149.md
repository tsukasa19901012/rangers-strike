                デンライナーイカヅチ

種類：Mユニット

カテゴリ：オーバーテクノロジー

BP：6000

SP：－

必要パワー：5+

追加条件：自軍Sユニットを1体パワーゾーンに送る。

CN：なし

特徴：メカ／車両／ドラゴン

テキスト：

【巨龍形態】これが自軍バトルエリアにある間、このユニットから「デンライナーゴウカ、デンライナーイスルギ、デンライナーレッコウ」の順にコンビネーションしたとき、本来のBPが3000以下の敵軍ユニットをすべて撃破する。

フレーバーテキスト

早くお姉ちゃんのところに帰りたいから、全部まとめてやっつけちゃうけどいいよね？

イラストレーター：EGC WORKS

レアリティ：ノーマル

作品：仮面ライダー電王

収録：ザ・マスクドライダーEXP vol.2　自販：パック

カード評価

- デンライナー4種のうちの1つ。ライダー環境で特徴に「ドラゴン」を持つ数少ないユニットでもある。

- 【巨龍形態】はラッシュエリアまで含む複数を対象とした除去効果。ラッシュエリアに引き篭もっているシザーズジャガーなどを撃破出来るのは良い。しかしバトルエリアを4つ埋めてしまうためOTのストライクの機会を失う事が多い点とデンライナーイスルギ以外のユニットがライダー環境では使いづらいのが難点。
- さらにそのイスルギの本来の役割であるOTライダーのSP1/4をSP1にする機会まで奪ってしまう。

- 原作での連結順はイカヅチ(電)、レッコウ(烈&quot;光&quot;)、イスルギ(&quot;石&quot;動)、ゴウカ(業&quot;火&quot;)で「電光石火」となるのだが、このカードでコンビネーションする際の並び順は異なるので注意。
