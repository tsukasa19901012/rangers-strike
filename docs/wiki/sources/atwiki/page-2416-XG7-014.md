                マジレッド（XG7）

種類：Sユニット

カテゴリ：ミステックアームズ

BP：2000

SP：！

必要パワー：2

追加条件：なし

CN：3

特徴：レッド／男／魔法 

テキスト：

※コールMA

※これは「マジフェニックス」としてつかえる。

【ジルマ・マジーロ】「SP1」

敵軍バトルエリアからSユニットを1体選び、持ち主の手札に戻してもよい。そうしたとき、戻したユニット以下のBPを持つ敵軍ユニットを1体選び撃破する。

フレーバーテキスト

ここはマルデヨーナ世界か？さっさとコイツを倒してみんなを探さないとな！

イラストレーター：Mがんぢー

レアリティ：ノーマル

作品：魔法戦隊マジレンジャー

収録：クロスギャザー ザ・ベストパートナー 自販：パック

カード評価

- 1度に2体のユニットを除去するNCを持つストライカー。

- 除去効果は1枚目に選ぶユニットはバトルエリア・Sユニット限定だが追加条件の有無やBPなどを問わず、2枚目に選ぶユニットはエリア・サイズを問わない。1体目に処理したユニットが強力なほど2体目に除去できるユニットの範囲が広がる。

- BPはあまり高くないが、アタックを含めて3：1交換ができる。

- 1枚目のカードは手札に戻るので、次のターンから相手が再利用することができるのに注意。

- コールを持つので、そのままマジフェニックスにゾードアップすることができる。

- BPは低いが、セイントカイザー（XG6）のサポートを受けられるのでアタックには強い。
