                メガイエロー

種類：Sユニット

テキスト：

※ウイング

【メガスリング】リリース状態の自軍コマンドを1つ選び、山札の上に戻してもよい。そうしたとき、このターン、敵軍ラッシュエリアのSユニットはBP-1500される。（BP0以下になったユニットは撃破される）

フレーバーテキスト

まぁまぁそう言わないの。これも正義の味方の務めでしょ。

イラストレーター：funbolt 

レアリティ：ノーマル

作品：電磁戦隊メガレンジャー

収録：蒼九の翼　自販：パック：スターター（ウイング）

カード評価

- 能力はタックやコロンといった引きこもりユニットの除去に役立つ。

- フレーバーはメガピンクのものの続き。

- BP下3桁を500にできるのでブラックコンドル（2nd）や仮面ライダーカイザなどとも相性がいい。

- 能力はミスアメリカをキーにした引き篭もり「女」デッキに対しても効果を発揮するだろう。

- イエローオウルの能力とも相性が良いので、「イエロー」デッキをETで組む場合は一考を。

- 相性が良い「イエロー」持ちと言えば、ダイナイエロー。山札トップに戻したコマンドのカードを再びコマンドに配置した上、サイズ無視でユニットを撃破できる強力なコンボだ。
