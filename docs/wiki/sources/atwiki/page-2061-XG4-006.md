                ドラゴンアーマー

種類：オペレーション

カテゴリ：ワイルドビースト

必要パワー：5

追加条件：なし

テキスト：

カテゴリにWBを持つ自軍Sユニットを1体選ぶ。そして、このカードを自軍ラッシュエリアに置き、選んだユニットをこのカードに重ねる。このカードに重ねたユニットはBP+1000され、特徴「獣奏剣」が追加される。重ねたユニットがユニットでなくなるとき、このカードを持ち主の手札に戻す。

フレーバーテキスト

「兄さん！」その悲痛な叫びは光の壁に遮られ届くことは無かった。

イラストレーター：日田慶治

レアリティ：ノーマル

作品：恐竜戦隊ジュウレンジャー

収録：XG4 ザ・ジェットアクセル　自販：パック

カード評価

- 特徴「獣奏剣」が追加されることで守護獣ドラゴンシーザーがバトルエリアに出やすくなるオペレーション。使用したユニットが倒されても手札に戻ってくるので安心。

- BPが上昇するものの必要パワーが重く、上昇量も少なめ。BP上昇が目当てならガオ・ソウルやサバイブの方が使いやすい。
