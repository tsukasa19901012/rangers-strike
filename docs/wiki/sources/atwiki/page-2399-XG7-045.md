                ロストドライバー

種類：オペレーション

カテゴリ：アーステクノロジー

必要パワー：0

追加条件：なし

テキスト：

※これが自軍コマンドゾーンにある間、自軍ラッシュフェイズ中、これをホールドして、自分の手札から特徴「ロストドライバー」を持つユニットカードを1枚選び、自軍ラッシュエリアに出してもよい。ただし、必要パワーと追加条件は満たすこと。

◎自軍山札を見て、これを使用するためにホールドしたコマンドと同じ必要パワーを持つSユニットのカードを1枚選び、相手に見せてから手札に加えてもよい。その後、山札をシャッフルする。

フレーバーテキスト

失われゆく者達に手を伸ばす。諦めない者だからこそ切札を手に出来る。

カード評価

- 初の主役以外のライダーのベルトカード。ダブルドライバーに似たコマンドで使えるラッシュ効果を持つが、特徴「ロストドライバー」を持つユニットはそこまでカテゴリがバラけているわけでもないので、複数投入するデッキでもわざわざ使う機会は少ないかもしれない。

- 通常のオペレーションとしては、スーパー戦隊アドレスブックの互換とも言える汎用性の高いSユニットサーチ効果を持つ。使うためホールドしたコマンドと同じパワー限定なのが厳しいが、あちらより低パワーで追加条件やカテゴリさえも関係なくサーチできるのはかなり魅力的。

- ホワイトスワンやグリーンサイのような低パワーのユニット同士のコンボパーツや、アバレッドや仮面ライダー電王PFなど「－」のゾードアップ元を序盤にサーチする際には重宝する。

- リードを使って使用した場合、ホールドしたユニットの必要パワーを参照する。
