カード評価

- ライダー2弾で登場したワームサナギ体の2ndカード的なもの。
- 旧弾と異なるスペックで特徴に2ndを持たないカードはこれが初。

- 旧弾と同様に、デッキに何枚でも入れられることや怪人をもっていることを生かしてアポロガイストや巨大化爆弾、ギョダーイと組み合わせることができる。
