                クロコダイルオルフェノク格闘態

種類：Sユニット

カテゴリ：ダークアライアンス

BP：500

SP：！

必要パワー：2

追加条件：なし

CN：なし

特徴：ラッキークローバー／オルフェノク／怪人／男

テキスト：

※これは自軍捨札にある「クロコダイルオルフェノク格闘態」のカード1枚につきBP+3000される。 

※これはBP5000以上のとき「SP1」になる。 

【三つの魂】敵軍ターン中、これが撃破されて捨札になったとき、次の効果を発動できる⇒自軍山札を見て「クロコダイルオルフェノク格闘態」のカードを1枚選び、相手に見せてから自分の手札に加えてもよい。その後、自軍山札をシャッフルする。

フレーバーテキスト

1度くらい死んだところで、彼は止まりませんよ。

イラストレーター：添田一平

レアリティ：ノーマルレア

作品：仮面ライダー555

収録:ザ・マスクドライダーEXP vol.4　自販：パック：スターター（龍騎） 

カード評価

- 【三つの命】は相手ターンに撃破されないと発動しない。パワーやコマンドに送られた際には発動しないため相手にアタックさせるゴーマ宮やサイズを変えて、コマンドやパワーに送られづらくするギョダーイ等で補助する必要がある。

- 捨札に２枚ある状態の性能は優秀なのでマーフィーK9を使ってサーチするなどして３枚目まで出し切りたい。

- ボウケンブラックで直接捨札にするという手もあるが、ストライクできる状態にまで持っていくにはビートチェイサーの補助も必要になるだろう。

- このカードのＢＰを上昇させるアポロガイストとも相性が良い。
