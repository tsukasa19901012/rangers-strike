テキスト：

【シティガーディアンズ隊長】これは自軍バトルエリアの特徴「戦闘員」を持つユニット1体につきBP＋1000され、BP5000以上のとき「SP1」になる。これが撃破されたとき、特徴「戦闘員」を持つ自軍ユニットを2体選び、かわりに捨札にしてもよい。

フレーバーテキスト

力は裏切るわ…女の言葉が甦る。ならば、裏切ろうと思いすらせぬほどにねじ伏せるまで。 

イラストレーター：Mitsuhiro Arita

レアリティ：レア

作品：未来戦隊タイムレンジャー

収録：五龍の逆鱗　自販：パック

カード評価

- 戦闘員を利用したカード。シティガーディアンズ隊員やゼクトルーパーあたりを使用するといい。仮面ライダーザビーMFとのシナジーで戦闘員をストライカーにするのもいい。その場合はミラーワールド等で戦闘員を保護する手段が必要になる。

- 逆に言うと、それ以外の利用方法はVレックスロボを使用した専用デッキのみである。大人しく2ndに期待したい。
- XG4にて待望の再収録。あちらの方がVレックスロボとの相性も良いので、こちらは戦闘員デッキのみでの活躍となるだろう。
