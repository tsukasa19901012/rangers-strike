                メガシップ

種類：Lユニット 

カテゴリ：アーステクノロジー 

BP：7000

SP：－

必要パワー：4+

追加条件：自軍Sユニットを5体捨札にする

CN：なし

特徴：メカ／母艦

テキスト：

※このカードの追加条件は、自軍捨札にウイングを持つSユニットのカードが5枚以上あるとき、次のように変更される⇒追加で自軍コマンドを2つホールドする。 

【シールドシステム】これが自軍エリアにある間、自軍ラッシュエリアにあるBP1000以下のユニットは相手に選ばれない。 

フレーバーテキスト

激しい敵の砲火に晒されながら、乗組員の誰もが彼等が来る事を信じていた。

イラストレーター：宮崎 良平

レアリティ：ノーマル

作品：電磁戦隊メガレンジャー

収録：蒼九の翼　自販：パック

カード評価

- 【シールドシステム】でコロンやタックなどの引きこもりユニットを守ることができるものの、追加条件が厳しいためなかなか使いにくいのが難。

- ウイングを持つSユニットが5枚以上捨札にあれば追加条件が変更されるので、超電子頭脳やJPカードと組み合わせるのも手。
