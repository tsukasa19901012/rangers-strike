                マジピンク×マジブルー

種類：Sユニット

カテゴリ：ミスティックアームズ 

BP：3000

SP：！

必要パワー：3+

追加条件：追加で自軍コマンドを1つホールドする

CN：3

特徴：ブルー／ピンク／女／魔法

テキスト：

※クロス1

※これは「マジマーメイド＋マジフェアリー」としてつかえる。

【トゥインクルイリュージョン】SP1

自軍山札の上から1枚をオモテにしてから手札に加える。そうしたとき、そのカードと同じ必要パワーを持つ敵軍Sユニットを1体選び、持ち主の山札の上に戻してもよい。

フレーバーテキスト

なんだか突然召還されて･･･こんな時に魁は何処に行ったのよ！

イラストレーター：funbolt

レアリティ：レア

作品：魔法戦隊マジレンジャー

収録：クロスギャザー ザ・ベストパートナー　自販：パック

カード評価

- マジブルーとマジピンクのクロスカード。NCはドロー、除去、ストライクを同時に行える。

- 【トゥインクルイリュージョン】はボウケンシルバー（2nd）のような山札を操作する効果と組み合わせることで、ドローと除去の効果が使い易くなる。

- 「～としてつかえる」というテキストを持つので、マジキングやマジドラゴンの合体素材に使える。一方でレジェンドマジブルーやレジェンドマジピンクにはゾードアップできない。
