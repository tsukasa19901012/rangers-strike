                コーカサスビートルアンデッド

種類：Sユニット

カテゴリ：ダークアライアンス

BP：4500

SP：－

必要パワー：5

追加条件：なし

CN：なし

特徴：アンデッド／昆虫

テキスト：

※これはアタックされるときBP+2000される。

【カード強奪】これがバトルエリアからラッシュエリアに戻るとき、相手の手札を見ないで1枚選んでもよい。そうしたとき、選んだカードを持ち主の山札に戻してシャッフルした後で、相手は1枚ドローする。

フレーバーテキスト

こちらの思惑などお構い無しに、全てを台無しにするほどの―圧倒的な力。

イラストレーター：Kakoi Kazuhiko

レアリティ：ノーマル

作品：仮面ライダー剣

収録：クロスギャザー ザ・ファーストエンカウント　自販：パック

カード評価

- 手札の数ではなく、手札の内容を変更させる能力。仮面ライダーブレイドに始まるブレイドライダー達や、シンケンゴールド、風雷丸のようなカードへの対抗策になり得る。

- 相手が必要枚数の多いコンボを狙っているときに使うと、とても嫌がられる。

- ゴーゴーダンプやバトルダンスを使えば、自軍ターン中にも効果を発動できる。
