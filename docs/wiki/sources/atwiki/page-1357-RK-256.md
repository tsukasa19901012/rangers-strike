                カブトロー

種類：Sビークル

カテゴリ：アーステクノロジー

必要パワー：4

追加条件：なし

特徴：メカ／車両

テキスト：

【カブトローサンダー】 自軍ターン中、これがバトルエリアに出たとき、敵軍バトルエリアからSPが空欄でないSユニットを1体選んでもよい。そうしたとき、このターン、選んだユニットはBP－1000される。（BP0以下になったユニットは撃破される）

フレーバーテキスト

夢を追いかけ果て無き道を、前だけ見つめて突っ走る！

イラストレーター：Masakazu Fukuda

レアリティ：ノーマル

作品：仮面ライダーストロンガー

収録：ザ・マスクドライダーEXP vol.4　自販：パック

カード評価

- 仮面ライダーストロンガーの愛機。BPが一番高ければSP1になれるストロンガーの能力を補佐するような効果を持つ。

- BP1000までならバトルを挟まずに撃破できるので、仮面ライダー蛮鬼やレッドルなどが相手ならばレジスト発動をさせずに除去できる。反面、「SPが空欄でないSユニット」という制約があるため仮面ライダードレイクMFやがんがんじいなどには効果が無い。

- テントローとのコンビネーションを発動しようとするとこれにライドしたユニットのRC発動ができないので使い勝手が悪くなる。カブトローは相手のBP減少効果を持つビークル、テントローは女ユニットなら誰でも乗れるBP補強ビークルと考えてそれぞれ単品で運用する方がいいだろう。
