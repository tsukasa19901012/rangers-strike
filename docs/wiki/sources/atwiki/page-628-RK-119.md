種類：Sユニット

フレーバーテキスト

戦いが始まると同時に、一族は動き出す。彼らだけに与えられた“数の力”を武器として。

イラストレーター：二見敬之

レアリティ：ノーマル

再録：ザ・マスクドライダーEXP vol.3　電王＆龍騎スターター専用（電王）

カード評価

- 速攻デッキの先鋒。序盤から前に出てただひたすらにストライク。

- 枚数制限が無いのを利用し、デッキに大量に入れてミラーワールドを使用すると相手は非常に倒しづらくなる。

- ライダー3弾で契約主とお仲間がやっとこ参戦。使い道に幅が出来た。
