                冥王ジルフィーザ

種類：Sユニット

カテゴリ：ダークアライアンス

BP：8000

SP：1

必要パワー：9+

追加条件：自軍Sユニットを3体捨札にする

CN：なし

特徴：災魔一族／男

テキスト：

※これは敵軍ターン中、「SP1」以上のユニットとバトルしたときバトルに勝っても撃破される。

【天の災】これをラッシュしたとき、お互いに次のようにする。自分自身のパワーゾーンからダメージではないカードをすべて捨札にする。その後、手札をすべてパワーゾーンに置く。

		「RS-124 超電子レーダー」が配置されている状態で、「RS-092 冥王ジルフィーザ」をラッシュしました。このとき効果はどちらから順に処理しますか？

カード評価

- パワー9と激重な点に加えてキツイ追加条件もあるためラッシュが非常に厳しい。SP1とバトルするとあっさり退場してしまう点もがっかり。

- 【天の災】はお互い手札を全部放棄してパワーにつぎ込むという超豪快な効果。しかし、このユニットをラッシュしている時点でパワーは存分に足りているため、恩恵はあまりに少ない。手札を無くさせるという効果だけが頼り。

- アレと組み合わせるのが有効か。

- 花忍者ランとシザースジャガーとゴ・ガドル・バのコンボでラッシュするのも近道。

- ダイナピンクでコマンドを手札に戻した状態で、上記のコンボをバトルフェイズ中に行えば、コマンド除去とパワーかく乱と手札破壊を同時に行える。

- 能力を2回発動すれば手札もパワーも破壊できる。バトルコサックとバトルダンスの組み合わせなら…。

- 戦闘員デッキに組み込めば、ラッシュに必要なSユニットに戦闘員を充てたり、必要パワーを巨神ゴードムで減らしたりできる。
