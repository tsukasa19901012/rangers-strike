                白熱する実況

種類：オペレーション

カテゴリ：ワイルドビースト

必要パワー：4

追加条件：なし

テキスト：

※常駐

自分がLユニットをラッシュしたとき、その追加条件で捨札にした合体ユニットのカードがあれば、すべてウラ向きにしてそのLユニットの下に重ねる。そのLユニットは、ユニットでなくなるとき下に重ねたウラ向きのカードを1枚捨札にすれば、その場に留まる。

これが常駐置き場を離れるとき、自軍Lユニットの下にウラ向きに重ねたカードがあれば、すべて捨札にする。

カード評価

- Lユニットの撃破や除去を防ぐオペレーション。何回防げるかはユニットによって異なるが、せっかく出したLユニットを即座に失うような事態を防げるのは大きい。

- 主に疾風流超忍法などで簡単に除去できるキラーオーのようなBP8000以下の合体ロボのラッシュを狙うデッキで使用される。

- 追加条件に「合体ユニットを捨札にする」を持つLユニット以外には使えない。例えば、サンバルカンロボには使えるが、ダイデンジンには使えない。

- XG2で再録されたが誤植で龍折神の特徴がそのまま付いていたり常駐のマークが消えていたりする。
