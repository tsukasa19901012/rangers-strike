※これは自軍コマンドを1つホールドしなければバトルエリアに出られない。

カード評価

- 相手のコマンドを破壊するには前進コストと合わせて実質２枚自軍コマンドをホールドしなくてはいけない。ギンガベリックで相手のコマンドを代わりにホールドしたりETと組み合わせてコマンドを増やすなど工夫が必要。

- 特徴人型を持つユニットからコンビネーションすればナンバーを無視して効果が使えるが、現在WBでは重騎士からしかこの効果が使えない。
