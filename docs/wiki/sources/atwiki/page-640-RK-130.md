【スペード5－キック】自軍ラッシュフェイズ中、これをラッシュするかわりに捨札にして、特徴「仮面ライダー」を持つ自軍ユニットを1体選んでもよい。そうしたとき、このターン、選んだユニットは次の能力を得る⇒ストライクしたとき、レジストを持つ敵軍Sユニットを1体選び、撃破する。

カード評価

- ユニット的には大した力は無いが、ストライクしつつ面倒なレジスト持ちを除去出来る能力は地味に強力。エリアも問わないので使い勝手も悪くない。

- 能力上、仮面ライダーと組まないと意味が無いので黒単にはさっぱり向かないのが難点といえば難点か。

- 現在のDAに特徴「仮面ライダー」を持つユニットは仮面ライダーガオウや仮面ライダーネガ電王や仮面ライダーアークがいるが、パワーが重かったりデメリットが厳しかったりするので、やはり黒には向かない
