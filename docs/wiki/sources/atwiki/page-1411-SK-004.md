                仮面ライダークウガUF（アルティメットフォーム）

種類：Sユニット

カテゴリ：ミスティックアームズ

BP：5000

SP：1

必要パワー：7+

追加条件：自軍常駐置き場のカードを（ウラ向きのカードはウラ向きのまま）4枚選び捨札にする

CN：なし

特徴：仮面ライダー／男／アマダム

テキスト：

【凄まじき戦士】これをラッシュしたとき、この追加条件で捨札にしたカードを見て、DAを持たないカードをすべてこれの下に好きな順でウラ向きに重ねる。このとき、ウラ向きに4枚重ねなかったなら、「仮面ライダークウガUF」以外の自軍ユニットをすべて捨札にする。また、これがユニットでなくなるとき、これにウラ向きで重ねたカードをウラ向きのまま1枚選び捨札にして、これをその場に留める。

フレーバーテキスト

究極へと至る道は一つではない。ただ人の為に己を高め空と成し我を得よ。

Q&A

		Q1
		敵軍ターン中、敵軍ユニットの効果で自軍ゾーンにあった「SK- 004 仮面ライダークウガUF」が自軍ラッシュエリアに出ました。このとき、「SK-004 仮面ライダークウガUF」の【凄まじき戦士】の効果が発動しますが、「SK-004 仮面ライダークウガUF」は追加条件を満たさずラッシュエリアに出たため「追加条件で捨札にしたカード」が存在しません。この場合どのように処理をすれば いいでしょうか？
		A1
		「追加条件で捨札にしたカード」を0枚として参照し、処理を続行してください。
		Q2
		自軍エリアにウラ向きのカードが重なっている「SK-004 仮面ライダークウガUF」があるとき、敵軍「RS-322 ベン・G」の【人身略取】が発動し、相手は追加条件に「自軍Sユニットを1体捨札にする」と書かれたMユニットのカードを捨札にしました。自軍Sユニット が「SK-004 仮面ライダークウガUF」しかない場合、追加条件を満たす為に「SK-004 仮面ライダークウガUF」を捨札にしなければなりませんが、このとき「SK-004 仮面ライダークウガUF」は【凄まじき戦士】の効果で場に留まることはできますか?
		A2
		はい、「SK-004 仮面ライダークウガUF」の【凄まじき戦士】の効果は強制なので、その場に留まることができます。ただし、その場合はまだ場に「SK-004 仮面ライダークウガUF」がいるので、追加条件を満たすことは可能であるとして、「RS-322 ベン・G」の効果を続行して下さい。
		Q3
		敵軍「SK-004 仮面ライダークウガＵＦ」がラッシュされ【凄まじき戦士】を発動したとき、それに対して「XG7-059 トリガードーパント」の【ゲームスタート……】を発動しました。このとき、【凄まじき戦士】の「また」以降の効果も無効化されますか？
		A3
		いいえ、それはできません。「また」で続く効果は、それ以前の効果とは独立した効果だと考えてください。

カード評価

- パワーの割りにBPが低く追加コストがやや厳しいが、アタック・除去耐性を持つため場に残り易い。カード枚数の許す限り1ターン中に何回でも生き残れるのが強み。

- 必要パワーが重いのでアークルでパワーを無視してラッシュを狙うのが基本。
- 仮面ライダークウガDF（XG4）からのモーフや仮面ライダーディケイドCFの効果でラッシュすることもできなくはないが、追加条件を満たせないためデメリット効果で自軍ユニットが全滅してしまう。耐性も得られないため、このユニットの旨みがほとんど無くなってしまう。

- 追加条件を満たすための常駐はライダーパスや超変身が使われる。

- 相手の場に冥獣人ニンジャキリカゲがいる場合、【凄まじき戦士】が発動できなくなる上に、BPを強化していなければ相打ちにされる。まさに天敵。

- 単純な除去耐性でよく似たテキストを持つ仮面ライダーディケイドCFとは違いキリカゲに弱い点はネックであるが、反面効果名を持つテキストである為仮面ライダーW・FJでは無効化されない為一長一短といえる。

- このカードの強みはこれだけの除去耐性を持ちながら常にSP1である点。単色でも連続ストライクが可能であり、且つ単独で勝負を決められるだけの打点を稼ぐことも可能である。

- フレーバーテキストには「空我（クウガの漢字表記名）」が隠されている。
