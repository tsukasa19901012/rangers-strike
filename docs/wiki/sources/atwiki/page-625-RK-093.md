カード評価

- 引きこもりユニットを撃破できるユニット。嫌らしいユニットを選んで除去してしまおう。欠点はパワー5とやや重いところ。言わずと知れたライダーシリーズの元祖「怪人」なので巨大化爆弾で大きくなれる。

- ウイングには「これはバトルエリアに出られない」の1文が含まれるため、【要人の暗殺】の対象になる。サイズ無視で効果を発揮するため、セイクウオーのような強力なウイング持ちユニットを除去できるのは大きい。

- 仮面ライダー鋭鬼のところでも触れたが、テキストの説明の中に対象の文が書かれていても有効なので蜘蛛男は蜘蛛男を能力で撃破することが出来る事になる。
