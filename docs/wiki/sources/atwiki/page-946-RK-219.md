                アルビローチ

種類：Sユニット

カテゴリ：ダークアライアンス

BP：500

SP：－

必要パワー：3

追加条件：なし

CN：なし

特徴：アンデッド／昆虫

テキスト：

※このカードはデッキに好きな枚数入れてもよい。

フレーバーテキスト

圧倒的な数の白い軍団は、雪崩のように戦場を押し潰した。

イラストレーター：黒田 清桐

レアリティ：ノーマル

作品：仮面ライダー剣 MISSING ACE

収録:ザ・マスクドライダーEXP vol.3　自販：パック

カード評価

- 枚数制限は無いが、特徴に戦闘員は持っていないのでゾル大佐などで補強する事は出来ない。

- アルビノジョーカーを主軸にしたデッキならば能力発動やバトルエリアに出るための生け贄ということもあり結構な枚数を用意したいところ。

関連カード

- 特徴「昆虫」関連

コメント

-  同弾に収録され、同じカテゴリと同じ特徴に昆虫を持つユニット、そのうえ女性ユニットの強化ができるアントロードと違ってバニラなので、アルビノジョーカーの能力発動やバトルエリアに出るための生贄以外役に立ってない  -- 名無しさん  (2009-10-24 11:58:44)
