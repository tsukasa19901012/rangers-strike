種類：Sユニット

BP：3000

テキスト：

※レジスト

【鬼幻術・鬼火】これが自軍エリアにある間、自軍バトルフェイズ中、敵軍ユニットがラッシュされたとき、これをホールドしてもよい。そうしたとき、ラッシュされたユニットを持ち主のパワーゾーンにダメージにして置く。

フレーバーテキスト

鬼の力と人の心が響き合い、魔を焼き尽す炎となる。

イラストレーター：小城　崇志

レアリティ：ノーマル

作品：仮面ライダー響鬼

収録：クロスギャザー ザ・ドラゴンタイガー　自販：パック

カード評価

- ズ・バヅー・バや仮面ライダー電王RFのような敵ユニットを場に出す能力と相性がよい。特に仮面ライダーギルス（XG2）とはカテゴリも収録も同じであるためあわせて使いやすい。
- 上記のカードで自軍ターンにモーフを狙う場合のフォローにも有効。

- セイントカイザー（XG6）や「－」の追加条件を持つユニットなど、相手バトルフェイズ中にラッシュする効果を持つユニットへのメタにもなる。

- このカードからも仮面ライダー響鬼紅へゾードアップ可能。響鬼はコストの重いカードが多く、最速でゾードアップを狙う場合このカードを使用する必要があったが、（XG3）でもっと軽い響鬼が収録された。
