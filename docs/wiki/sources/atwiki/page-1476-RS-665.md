                キョウレツオー

種類：Lユニット 

カテゴリ：オーバーテクノロジー 

BP：16000

SP：！

必要パワー：7+

追加条件：自軍合体ユニットを捨札にする 

CN：なし

特徴：恐竜／人型／炎神

テキスト：

合体―キシャモス＋ティライン＋ケライン

【キョウレツエクスプレス】 自軍ターン中、これがバトルエリアに出たとき、次の効果を発動できる⇒自軍山札の上から1枚をオモテにして、それが特徴「炎神」または「恐竜」を持つカードだったなら、このターン、これは「SP1」になる。その後、オモテにしたカードは山札の下に戻す。

フレーバーテキスト

赤く燃える戦士の心が、古代の眠りより目覚めし王を闘いの地へと誘（いざな）った。

イラストレーター：R-AREA 

レアリティ：ノーマルレア

作品：炎神戦隊ゴーオンジャー

収録：蒼九の翼 自販：パック

カード評価

- 三体合体の炎神の中では最高のBPを誇る代わりにＳＰが「！」になっており、安定したストライクが難しくなった。高いＢＰを持つため相手の合体ロボ同士の戦いで優位に立てる。

- 特徴「恐竜」持ちなのでVコマンダーの恩恵を受けられる。素材となるユニットも炎神と恐竜の特徴を持つため、サーチは容易。上手くすればかなり早い段階でのラッシュが可能である。

- 【キョウレツエクスプレス】を安定して使うためにも、クライマックス刑事やボウケンシルバー（2nd）でデッキトップを操作する手段を用意しておこう。

- 山札下に戻した炎神または恐竜持ちのカードを仮面ライダードレイクMFで手札に回収することで、クライマックス刑事とのコンボを毎ターン確実に決められる。全てOTで揃えられるのもポイント。

- 呉越同舟を利用すればガオジュラフのJCでSP2になれる。頼もしい相棒の効果も活かし易くなるので赤青でこのカードをつかうなら狙ってみよう。
