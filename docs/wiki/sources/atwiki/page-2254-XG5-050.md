カード評価

- 4パワーでBP4000・SP1/3・レジストはMAのSユニットの中ではかなりの高スペック。しかし旧版と比較すると、デッキに入れやすくなった反面効果が地味。デッキの傾向やバランスに応じて使い分ける必要がある。

- 【語る背中】の発動条件は相手依存だが、分数SPが増えた現在の環境なら発動はそれほど難しくない。相手への牽制とするのもありか。
