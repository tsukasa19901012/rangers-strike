                スピルバン（XG4）

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：4000

SP：1/4

必要パワー：4

追加条件：なし

CN：なし

特徴：メカ／男 

テキスト：

【トリプルボンバー】このユニットの両隣に特徴「女」を持つ自軍ユニットが並んでいる間、このユニットはBP+2000され、次の能力を得る⇒自分がターンを終えるとき、このユニットのBP以下のBPを持つ敵軍ユニットを1体選び持ち主のパワーゾーンに送る。 

フレーバーテキスト

両手に花？甘く見てると女は怖いぜ。

イラストレーター：ＮＡＫＡＧＡＷＡ

レアリティ：ノーマルレア

作品：時空戦士スピルバン

収録：XG4 ザ・ジェットアクセル　自販：パック

カード評価

- ストライクと除去を同時にこなせたXG1版とは反対に、コントロールデッキで活躍する能力になった。

- 【トリプルボンバー】は条件が少々厳しいがエリア・サイズを問わずにBP6000以下のユニットをパワーゾーンに送れるので強力。BP上昇の効果は敵軍ターン中も有効。

- 理想は女を持つユニットからコンビネーションしつつストライクし、デカピンクでロックするという状況。青緑のコントロールデッキでレッカー以外の手段で場を制圧することができる。
