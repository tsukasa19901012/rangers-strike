                仮面ライダーキバDF（ドッガフォーム）

種類：Sユニット

カテゴリ：ミスティックアームズ

BP：5000

SP：－

必要パワー：4

追加条件：なし

CN：なし

特徴：仮面ライダー／男／魔皇力

テキスト：

※これは自軍コマンドを2つホールドしなければバトルエリアに出られない。

【ドッガ・サンダースラップ】自軍ターン中、これがバトルエリアに出たとき、このユニットをホールドしてもよい。そうしたとき、敵軍バトルエリアから、自分の手札の枚数以下の必要パワーの数字を持つ敵軍Sユニットを1体選び撃破する。

フレーバーテキスト

その力は電気を纏い牙を剥き、全てを砕く槌となる。

イラストレーター：小城 崇志 

レアリティ：レア

作品：仮面ライダーキバ

収録:ザ・マスクドライダーEXP vol.4　自販：パック：スターター（クウガ）

Q&A

		Q1
		自軍「RK-312 仮面ライダーキバDF」が、【ドッガ・サンダースラップ】を発動して敵軍「RK-203 仮面ライダーファイズAF」を撃破しました。これにより、敵軍捨札から「RK-064 仮面ライダーファイズ」がラッシュされたので、自軍ユニットは「モーフ」の効果を発動することができますが、このとき置き換えたユニットがバトルエリアに 出ていたなら、アタックやストライクをすることができますか？
		A1
		置き換える元のユニットが、まだアタックやストライクを行っていないのであれば、置き換えた後のユニットもアタックやストライクを行うことができます。
		Q2
		「RK-312 仮面ライダーキバDF」は、「RK-316 キバットバットIII世」の【フエッスル】の効果で与えられた「モーフ」によってバトルエリアに出る際にもコマンドをホールドする必要がありますか？
		A2
		はい、コマンドをホールドしてください。

カード評価

- 高BP、ストライク出来ない、バトルエリアに出るのにコマンドのホールドが必要と、仮面ライダークウガTFを彷彿とさせるユニット。ただし、こちらはレジストこそ無くなったものの除去能力が付き、後述の特徴「魔皇力」を利用したカードでの強化が出来るため活躍の場は十分ある。

- 【ドッガ・サンダースラップ】はガルル・ハウリングスラッシュと違って撃破止まりな代わりに、自分の手札の枚数に依存する効果になり、扱い易くなった。

- 高いBPと除去能力で敵を撃破する機会が多いため、ブロンブースターやキャッスルドランとの相性はキバの3フォームの中でも一番。ストライク出来ない弱点をフォローし、追加ドローも狙える。

- 欠点はクウガTFと同じでコマンドのホールドが2つ必要な点。勇気の魔法やジェイクロッサーなどでフォローしてやる必要がある。

- 似たようなポジションのクウガRTと違い、モーフでバトルエリアに出る際もコマンドをホールドする必要があるので注意。

- モーフの基点として優秀な仮面ライダーキバ（XG5）が登場したことによって、以前よりは幾分か使い易くなった。
