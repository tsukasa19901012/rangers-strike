                仮面ライダーキバDGBKF（ドガバキフォーム）

種類：Sユニット

カテゴリ：ミスティックアームズ

BP：4500

SP：1/3

必要パワー：7-

追加条件：自軍「仮面ライダーキバ」を1体捨札にすれば必要パワー0になる

CN：なし

特徴：仮面ライダー／男／魔皇力 

テキスト：

※これが撃破されて捨札になったとき、自軍捨札から「仮面ライダーキバ」を1体選び、自軍ラッシュエリアに出す。

※レジスト（これがバトルで撃破されたとき、捨札にするかわりにこれをホールドしてその場に留めてもよい）

【ダークネスムーンブレイク】自軍ターン中、これがバトルエリアに出たとき、このユニットをホールドしてもよい。そうしたとき、敵軍Sユニットを1体選び、持ち主のパワーゾーンにダメージにして置く。

フレーバーテキスト

三色の音色が響き渡り、闇の住人達が次々と裂け撃ち砕かれ消えていった。

イラストレーター：小城 崇志

レアリティ：レア

作品：仮面ライダーキバ

収録：ザ・マスクドライダーEXP vol.4　自販：パック

再録：XG5 ザ・チケットブレイカー　スターター（カードヒーローデッキ）

カード評価

- 仮面ライダーキバからゾードアップするユニット。BPが上昇し、リリース状態でラッシュされるため、【ダークネスムーンブレイク】が格段に使い易くなった。

- キバットベルトで素出しすることができる。強力な効果である【ダークネスムーンブレイク】をラッシュしたターンに使えるため対処が困難なこともあり非常に強力。

- ディケイド キバからもゾードアップが可能。こちらはモーフを使って更に早くラッシュが出来るようになっただけでなく、このカードが撃破された時にディケイド キバをラッシュして、次のターンにダメージ送りが狙える。モーフ前提での運用なので使うデッキを選ぶのが難点か。

- FFRを多用するデッキでは、仮面ライダーディケイド（XG3）の効果で呼び出した仮面ライダーキバ（XG2）からゾードアップする方法もある。手札のこのカードとディケイドまたはディケイドライバーのみで相手に依存しないためさらに素早く確実にラッシュを行える。

- ガルル獣人態とバッシャー獣人態、ドッガ怪人態の効果でのラッシュも可能。こちらは条件が厳しく、この効果でのラッシュは難しい。

- マイナスの追加条件であるためパワー7から直接ラッシュされる光景も多い。特にOTとの混色においては素出しを前提として単独でデッキに組み込まれることも多い。
