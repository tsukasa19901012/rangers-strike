                ズー

種類：Sユニット

テキスト：

【バームニードル】これをラッシュしたとき、カード1枚につきBP1000として、相手の手札の枚数分のBPを計算し、そのBP以下の敵軍ユニットを1体選び撃破してもよい。

フレーバーテキスト

突然降ってきたハリの雨、空には妖艶な悪魔が羽ばたいていた。

イラストレーター：不破

レアリティ：ノーマル

作品：仮面ライダーJ

収録:ザ・マスクドライダーEXP vol.3　自販：パック：スターター（キバ）

再録：ザ・マスクドライダーEXP vol.4　スターター（龍騎）

Q&A

		Q1
		敵軍エリアに「RK-305 仮面ライダー電王SF」があり、敵軍コマンドゾーンに「RK-306　仮面ライダー電王AF」がある状態で、相手の手札が3枚あったとします。この状態 で、自軍ターンに「RK-193 ズー」をラッシュし【パームニードル】を発動しようとしたところ、相手は「モーフ」の能力を使い「RK-305　仮面ライダー電王SF」と「RK-306 　仮面ライダー電王AF」を入れ替えました。「RK-306 仮面ライダー電王AF」はBP4000なので、上記の状態では【パームニードル】の効果は及びませんが、効果が同時発動しているのでターンプレイヤーを優 先し「モーフ」の発動前まで巻き戻した上で【パームニードル】の効果を使用することはできますか？
		A1
		いいえ。「ラッシュしたとき」とある「RK-193 ズー」の【パームニードル】の効果が先に発動し、「RK-305　仮面ライダー電王SF」は「ラッシュされたとき」とある「モーフ」が発動する前に撃破され捨札になります。

カード評価

- 相手の手札の枚数に効果が依存するため単体だと使いづらい。MAのキャッスルドランやDAのパラダイス・ロスト等で相手の手札を増やしながら使いたい
