                ジライヤ第二装着

種類：Sユニット

カテゴリ：ミスティックアームズ

BP：4500

SP：1/3

必要パワー：7-

追加条件：自軍「ジライヤ」1体を捨札にすれば必要パワー0になる

CN：なし

特徴：戸隠流／男／忍者／パワープロテクター

テキスト：

※これが撃破されて捨札になったとき、自軍捨札から「ジライヤ」のカードを1枚選び、自軍ラッシュエリアに出す。

【十文字斬り】自軍ターン中、これがバトルエリアに出たとき、敵軍捨札からユニットカードを1枚選んでもよい。そうしたとき、選んだユニットカードと同じカード名の敵軍ユニットを1体選び、持ち主のパワーゾーンにダメージにして置く。

フレーバーテキスト

力を得て変わるのは、姿形だけでは無い。心と技も共にあり、悪を切り裂く剣に変わる。

イラストレーター：NAKAGAWA

レアリティ：スーパーレア

作品：世界忍者戦ジライヤ

収録：スペシャルメタルエディション　自販：パック

カード評価

- オルタナティブ・ゼロの【無意識の記憶力】に近い効果の【十文字斬り】は除去とダメージを一度に行える。サイズに影響されないのでＬユニットであっても問答無用。さらにラッシュエリアにも届く。と、刺さればかなり強力。

- ジライヤを捨てればパワー0になるのだが、肝心のジライヤがパワー5なのであまり旨味を感じられないのが残念。

- 肝心のジライヤはメタルエディションには収録されていない。七忍の炎陣のプロモーションレアとして収録されている。幸い、封入率が高く手に入れやすいので集めるのは楽。
