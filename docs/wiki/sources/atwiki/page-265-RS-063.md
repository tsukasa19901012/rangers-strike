                ボウケンブラック

種類：Sユニット

カテゴリ：アーステクノロジー

BP：2000

SP：！

必要パワー：1

追加条件：なし

CN：5

特徴：ブラック／男

テキスト：

【ラジアルハンマー】「SP1」自軍山札の上から3枚を見てもよい。そうしたとき、1枚選んで山札の上に戻し、それ以外を捨札にする。

フレーバーテキスト

退路無し、進むも危機。ここが度胸の見せ所。 

イラストレーター：funbolt

レアリティ：ノーマル

作品：轟轟戦隊ボウケンジャー

収録：英雄の再誕　自販：パック

再録1：三界の獅子　スターター（轟の翼）

再録2：リバイヴァ　自販：パック

カード評価

- 【ラジアルハンマー】はデッキトップの操作とデッキからカードを捨札に送る事でデッキの圧縮を行える。、主に捨て札置き場を利用するカードとセットで使われる。山札のトップを操作する能力はおまけ程度と割り切ったほうがいいかもしれない。

- 捨札置き場のカードを増やすことによってバトルフィーバーロボ（2nd）の捨札7枚以上という条件を満たしたり、リュウタロスなど捨札の数を参照するようなカードの効果を補助することができる。

- 効果でデッキから欲しいカードを捨札に送り、ゴーレッドやイエローアーマー、スーパーレスキューなどで回収するコンボも強い。

- 8弾でボウケンレッドと同じくアクセルテクター装備が収録された。
