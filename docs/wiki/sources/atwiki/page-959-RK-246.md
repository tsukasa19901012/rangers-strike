                仮面ライダーキバGF（ガルルフォーム）

種類：Sユニット 

カテゴリ：ミスティックアームズ 

BP：500

SP：1/3

必要パワー：3

追加条件：なし

CN：なし

特徴：仮面ライダー／男／魔皇力

テキスト：

※これは自軍パワーゾーンのオモテ向きのカード1枚につきBP+1000される。

【ガルル・ハウリングスラッシュ】自軍ターン中、これがバトルエリアに出たとき、このユニットをホールドしてもよい。そうしたとき、敵軍バトルエリアから相手の手札の枚数以下の必要パワーの数字を持つSユニットを1体選び、持ち主のパワーゾーンにダメージにして置く。 

フレーバーテキスト

笛の音（ね）に召喚されし魔獣の力、牙に宿して剣と成す。 

イラストレーター：小城 崇志 

レアリティ：レア

作品：仮面ライダーキバ

収録:ザ・マスクドライダーEXP vol.3　キバ＆ネガ電王スターター専用

再録：XG5 ザ・チケットブレイカー　スターター（カードヒーローデッキ）

カード評価

- BPが貧弱そうに見えるが実際にはラッシュした時点で+3000（ダメージを受けていなければ）。そうそう当たり負けする事はない。仮面ライダー1号やZブリンガーのようにドーピング無効化を持つカードには注意したい。

- 【ガルル・ハウリングスラッシュ】は相手のＳユニットをダメージ送りにする。自身のホールドが発動条件で、同じくダメージ送りの効果を持つ仮面ライダーキバと比べてラッシュ時にホールドされないため単体でも使えるためデッキに入れやすい。

- 状況によっては必要パワー３のMAのＳユニットの中でも高ＢＰとＳユニット除去、与ダメージの３つを兼ねそろえる破格の強さを得ることができる。しかし、終盤になってくるとダメージを受けてＢＰが低くなり、相手が手札を消耗して【ガルル・ハウリングスラッシュ】の効果が発揮できなくなる等弱体化する可能性が高いので過信は禁物。こういった特性上、相手のコマンドをバウンスして展開を遅らせることで手札を使わせないアドベンチャーやイエローターボなどを使うタイプのデッキと相性が良い。
- また、シンケンピンクやロブスターオルフェノクで相手の手札を増やすのもよい。

- 又、その性質上OTとの混色でパワー加速を併用するのも有効。特に半恒久的にパワー加速できる仮面ライダーディケイドなどを併用する事で軽くBP4000～5000を超え、相手が速攻でもなければBPが9000越えというLユニット級のサイズになることもしばしば。

- BPが2000以下の時はキリンレンジャーで手札に戻して、同ターンに効果を再利用することで一気にダメージを取ることも出来る。
