                キカイダー

種類：Sユニット

カテゴリ：アーステクノロジー

BP：4000

SP：1/5

必要パワー：1

追加条件：なし

CN：RC

特徴：メカ／人型

テキスト：

※これは、DAを持つ自軍コマンドがないとき、特徴「男」または「女」を持つユニットにアタックできない。

【デンジエンド】特徴「メカ」または「人型」を持つ敵軍Sユニットを1体選び撃破してもよい。

フレーバーテキスト

俺には逃げるところなど無い。博士を…返してもらうぞ！

イラストレーター：As&#039;まりあ

レアリティ：スーパーレア

作品：人造人間キカイダー

収録：クロスギャザー ザ・ドラゴンタイガー　自販：パック

カード評価

-  パワー1・BP4000・SP1/5・RCと驚異的なスペックを誇るが、黒のコマンドがないと男または女にアタックできないデメリットを持つ。性能をフルに活用するならDAと混色にして、ロボコンやオメデトロフィーでコマンドを増やし早期からアタックの機会を与えたい。

- ジャンパーソンと同様にダークレイダーを使って特徴を消す手もあるが、そうすると【デンジエンド】が使いづらくなってしまうのが難点。

- ストライクやライドは問題なくできるので、序盤のビークルの活用に適している。

- 【デンジエンド】はラッシュエリアも射程に入り、参照する特徴もどちらもメジャーで対象が多い除去能力。特に大抵のメタルヒーローを一撃で葬れるのは大きい。DAとの相性がいいので花忍者スイレンや大帝ラー・デウスで相手の特徴を追加するのもいい。

- 低パワーを生かして序盤に出た敵軍のロボコンを潰しやすい。ロボコンは男や女を持たないのでわざわざＲＣを使わなくてもアタック可能である。
