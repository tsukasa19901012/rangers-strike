                仮面ライダー響鬼（XG5）

種類：Sユニット

カテゴリ：ミスティックアームズ

BP：3000

SP：1/3

必要パワー：3

追加条件：なし

CN：1

特徴：仮面ライダー／男／猛士

テキスト：

※レジスト

※リードMA

【鍛えてます】このユニットよりBPの低い自軍ユニットがあれば、このターン、これは次の能力を得る⇒BP+1000され、このターンを終えるときホールド状態ならリリースしてもよい。

フレーバーテキスト

守るモノがあればこそ、己の鍛錬に終わりは無い。

イラストレーター：村上ヒサシ

レアリティ：レア

作品：仮面ライダー響鬼

収録：XG5 ザ・チケットブレイカー　自販：パック

カード評価

- パワー3でBP3000、分数SP、レジスト、リードMAと基本スペックが非常に優秀。過去弾の各種響鬼と比べてクセがなく、デッキに入れやすいのもポイント。効果もNC1で条件が緩い割に使いやすい。

- 【鍛えてます】は効果自体も強力だが、何より原作での決め台詞を再現した効果名に目を惹かれる。
- 毎ターンリードかレジストを使えます。鍛えてますから。

- クウガゴウラムに轢かれないままBP4000を殴れます。鍛えてますから。

- 毎ターンウエイクアップ！要員にもなれます。鍛えてますから。

- リリース効果はターン終了時に発動するため、自ターン中にレジストを活かしての相打ちが狙いやすい。
