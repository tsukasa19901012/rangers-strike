                リンライオン

種類：Mユニット

カテゴリ：ダークアライアンス

BP：6500

SP：1/2

必要パワー：3+

追加条件：特徴「臨気」と「男」を持つ自軍ユニットがある

CN：L

特徴：臨気

テキスト：

※これは自軍バトルフェイズ中、カテゴリにWBが追加される。

【激臨剣】このユニットからコンビネーションする同カテゴリのLユニットは、このターン、次の能力を得る⇒これは、自軍捨札にあるカテゴリを2つ以上持つカード1枚につきBP+2000され、BP20000以上のとき「SP2」になる。

フレーバーテキスト

いいだろう。お前が馬鹿にした獣拳の真の力を見せてやろう。

イラストレーター：A.t.Factory

レアリティ：レア

作品：電影版 獣拳戦隊ゲキレンジャー ネイネイ!ホウホウ!香港大決戦

収録：XG6 ザ・ギガンティックタイタン

カード評価

- DAでありながら２番目でストライクができる。Mユニットなので天空大聖者マジエルの影響を受けず、除去されづらい。BPも6500とMユニットの中でも高めの数値で、シグナルキャノンで除去できないので場持ちは良い。また、ＪＣを持つのでゴーゴージェットを使うデッキにタッチで入れることも出来る。

- 自軍バトルフェイズ中にWBのカテゴリが追加される。なので、WBのユニットから【激臨剣】を発動したり、激気でラッシュすることができる。
- ただし、マルチカテゴリのユニットがコンビネーションする場合は、WBとDAの両方を含まなければ、他方がもう一方のカテゴリを全て含まないため、両者は同じカテゴリとみなされない。カテゴリを追加する効果関連も参照。
