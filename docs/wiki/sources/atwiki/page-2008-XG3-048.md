                仮面ライダーBLACK RX（XG3）

種類：Sユニット

カテゴリ：ミスティックアームズ

BP：4000

SP：1/3

必要パワー：5

追加条件：なし

CN：RC

特徴：仮面ライダー／男／改造人間／ハイブリッドエネルギー

テキスト：

※レジスト

※モーフ

【リボルクラッシュ】敵軍バトルエリアのユニットがSユニット1体だけなら、そのユニットを持ち主のパワーゾーンにダメージにして置いてもよい。 

フレーバーテキスト

たとえ離れていても、互いを信じ戦っている仲間がいる。それが俺の戦う理由だ！

イラストレーター：As&#039;まりあ

レアリティ：スーパーレア

作品：仮面ライダーディケイド

収録：クロスギャザー ザ・Wインパクト　自販：パック

カード評価

- 仮面ライダーBLACK RXに比べ必要パワーが上がった代わりにBP4000+レジストと耐久力が上昇し場持ちが良くなった他、モーフからの宏のオルゴール時計を狙いやすくなった。

- RC能力はストライクを合わせて除去+2点を狙える優秀な能力だが条件が限定的。仮面ライダーBLACK RXとどちらを使うかは好みが分かれるところだろう。
