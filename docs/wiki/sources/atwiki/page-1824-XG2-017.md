                大連王

テキスト：

合体―気伝武人龍星王（または気伝獣龍星王）＋天空気殿

【大王剣・疾風怒濤】自軍ターン中、これが自軍バトルエリアに出たとき、敵軍バトルエリアからDAを持つ敵軍ユニットを1体選び撃破してもよい。そうしたとき、撃破したユニットがLユニットなら、捨札にするかわりに持ち主のパワーゾーンにダメージにして置く。 

フレーバーテキスト

受け継ぎし戦士たちの気力と共に、大王剣を抜き放つ。

イラストレーター：Hiroshi Ayaragi

レアリティ：スーパーレア

作品：五星戦隊ダイレンジャー

収録：クロスギャザー ザ・ドラゴンタイガー　スターター専用（ドラゴンストライク）

Q&A

		Q1
		「XG2-017 大連王」の【大王剣・疾風怒濤】でDAのLユニットを撃破したとき、そのユニットが「RS-437 白熱する実況」等の効果でその場に留まりました。このとき、「捨札にするかわりに持ち主のパワーゾーンにダメージにして置く」というテキストの処理はどの ように行いますか？
		A1
		撃破したユニットがその場に留まった場合は、捨札になることがないので、「捨札にするかわりに持ち主のパワーゾーンにダメージにして置く」という効果も発動しません。

カード評価

- 闇のヤイバによる定番除去コンボが狙えるが、ダメージ効果はLユニットが相手だった場合のみなので使用できない。

- 狙い目は冥府神やバルジオン（2nd）、巨大化爆弾を使ったユニットあたりだろうか。どちらにしろDAデッキ相手でないと真価は発揮できない。

- パワー5で2体合体ため、ラッシュしやすい。ETと組んで使えば、ゴーゴージェットやバトルシャークを利用して素材を集めることができる。
