                蒸着

種類：オペレーション

カテゴリ：オーバーテクノロジー

必要パワー：4

追加条件：なし

テキスト：

次の効果から１つ選び発動する⇒◎自軍山札から「宇宙刑事ギャバン」のカードを1枚選び、自軍ラッシュエリアに出してもよい。その後、山札をシャッフルする。◎自軍Sユニットを1体選ぶ。このターン、選んだユニットはSP1/4になる。

フレーバーテキスト

その言葉が放たれてから犯罪者に許される逃走の猶予は、わずか0.05秒にすぎない。

イラストレーター：増尾 隆幸

レアリティ：メモリアルレア

作品：宇宙刑事ギャバン

収録：スペシャルメタルエディション　自販：パック

カード評価

- 分類ナンバー順で、メタルヒーローの先頭となるカード。シリーズの象徴、輝くヒーローへの変身の原点を体現している。

- ベルトカードと同じようにユニットのサーチともう一つの効果から選んで使用するオペレーション。OTのベルトカードよろしく、山札から直接ラッシュできる。

- 宇宙刑事ギャバンは特徴にメカを持つのでマーフィーK9でサーチができない。そのためサーチ手段としてこれを使うのも十分あり。

- ETとの混色ではスーパー戦隊アドレスブックの方が汎用性があるので、そちらの方が優先されるか。

関連カード

コメント

-  ギャバンのラッシュよりも、SP1/4をどんなSユニットにも付加出来るのが地味に大きい。混色ではもちろんのこと、単色でもゴーオンブラック辺りに使えば十分生きてくる。  -- 名無しさん  (2010-06-02 22:13:07)

-  タクスＯＴが登場した今では、このカードが利用される確率は少なくなりそう。  -- 名無しさん  (2010-07-05 10:31:36)
