                ドラフトレッダー

種類：Sユニット

カテゴリ：アーステクノロジー

BP：3000

SP：なし

必要パワー：1

追加条件：なし

CN：1

特徴：メカ／レッド／男／警察／スワット

テキスト：

※スクラム

【リボルバックG-3】特徴「警察」を持つ自軍ユニットの数を数え、その数以下の必要パワーの数字を持つ敵軍ユニットを1体選び、持ち主のコマンドゾーンにホールド状態で置いてもよい。置けなければ捨札にする。

フレーバーテキスト

これは博物館の警備どころじゃ無いな。ブルースは俺の援護、キースは消火を頼む！

イラストレーター：W.AIAI

レアリティ：レア

作品：特捜エクシードラフト

収録:クロスギャザー ザ・ベストパートナー　自販：パック

カード評価

- パワー1、BP3000、スクラムと基礎スペックも及第点レベルだが、豊富かつ有用な特徴と【リボルバックG-3】が強力。

- 【リボルバックG-3】はサイズ無視、エリア無視に加えNC1のため発動も容易。自軍警察ユニットの数にこそ影響されるものの、特徴「警察」持ちには強力なユニットが多いため気にならない。
- 自身も数に数えるので、単体でも必要パワー1以下のユニットを除去できる。
