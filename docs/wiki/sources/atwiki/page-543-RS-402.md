                ガオレッド（2nd）

種類：Sユニット

カテゴリ：ワイルドビースト

BP：3000

SP：！

必要パワー：4

追加条件：なし

CN：2

特徴：レッド／男／2nd

テキスト：

【灼熱の獅子】「SP1」敵軍コマンドの数が自軍コマンドの数より多ければ、相手は自分自身のコマンドを1つ選び、捨札にする。

フレーバーテキスト

あっちが“ニキニキ”なら、俺はやる気“マンマン”だ！　よおっし！行っくぞぉ～っ！ 

イラストレーター：K2商会 

レアリティ：レア

作品：百獣戦隊ガオレンジャー

収録：紅き六戦士の帰還　自販：パック

カード評価

- コマンド除去能力を持ったストライカー。

- 【灼熱の獅子】相手の方がコマンドが多くなくてはいけなく、除去するコマンドも相手が選ぶなど使いづらさが目立つ。

- 相手がコマンド加速を得意としたデッキなら相手のコマンドを削り易い。その後はミッシングエースなどに繋げたい。
