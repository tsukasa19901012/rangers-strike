                ガオベアー

種類：Mユニット

カテゴリ：ワイルドビースト

BP：1000

SP：1/2

必要パワー：3

追加条件：なし

CN：R

特徴：獣

テキスト：

※これは自軍コマンドを1つホールドしなければバトルエリアに出られない。

※これは自軍「ガオポーラー」があればBP+3000される。 

【氷牙炎滅ベアーストライク】これが、「ガオポーラー」か特徴「人型」を持つLユニットからコンビネーションするとき、次の効果を発動できる⇒ホールド状態の敵軍ユニットを1体選び撃破する。また、自軍バトルエリアに「ガオポーラー」と特徴「人型」を持つLユニットがあれば、これは「SP1」になる。

フレーバーテキスト

つまり、あの時の恩返しってワケ？義理堅いんだなお前達。

イラストレーター：キクチヒラメ

レアリティ：ノーマル

作品：百獣戦隊ガオレンジャー

収録：クロスギャザー ザ・Wインパクト　自販：パック：スターター（アニマルジョイント）

カード評価

- ホールドされた敵軍ユニットを撃破するJCを持つMユニット。

- ガオポーラーが場にいるとBPが4000になる。ガオポーラーとJCすることで、BP4000までのユニットをエリア・サイズ問わず除去できるので強力。

- このカードとガオポーラーの間に特徴「人型」を持つLユニットをコンビネーションさせることで、ナンバーに関係なくSPを得ることができる。一般的なJCと違ってカテゴリも問わないため、MAのガンマジンなど、ラッシュが容易で条件付きでLサイズになるユニットで効果を発動させやすい。

- ガオポーラーとJCするにはコマンドが２つ必要になる。あらかじめコマンドを確保しておくか、コマンドをリリースする手段を用意しておきたい。

- あまり現実的ではないが、獣人メレがいて、コマンドが1つの状態で
1.コマンドをホールドしてガオポーラーをバトルエリアに出し、獣人メレの効果でコマンドを捨札に。
2.冥府神ゴーゴン等特徴「人型」を持つLユニットをコンビネーションさせる。この時に獣人メレの効果でリリース状態のコマンドを確保。
3.ガオベアーをコンビネーションさせる。
これによってコマンドが一つでもガオポーラーとLユニットとのコンビネーションが可能。

- フレーバーテキストの「あの時」とはレスキューファイターの時のこと。

- ガオポーラーの能力はコンビネーションするユニットのBPに依存するため、こちらにユナイトベントを使用するが効果的。

- 獣騎神キングブラキオンでレジストを付与すると場持ちがよくなるため効果的。
