                ボウケンレッド（プロモーション）

種類：Sユニット

カテゴリ：アーステクノロジー

BP：4000

SP：！

必要パワー：3

追加条件：なし

CN：5

特徴：レッド／男

テキスト：

【サバイバスター】「SP1」これは特徴「メカ」をもつユニットにアタックするとき、BP＋4000される。

フレーバーテキスト

時を超えて受け継がれる想いもまた宝(プレシャス)である。汚そうとするものに容赦はしない。

イラストレーター：森下直親

レアリティ：プロモーションカード

作品：轟轟戦隊ボウケンジャー

収録：オフィシャルバインダー付録

カード評価

- 二種類あるボウケンレッドのプロモーション一つ。イラストやフレーバーが違うほか、能力名が【サバイバスター】になっている。
