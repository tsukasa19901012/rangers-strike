                マシンボクサー

種類：Sビークル

カテゴリ：オーバーテクノロジー

必要パワー：2

追加条件：なし

特徴：メカ／車両

テキスト：

※これにライドしているユニットはBP+500される。 

※特徴「警察」を持つ自軍Sユニットは、ＲＣを持っていなくてもこのビークルにライドできる。 

フレーバーテキスト

誰も居なくなったハイウェイを、鋼鉄の猟犬が走り抜けた。

イラストレーター：PLEX（山田耕司）  

レアリティ：ノーマル

作品：特捜戦隊デカレンジャー

収録：紅き六戦士の帰還　自販：パック

再録：クロスギャザー ザ・ファーストエンカウント　スターター（メカニカル）

カード評価

- 警察のユニットなら誰でも乗れるビークル。マシンゼクトロンと比べるとＲＣを持たないユニットが多いので必要パワーが高めに設定されている。

- 特徴に警察を持つユニットはETやOTがほとんどなのでナンバーを稼ぐのに活躍してくれる。
