                キンタロス（2nd）

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：5000

SP：－

必要パワー：2

追加条件：なし

CN：5

特徴：イマジン／2nd

テキスト：

※これは自軍ユニットの数が敵軍ユニットの数より多いときアタックできない。 

【俺の強さにお前が泣いた】次の相手ターン、バトルエリアに出た敵軍Sユニットは、可能ならこれにアタックする。

フレーバーテキスト

こりゃあ先に渡しといた方がええな。ほら涙拭くだけじゃのうて色々便利やで。

イラストレーター：F.M.U

レアリティ：ノーマル

作品：仮面ライダー電王 俺、誕生！

収録：ザ・マスクドライダーEXP vol.4　自販：パック

再録：クロスギャザー ザ・ジェットアクセル　スターター（ウイングデッキ）

カード評価

- パワー2でBP5000の良コストユニット。序盤から活躍できるアタッカーとして十分な性能を持ち、尚且つ能力の【俺の強さにお前が泣いた】も非常に強力。ナンバーが少々重たいが、大きく相手の行動を制限できる。

- その分、こちらのユニット数が相手の数よりも多いときは自分からアタックできないというデメリットを持っているが、能力発動すれば向こうからこちらにアタックしてくれるのであまりきつくは無い。

- 仮面ライダー電王GFや仮面ライダーキックホッパーといったラッシュエリアのユニットを除去できるユニットと組ませればお互いの能力を生かすことが出来る。

- ＮＣは相手の行動を大きく制限できる。特にタイガーロイドと組み合わせれば、バトルで撃破するのが困難になる。ただし、ケタロスやアギトSFのようなカードでロックを外せるので過信は禁物。

- ダイナレッドのようにアタックとストライクを一度ずつ行えるユニットは、バトルエリアに出た時点でアタックが可能なので、先にアタックを選択しなければならない。
