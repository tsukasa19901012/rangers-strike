テキスト：

【シノビボールの争奪戦】これが自軍バトルエリアにある間、敵軍ターン中、敵軍Sユニットは、バトルエリアに出たとき、可能ならこのユニットにアタックする。

フレーバーテキスト

あの玉を胸から抜いたら、あいつくたばっちまうんじゃねぇのか？そりゃ逃げるだろ…。

イラストレーター：hippo

レアリティ：ノーマル

作品：光戦隊マスクマン

収録：七忍の炎陣　自販：パック

カード評価

- 【シノビボールの争奪戦】は相手Sユニットにアタックを強制させる。単体では自身のBPが低いため簡単に撃破されてしまい、効果による撃破にも弱く、ロック手段としては機能しづらい。冥獣人ニンジャキリカゲやタイガーロイドを併用したり、巨大化爆弾で強化すれば強力なロックとなる。

- 効果は相手が「可能なら」アタックを強制させる。相手がジャンパーソンのような場合は効果が機能しない。このカード自身をハリケンウィンガーにライドさせた場合も相手がこのカードにアタックできなくなるので効果は機能しなくなる。
