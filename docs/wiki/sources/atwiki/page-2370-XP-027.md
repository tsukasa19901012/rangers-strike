                ダイノミッション

種類：オペレーション

カテゴリ：ワイルドビースト

必要パワー：5

追加条件：なし

特徴：なし

テキスト：

合体が必要な自軍ユニットが１体もなければ、特徴「メカ」を持たない、５体以上の合体が必要な自分の手札を１枚選び相手に見せる。そうしたとき、自軍ユニットまたは自軍ビークルを好きな数選び捨札にしてもよい。その後、見せたカードの５体以上の合体に必要な、ユニットまたはビークルのカードが自軍捨札にすべてあれば、見せたカードをこのカードに重ねて自軍ラッシュエリアに出す。重ねたユニットがユニットでなくなるとき、このカードを捨札にしてその場に留める。

フレーバーテキスト

一億数千年前より蘇りし勝利の理(ことわり)を手に、今こそ伝説を創る時！！

イラストレーター：Ishibashi Yosuke

レアリティ：プロモーションカード

作品：恐竜戦隊ジュウレンジャー

収録：2010年11月～　合体ロボ大会優勝賞品

カード評価

- WBの合体補助カード。出せるのは特徴「メカ」を持たないユニット限定なので、WBやMAが中心となる。

- 合体素材が打たれ弱くても、捨札と自軍エリアに揃えてしまえば合体できる。出したユニットには1回分の除去耐性が付くのも魅力。

- 必要パワーも無視できるので、大型ユニット用のパワー加速のためにわざわざOTと組ませる必要がなくなる。もっとも捨札を増やせる超電子頭脳があればさらに有効活用できるが。

- 似た効果の侍合体よりも対象は狭いが、より容易な条件となっており、サイズの指定がないので究極大獣神や、ビークルが使えるのでギンガイオーにも対応している。
