                ファイタージゲン

種類：Mユニット

カテゴリ：ダークアライアンス

BP：7000

SP：1

必要パワー：4+

追加条件：特徴「航空機」を持つ自軍ユニット1体を捨札にする

CN：なし

特徴：メカ／航空機／怪人

テキスト：

※これは敵軍ターン中、「SP1」以上のユニットとバトルしたときバトルに勝っても撃破される。

フレーバーテキスト

まんまと航空基地に潜り込み、防備が手薄になった隙にその本性を現した。 

イラストレーター：二見敬之

レアリティ：ノーマル

作品：鳥人戦隊ジェットマン

収録：五龍の逆鱗 自販：パック

カード評価

- トリプターやジェットラス、ウォルターなどパワーが軽めで追加条件も無く出せる航空機ユニットが増えた事により出しやすくなった。

- 性能的には申し分ないが、やはりSP1以上のユニットにアタックされるとあっさり撃破されてしまうデメリットが痛い。巨大化爆弾で復活するなりタイムジェット5でアタックされない状況を作る事ができれば活躍できる時間を延ばせるだろう。

- 合体パーツが全て追加条件を持たない特徴「航空機」持ちのセイクウオーの余った合体パーツからゾードアップしやすい。ジャン・ボエールでユニットを確保しやすいのも利点。

- DAなのでバラクティカと組み合わせやすい。

- 今の所、唯一の特徴「怪人」を持ちながらSユニットでないユニット。しかしながら芋長の芋ヨーカン以外の強化カードは使用できるので安心。メタカードにも対応されているのは残念だが……
