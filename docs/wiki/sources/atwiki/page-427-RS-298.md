                バーロ兵

種類：Sユニット

カテゴリ：ダークアライアンス

BP：1500

SP：－

必要パワー：3

追加条件：なし

CN：なし

特徴：メカ／戦闘員

テキスト：

※このカードはデッキに好きな枚数入れてもよい。

フレーバーテキスト

胸を叩く無数の音が不気味に混ざり、響き渡る。“破滅”という怪物の唸り声のごとく。

イラストレーター：Nottsuo

レアリティ：ノーマル

作品：超力戦隊オーレンジャー

収録：五龍の逆鱗　自販：パック：スターター

カード評価

- 必要パワー3とやや割高だがBP1500を持った戦闘員。2体を並べてぴったりBP3000を弾き出せるゾル大佐との組み合わせが鉄壁か。

- 同BPで必要パワーが1低いジャマーがいる。特徴メカを取るか必要パワー1の差を取るかはお好みで。
