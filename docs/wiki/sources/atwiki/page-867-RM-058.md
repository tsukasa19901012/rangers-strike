                老師グル

種類：Sユニット

カテゴリ：ワイルドビースト

BP：1000

SP：－

必要パワー：0

追加条件：なし

CN：なし

特徴：昆虫／男

テキスト：

【昆虫の精】これが自軍ラッシュエリアにある間、次の効果を発動する⇒特徴「メカ」を持つユニットと、特徴「メカ」を持つビークルに、特徴「昆虫」を追加する。 

フレーバーテキスト

彼は自然の一部ともいえる昆虫の意志を代弁する。それはつまり、この地球の言葉だ。

イラストレーター：スミヒト

レアリティ：ノーマル

作品：重甲ビーファイター

収録：スペシャルメタルエディション　自販：パック

カード評価

- サイズを問わず特徴にメカを持つユニットとビークルに特徴「昆虫」を付加させることができる。

- 特徴「昆虫」を付与することでレッドジャイロやビーファイタークワガーとのシナジーが得られるようになる。

- ビーファイターカブトのような特徴「昆虫」を参照するユニットの多くはWBとETのマルチカテゴリ。ETには特徴「メカ」を持つユニットが多いため効果の恩恵を受け易いためETと組み合わせて使いたい。

- 相手にも特徴を追加できるのでサイドマシーンなどと組み合わせて使うのも有効。

- 所謂システムユニットの類いだが、BPが500ではなく、かつバトルエリアに普通に出られる珍しいユニット。 スカイライダー（XG4）の効果で即死せず、いざという時にはナンバー稼ぎにも使える。
