- というより、イマジンの中でこのデメリットを持ちつつバトルエリアに出ることが前提の効果のあるユニットは、これが唯一である。これらのオペレーションの効果も事実上バットイマジン専用といえる。

- 常駐の効果を止めたい時や常駐置き場から手札に戻したいカードがある時に役に立つ。

- 超変身やオルタフォースと合わせて追加ドローをするという使い方もある。
