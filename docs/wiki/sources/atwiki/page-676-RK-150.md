                ゼロライナードリル

種類：Mユニット

カテゴリ：オーバーテクノロジー

BP：4000

SP：－

必要パワー：3+

追加条件：自軍Sユニットを1体パワーゾーンに送る。

CN：なし

特徴：メカ／車両

テキスト：

【掘削】これをラッシュしたとき、敵軍パワーゾーンのダメージ以外のカードの枚数を数えてから、そのカードをすべて捨札にしてもよい。そうしたとき、数えた枚数と同じ枚数になるまで敵軍捨札からカードを選び、敵軍パワーゾーンにオモテ向きで置く。

フレーバーテキスト

おいおい、電車は地面を走るもんだろうが。…え？地下鉄？あーもう、馬鹿にすんな！

イラストレーター：矢薙 じょう

収録：ザ・マスクドライダーEXP vol.2　自販：パック

Q&A

		Q1
		敵軍ユニットの中に「モーフ」を持つユニットがあり、さらにその ユニットの「モーフ」の対象になるユニットカードが敵軍パワーゾーンにオモテ向きであると します。この状態で、自軍ラッシュフェイズ中に「RK-150 ゼロライナードリル」をラッシュしました。このとき、相手が「モーフ」を発動する前に、「RK-150 ゼロライナードリル」の効果で敵軍パワーゾーンのオモテ向きのカードを捨札にすることができますか？
		A1
		はい、できます。「ラッシュしたとき」とある「RK-150 ゼロライナードリル」の効果が、「ラッシュされたとき」とあるモーフより先に発動します。

カード評価

- 相手のパワーゾーンのカードをこちらで操作出来るため、キングライナーを利用した電車デッキや、モモタロスやキンタロスなどをパワーゾーンに置いて利用するデッキに強い。

- 他にもミッシングエースやタイムシャドウのような相手の捨札やパワーゾーンを参照するカードとの相性も非常に良い。

- モーフ対策にも使える。相手のモーフよりも先に発動できるため、パワーに置かれたモーフ用のユニットカードはなすすべもない。
