                仮面ライダーW・CJ（サイクロンジョーカー）（XG5）

種類：Sユニット

BP：3000

必要パワー：2

テキスト：

※モーフ

【『お前の罪を数えろ』】これは自軍捨札にSユニットのカードが5枚以上あれば、次の相手ターン中、次の効果を得る⇒これ以外のSユニットがアタックされたとき、アタックされたユニットのかわりにこのユニットがバトルしてもよい。そうしたとき、そのバトル中、これはBP+3000される。

フレーバーテキスト

この街を泣かせている奴を、見逃すわけにはいかないんでね。さあ…

イラストレーター：F.M.U

レアリティ：レア

作品：仮面ライダーW

収録：XG5 ザ・チケットブレイカー　スターター専用（仮面ライダーW＆電王デッキ）

カード評価

- SP空欄・マルチカテゴリのパワー2でBP3000と主役ライダーにしては地味な基本スペックだが、モーフの起点や仮面ライダーW・CJX（XG6）へのゾードアップ元としては使いやすい。

- 他のSユニットがアタックされたとき、かわりに自身がバトルする効果を持つ。効果によるバトル時はBPが上がるので、他のSユニットをアタックから守るだけでなく、相手を返り討ちにできる可能性もある。

- ただし、自身がアタックされてしまうと無意味なので確実に使うには工夫がいる。以下のような手段が考えられる。
- シノビドグラー・キンタロス（2nd）・オートバジンBM（XG4）・共同戦線などで自身がアタックされない状況を作る

- がんがんじい・バトルダンス・ゴーゴーダンプ・仮面ライダースカル（XG6）などで効果発動後にラッシュエリアに戻る

- 二体並べる・仮面ライダーディケイドCF（XG3）・コピーベントなどで庇い合う

- タイガーロイドやイカファイアでこのアタックから守る。これらのカードは、ウイングによるアタックに弱いので、それから守ることができるので互いにシナジーがある。
