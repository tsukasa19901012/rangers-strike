		A2
		はい、可能です。「RK-086アカネタカ」は、「敵軍ユニットにス トライクされて、自軍パワーゾーンのオモテ向きのカードか自軍山札の上からひいたカー ドをダメージにする」かわりに「RK-086アカネタカ」のカード自体をダメージにする効果ですので、ストライク以外の方法でダメージを受けたことになり ます。

カード評価

- マスクドライダーVol.2で初登場した、特徴を持つオペレーションカード。ダメージを受けるという結果自体は変わらないものの、パワー加速と追加ドローが出来る。パワー0で使用でき、ゲーム序盤でのパワーの差はデカイので手札に持っていたら忘れずに使いたい。

- パワーゾーンのオモテ向きのカードを裏返さずに済むのでモーフやニンジャマン、仮面ライダーディケイドCFと相性が良い。

- ストライクされた時だけなので能力でダメージを与えられた時には使えない。

- ルール改正とエラッタ修正によってストライク1回につき使用できるのは1枚までとなった。
