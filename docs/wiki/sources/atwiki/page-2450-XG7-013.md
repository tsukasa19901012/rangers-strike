                デカブルー×デカレッド

種類：Sユニット

カテゴリ：オーバーテクノロジー 

BP：4000

SP：－

必要パワー：3+

追加条件：追加で自軍コマンドを1つホールドする

CN：1

特徴：レッド／ブルー／男／警察

テキスト：

※クロス1

※タクスOT

【ファイヤーソウル・クールブレイン】これがアタックするとき、敵軍ラッシュエリアからSユニットを1体選び撃破してもよい。（この効果はバトルエリアの2番目にコンビネーションするときは、ナンバーに関係なく発動する）

フレーバーテキスト

ハードボイルドなら俺の相棒だな！あれ？何怒ってんだよ！おい！

イラストレーター：F.M.U

レアリティ：スーパーレア

作品：特捜戦隊デカレンジャー

収録：クロスギャザー ザ・ベストパートナー　自販：パック

カード評価

- 【ファイヤーソウル・クールブレイン】で、アタック時にバトルエリアとラッシュエリアの両方のSユニットを一度に撃破できる。逆にデカレッドと同様に、アタックする対象がいなければラッシュエリアのユニットの撃破もできない。
- 効果の発動条件がアタックすることなので、敵軍ユニットに自身よりもBPが低いユニットがいない時でも、返り討ちになることと引き換えに発動可能。

- 1番目、2番目どちらでも効果を発動することができるので、並び順はある程度融通が利く。

- クロス1とタクスOTを持っているため、3番目に並べばデカピンクやデンジイエローがNCを発動させつつストライクできるようになる。

- パワー3であることを利用して、重力忍者オモ・カルでタクスとNCを同時に発動できる。

- フレーバーテキストは仮面ライダーWを意識したものである。この後ゴーオンレッド（XG7）に続いていく。
