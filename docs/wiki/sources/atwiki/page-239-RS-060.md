                マジピンク

種類：Sユニット

BP：1000

SP：なし

※これは「マジフェアリー」としてつかえる。

【ピンクストーム】BP3000以下のユニットを1体選んで持ち主の山札の上に戻してもよい。

芳しき風。その優美なる香りに魅せられたものは、情愛の迷路に迷い込む。

Q&A

		「RS-060 マジピンク」のナンバーコンビネーション「ピンクストーム」の効果で、パワーゾーンやコマンドゾーンにあるユニットのカードを選ぶことができます？

		Q2
		「RS-060 マジピンク」のナンバーコンビネーション「ピンクストーム」の効果で、自分のユニットを選ぶことができますか？

カード評価

- ＢＰ3000までのユニットをエリアとサイズを問わず除去でき、相手のドローを遅らせることもできる。必要パワーが0で即ラッシュ出来る点も魅力。

- バトルフランスやタクスMAでストライクさせたユニットを山札に戻して、３番目に並んだところで上記のカードの効果でストライクするコンボが強力。
- バトルフランスでＳＰ付与を狙う場合は特徴「女」を持つユニットを除去してバトルフランスの効果が使えなくなる場合があるので注意が必要。

- 当初はMAのタクス持ちは必要パワー２以上のみだったが、チェンジマーメイドの登場によりパワー０の状況でもこのコンボが使用できるようになった。
