自軍山札を見て、追加条件を持たずＤＡを持たないＳユニットのカードを１枚選び、相手に見せてから手札に加えてもよい。その後、山札をシャッフルする。

カード評価

- 遂に登場した強力サーチオペレーション。Sユニット限定、DA以外、追加条件無しと制限はあるものの、そんなことは気にならないくらい便利な1枚。Sユニットのコンボ主体のデッキに入れれば肝心な時にキーカードが引けないという確率を大きく減らし、安定感が増す。

- 「全戦隊の住所録」という設定なのに、なぜか仮面ライダーやメタルヒーローの面々も持ってこられるのはご愛嬌。

- このカードのおかげでほとんどのベルトカードが評価を下げている。
