種類：Sユニット

テキスト：

※これはアタックすることができない。

【道路封鎖】これが自軍バトルエリアにある間、自軍コマンドゾーンのカードは相手に選ばれない。

フレーバーテキスト

私は人を救う為に生まれました。それは何時何処であっても変わりません。

レアリティ：ノーマル

カード評価

- バトルエリアにいるときコマンドを保護できる。相手にこちらのコマンドを選べなくする効果は守護獣プテラノドンのようなコマンド除去やギンガベリックのようなコマンドをホールドする効果、ゴーオンゴールドのような敵軍コマンドをリリースして発動する効果を防ぐことができる。

- ただしアバレブラックやマジキングなどの自分でコマンドを選ぶ効果には無力。特に強力なコマンド破壊コンボ「メレスラスター」を防げないので、コマンド除去からコマンドを守る手段としては使いづらい。コマンド除去対策としてはゴーゴーファイヤーの方が有効か。

- 出しやすく硬い警察持ちということで、共同戦線やガードチェイサー要員としての起用も見込める。

- BPが高いので仮面ライダーW・CCからのJCでSP1を得られる。
