                デカバイクロボ

種類：Lユニット

カテゴリ：オーバーテクノロジー

BP：7000

SP：！

必要パワー：6+

追加条件：自軍「デカバイク」1体を捨札にする 

CN：なし

特徴：メカ／人型

テキスト：

【ソードトルネード】これが自軍エリアにある間、自分か相手の山札がシャッフルされたとき、そのターン中、これは「SP1」になる。 

フレーバーテキスト

勝利の余韻に浸る暇は無い。広がり続ける悪意を前に彼は次の現場へと向かった。

イラストレーター：別役裕之

レアリティ：レア

作品：特捜戦隊デカレンジャー

収録：究極の八神　自販：パック

カード評価

- ビークルからゾードアップするLユニット。ゾードアップ前のデカバイクはビークルであってユニットではないので、デンジ犬アイシーによるラッシュ補助が受けられない点は注意。

- ただしデカバイクはLビークルなため、除去の心配が少ない上ソルインジケーターでサーチできる。さらにデカバイクロボ自体もバトルシャークで山札から引っ張ってこられるので、ラッシュの難易度自体はそう高くはないだろう。

- その分BPが7000と低く、圧縮冷凍の射程範囲に入ってしまっている。

- SPを得るには自分か相手の山札がシャッフルされる必要がある。OTにはデネブや仮面ライダーディケイド（XG3）、ディケイドライバー、異次元からの翼などのサーチカードが豊富であり、自分の山札をシャッフルする機会は意外と多い。また仮面ライダー威吹鬼（XG5）から続けば確実にSPを得られる。
