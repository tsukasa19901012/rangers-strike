                ガオコング

種類：Mユニット

カテゴリ：ワイルドビースト

BP：6000

SP：－

必要パワー：5

追加条件：なし

CN：なし

特徴：獣

テキスト：

※これは自軍コマンドを1つホールドしなければバトルエリアに出られない。

【ファイヤーダンス】これがバトルエリアに出たとき、敵軍コマンドを敵軍ダメージの数まで選んでホールドする。

フレーバーテキスト

戦場であのダンスを見たら誰でも気が抜ける。それを戦意喪失と言うなら、否定はしない。 

イラストレーター：funbolt

レアリティ：ノーマル

作品：百獣戦隊ガオレンジャー

収録：三界の獅子　自販：パック：銀の冒険者スターター

再録：リバイヴァ　自販：パック

カード評価

- 相手のコマンドをダメージの分ホールドする。パワーが重く活躍するのはゲーム終盤になるため、大抵は３枚以上はホールドできる。

- 相手のカウンターを封じるのに最適。

- BP6000はアタッカーとしても及第点。【ファイヤーダンス】も相まって殴り屋としての活躍が期待できる。
