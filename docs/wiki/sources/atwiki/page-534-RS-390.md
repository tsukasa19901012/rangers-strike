                ゴーグリーン

種類：Sユニット

カテゴリ：アーステクノロジー　

BP：2000

SP：！

必要パワー：3

追加条件：なし

CN：5

特徴：グリーン／男

テキスト：

【ファイブレイザー】「SP1」敵軍捨札からカードを1枚選び、持ち主のコマンドゾーンにホールド状態で置いてもよい。置けなければ敵軍コマンドを1つ選び、捨札にしてから置く。（この効果は特徴「航空機」を持つユニットからコンビネーションするときはナンバーに関係なく発動する）

フレーバーテキスト

単なるレスキュー隊だと侮ったのが運の尽きだな。こういう芸当だって出来るんだよ！ 

イラストレーター：F.M.U

レアリティ：ノーマル

作品：救急戦隊ゴーゴーファイブ

収録：紅き六戦士の帰還　自販：パック

カード評価

- 強制的にコマンドを埋めることが出来る能力は、相手が二色以上のカテゴリで組んでいるデッキならば凶悪な効果を発揮する。一度埋まってしまったコマンドは普通には取り除けないので相手コマンドゾーンのカテゴリを一色だけにしてしまえば、もはやその色以外のユニットをラッシュできなくなってしまい、ほぼ詰みになるケースがある。

- 仮面ライダーG4（XG6）や仮面ライダーリュウガ（XG6）など、捨札から発動する効果を持っているカードへの対策になる。

- レッドターボと組めば単色デッキ相手でも能力が腐らずに済む。

- 航空機からなら重いナンバーも気にする事無く能力発動出来るのも強み。さりげなくストライクも狙える点も忘れてはいけない、ウォルターの登場で使いやすさが格段にあがった。
