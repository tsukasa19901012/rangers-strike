                アントロード

種類：Sユニット

カテゴリ：ダークアライアンス

BP：500

SP：－

必要パワー：4

追加条件：なし

CN：なし

特徴：アンノウン／昆虫 

テキスト：

※このカードはデッキに好きな枚数入れてもよい。 

※これが自分の手札にある間、自軍ラッシュフェイズ中、MAを持つ敵軍Sユニットがあれば、これを自軍ラッシュエリアに出してもよい。 

【女王の僕】これが自軍バトルエリアにある間、特徴「女」を持つユニットは次の能力を得る⇒レジスト (これがバトルで撃破されたとき、捨札にするかわりにこれをホールドしてその場に留めてもよい)

フレーバーテキスト

何だ！？いったい何がヤツらを呼び寄せているんだ！

イラストレーター：黒田 清桐

レアリティ：ノーマル

作品：仮面ライダーアギト PROJECT G4

収録:ザ・マスクドライダーEXP vol.3　自販：パック

カード評価

- BP500の割りに必要パワーが高く、特徴に戦闘員も持っていない。MAの敵ユニットがいればパワーもコマンドも無視してラッシュできるが、現状は完全に相手次第。

- 女性ユニットにレジストを付加する効果は敵軍も受けてしまうので注意が必要。クイーンアントロードの支援としての役割が主か。

- ハサミジャガーや低パワーのローカストアンデッドと組合わせてラッシュエリアに引きこもったクレインオルフェノク等を強引に撃破することもできる。

- 特徴「昆虫」関連

コメント

-  女性ユニットにレジストを付加させるのはいいけど、敵軍の女性ユニットにもレジストが追加されるので、ダークウイングで特徴に女を持つ敵軍ユニットの特徴を消しておくなど、相手にレジストを使わせない方法が必要なので、使いどころが難しい  -- 名無しさん  (2009-10-19 11:49:16)

-  マジレスすると、クイーンアントロードと一緒に使うから問題はない  -- 名無しさん  (2009-10-19 21:11:27)

-  レジスト付加は魅力だが、当然ながら真っ先に狙われる上にバトルでは勝ち目がない。防御手段が欲しいところだが。  -- 名無しさん  (2009-12-10 19:45:45)

-  評価のところ、クワガライジャーとキリンレンジャーのコンボで、完全に相手依存ではなくなった。誰もしないと思うが。  -- 名無しさん  (2010-03-13 12:21:36)
