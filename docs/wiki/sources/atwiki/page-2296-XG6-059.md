カード評価

- 単純な低パワー・低BPのストライカーだが、BP3000以上のユニットにアタックされないため場持ちがよく、特徴「仮面ライダー」を持つ為マシンゼクトロンからライドオフしてストライクできるなど速攻デッキとは相性が良い。

- モーフの基点としても優秀。

- WBの必要パワー２のSユニットでウイングを持つ貴重なストライカー。元々のBPが低いが、デカピンクと相打ちがとれるので活用する機会は十分にある。
