## オンライン確認が必要な事項

- 先攻の決め方、マリガンの有無、先攻1ターン目の追加制限
- BP 計算順（「〜になる」と増減の優先）、同時効果の優先順位表
- 「〜するかわりに」の一般則（公式 RS-100/106 とコミュニティ解釈が食い違う）
- `errata.ts` の RS-030 / RS-067（公式 errata.html に記載なし、出典の wikiwiki 未保存）
- XG 以降のキーワードの公式 Q&A
