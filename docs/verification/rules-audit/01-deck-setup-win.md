## 1. 確定ルール一覧

### 1-1. デッキ構築

- **デッキ枚数（XG以降）: 40枚以上、上限なし。** [wiki本文]
  - page-71-p71.md（デッキ）:「レンジャーズストライクでは40枚1組のカードをデッキと呼ぶ。」「クロスギャザーからはデッキ枚数の上限がなくなり、40枚以上ならば何枚でもよくなった。」
  - page-604-beginner.md:「デッキの40枚制限が無くなったからといってあれこれ詰め込むと…基本は40枚でそこに+3～4枚」
  - まとめ: XG以前は **ちょうど40枚**。XG以降は **最小40・上限なし**。page-604 の「40枚制限が無くなった」は上限の撤廃を指しており、最小40枚は残っている。
- **同名カードは1デッキ3枚まで。** テキスト・種類が違っても、カード名が同じなら合算する。 [wiki本文]
  - page-1739-p1739.md（カード名）:「同じ カード名を持つカードは、テキストや種類の違いに関わらず1つのデッキに3枚までしか入れられない。ただし戦闘員カードなど例外が存在する。またコマンダーカードは枚数には含まれない。」
  - page-71:「基本的に1組のデッキに同じ名前のカードは3枚までしか入れることは出来ない。（戦闘員等無制限で入れることのできるカードもある）」
- **2nd の扱い:** 1st と 2nd は同名として合計3枚まで。XG以降は同名カードに「2nd」の特徴が付かず、この区分は事実上なくなった。 [wiki本文]
  - page-1646-2nd.md:「無論カードテキストやイラスト、種類が異なっても同名のカードはデッキに３枚までである。」「クロスギャザーからは同名カードでも特徴に2ndは付かず、この区分は事実上消滅している。」
- **「これは『○○』としてつかえる」カード:** ゲーム中は「○○」として扱うが、デッキ構築では別名のカード。そのため「○○」とは別に3枚まで入れられる。 [公式（page-1739 内 Q&A）]
  - page-1739 Q1/A1:「本来のカード名は異なりますので、デッキ構築の際は別のカードとして扱います。」
- **3枚制限の例外はカード本文の注記で決まる。** 注記は「※このカードはデッキに好きな枚数入れてもよい。」で、最初期の RS-080 だけ「※このカードはデッキに3枚以上入れてもよい。」になっている。 [カード本文]
  - page-326-RS-080.md:32「※このカードはデッキに3枚以上入れてもよい。」
  - page-1278-RK-303.md:32 と page-962-PK-002.md:32:「※このカードはデッキに好きな枚数入れてもよい。」
  - 特徴「戦闘員」を持たないカードにもこの注記はある。例: ライドシューター、ギガゼール、ショッカーライダー、ワームサナギ体、港区のウワン、オーズ・ガタキリバコンボ（カタログの text で確認、§2 参照）。
- **禁止カード（通常大会）:** 基本は禁止なし。コマンダーカードだけが例外。 [wiki本文]
  - page-1704-p1704.md:「通常ルールの公式大会で使用できないカードはコマンダーカード以外は今のところ存在しない。」「ツアーフェスティバル'08のガンスリンガー大会においてのみ、魔法猫スモーキーが禁止」
  - page-2079-banned.md:「XG2-???[RS] ドギー・クルーガー（XG2）(2010年4月1日より)」「RS-244 命の泉 / RS-289 ドラゴンレンジャー / RS-348 メディテーション(タッグストライク大会のみ)」
  - page-1690-p1690.md:「2010年7月10日付けで、クロスギャザー大会（混合大会）では全てのコマンダーが使用禁止となる。現在は合体ロボ大会で使用可能。」
- **コマンダーカード（XG2〜）** [公式Q&A＋wiki本文、page-1690]
  - デッキとは別に扱い、デッキ枚数にも同名制限にも数えない。「デッキとは別に使用するため、枚数制限とは関係なしに使える。デッキの総枚数にも含まれない。」
  - 事前にウラ向きで提示する。先攻後攻を決めた後にオモテにして発動し、先攻から処理する。公式 A2:「先攻プレイヤーがスタートフェイズに入る前のタイミングで、先行・後攻の順に効果を発動して下さい。」
  - 試合ごとに使う・使わない・別のコマンダーに変えるを選べる（公式 A1）。
  - 「カテゴリは存在するが今のところ意味を成しておらず、デッキの内容とは関係なしに使用できる。」
  - ハイランダー大会ではコマンダーは使えない（page-2252）。
- **マルチカテゴリ:** 構築上の制限についての記述は見つからない。page-1559 は使用時のルールで、手札から使うときは全カテゴリのコマンドが自軍コマンドゾーンに必要になる。 [wiki本文＋公式Q&A]
- **ハイランダー（特殊レギュレーション）:** 同名1枚まで。カードナンバーが違っても名前が同じなら合わせて1枚。 [wiki本文、page-2252]

### 1-2. ゲーム準備

- **山札はシャッフルして裏向きに置く。** [wiki本文] page-154:「シャッフルされた自軍のカードが重なったもの。裏側を上にして積み上げられる。」
- **相手の山札をシャッフル・カットできるか:** 大会では大会規定に従う。フリープレイでは相手の同意のもとで行う。 [公式（page-154 Q2）]
- **初期手札は7枚。** [wiki本文] page-122:「ゲーム開始時に互いに自分の山札から７枚を引く。」
- **手札に上限はない。** [公式（page-122 Q1）]
- **マリガン:** 一次資料に記述は見当たらない（「マリガン」「引き直」を grep して0件）。
- **先攻の決め方:** 一次資料に記述はない（「ジャンケン」「じゃんけん」を grep して0件）。分かるのは「先攻後攻を決定後」（page-1690）ということだけで、決め方は書かれていない。
- **先攻1ターン目はスタートフェイズを飛ばし、チャージフェイズから始める。** [wiki本文] page-264-start-phase.md:「先攻側は１ターン目のみ、この フェイズ を飛ばして チャージフェイズ からの始まりとなる。」この結果、先攻1ターン目はドローしない。
- **ターン構成:** スタート・チャージ・ラッシュ・バトル・エンドの5フェイズ。フェイズ内の行動順は自由。 [公式（page-69 Q1）＋wiki本文]
- **スタートフェイズの追加ドロー:** ドロー後の手札がダメージ未満なら、もう1枚引いてもよい（任意で、1ターン1回まで）。 [wiki本文 page-264／公式 page-123 Q1]

### 1-3. 勝利条件

- **ダメージ7点で敗北。** [wiki本文＋公式]
  - page-105:「7点になるとそのプレイヤーは敗北となる。」
  - grnrngr faq-card-1.html:1175-1179 と faq-card-2.html:410-414:「同時に７点目のダメージを受けた場合はターンプレイヤーがゲームに勝利します。」
- **デッキアウト:** 山札が0枚になっただけでは負けない。引くべきときに引けなかったら負け。 [公式]
  - page-154 Q1/A1:「山札が無くなっただけではゲームに負けることはありません。山札が無くなったあとで、カードを引くべきときに引けなかった場合にゲームに負けてしまいます。」
  - page-154 本文:「ダメージに関係なく負けになってしまう（デッキアウト）」
  - **効果で引く場合も負けになる（公式）:** grnrngr faq-card-1.html:836-838（RS-027 ダイノガッツで山札から引いて捨札にする途中で山札がなくなった場合）「はい、ゲームに負けてしまいます。カードをひくべきときにひけなかった場合はゲームに負けてしまいます。」
  - 一方で、自軍山札が2枚以下だと RS-004 デンジマシーンは発動できない（コスト目的での使用は可）。faq-card-1.html:165-166。発動可否はカードごとに裁定が違う。
- **同時に勝敗条件を満たした場合:** ターンプレイヤーが勝つ。引き分けはない。 [公式＋wiki本文]
  - page-1827:「互いのプレイヤーが勝利条件や敗北条件を同時に満たしてもターンプレイヤーが適用順を決められるため、このゲームに引き分けは存在しない。」
- **ダメージの表し方:** パワーゾーンのウラ向きカード1枚が1点。オモテ向きがあればそれを裏返し、なければ山札の上から1枚をウラ向きで置く。 [wiki本文 page-105]

### 1-4. フォーマット・エクスパンション

- **シリーズ:** 戦隊（英雄の再誕〜蒼九の翼）、ライダーEXP vol.1〜4、メタルエディション、リバイヴァ、ベルトコレクション、プロモ。2009年6月からはクロスギャザー XG1〜XG7 に一本化された。旧ナンバーのカードも引き続き使える。 [wiki本文 page-1535・page-174・page-604 メニュー]
- **XG での変更点:** 確認できたのは次の2つ。 [wiki本文 page-71・page-1646]
  - デッキ枚数の上限が撤廃された（40枚以上）。
  - 2nd の付与がなくなった。
  - このほか、コマンダーカードが XG2 から追加された（page-1690）。
- **大会レギュレーション:** 混合、ライダー単（page-730・731）、合体ロボ大会（page-1690）、ハイランダー大会（page-2252）、特撮ヒーロー大会（page-750）。
- **タッグストライク（4人・2対2）:** [wiki本文 page-750]
  - 「２人同志でチームを組み、相手チームの各プレイヤーに５点のダメージを与えることができたチームが勝利」
  - 常駐（4枚まで）、パワー、コマンド、NC をチームで共有する。
  - リーダーが全フェイズを終えてからサポーターが行動する（スタートフェイズだけはリーダーの次にサポーター）。
  - 禁止: 命の泉、メディテーション、ドラゴンレンジャー。
- **スタック:** 存在しない（page-604）。

## 3. 原文でも不明・要オンライン確認の事項

1. **先攻の決め方**（ジャンケンか、勝者が選べるか）。core-rules / faq の「ジャンケン勝者が先攻、選択不可」はローカルの一次資料にない。grnrngr `rule/rule_preparation.html` で確認が必要。
2. **XG以前の構築ルールの正確な記述**（ちょうど40枚か、40枚以上か）と、XG で上限が撤廃された公式告知の日付・文言。page-71 は wiki 本文で、公式の文言ではない。
3. **マリガン（手札の引き直し）の有無。** 一次資料に言及がない。公式準備ページで確認する。
4. **先攻1ターン目の追加制限**（バトル・ストライクの禁止など）があるか。page-264 にあるのはスタートフェイズ省略だけ。
5. **ダメージ処理で山札が空のとき**の扱い。「引くべきときに引けない」としてデッキアウトになるのか、ダメージだけ加算されるのか（D14）。
6. **効果ドローの部分不足**（例: 2枚引く効果で山札が1枚）が敗北になるか。カード別の裁定（デンジマシーンは発動不可、ダイノガッツは使えて敗北）を見ると、効果ごとに違う可能性がある。grnrngr faq/card_3〜9 は未取得。
7. **コマンダーカードの正式ルール**（公式ルールページ／XG2 同梱ルール）と、通常大会でのコマンダー禁止の公式告知（2010-04-01 のドギー・クルーガー、2010-07-10 の全面禁止）の原文。
8. **wiki の区別表記と印刷名の対応。** 「（THE FIRST）」「（THE NEXT）」「（志葉 薫）」「（1号）」「（太陽の石）」「（龍騎）」「（Vジェット）」は印刷名の一部なのか、wiki の区別用なのか。同名3枚判定に直結する。公式カードリスト（grnrngr cards）で照合する。
9. **タッグストライク公式ルール全文**（チーム共有の詳細、ダメージ5点の根拠）。
10. **ガンスリンガー大会・ハイランダー大会など特殊レギュレーション**の公式文書。
