## 1. 確定ルール一覧

### 1.1 ターン構造

- ターンは **スタート → チャージ → ラッシュ → バトル → エンド** の5フェイズからなる。フェイズの順番は入れ替えられない。【wiki本文】
  - page-69「スタートフェイズ、チャージフェイズ、ラッシュフェイズ、バトルフェイズ、エンドフェイズの５つに分けられる」「フェイズの順番を前後させることはできない」
  - page-588「ターンはさらに５つのフェイズに分かれており、これを順番に行う。片方のターンが終了した場合、速やかにもう片方のターンが開始される」
- 各フェイズ内の行動は順番自由。ラッシュ → オペレーション → ラッシュ のような順序も可。【公式】
  - page-69 Q1/A1「各フェイズ中の行動には、順序の制限はありません」
- **先攻は1ターン目だけスタートフェイズを飛ばし、チャージフェイズから始める**。後攻の1ターン目に例外の記述はない。【wiki本文】
  - page-264「先攻側は１ターン目のみ、この フェイズ を飛ばして チャージフェイズ からの始まりとなる」
- 初期手札は7枚。手札の枚数に上限はない。【公式】
  - page-122 Q1/A1「ありません。何枚でも持つことができます」、本文「ゲーム開始時に互いに自分の山札から７枚を引く」
- 「このターン」とは、そのテキストが有効になった時点から、ターンプレイヤーが「ターンエンド」を宣言するまで。【公式】
  - page-588 Q1/A1「ターンプレイヤーが「ターンエンド」と宣言するまでです」

### 1.2 スタートフェイズ（page-264, 123, 105, 122, 157, 158）

- 次の3行程を **好きな順に、必ず** 行う。【wiki本文】page-264「スタートフェイズでは次の３つの行程を好きな順に必ず行う」
  1. ホールド状態の自軍コマンドをリリースする
  2. バトルエリアにいる自軍ユニットとビークルをラッシュエリアに戻す
  3. 山札から1枚だけドローする
- **追加ドロー**: 上の3のドローで引いたカードを手札に加えたうえで、手札の枚数が自軍ダメージ未満なら、続けてもう1枚だけドローしてよい。任意。【wiki本文】
  - page-264「ドロー したカードを手札と合わせて、枚数が自軍 ダメージ の数値未満ならばもう一枚だけ続けて ドロー することも出来る」「二度目のドローに関しては強制ではない」
- 追加ドローは **1ターンに1度だけ**。手札がダメージと同じ枚数になるまで引けるわけではない。【公式】
  - page-123 Q1/A1「いいえ。追加ドローは1ターンに1度だけです」
  - 【コミュニティQ&A】page-1974「↑追加で1枚だけドローできます」(2011-06-05)
- 公式 FAQ では追加ドローも「ドロー」として扱われ、「ドローするとき」の効果が誘発する。【公式】
  - faq-card-1.html RS-008「マジブルーの効果でドローするときや追加ドローのときにも発動しますか？」→「はい、発動します」
- ドローすべきときに山札から引けなければ負け。【wiki本文】page-123「山札からドローすべき時にカードが引けなければ負けとなる」、page-623
- 自軍コマンドは、何らかの効果を受けていない限り、スタートフェイズに強制的にすべてリリースされる。【wiki本文】
  - page-157「自軍スタートフェイズには、何らかの効果を受けていない限りすべての自軍コマンドは強制的にリリースされる」
  - page-158「コマンドはスタートフェイズに強制的にリリースされるが、ユニットは何らかの効果を使わなければリリースできない」
- **ホールド状態のユニット（レジスト使用後など）は、スタートフェイズになってもリリースされない**。【wiki本文】
  - page-157「ホールド状態のユニットはスタートフェイズになってもリリースされず、ユニットである限り普通はずっとホールドされたままである。これをリリースするにはギルスレイダーやウエイクアップ！といったカードの効果が必要」
  - page-1289（レジスト）「リリースする効果のカードが無ければ基本的にずっとホールド状態のままということになる」「ホールド後も扱いは同じで、こちらのターンが始まればラッシュエリアに戻る」
- ラッシュエリアとバトルエリアはどちらも「エリア」なので、バトルエリア → ラッシュエリアの移動ではホールド状態は消えない。状態が消えるのはエリアとエリア外の間で移動したときだけ。【wiki本文】
  - page-1512「エリアとエリア以外の間をカードが移動した場合 … ホールド/リリースの状態 … はすべて消える」

### 1.3 チャージフェイズ（page-145, 153, 109, 108, 151）

- 手札からカードを1枚選び、パワーゾーンかコマンドゾーンのどちらかに置ける。1ターンに置けるのは1枚だけで、置かなくてもよい。【wiki本文】
  - page-145「自分の手札からカードを一枚選び、パワーゾーンもしくはコマンドゾーンのどちらかに置くことが出来る」「1ターンに置く事が出来るのは一枚だけ。無論、置かずに手札を維持することもできる」
- コマンドゾーンに置くカードの種類に条件はない。上限は5枚。【wiki本文】page-151「どんな種類のカードでも置くことができる」「最大5枚まで」
- 公式: コマンドゾーンには5枚まで置ける。効果で5枚を越えて置かれるカードは捨札になる。一度置いたコマンドは、カードの効果以外では差し替えられない。【公式】
  - page-108 A2「一度コマンドゾーンに置いたカードは、カードの効果以外で勝手に置きかえたりすることは出来ません」、A3「5枚まで置くことができます。…5枚を越えて置かれるときは、そのカードは捨札になります」
  - ただし wiki 本文の補足では、効果で送るときの処理は「かわりに捨札になる」「発動できない」「コマンドを捨ててから送る」など、効果ごとに異なる（page-108）。
- パワーゾーンの枚数に上限はない。【公式】page-109 A3「何枚でも置くことができます」
- コマンドゾーンに送られたカードは、特に指定がなければリリース状態で置く。パワーゾーンに送られたカードは、指定がなければオモテ向きで置く。【公式＋wiki本文】
  - page-108 A1、page-1872「コマンドゾーンに送られる場合、特に指定がなければカードはリリース状態で置く。パワーゾーンに送られる場合、指定がなければオモテ向きで置く」
- チャージしたカードをオモテ向きで置く、という明文はスナップショット中に見つからなかった（後述 3 章）。ただし page-105 の「ウラ向き＝ダメージ」という定義からすると、オモテ向きで置くのが自然。

### 1.4 パワー・必要パワー（page-110, 1721, 109, 公式 FAQ）

- 自軍のパワー ＝ 自軍パワーゾーンのカード枚数 ＋ **敵軍コマンドゾーンにあるマルチカテゴリカードの枚数**。カードの表裏は関係ない。【wiki本文】
  - page-110「自軍のパワーは自軍パワーゾーンに置かれているカードの枚数と、敵軍コマンドゾーンに置かれているマルチカテゴリのカードの枚数で決まる」「カードの裏表は関係ない」
  - page-108「マルチカテゴリ のカードが置かれた場合、敵軍 パワー 1つ分としても数える」
- **必要パワーは消費するコストではなく、満たしているかを見る閾値**。自軍パワーがその数以上あれば、ラッシュやオペレーション使用ができる。【公式＋wiki本文】
  - page-1721「自軍パワーがこの数字の数以上なければ、基本的に…ラッシュしたりオペレーションを使用することはできない」（公式用語集ver1.0 からの引用を含む）
  - faq-card-1.html RS-005/RS-013「選ばれたカードの「必要パワー」以上のカードが自軍パワーゾーンに置かれていること」
- 必要パワーは効果で変動するが、0未満にはならない。上限はない。【wiki本文】page-1721
- 追加条件で必要パワーが0になるのは、ラッシュするその瞬間だけ（アバレッドAM）。【公式】faq-card-1 RS-230「追加条件で必要パワー０になるのは、ラッシュするそのときだけ」
- ダメージ: 7点で敗北。受けるときは、オモテ向きのパワーがあれば自分で選んで裏返す。なければ山札の上から1枚をウラ向きのままパワーゾーンに置く。【wiki本文＋公式】page-105、page-109 Q1/A1

### 1.5 コマンド・ホールド・リリース（page-151, 157, 158, 公式 FAQ）

- 手札からユニットをラッシュするときやオペレーションを使うときは、そのカードと同じカテゴリのコマンドをホールドする。【wiki本文】page-151
- ホールドしたコマンドは「消費された」扱いになり、リリースされるまでそのまま。【wiki本文】page-157
- 正規の手順ではなく、効果によってラッシュやオペレーション効果を使う場合は、コマンドのホールドは要らない。ただし個別にホールドを要求するカードは例外。【wiki本文＋公式】page-151、faq-card-1 RS-005/RS-013「コマンドをホールドしなくてもラッシュエリアに出すことができます」
- ユニットをコマンドの代わりに使った場合（コール・リード等）、そのユニットはスタートフェイズにリリースされない。【wiki本文】page-151

### 1.6 ラッシュ / バトルフェイズ（概要だけ）

- ラッシュフェイズ: ユニット・ビークルのラッシュと、オペレーションの使用。【wiki本文】page-516
- カウンター以外のオペレーションを使えるのはラッシュフェイズだけ。【wiki本文】page-1828
- バトルフェイズ: ユニットのバトルエリアへの移動、アタック、ストライク。【wiki本文】page-593

### 1.7 エンドフェイズ（page-155, 公式 FAQ）

- エンドフェイズはバトルフェイズの次。ターン終了を宣言すると相手のターンに移る。【wiki本文】page-155
- 「ターンを終えるとき」の効果はこのフェイズ中に処理する。**「自軍エンドフェイズ」の効果は「ターンを終えるとき」の効果より先に処理する**。【wiki本文】page-155
- エンドフェイズに手札上限やディスカードの手順はない（手札上限なし: page-122）。【公式】
- 「アドベンチャー」（RS-030）のターン終了処理は、ターンを終えたプレイヤーだけが行う。【公式】faq-card-1 RS-030

### 1.8 タイミング・効果の解決・同時（page-1828, 1869, 1827, 1864, 2167, 2395, 1413）

- 1つの行動「～」について、タイミングは「～するとき」→「～されるとき」→ 実際の行動 →「～したとき」→「～されたとき」の順に発生する。能動のタイミング（～したとき）を先に処理する。【wiki本文】page-1828
- 1つのタイミングの中は「発動」と「解決」に分かれる。互いにもう発動しないことを確認してから解決に入る。解決に入った後、そのタイミングに新しく効果を発動することはできない。【wiki本文】page-1828
- 解決の途中で別の効果の発動条件を満たしたときは、その時点で割り込んで発動でき、入れ子のように解決する。【wiki本文】page-1828。【コミュニティQ&A】page-1974 G4 の例「割り込んでG4の効果を発動できます」
- 「あるフェイズの開始時／終了時」に発動する効果は、そのフェイズ中の行動を一切行う前／すべて行った後に、発動と解決をまとめて行う。複数あるときはターンプレイヤーが順番を決める。【wiki本文】page-1828
- 「～フェイズ中」に発動できる効果は、フェイズ中の行動の1つとして使い、発動と解決を交互に行う。【wiki本文】page-1828
- 効果は優先順位の高いものから解決し、同じ優先順位のものは **ターンプレイヤーが解決順を決める**。解決は1つずつ行い、複数のカードを操作するときも1枚ずつ処理する。【wiki本文】page-1869、page-1827、page-2167
- 否定文の効果（～しない／できない）は、強制効果・任意効果より優先される。【wiki本文】page-1864
- **両プレイヤーが同時に7点目のダメージを受けたら、ターンプレイヤーの勝ち**（引き分けはない）。【公式】
  - faq-card-1 RS-054「同時に７点目のダメージを受けた場合はターンプレイヤーがゲームに勝利します」
  - page-1827「このゲームに引き分けは存在しない」
- 非ターンプレイヤーは、相手がラッシュするたびにカウンターで応答できる。ターンプレイヤーが確認を怠って先へ進めた場合は、巻き戻しを要求できる。【公式】
  - faq-card-1 RS-026「「ラッシュされたとき」というのは、そのユニット自身の「ラッシュした時」の効果を適用したり、それに誘発する全ての処理を終えて、相手が次の宣言を行うまでの間です」
- スタック（積み重ねて逆順に解決する仕組み）の概念は存在しない。【wiki本文】page-604「スタック概念は今のところ存在しません」
- 「置き換え」は、このゲームでは **2枚のカードの位置を、ホールド／リリースの状態を保ったまま入れ替えること** を指す。他のTCGでいう置換効果ではない。置換効果に当たるのは「するかわりに」（page-2395）。【公式】page-1413「（公式用語集ver1.0より）」
- 「AするかわりにBする」は、Aが実行できない場合でもBを実行できる（2008年10月改正）。【wiki本文】page-2395

## 3. 原文でも不明・要オンライン確認の事項

1. **公式ルールページ本体**（`rule_phase1-2.html`, `rule_phase3.html`, `rule_phase4.html`, `rule_tarn.html`, `rule_preparation.html`）がスナップショットに無い。doc が出典として挙げているこれらのページは検証できなかった。特に次の点。
   - 先攻・後攻の決め方（ジャンケンかどうか、選べるかどうか）（D11）
   - チャージしたカードを必ずオモテ向きに置くことの明文（D12）
   - エンドフェイズの公式ステップ一覧（doc も UNKNOWN としている）
   - timing.md が「公式」とする「離場→ストライク→バトル→ラッシュ」の優先順（D13）
2. **追加ドローを行える時点**: page-264 の「続けて」が通常ドローの直後だけを意味するのか、スタートフェイズ中ならいつでもよいのか（D10）。
3. **ドローを判定する手札枚数の時点**: page-105「ダメージの枚数が手札を上回る」、page-122「手札枚数がダメージより少なければ2回ドロー」は、通常ドローの前と後のどちらで判定するかが曖昧。page-264 は「ドローしたカードを手札と合わせて」と後で判定すると明記している。ページ間で表現に揺れがあるので、公式ルールで確定させたい。
4. **スタートフェイズ行程とターン開始時効果の前後関係**: page-1828 の「フェイズ開始時」の一般則はあるが、「ターン開始時」「スタートフェイズ時」と書かれたカード（ゲゲル、XG4 の入れ替え、メガシルバー等）が3行程のどこで処理されるかを公式に確認したい（D5）。
5. **効果でコマンドゾーンが5枚を超える場合の既定処理**: 公式 page-108 A3 は「捨札」、wiki 本文は「効果ごとに異なる」。既定は捨札で、テキストに指定があればそれに従う、という解釈でよいか。
6. **時期によるルール変更**（実装はいずれも新しいルールに合っているとみられる）:
   - 2008年10月改正: 「ひとつのタイミングに発動できる効果はひとつまで」が廃止された（page-1828）。
   - 2008年10月改正: 「するかわりに」は A が実行不可能でも B を実行できる（page-2395）。
   - デッキの40枚制限の撤廃（page-604「デッキの40枚制限が無くなった」）。デッキ構築の担当範囲。
   - パワー計算へのマルチカテゴリの加算は、マルチカテゴリカードの登場（クロスギャザー期）以降のルール（page-110 の最終更新は 2009-12）。
7. **同時処理の例外**: page-2167「マルチカテゴリに関する処理順など、自由には決められない例外も存在する」の中身は、スナップショット中に詳しい記述がない（page-1827 は「マルチカテゴリに関する処理で気をつけなければならない」とだけ）。
