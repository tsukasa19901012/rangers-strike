# RM・BK 照合：出典で決まらず判断したところ（2026-10〜）

RM（スペシャルメタルエディション）などのカード照合で、カード本文・公式 FAQ・atwiki では決まらず、実装するときに決めた点の一覧です。
書き方は docs/verification/rk-judgments.md と同じです。バッチごとに追記します。ユーザーの確認が済んだものには「【YYYY-MM-DD ユーザー確認】」を付けます。

ほかのカードへの影響: XG2-082 電子星獣ドルは、自軍捨札に超次元高速機ドルギランがあり自軍エリアに同じカード名のユニットがなければ、追加条件（「宇宙刑事」のユニットがある）なしでラッシュできるようになった。オメデトロフィーを常駐させていると、どの経路でバトルエリアに出た自軍ユニットでも発動する（RK-139 ゼロノスAF の RC で敵軍ターン中に出されたときなど）。マルチパック・ターボユニット-W は Jパワーと同じ「ユニットの下に重ねたオペレーション」の一覧（rules/rk/rk1Features.ts）に入ったので、RK-250 サバイブと同時の「ユニットでなくなるとき」の順番の選択にも出る。RM-009・RM-010 は本文の再録から読んでいた既存の汎用の効果ではなく、カード固有の効果で処理する（RM-009 は使うときに対象を先に選ばない）。

古い it.todo の整理: rulesSpec/07-call-read の R-KW-READ-01（リードでホールドしたユニットが RM-015 に参照される。atwiki/page-2250 Q3）を実テストにした。RM-018 Q1（パトストライカーの追加条件に指定してチェイス）は RS1-024-046.units-b の RS-043 の it.todo のまま（追加条件の支払いの途中にチェイスを差し込む公開アクションがない。RM の照合とは関係しない）。

ユーザー確認待ちの (a)「相手に選ばれない」がゾーンでも効くか: 本範囲でゾーンのカードを選ぶ効果（RM-001〜004・010・016 の山札、RM-009・012 の捨札、RM-021 のパワーゾーン、RM-012 の手札）はすべて自分のカードなので関係しない。場のユニットを選ぶ効果は今の扱い（相手に選ばれないユニットは選べない）のまま。(b)・(c) には触れていない。公式どうしの新しい食い違いは見つからなかった（本範囲の公式 FAQ の項はなく、atwiki に転載された公式 Q&A だけ）。コミュニティの記述どうしでは、RM-012 のマルチカテゴリの効果の順番（「好きな順」）を確かめる公式の記述がない。
