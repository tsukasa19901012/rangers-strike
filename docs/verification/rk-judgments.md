ほかのカードへの影響: 「自軍コマンドをNつホールドしなければバトルエリアに出られない」すべてのユニットが、モーフでバトルエリアに出るときもホールドするようになった（リリース状態のコマンドが足りなければ置き換え先に出ない）。モーフで置き換えたユニットは、置き換え元が出たばかりならそのアタック・ストライクの権利を引き継ぐ。シュードランがあると、どのモーフでも捨札のカードが候補に出る。RK-334 が場にあると、両軍の必要パワー2以下のユニットの効果名を持つテキスト（DSL の名前つき効果・起動型の効果など、RS-379【雷の雄叫び】と同じ判定を使う場所）が無効になる。RK-332 の BP は前より低くなる（2重に数えていたのを直した）。rules/rkFieldPassives.ts の「特徴「X」を持つ自軍ユニット1体につき」は RK-332 だけを外した（ほかの RK カードにこの文言はない）。ストライクのたびに、ストライクされた側にこのターンの回数の記録が付く（RK-320 のため）。RK-327 は敵軍のどのユニットからもホールド中はアタックされない。rkHashStub.test.ts の RK-326 のキーワードを新しいものに合わせた。
