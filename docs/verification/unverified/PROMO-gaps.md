# PROMO 照合：エンジンの不足（it.fails / it.todo の一覧）

テストは packages/engine/src/cardSpec/PROMO1-PK-SK.{a,b,c}.test.ts と PROMO2-SX-SR.{a,b,c}.test.ts。「カタログ」はカードデータ（packages/cards）の誤り、それ以外はエンジンの不足です。
多くのプロモ・シークレットレアの再録は、元のカード（RK-033・RK-066 など）と効果名や言い回しだけが違います。元のカードは同じ盤面で効くので、カード番号や効果名で効果を探しているところが再録に届いていないと考えられます。

| SK-004 | it.todo ×1 | Q3（XG7-059 トリガードーパントで前半を無効にしても「また」以降は残る）— ラッシュしたときの効果に割り込む盤面をこの範囲で作っていない |
