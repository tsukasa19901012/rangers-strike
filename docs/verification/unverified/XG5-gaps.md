# XG5 照合：エンジンの不足（it.fails / it.todo の一覧）

テストは packages/engine/src/cardSpec/XG5-<from>-<to>.{a,b,c}.test.ts。「カタログ」はカードデータ（packages/cards）の誤り、それ以外はエンジンの不足です。
XG5 の96枚では、カタログの本文・BP・レアリティと atwiki の食い違いは見つからなかった（「カタログ」の行はない）。XG5-035 は atwiki にレアリティの記載がないため照合していない。
it.todo の行は「（todo）」の後にテストできない理由を書いた。XG5-043〜045・XG5-061〜062 は共通のテスト関数（greatTests・insteadTests）の it.fails をカードごとに数えている。
