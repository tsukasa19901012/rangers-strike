# XG5 照合：エンジンの不足（it.fails / it.todo の一覧）

テストは packages/engine/src/cardSpec/XG5-<from>-<to>.{a,b,c}.test.ts。「カタログ」はカードデータ（packages/cards）の誤り、それ以外はエンジンの不足です。
XG5 の96枚では、カタログの本文・BP・レアリティと atwiki の食い違いは見つからなかった（「カタログ」の行はない）。XG5-035 は atwiki にレアリティの記載がないため照合していない。
it.todo の行は「（todo）」の後にテストできない理由を書いた。XG5-043〜045・XG5-061〜062 は共通のテスト関数（greatTests・insteadTests）の it.fails をカードごとに数えている。

| XG5-003 | it.todo ×1 | （todo）必要パワーの数字が0か−1かで結果が変わる効果（「○以下」以外の参照）が本範囲になく、公開 API で違いを観測できない |
| XG5-010 | it.todo ×1 | （todo）XG7-059 は本範囲外で照合がまだのため |

it.fails はすべて直した（rules/xg5/xg5dEffects.ts）。XG5-064 は、敵軍バトルフェイズ開始時に使用の窓（pendingEffectChoice の xg5_064_confine_window。窓の間はこれの支払い・play_counter と見送り）を開くようにし、選んだユニット・ビークルの効果名を持つテキストの無効は共通の判定（rules/legend1/set6NamedEffects348.ts namedTextNegated）に足した。

| カード | 種類 | 内容 |
|---|---|---|
| XG5-064 | 仕様の省略 | 無効が効くのは namedTextNegated を見る経路（DSL の誘発・場のキーワード等）だけ。RK-011 第三の眼はこの窓のカウンターに割り込まない |
| XG5-066 | it.todo ×2 | （todo）【コピーベント】は起動できるようになった（自軍ラッシュフェイズに場のこれから）。RK-043【突入】の直後に使う盤面と、「－」の追加条件（RK-333）を持つカードを選べないこと（Q2）は、この範囲のテストで組んでいない |
| XG5-072 | it.todo ×1 | （todo）ライドオフ（RC）するときこのユニットはリリース状態で出るため、ホールド状態からのリリースを公開 API で組めない（エンジンは DA を持つカードがあればリリースする） |

| XG5-078 | it.todo ×1 | （todo）置き換えはエンジンにあるが、置き換えのときに追加条件を満たす手順を出していない。それが Q1 によるものかはテストで確かめていない |
