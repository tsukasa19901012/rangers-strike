# XG4 照合：ユーザーに確認したい点（候補）

XG4 のカード照合で、出典（カード本文・atwiki 転載の公式 Q&A・atwiki）では決まらず、
読み方によってゲームの結果が変わるところだけを挙げます。決めたことの一覧は XG4-judgments.md にあります。

## XG4-001〜021

### Q-XG4-1 XG4-011 獣装光ギンガグリーン【銀河の戦光】で数えるユニット
- カード: XG4-011 獣装光ギンガグリーン
- 本文: 「【銀河の戦光】本来の特徴に「ギンガの光」を持つユニットが5体以上あれば、敵軍バトルエリアのユニットをすべてゲームから除外する。」（atwiki/page-2099）
- テストの前提: 両軍の場の「ギンガの光」ユニットを数える（敵軍の分も入れて5体以上なら除外する）。
- 根拠: 本文に「自軍」の限定がない。コメント欄に相手の場のユニットも数えるという書き込みがある（公式の記述ではない）。一方、§5.7 f（RS-657 の付与は自軍ユニットだけ）のように、限定のない文を自軍だけと決めた例もある。
- 別案: (a) 両軍を数える（今回の前提）。(b) 自軍のユニットだけを数える。

### Q-XG4-2 XG4-013 ギンガグリーン【疾風一陣】で相手のコマンドが2つないとき
- カード: XG4-013 ギンガグリーン
- 本文: 「【疾風一陣】相手は自分自身の山札の上から1枚を捨札にするか、自分自身のコマンドを2つ選び手札に戻すかを選ぶ。」（atwiki/page-2092）
- テストの前提: 相手のコマンドが2つ以上ある場合だけを書いている（0〜1つの場合はテストしていない）。
- 根拠: コマンドが1つ以下のときに「コマンドを2つ戻す」を選べるか（できるだけ戻すか）が、本文・atwiki にない。選べれば、相手は山札を減らさずに1つだけ戻して済ませられる。
- 別案: (a) コマンドが2つないときは、その選択肢を選べない（山札を捨札にする）。(b) 選べて、あるだけ戻す。

## XG4-044〜063

### Q-XG4-3 XG4-057 仮面ライダー龍騎サバイブの「常駐置場」
- カード: XG4-057 仮面ライダー龍騎サバイブ
- 本文: 「※これは常駐置場にカードが1枚もなければ、「SP1」になる。」（atwiki/page-2135）
- テストの前提: 両軍の常駐置場が空なら SP1、自軍の常駐置場にカードがあれば SP1 にならない、の2つだけを確かめている。敵軍の常駐置場にだけカードがある場合はテストしていない。
- 根拠: 「常駐置場」が自軍だけを指すのか、両軍を指すのかが本文・atwiki にない。【叶えたい願い】は両軍の常駐を捨札にできるので、相手の常駐を消して SP1 にする使い方ができるかが変わる。
- 別案: (a) 自軍の常駐置場だけを見る。(b) 両軍の常駐置場を見る（どちらかにあれば SP1 にならない）。

### Q-XG4-4 XG4-047 シンケンレッドのかっこ書き
- カード: XG4-047 シンケンレッド
- 本文: 「【車上の赤き侍】ライドしている敵軍Sユニットを1体選び、持ち主のパワーゾーンにダメージにして置いてもよい。（この効果はライドしている自軍ユニットからコンビネーションするときはナンバーに関係なく発動する）」（atwiki/page-2108）
- テストの前提: 4番目に出たときの NC だけを書き、かっこ書きは it.todo にしている。
- 根拠: 「ライドしている自軍ユニットからコンビネーションする」が、ライドしているユニットの次に並べたとき（並び順を問わず NC が成立する）なのか、RC のようにライドオフしたときなのかが、本文・atwiki にない。
- 別案: (a) ライドしている自軍ユニットのすぐ後に出れば、何番目でも発動する。(b) ライドしている自軍ユニットがバトルエリアにいれば、何番目でも発動する。

### Q-XG4-5 XG4-044 ゴセイブラック【ランディックアックス】の数えるとき
- カード: XG4-044 ゴセイブラック
- 本文: 「【ランディックアックス】このターン、これは、リリース状態の自軍コマンド1つにつきBP+1000される。」（atwiki/page-2096）
- テストの前提: 効果が発動したときのリリース状態のコマンドの数で BP を決める。
- 根拠: 「このターン」の BP が、発動したときに決まるのか、このターンの間ずっと数え直すのか（あとでコマンドをホールドすると下がるのか）が、本文・atwiki にない。
- 別案: (a) 発動したときに決まる（今回の前提）。(b) このターンずっと数え直す。

## XG4-064〜083

### Q-XG4-6 XG4-067・069 追加条件「特徴を持つ自軍コマンド」
- カード: XG4-067 仮面ライダーW・LM、XG4-069 仮面ライダーW・FJ
- 本文: 追加条件「特徴「メカ」を持つ自軍コマンドがある」（XG4-067、atwiki/page-2117）、「特徴「獣」または「恐竜」を持つ自軍コマンド」（XG4-069 の追加条件と【ショルダー・ファング】、atwiki/page-2043）
- テストの前提: コマンドゾーンにあるカードなら、オペレーションでもユニットのカードでも、特徴があれば数える。エンジンはオペレーションだけを数える（XG4-gaps.md に記載）。
- 根拠: コマンドゾーンにユニットのカードを置く効果（コマンドゾーンに送る・コールなど）があり、そのカードを「特徴を持つ自軍コマンド」に含めるかが、本文・atwiki にない。
- 別案: (a) コマンドゾーンのどのカードでも数える（今回の前提）。(b) オペレーションのカードだけ数える（今のエンジン）。

### Q-XG4-7 XG4-068 仮面ライダーW・CT【トリガーマグナム】の送り先を選ぶ人
- カード: XG4-068 仮面ライダーW・CT
- 本文: 「【トリガーマグナム】自軍ターン中、これがバトルエリアに出たとき、必要パワーの数字が3以下の常駐しているオペレーションを1つ選び、持ち主のゾーンに送ってもよい。」（atwiki/page-2136）
- テストの前提: 持ち主のパワーゾーンかコマンドゾーンのどちらかに送られればよいとしている（どちらを誰が選ぶかは決めていない）。
- 根拠: カード評価は「パワーゾーンかコマンドゾーン」とだけ書いている。敵軍の常駐を送るとき、効果を使う自分が選ぶのか、持ち主（相手）が選ぶのかが出典にない。パワーに送るか、コマンドに送り直されるかで結果が変わる。
- 別案: (a) 効果を使うプレイヤーが選ぶ。(b) 持ち主が選ぶ。

## XG4-084〜102

### Q-XG4-8 XG4-101 バイクロッサー・ギン【ブレーザーカノン】の「これがライドしていれば」
- カード: XG4-101 バイクロッサー・ギン
- 本文: 「【ブレーザーカノン】これがライドしていれば、相手に1点ダメージを与える。」（atwiki/page-2110）
- テストの前提: it.todo（テストを書いていない）。
- 根拠: CN が RC なので、効果はライドオフしたときに発動するはずだが、ライドオフした後は「ライドしている」状態ではない。どの時点で「ライドしていれば」を見るのかが本文・atwiki にない。
- 別案: (a) ライドオフする直前にライドしていたなら与える（RC が成立すればいつも与える）。(b) RC 以外（効果でライドしたままバトルエリアに出たときなど）だけで与える。(c) RC で出たときは与えない。
