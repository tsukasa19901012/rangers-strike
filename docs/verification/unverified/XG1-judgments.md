# XG1 照合：出典で決まらず判断したところ（2026-10〜）

XG1（クロスギャザー ザ・ファーストエンカウント）のカード照合で、カード本文・atwiki（公式 Q&A の転載を含む）では決まらず、テストを書くときに決めた点の一覧です。
XG のカードには公式 FAQ（grnrngr）の項がありません。書き方は docs/verification/rm-bk-judgments.md と同じです。バッチごとに追記します。
テストは packages/engine/src/cardSpec/XG1-<from>-<to>.{a,b,c}.test.ts です。
