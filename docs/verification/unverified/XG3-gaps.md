# XG3 照合：テストで残したエンジンの不具合（it.fails）・確かめられないところ（it.todo）

XG3（クロスギャザー ザ・Wインパクト）のカード別スペック（packages/engine/src/cardSpec/XG3-*.test.ts）で、
出典どおりの期待値を `it.fails`（「既知の不具合: CARD-XG3-NNN …」）か `it.todo` で残したものの一覧です。
1行に1つのテストではなく、カードごとにエンジンの足りないところを1行でまとめています。「カタログ」と書いたものはカードデータの誤りです。
