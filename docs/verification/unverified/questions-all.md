## PROMO

### U-1. PM-001 ジライヤ【真っ向両断】ほか（まとめ：「そして」「その後」の後ろは、前ができなくても行うか）
- **本文**
  - PM-001：「敵軍パワーゾーンのオモテ向きのカードから…ユニットカードを1枚選び、ウラ向きにしてダメージにする。**そして**、敵軍バトルエリアから…ユニットを1体選び、持ち主の手札に戻す。」
  - XG3-032 ゲキイエロー【弾弾丸】：「…カードを1枚選び捨札にしてもよい。そうしたとき、敵軍ラッシュエリアにSユニットがあれば1体選び撃破する。**その後**、自分は1枚ドローする。」
  - XG7-035 ヨロイ騎士【結束するデルザー改造魔人】：「自軍捨札を1枚選び、ゲームから除外してもよい。そうしたとき、このターン、これはクロス1を得る。**その後**、クロス1を持つ敵軍Sユニットを1体選び撃破する。」
- **今のテストの前提**
  - XG3-032：捨札にすれば、**撃破しなくてもドローする**。
  - XG7-035：**除外したときだけ撃破する**。
  - PM-001：パワーゾーンに選べるカードがないとき、後半（手札に戻す）を行うかは**テストしていません**。
- **根拠**：公式 Q&A の XG7-041 Q4・XG7-059 Q3 に「「その後」で続く効果は、それ以前の効果に含まれる」とあります。この読みだと、「その後」は前の「そうしたとき」の中に入ります。XG3-032 と XG7-035 の前提は、どちらもこれに合っています。PM-001 の「そして」は「そうしたとき」の後ではないので、この回答では決まりません。
- **別案**
  - PM-001：前半ができなくても後半を行う。または、前半ができなければ後半も行わない。
  - XG3-032：撃破したときだけドローする。
  - XG7-035：除外しなくても撃破する。
- **回答（TSU YA・2026-10-20）**：PM-001 は前半ができなくても後半を行う。XG3-032 は撃破できる S ユニットがあるときだけ、捨札にするかを選べる（捨札にしたら撃破し、ドローは必ず行う）。XG7-035 は除外したときだけ撃破する。→ テストと処理をこのとおりにした。

### U-3. SX-006 仮面ライダーG電王【時間警察の使者】
- **本文**：「これをラッシュしたとき、必要パワーを満たしていないSユニットとSビークルを可能な限りすべて選び、捨札にする。」
- **今のテストの前提**：それぞれのカードの**持ち主のパワーゾーンの枚数**が、必要パワーの数字（7- なら7、5+ なら5）より少なければ「満たしていない」とします。RK-211 の実装と同じです。マルチカテゴリで増えるパワーはテストしていません。
- **根拠**：カード評価「相手のパワーを削ってからラッシュすると…敵軍ユニット・ビークルも捨札に出来る」。どのプレイヤーのパワーと比べるかの記述はありません。
- **別案**：ラッシュした自分のパワーと比べる（両軍とも）。または、「－」のユニットは追加条件を満たせば必要パワー0なので、満たしているとみる。
- **回答（TSU YA・2026-10-20）**：今の前提（持ち主のパワーと比べる）でよい。マルチカテゴリなどで増えるパワーも数える。→ 処理はもともと「利用可能パワー」（R-POW-01。相手のコマンドゾーンのマルチカテゴリ・XG6-013 の加算を含む）で比べていた。マルチカテゴリで増えた分を数えるテストを両軍について足した。

### U-8. XG1-002 デンジレッド【デンジスティック】ほか（まとめ：常駐置き場の枚数に、重ねたカードを数えるか）
- **本文**
  - XG1-002：「敵軍常駐置き場にカードが2枚以上あれば、その中から1枚選んでもよい（ウラ向きのカードはウラ向きのまま選ぶ）。」
  - XG2-065 仮面ライダーカブトHF【ハイパークロックアップ】：「これは、自軍常駐置き場にカードが5枚以上あるとき、次の能力を得る⇒…」
- **今のテストの前提**
  - XG2-065：**重ねたカードも数えます**（クロックアップ1枚＋重ねた4枚で5枚）。it.fails。
  - XG1-002：重ねたウラ向きのカードを選べる、とは書きました（it.fails）。常駐1枚＋重ねた1枚を「2枚」と数えるかは**テストしていません**。
- **根拠**：XG1-002 の括弧書きは、ウラ向きのカードが常駐置き場にあることを前提にしています。XG2-065 のカード評価に「クロックアップで重ねるカードを稼ぎやすい」とあります。公式の記述はありません。
- **別案**：常駐オペレーションの枚数だけを数える（重ねたカードは数えない）。
- **回答（TSU YA・2026-10-20）**：重ねたカードも数える（今の前提どおり）。タッグの常駐も数える。→ XG1-002 の「常駐1枚＋重ねた1枚で2枚」と、XG1-002・XG2-065 でタッグの常駐を数えるテストを足した（処理は前から同じで、通る）。

### U-9. XG1-012 レッドパンチャーほか（まとめ：0枚のとき「すべて」「同じ枚数」が成り立つか）
- **本文**
  - XG1-012：「※これは自軍コマンドがすべてリリース状態なら「SP1」になる。」
  - XG2-005 スカイアルファー【アルファーレーザー】：「ホールド状態の敵軍コマンドをすべてリリースしてもよい。そうしたとき、リリースした枚数を数えて、その数以下の必要パワーの数字を持つ敵軍ユニットを1体選び…」
  - XG7-012 アバレッド×爆竜ティラノサウルス【荒ぶるダイノガッツ】：「自軍山札の上からそのユニットの必要パワーの数字と同じ枚数を捨札にして、その場に留めてもよい。」
- **今のテストの前提**：**どれも0枚の場合はテストしていません**。XG7-012 だけ、判断表に「0枚捨てて留まれる」と書きました。
- **根拠**：XG1-012 はコメント欄に「1枚だけでリリースなら SP1」の回答があるだけです。XG7-012 はコメント欄で意見が割れています。XG2-005 は記述がありません。
- **別案**
  - 0枚でも成り立つ：コマンド0枚で SP1／0枚リリースで必要パワー0の敵軍ユニットを選べる／必要パワー0のユニットは0枚捨てて留まれる。
  - 0枚では成り立たない：どれも起きない。

### U-10. XG1-013 キングピラミッダーPF【巨大要塞】
- **本文**：「…追加条件を満たすために次のようにしてもよい⇒自軍Sユニットを1体捨札にするかわりに、自軍Sユニットを1体ホールドする。」
- **今のテストの前提**：「自軍Sユニットを1体捨札にする」（指定のない条件）の L ユニット（XG1-012）**だけ**を書きました。
- **根拠**：カード評価「Sユニットを複数捨てる必要のあるユニットにも使える」。名前・特徴の指定がある条件（例「自軍「ニンジャレッド」1体を捨札にする」）は、コメント欄で結論が出ていません。
- **別案**：名前・特徴の指定がある条件でも、指定に合う S ユニットをホールドすれば使える。

### U-11. XG1-058 ウルフアンデッド【ワーウルフ化】
- **本文**：「ホールド状態のSユニットを2体選んでもよい。そうしたとき、選んだ2体でバトルさせる。ただし、特徴「男」を持つユニットを必ず1体選ぶこと。」
- **今のテストの前提**：BP の低いほうが撃破されることだけを書きました（it.fails）。**どちらがアタックした側かは決めていません**。
- **根拠**：本文・カード評価に記述がありません。「アタックされるときBP+2000」（XG1-060）や、アタック側のダメージ（ジャイアントローラー）のように、アタックした側かどうかで結果が変わるカードがあります。
- **別案**：「男」のユニットがアタックした側。先に選んだユニットがアタックした側。どちらもアタックしていない（アタックした・されたを見る効果は働かない）。

### U-12. XG1-096 ビーファイタークワガー
- **本文**：「※これはＮＣもＲＣも発動していないSユニットにアタックされない。」
- **今のテストの前提**：NC を満たして並んだが、「してもよい」の効果を見送ったユニットは**テストしていません**。
- **根拠**：公式 Q&A（atwiki/page-1661）Q2「効果を無効にされても、RC を持つユニットはライドオフすることで RC を発動しているとみなす」。ナンバーを満たしたことを「発動」と見るように読めますが、見送った場合の回答はありません。

### U-13. XG2-001 ファイブレッド【ファイブラスター】ほか（まとめ：「持ち主のゾーンに置く」で、パワーとコマンドのどちらかを誰が選ぶか）
