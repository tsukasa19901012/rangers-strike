# XG7 照合：ユーザーに確認したい点（候補）

出典（カード本文・atwiki・公式 Q&A の転載）では決まらず、読み方でゲームの結果が変わる点だけを挙げます。
テストはいまの前提で書いてあり、決まったら it / it.fails を直します。

## XG7-001〜023

### Q1. XG7-007 ドラゴンレンジャー×ティラノレンジャー【龍撃剣＆獣奏剣】で数える「恐竜」のユニット
- 本文: 「これは自軍ターン中、特徴「恐竜」を持つユニット1体につきBP+1000され、BP8000以上のときSP1になる。」
- テストの前提: 自軍・敵軍の両方の「恐竜」のユニットを数える（it.fails。効果が未実装）。
- 根拠: 本文に「自軍」の限定がない。同じカードの※は「特徴「恐竜」を持つ自軍Mユニット」と書き分けている。
- 別案: 自軍のユニットだけを数える。

### Q2. XG7-012【荒ぶるダイノガッツ】で必要パワー0のユニットが撃破されたとき
- 本文: 「自軍山札の上からそのユニットの必要パワーの数字と同じ枚数を捨札にして、その場に留めてもよい。」
- テストの前提: 必要パワー2のユニットでだけ書いた。0のユニットは0枚捨てて留まれる、という前提で判断表に書いた（テストなし）。
- 根拠: atwiki のコメント欄で意見が分かれている。公式 Q&A はない。
- 別案: (a) 0枚捨てて留まれる。(b) 捨てるカードがないので発動できない。

### Q3. XG7-021【ガールズ・イン・トラブル！】で選べる自軍パワーゾーンのカード
- 本文: 「自軍パワーゾーンからSユニットのカードを1枚選び、手札に加えてもよい。」
- テストの前提: オモテ向きのカードだけでテストした。
- 根拠: 本文に表裏の指定がない。XG7-039 のように「（ウラ向きのカードはウラ向きのまま）」と書くカードもある。
- 別案: (a) オモテ向きだけ。(b) ウラ向き（ダメージ）も選べる。

### Q4. XG7-022（ほか XG7-045）の「同じ必要パワー」と「+」「-」
- 本文: XG7-022「そのカードと同じ必要パワーの数字を持つ敵軍Sユニット」、XG7-045「ホールドしたコマンドと同じ必要パワーを持つSユニットのカード」。
- テストの前提: 「+」「-」を除いた数字で比べる（「2+」と「2」は同じ）。
- 根拠: RM-015 の既存の扱い。XG7-045 は「必要パワーの数字」ではなく「必要パワー」と書いている。
- 別案: XG7-045 は「+」「-」まで同じものだけ。

## XG7-024〜046

### Q5. XG7-035 ヨロイ騎士【結束するデルザー改造魔人】の「その後」
- 本文: 「自軍捨札を1枚選び、ゲームから除外してもよい。そうしたとき、このターン、これはクロス1を得る。その後、クロス1を持つ敵軍Sユニットを1体選び撃破する。」
- テストの前提: 除外したときだけ撃破する（除外しなければ撃破もしない）。
- 根拠: 「そうしたとき」に続く文の中の「その後」とした。XG7-041 Q4・XG7-059 Q3「「その後」で続く効果は、それ以前の効果に含まれる」。
- 別案: 除外しなくても、クロス1を持つ敵軍 S ユニットを撃破する。

### Q6. XG7-038【ライトニングブラスト&バーニングスマッシュ】の「カテゴリが同じ」とマルチカテゴリ
- 本文: 「見せたカードのカテゴリが同じなら、敵軍Sユニットを1体選び撃破する。」
- テストの前提: 単カテゴリの2枚（WB と WB、WB と MA）でだけ書いた。
- 根拠: マルチカテゴリのカードの扱いを書いた出典がない。
- 別案: (a) 1つでも同じカテゴリがあれば同じ。(b) カテゴリの組がすべて同じときだけ同じ。

## XG7-047〜068

### Q7. XG7-051 ラトラーターコンボの「毎ターン、可能ならバトルエリアに出る」の順番
- 本文: 「※これは毎ターン、可能ならバトルエリアに出る。」
- テストの前提: 出さないまま自軍バトルフェイズを終えられない、だけを書いた。ほかのユニットを先に出せるかはテストしていない（エンジンは先に出せる）。
- 根拠: rules R-BA-04 は出す義務だけを決め、順番は書いていない。並び順は NC・SP の結果を変える。
- 別案: (a) いつ出してもよい（フェイズを終える前まで）。(b) ほかのユニットより先に出さなければならない。

### Q8. XG7-060 ドデカブタック・XG7-061 トンデモジョーズの追加条件とウラ向きのパワー
- 本文: 「追加条件：カード名に「スター」または「SM」を含む自軍パワーがある」
- テストの前提: オモテ向きの XG7-063 シャークラーSM でだけ書いた。
- 根拠: ウラ向き（ダメージ）のカードのカード名を数えるかの出典がない。
- 別案: (a) オモテ向きだけ。(b) ウラ向きも含める。
