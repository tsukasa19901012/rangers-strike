# XG6 照合：出典で決まらず判断したところ（2026-10〜）

クロスギャザー ザ・ギガンティックタイタン（XG6-001〜065）のカード照合で、カード本文・atwiki に転載された公式 Q&A・atwiki のカード評価では決まらず、テストを書くときに決めた点の一覧です。
書き方は docs/verification/rm-bk-judgments.md と同じです。テストは packages/engine/src/cardSpec/XG6-<from>-<to>.{a,b,c}.test.ts。
XG6 のカードは grnrngr の公式 FAQ に項がありません（同名の旧カードの項だけ）。ユーザーに確認したい点は XG6-questions.md、エンジンの不足は XG6-gaps.md にあります。
