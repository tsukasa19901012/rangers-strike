# XG5 照合：ユーザーに確認したい点（候補）

出典（カード本文・atwiki に転載された公式 Q&A・atwiki のカード評価）では決まらず、読み方でゲームの結果が変わる点だけを挙げます。
テストはいまの前提で書いてあり、決まったら it / it.fails を直します。grnrngr の公式 FAQ に XG5 のカードの項はありません。

## XG5-001〜020

### Q1. XG5-001 ゴーグルレッド【レッドロープ】の「その処理をすべて終えてから」がどこまでを指すか
- カード（ID 名前）: XG5-001 ゴーグルレッド
- 本文: 「【レッドロープ】「SP1」これがストライクしたとき、その処理をすべて終えてから、このバトルフェイズを終える。」
- テストの前提: ストライクのダメージ（相手の「ストライクされたとき」の反応やダメージの処理を含む）まで終えてから、バトルフェイズを終える。テストはダメージが1点入ること・フェイズがバトルでなくなること・残りのユニットがラッシュエリアに残ることを見る。
- 根拠: 本文の「その処理」はストライクの処理と読んだ。atwiki のコメント欄で、「その」がストライク全体を指すか「ストライクしたとき」の時点を指すかで意見が割れている（コミュニティの記述）。相手の反応（ファイブテクター等）やダメージを受けたときの効果（ビクトリーウォーカー等）を使えるかが変わる。
- 別案: (a) ダメージと相手の反応まで終えてから終える（いまの前提）。(b) ストライクしたとき（ダメージより前）に終える。ダメージは入らないか、相手は反応できない。

## XG5-021〜040

### Q2. XG5-034 シンケンレッド の BP 上昇で敵軍の「侍」も数えるか
- カード（ID 名前）: XG5-034 シンケンレッド
- 本文: 「※これは自軍ターン中、これ以外の特徴「侍」を持つSユニット1体につきBP+2000される。」
- テストの前提: 自軍の「侍」の S ユニット（ラッシュエリア・バトルエリア）だけを置いて確かめた（敵軍の「侍」がいる場面はテストしていない）。判断表では、本文どおり敵軍のユニットも数える読みを書いた。
- 根拠: 本文に「自軍」がない。同じ範囲の他のカード（XG5-090 クワジーロ等）は「自軍バトルエリアのSユニット」と書いており、書き分けとも、書き落としとも読める。atwiki のカード評価にも記述がない。シンケンジャーどうしの対戦では BP が変わる。
- 別案: (a) 両軍の「侍」を数える（本文どおり）。(b) 自軍の「侍」だけを数える。

### Q3. XG5-040 ゴセイブラック【スネークバレット】で、マルチカテゴリの敵軍ユニットの一部のカテゴリだけが自軍コマンドゾーンにないとき選べるか
- カード（ID 名前）: XG5-040 ゴセイブラック
- 本文: 「【スネークバレット】「SP1」自軍コマンドゾーンにないカテゴリを持つ敵軍Sユニットを1体選び撃破する。（自分の手札が1枚以下なら、…自軍コマンドゾーンにあるカテゴリを持つ敵軍Sユニットを選んでもよい）」
- テストの前提: 持つカテゴリのうち1つでも自軍コマンドゾーンにないものがあれば選べる（自軍コマンドゾーンが WB だけのとき、WB/ET の S ユニットは選べる）。
- 根拠: 「ないカテゴリを持つ」はそのまま読めば1つでも持てばよい。一方、括弧書きの「あるカテゴリを持つ敵軍Sユニット」と対になっているので、どちらか一方に分けて読むなら、カテゴリが1つでも自軍コマンドゾーンにあるユニットは括弧書きの側になる。atwiki に Q&A・カード評価の記述はない。
- 別案: (a) 1つでも自軍コマンドゾーンにないカテゴリを持てば選べる（いまの前提）。(b) 持つカテゴリがすべて自軍コマンドゾーンにないときだけ選べる。

## XG5-041〜060

### Q4. XG5-041 ゴセイイエロー【兄妹の絆】の「自分の手札が1枚以下なら」を見るとき
- カード（ID 名前）: XG5-041 ゴセイイエロー
- 本文: 「【兄妹の絆】これは次の相手ターン終了時まで、次の能力を得る⇒「BP+3000｣「スクラム」（自分の手札が1枚以下なら、追加で次の能力を得る⇒これはアタックされる以外では相手に選ばれない）」
- テストの前提: NC を解決したときに手札が1枚で、相手ターン中も手札は1枚のまま（どちらの読みでも同じ結果になる場面だけをテストした）。
- 根拠: 括弧書きが、能力を得るときの条件なのか、能力を得ている間ずっと見る条件なのかが本文から決まらない。相手ターンのスタートフェイズに手札を引くと2枚以上になるので、相手のユニットの効果で選べるかが変わる。atwiki に記述はない。
- 別案: (a) NC を解決したときに数え、その後に手札が増えても選ばれない。(b) 能力を得ている間ずっと数え、手札が2枚以上になれば相手に選ばれる。
