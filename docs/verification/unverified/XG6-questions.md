# XG6 照合：ユーザーに確認したい点（候補）

出典（カード本文・atwiki に転載された公式 Q&A・atwiki のカード評価）では決まらず、読み方でゲームの結果が変わる点だけを挙げます。
テストはいまの前提で書いてあり、決まったら it / it.fails を直します。

## XG6-001〜022

### Q1. XG6-007 ゲキリントージャ【激激臨臨斬】で「WBとDAの両方を持つ自軍捨札」を選んだとき、そのカードもゲームから除外するか
- 本文: 「WBのみを持つ自軍捨札とDAのみを持つ自軍捨札を1枚ずつ選びゲームから除外するか、WBとDAの両方を持つ自軍捨札を1枚選んでもよい。そうしたとき、このユニットのBP以下のBPを持つ敵軍ユニットを1体選びゲームから除外する。」
- テストの前提: 選んだ両方持ちのカードもゲームから除外する（it.fails。【激激臨臨斬】が未実装）。
- 根拠: 前半の「1枚ずつ選びゲームから除外するか」と並ぶ文なので、後半も除外まで含むと読んだ。後半には「除外」の語がなく、カード評価・コメント欄にも記述がない。捨札に残るかどうかで、XG6-021 リンライオン・XG6-022 リンカメレオンが数える「カテゴリを2つ以上持つカード」の枚数が変わる。
- 別案: (a) 選んだカードもゲームから除外する。(b) 選ぶだけで捨札に残る（両方持ちのカード1枚が条件の確認だけになる）。

### Q2. マルチカテゴリのユニットどうしの「同カテゴリ」（XG6-021 リンライオン・XG6-022 リンカメレオンの JC）
- 本文: XG6-021「このユニットからコンビネーションする同カテゴリのLユニットは…」、XG6-022「これが同カテゴリのLユニットからコンビネーションするとき」。どちらも「※これは自軍バトルフェイズ中、カテゴリにWBが追加される」（バトルフェイズ中は DA と WB を持つ）。
- テストの前提: WB と DA の両方を持つ L ユニット（XG6-007 ゲキリントージャ）とのコンビネーションだけを書いた。DA だけの L ユニットとのコンビネーションはテストしていない。
- 根拠: atwiki/page-2351・2306 のカード評価「マルチカテゴリのユニットがコンビネーションする場合は、WBとDAの両方を含まなければ、他方がもう一方のカテゴリを全て含まないため、両者は同じカテゴリとみなされない」（コミュニティの記述）。一方 docs/verification/rm-bk-judgments.md の RM-017 では「カテゴリを1つでも共通に持てば同じとする」と決めており、いまのエンジンも DA だけの L ユニットとリンライオンの JC を成立させる（ログ joint_combo_l）。
- 別案: (a) 一方が他方のカテゴリをすべて含むときだけ同カテゴリ（カード評価どおり。DA だけの L ユニットはバトルフェイズ中のリンライオンと同カテゴリでない）。(b) 1つでも共通なら同カテゴリ（RM-017 と同じ）。

### Q3. XG6-001 火の山、吠える の「自軍ダメージの数まで」オモテにする枚数
- 本文: 「自軍ダメージの数まで、自軍山札の上をオモテにして、その中から…１枚まで選び自軍ラッシュエリアに出す。」
- テストの前提: 自軍ダメージの点数と同じ枚数をオモテにする（it.fails。常駐の効果が未実装）。少なくオモテにする選び方はテストしていない。
- 根拠: 「まで」は上限を表すが、山札が足りないとき（山札の枚数まで）の意味とも読める。カード評価「オモテにする枚数はほとんど相手に依存し」は、ダメージの点数で決まる（選ばない）とする読み方に近い。
- 別案: (a) ダメージの点数と同じ枚数（山札が足りなければ全部）。(b) 0〜ダメージの点数の好きな枚数をプレイヤーが選ぶ。

## XG6-023〜044

### Q4. XG6-037 仮面ライダーアクセル【振り切るぜ】で選べる「Sビークル」の場所
- 本文: 「自軍バトルフェイズ中、これが自軍ラッシュエリアでライドしていなければ、Sビークルを1体選んでもよい。そうしたとき、このターン、これは本来のテキストをもたないSビークルとして扱い、選んだビークルの効果名を持つテキストと…が追加される。」
- テストの前提: 自軍ラッシュエリアの S ビークルがあるとき、選ぶ行動があることだけを書いた（it.fails。【振り切るぜ】が未実装）。どこのビークルを選べるかはテストしていない。
- 根拠: 本文に場所（自軍・敵軍、エリア）がない。atwiki/page-2318 のカード評価「敵軍ビークルの効果もコピーできる」、コメント欄「すでにライドされているビークルでも選べますか？」「選べると思います」（どちらもコミュニティの記述）。
- 別案: (a) 両軍の場（ラッシュエリア・バトルエリア）の S ビークルならどれでも（ライド中も）。(b) 自軍の場の S ビークルだけ。(c) 場のライドされていない S ビークルだけ。

### Q5. XG6-044 仮面ライダーNEW電王SF の「自軍パワーゾーンから「テディ」のカード」にウラ向き（ダメージ）のカードを含むか
- 本文: 「※これをラッシュしたとき、自軍パワーゾーンから「テディ」のカードを1枚選び自軍ラッシュエリアに出してもよい。」
- テストの前提: オモテ向きの「テディ」を出せることだけを書いた。ウラ向きの「テディ」はテストしていない。
- 根拠: 本文は「オモテ向き」と書いていない。XG6-043 などほかのカードは「オモテ向きのカード」と書き分けている。ウラ向きのカードは中身を見ないので、選べるとするとダメージを減らす効果にもなる。
- 別案: (a) オモテ向きの「テディ」だけ。(b) ウラ向き（ダメージ）の「テディ」も選べる（出したぶんダメージが減る）。

## XG6-045〜065

### Q6. XG6-045 テディの「このユニットからコンビネーションする「仮面ライダーNEW電王SF」」が何を指すか
- 本文: 「※このユニットからコンビネーションする「仮面ライダーNEW電王SF」は、ナンバーにRCを持っていればライドオフしなくてもその効果を発動できる。また、このコンビネーションが成立している間BP+2000される。」
- テストの前提: バトルエリアでテディのすぐ次に、ライドしていない XG6-044 NEW電王SF が出たとき、SF の RC【カウンターストライク】が発動し、SF は BP+2000 になる（どちらも it.fails。未実装）。
- 根拠: テディはナンバーを持たず、SF のナンバーは RC なので、ふつうのナンバーコンビネーションは成立しない。本文は「コンビネーション」が何かを書いていない。atwiki/page-2305 のカード評価「RC発動を補助する能力」「BP上昇効果はXG6の方のSP1の条件を満たすことができる」は、ライドオフしない SF がテディの次に並ぶ使い方を示している（コミュニティの記述）。
- 別案: (a) テディの次に SF が並べば成立（ライドの有無を問わない）。(b) ライドした SF がテディの次に並んだときだけ成立（ライドオフしないで RC を使える）。

### Q7. XG6-046 仮面ライダーディエンドCF【ゲキジョウバン】の「8枚までオモテにして」の枚数
- 本文: 「自軍山札の上から8枚までオモテにして､その中から…出してもよい。」
- テストの前提: 山札の上8枚をオモテにする（9枚目は選べない）（it.fails。未実装）。少なくオモテにする選び方はテストしていない。
- 根拠: XG6-questions Q3（XG6-001「自軍ダメージの数まで」）と同じく、「まで」が上限なのか、山札が足りないときの意味なのかが本文で決まらない。カード評価「うまくいけば最大8体まで展開できる」は8枚オモテにする読み方に近い。
- 別案: (a) 8枚（山札が足りなければ全部）。(b) 0〜8枚の好きな枚数をプレイヤーが選ぶ。
