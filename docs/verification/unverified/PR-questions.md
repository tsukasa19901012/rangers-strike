### Q1. PR-006 デカレッド【ジュウクンドー】に RS-106 の読み替えを当てはめるか
- カード: PR-006 デカレッド
- 本文: 印刷の文は「アタックするかわりに」敵軍ラッシュエリアのユニットを撃破する。
- テストの前提: 元の RS-106 の読み替え（08-errata R-ERR-RS106「そうしたとき、これはアタックすることができない」）を当てはめた。1体も撃破しなければアタックできる。敵軍バトルエリアにユニットがいない（アタックできない）ときは発動できない。
- 根拠: card_plomo は PR-006 を RS-106 の Q&A に案内している（Q3「敵軍バトルエリアがジェットファルコンだけなら発動できない」）。ただし読み替えそのものが PR-006 にも出ているかは確かめられていない。
- 別案: 印刷の文どおりに読む（発動すれば0体でもアタックできない。敵軍バトルエリアにユニットがいなくても発動できる）。
