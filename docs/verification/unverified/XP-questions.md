# XP 照合：ユーザーに確認したい点（候補）

出典（カード本文・atwiki・公式 Q&A の転載）では決まらず、読み方でゲームの結果が変わる点だけを挙げます。
テストはいまの前提で書いてあり、決まったら it / it.fails を直します。

## XP-001〜016

### Q1. XP-003 デカレッドバトライザーで捨札にするパワーゾーンのカード
- カード: XP-003 デカレッドバトライザー
- 本文: 「【バトライズファイヤードライブ】これをラッシュしたとき、自軍パワーゾーンからカードを1枚選び捨札にしてもよい。そうしたとき、捨札にしたカードの必要パワーの数字と同じ必要パワーの数字を持つ敵軍Sユニット…」
- テストの前提: オモテ向きのカードでだけ確かめた。ウラ向き（ダメージ）を選べるかはテストにしていない。
- 根拠: 本文に表裏の指定がない。XP-017 のように「オモテ向きの」と書くカードもある。
- 別案: (a) オモテ向きだけ。(b) ウラ向き（ダメージ）も選べる（ダメージを減らす使い方ができ、ウラ向きのカードの必要パワーで対象が決まる）。

## XP-017〜032

### Q2. XP-028 ワンダーゴセイグレート【サモン・ワンダーパワー】で MA を含むマルチカテゴリのコマンドを使えるか
- カード: XP-028 ワンダーゴセイグレート
- 本文: 「…相手が常駐以外のオペレーションカードを使用して、その処理をすべて終えたとき、MAとMA以外の自軍コマンドを1つずつホールドして、これを自軍ラッシュエリアに出してもよい。」
- テストの前提: 公式 Q&A Q1「はい、できます。」のまま、MA だけのコマンドと MA を含むマルチカテゴリのコマンドで発動できる（it.fails。発動が未実装）。
- 根拠: atwiki/page-2369 の Q1 は「はい」。同じページの注釈は「公式コラム vol44 によりできなくなった」と書く。コラムそのものは確かめられていない。
- 別案: マルチカテゴリのコマンドは「MA 以外」に数えない（vol44 の注釈に従う）。
