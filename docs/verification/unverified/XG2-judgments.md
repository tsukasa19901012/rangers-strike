# XG2 照合：出典で決まらず判断したところ（2026-10〜）

XG2（クロスギャザー ザ・ドラゴンタイガー）のカード照合で、カード本文・公式 FAQ・atwiki では決まらず、テストを書くときに決めた点の一覧です。
書き方は docs/verification/rm-bk-judgments.md と同じです。バッチごとに追記します。
XG2 のカードには grnrngr の公式 FAQ の項がありません（XG2 のカード番号とカード名で FAQ を検索。同じ名前の RS のカードの項だけが見つかる）。
出典は atwiki のカードページ（本文・atwiki に転載された公式 Q&A・カード評価・コメント欄）と docs/rules の一般ルールです。
