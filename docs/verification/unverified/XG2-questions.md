# XG2 照合：ユーザーに確認したい点（候補）

出典（カード本文・atwiki・公式 Q&A の転載）では決まらず、読み方でゲームの結果が変わる点だけを挙げます。
テストはいまの前提で書いてあり、決まったら it / it.fails を直します。

## XG2-001〜020

### Q1. 「持ち主のゾーンに置く」で、パワーゾーンとコマンドゾーンのどちらにするかを誰が選ぶか（XG2-001 ファイブレッド・XG2-002 ファイブブルー・XG2-003 ファイブピンク・XG2-005 スカイアルファー）
- 本文: 例「【ファイブラスター】「SP1」特徴「メカ」を持つ敵軍Sユニットを1体選び、持ち主のゾーンに置いてもよい。」
- テストの前提: 持ち主（敵軍）のパワーゾーン（オモテ向き）かコマンドゾーンのどちらかに置かれることだけを書いた。どちらを誰が選ぶかは書いていない。
- 根拠: atwiki/page-1517 Q1「「ゾーン」とはパワーゾーンとコマンドゾーンの両方を指した総称」、Q2「特に指定のない場合は、カードは持ち主のゾーンに送って下さい」。どちらのゾーンかを誰が決めるかの記述はない。コメント欄（atwiki/page-1852）「パワーゾーン、コマンドゾーンのどちらかから選んでいいんですよね？」に回答はない。
- 結果が変わる例: パワーゾーンに置けば相手のパワーが1増える。コマンドゾーンに置けば相手のコマンドが増える（カテゴリが揃う）が、5枚あれば置けない。
- 別案: (a) 効果を使った側が選ぶ（「1体選び、…置いてもよい」の主語）。(b) 持ち主が選ぶ。(c) 効果を使った側が選ぶが、コマンドゾーンが5枚ならパワーゾーン。

### Q2. XG2-019 知恵の樹モークを1ターンに何回使えるか
- 本文: 「※常駐 自軍バトルフェイズ中、自軍ラッシュエリアから、ライドされていない特徴「獣」を持つMビークルを1体選んでもよい。そうしたとき、選んだビークルは、このターン、テキストを持たないMユニットとして扱い…」
- テストの前提: 1回使えることだけを書いた（エンジンはまだ起動できない）。
- 根拠: 本文に「1度だけ」などの回数の記述がない。atwiki Q1〜Q4 にも回数の問いはない。
- 結果が変わる例: 「獣」の M ビークルが2台あれば、2台ともユニットにしてバトルエリアに出せるか。
- 別案: (a) 1ターンに1回（1台だけ）。(b) 何回でも（条件に合うビークルをそれぞれユニットにできる）。

### Q3. XG2-005 スカイアルファー【アルファーレーザー】で、ホールド状態の敵軍コマンドが0枚のとき
- 本文: 「自軍ターン中、これがバトルエリアに出たとき、ホールド状態の敵軍コマンドをすべてリリースしてもよい。そうしたとき、リリースした枚数を数えて、その数以下の必要パワーの数字を持つ敵軍ユニットを1体選び持ち主のゾーンに置く。」
- テストの前提: ホールド状態の敵軍コマンドが3枚のときだけを書いた。
- 根拠: 0枚を「すべてリリース」したと言えるかの記述はない（カード評価・コメントにもない）。
- 結果が変わる例: 0枚で発動できれば、必要パワー0の敵軍ユニット（ファイブピンク等）を持ち主のゾーンに置ける。
- 別案: (a) 0枚でも「リリースした」ことにして、必要パワー0のユニットを選ぶ。(b) 1枚もリリースしていなければ「そうしたとき」以降は起きない。

## XG2-021〜041

### Q4. XG2-021 重騎士【騎乗】で、相手にリリース状態のコマンドがないとき
- 本文: 「このターン、選んだユニットをバトルエリアに出すとき、自軍コマンドを1つホールドするかわりに、相手は自分自身のコマンドを1つ選びホールドする。」
- テストの前提: 相手にリリース状態のコマンドが2つあるときだけを書いた。
- 根拠: 相手がホールドできないときの記述がない（atwiki/page-1192 のカード評価・コメントにもない）。
- 結果が変わる例: 相手のコマンドがすべてホールド状態のとき、XG2-022 重星獣・ゴウタウラスをコマンドをホールドせずに出せるか。
- 別案: (a) 相手がホールドできなくても、自軍コマンドをホールドせずに出せる。(b) 相手がホールドできないなら「かわりに」できず、自軍コマンドを1つホールドして出す（ホールドできなければ出られない）。

## XG2-042〜061

### Q5. XG2-042 仮面ライダーディケイドCF の ※ で捨札にするカードは1枚か2枚か
- 本文: 「※これがユニットでなくなるとき、オモテ向きの自軍パワーから特徴「仮面ライダー」を持つカードを1枚選び捨札にすれば、その場に留まる。」（カタログ・atwiki/page-1687 の本文）
- テストの前提: 1枚捨札にすれば留まる、と書いた（エンジンにこの効果がないので it.fails）。
- 根拠: atwiki/page-1687 の公式Q&A Q3 の問いの文は「…カードを2枚選び捨札にすれば、その場に留まる」と書く。コメント欄に「公式ではとどまる効果で捨てるのが２枚になってるんだが」「Q＆Aにあった気がする」とあり、エラッタかどうかは書かれていない。docs/rules/08-errata.md に XG2-042 の項はない。
- 結果が変わる例: パワーゾーンに「仮面ライダー」のカードが1枚しかないとき、留まれるか。
- 別案: (a) 1枚（印刷の本文のとおり）。(b) 2枚（Q3 の文のとおり。エラッタとして扱う）。

## XG2-062〜081

### Q6. XG2-065 仮面ライダーカブトHF【ハイパークロックアップ】の「自軍常駐置き場にカードが5枚以上」に、常駐オペレーションに重ねたカードを数えるか
- 本文: 「これは、自軍常駐置き場にカードが5枚以上あるとき、次の能力を得る⇒特徴「加速」を持たないユニットにアタックされない。」
- テストの前提: 重ねたカードも数える（常駐オペレーション1枚＋重ねたカード4枚で5枚）。常駐オペレーション5枚のときも書いた（エンジンにこの効果がないので、どちらも it.fails）。
- 根拠: atwiki/page-895 のカード評価に「常駐置き場に5枚以上カードを貯めていれば」「クロックアップで重ねるカードを稼ぎやすい」とある。公式の Q&A・FAQ はない。
- 結果が変わる例: クロックアップ1枚に4枚重ねただけの盤面で、「加速」を持たないユニットにアタックされるか。
- 別案: (a) 重ねたカードも数える。(b) 常駐置き場に配置されたオペレーションの枚数だけを数える。
