# PROMO 照合：ユーザーに確認したい点（候補）

出典（カード本文・atwiki・公式 Q&A の転載・公式 FAQ）では決まらず、読み方でゲームの結果が変わる点だけを挙げます。
テストはいまの前提で書いてあり、決まったら it / it.fails を直します。

## PROMO1-PK-SK

### Q1. PM-001【真っ向両断】で、敵軍パワーゾーンに選べるカードがないとき
- カード（ID 名前）: PM-001 ジライヤ
- 本文: 「…次の効果を発動できる⇒敵軍パワーゾーンのオモテ向きのカードから、特徴1と同じ特徴を持つユニットカードを1枚選び、ウラ向きにしてダメージにする。そして、敵軍バトルエリアから、特徴2と同じ特徴を持つユニットを1体選び、持ち主の手札に戻す。」
- テストの前提: 選べるカードがあって両方を行う場合だけを書いた。パワーゾーンに選べるカードがない（バトルエリアに特徴2のユニットはいる）とき、後半（手札に戻す）を行うかはテストしていない。
- 根拠: 「そして」は前半ができなくても後半を行う読み方と、前半を行ったときだけ後半を行う読み方のどちらもとれる。カード評価・Q&A に記述はない。
- 別案: (a) 前半ができなくても後半は行う。(b) 前半ができなければ後半も行わない。

## PROMO2-SX-SR

### Q2. SX-002 仮面ライダークウガRU【黒い瞳に映るもの】が敵軍の仮面ライダーにも効くか
- カード（ID 名前）: SX-002 仮面ライダークウガRU
- 本文: 「これが自軍バトルエリアにある間、特徴「仮面ライダー」を持つユニットは、アタックかストライクを選ぶとき、可能ならアタックを選ぶ。」
- テストの前提: 自軍・敵軍の両方の仮面ライダーに効く、で書いた（敵軍の仮面ライダーもアタックできる自軍ユニットがいればストライクを選べない。it.fails）。
- 根拠: 本文に「自軍」「敵軍」の限定がない。カード評価は「仮面ライダー限定でストライクを強制的にアタックに変更する」で、軍についての記述はない。
- 別案: (a) 両軍の仮面ライダー（いまの前提）。(b) 自軍の仮面ライダーだけ。

### Q3. SX-006 仮面ライダーG電王【時間警察の使者】の「必要パワーを満たしていない」の数え方
- カード（ID 名前）: SX-006 仮面ライダーG電王
- 本文: 「これをラッシュしたとき、必要パワーを満たしていないSユニットとSビークルを可能な限りすべて選び、捨札にする。」
- テストの前提: それぞれのカードの持ち主のパワーゾーンの枚数が、必要パワーの数字（7- なら7、5+ なら5）より少なければ「満たしていない」とした（RK-211 の実装と同じ）。相手コマンドゾーンのマルチカテゴリで増えるパワーは盤面に置かず、テストしていない。
- 根拠: カード評価「相手のパワーを削ってからラッシュすると…敵軍ユニット・ビークルも捨札に出来る」「すべての7-ユニットの天敵。大抵の場合必要パワーは満たせておらず」。どのプレイヤーのパワーと比べるか、「－」の追加条件で必要パワー0にできるユニットを満たしているとみるかの記述はない。
- 別案: (a) 持ち主のパワーと必要パワーの数字を比べる（いまの前提）。(b) ラッシュした自分のパワーと比べる（両軍とも）。(c) 「－」のユニットは追加条件を満たせば必要パワー0なので、満たしているとみる。

### Q4. SX-007 スーパーゴセイレッド【スーパースカイダイナミック】の「これをリリースしてもよい」
- カード（ID 名前）: SX-007 スーパーゴセイレッド
- 本文: 「敵軍Sユニットを1体選び持ち主のパワーゾーンにダメージにして置く。そうしたとき、これをリリースしてもよい。」
- テストの前提: it.todo にした（ナンバーコンビネーションはバトルエリアに出たときに成立し、ホールド状態のユニットはバトルエリアに出られないので、リリースが意味を持つ場面を作れない）。
- 根拠: カード評価「さらにリリースして各能力を再利用できる」。どの場面でホールド状態になっているのか（※ウイングでホールドしてアタックしたあとなど）、ナンバーコンビネーション以外で発動するのかの記述はない。
- 別案: (a) ※ウイングなどでホールド状態のときにこの効果が発動する場面があり、そのときリリースできる。(b) 効果でホールド状態のままバトルエリアに出たときだけ意味がある。
