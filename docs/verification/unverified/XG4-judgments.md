# XG4 照合：出典で決まらず判断したところ（2026-10〜）

XG4（クロスギャザー 第4弾）のカード照合で、カード本文・atwiki 転載の公式 Q&A・atwiki では決まらず、テストを書くときに決めた点の一覧です。
書き方は docs/verification/rm-bk-judgments.md と同じです。テストは packages/engine/src/cardSpec/XG4-*.test.ts にあります。
ゲームの結果が変わるもののうち、ユーザーに確かめたい点は XG4-questions.md に、エンジンが出典どおりに動かない点は XG4-gaps.md にまとめています。
