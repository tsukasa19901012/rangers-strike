## XG6-023〜044

it.fails は XG6-035 を除いて実装済み（XG6 023..044 のコミット。XG6-037 は部分実装）。

| カード | 種類 | 内容 |
|---|---|---|
| XG6-024 | it.todo ×1 | NC【ナイトダイナミック】の「手札が1枚以下なら、これをリリースする」は確かめる手順がない（ホールド状態のこれがバトルエリアに出て NC が成立する手順を、公開 API の通常の手順で用意できない）。実装は撃破の選択を開く前に、手札1枚以下ならリリースする |
| XG6-031 | it.todo ×1 | 手札からしかラッシュできない点は確かめる手順がない |
| XG6-035 | it.todo ×1 | 手札からしかラッシュできない点は確かめる手順がない（it.todo）。（※ブレイカーの同名禁止は追加条件の素材を払う経路 rules/zordSetup.ts でも見るよう修正、手札のカテゴリ追加は core/catalog.ts handCardCategories で修正済み） |
