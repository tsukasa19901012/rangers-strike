# XG2 照合：エンジンの不足（it.fails / it.todo の一覧）

テストは packages/engine/src/cardSpec/XG2-<from>-<to>.{a,b,c}.test.ts。「カタログ」はカードデータ（packages/cards）の誤り、それ以外はエンジンの不足です。
「×N」は同じ不足を確かめる it.fails の数です。
