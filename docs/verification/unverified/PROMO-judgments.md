プロモーションカード（PK・PM・SM）、シークレットレア（SK・SX・SR）のカード照合で、カード本文・atwiki（公式 Q&A の転載を含む）・公式 FAQ では決まらず、テストを書くときに決めた点の一覧です。
書き方は docs/verification/rm-bk-judgments.md と同じです。
テストは packages/engine/src/cardSpec/PROMO1-PK-SK.{a,b,c}.test.ts と PROMO2-SX-SR.{a,b,c}.test.ts です。
