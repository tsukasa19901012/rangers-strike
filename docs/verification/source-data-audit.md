# 保存済みソースデータ検証レポート

**実施日:** 2026-10-10
**対象:** `docs/wiki/sources/atwiki/page-*.md`（2,052 ページ、取得 2026-06-09〜06-28）と、それから生成されたカタログ `packages/cards/src/generated/catalog/full-playable/cards.json`（1,832 枚）・DSL stub `packages/cards/src/generated/dsl-stubs/stubs-bundle.json`

## 前提と限界

- この検証環境からは `w.atwiki.jp` / `wikiwiki.jp` / `www.grnrngr.com` に接続できない（ネットワークポリシーで拒否）。
  **ライブのサイトとの照合（保存後にwikiが更新されていないか）は未実施。**
- 検証は「保存済み原文が壊れていないか」と「原文 → カタログ / DSL への変換が正しいか」の2点。

## 3. 原文 → カタログの効果テキスト

## 4. 推奨対応

1. 3-1 の 13 枚: カタログ生成パイプラインのテキスト抽出を修正し、DSL を再生成。監査に「原文に効果テキストがあるのに effects=0」の検出を追加。
2. 3-2 の 8 枚: 修正後テキストをカタログ / DSL に反映し、効果定義（トリガー等）も修正後に合わせる。
3. 2 のサイズ・特徴: RS-076 / RS-105 を XL に、オペレーション等の特徴を反映。
4. ネットワーク許可後: ライブの atwiki / 公式ページと保存済み原文の差分を取り、保存後の更新有無を確認。

## 再現

検証スクリプトはセッションの作業領域で実行（`verify.py` / `errata.py` / `text2.py`）。リポジトリへの組み込みは推奨対応 1 と合わせて行う。
