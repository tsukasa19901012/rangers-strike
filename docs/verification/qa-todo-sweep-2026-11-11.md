## エンジンを直したもの

- **RK-008**: メカニンジャ／ライアのカウンター処理の途中でコマンドがコマンドゾーンを離れたとき、RS-238 の補充の選択が開かずにバトルが進んでいたため、バトルのフレームを退避して止め、選択の後に後処理フックで再開するようにした。
- **RK-010**: 海底ドローで山札の下に置いたとき、ハイブリッドで公開したカードが手札に加わっていなかったため、加えるようにした。
- **RK-012**: BP4000 以上の判定に現在の BP を使っていたため、ラッシュ時点の BP スナップショットを優先して使うようにした。
- **RK-013**: モーフの特徴の完全一致で効果により追加された特徴を数えていなかったため数えるようにし、JC の相手の判定で J パワーによるサイズ変更を反映するようにした。
- **RS-171**: 再登場で JC の付与がすべて消え、武器換装で戻したカードのバトル済み状態も残っていたため、同じターンの L の付与を残し、武器換装で戻したカードのバトル済み状態を外すようにした。
- **RK-016**: 鏡の世界のコストを自軍コマンドだけで数えていたため、ギンガベリックの代用で敵軍コマンドもホールドして払えるよう判定と支払いを直した（RK-016 Q5）。
- **RK-021**: 無限連鎖中でも常駐オペの効果が働いていたため、相手の無限連鎖があるときは常駐の効果を止めるようにした（RK-021 Q1）。
- **RK-021**: カウンター窓からバトルを防いだときに pendingBattle が残り、バトルが二重に解決されていたため、preventBattle の分岐で pendingBattle を消すようにした（RK-021 Q2）。
- **RK-334**: LF でテキストを無効にされたトリガー・ドーパントの GAME_START 処理を無効化扱いにしていなかったため、namedTextNegated で判定するようにした（RK-334 Q1）。
- **RS-208**: 時間戻しのやり直しでバトルフェイズ終了時の効果が走らず、ラッシュフェイズのフラグも戻らなかったため、終了時フックを実行し resetRushPhaseFlags でフラグを戻すようにした（RS-208 Q2・Q3）。
- **RS-210**: 疾風流超忍法で山札に戻した後に BP0 以下になったユニットがルールで撃破されなかったため、該当ユニットを記録して R-BP-02 の撃破処理に回すようにした（RS-210 Q1）。
- **RS-224**: JC の相手のサイズを定義のサイズで見ていたため、Jパワーで L になったユニットが組めなかった。unitSizeOf で判定するようにした（RS-224・RK-013 Q）。
- **RS-440**: 武器換装で戻したユニットに battleActed が残ってアタックできず、出し直したときに JC の能力も消えていたため、エリアでの状態を消して JC の能力だけ持ち越すようにした（atwiki/page-780 Q2・page-353 Q1 重複して2点）。
- **RS-576**: コサックダンスの同名判定がカード名の完全一致だけで、「マジフェニックスとしてつかえる」マジレッドからマジフェニックスを選べなかったため、戻したカードの別名も同じカード名として扱うようにした（faq-card-8 RS-576 Q1）。
- **RK-321**: XG2-052 のベント移動後、表向きの XG2-052 が場に残らないと失われた裏向きの重ねたカードを捨札に送っていなかったため、残っていなくても捨札に送るようにした（atwiki/page-1253 Q1）。
- **RK-026**: タイムロボの SEIGI 効果で戻したあとに【チェンジフォーメーション】が開かなかったため、戻した直後に trySet6BBattleToRush を呼ぶようにした（faq-card-6 RS-394 Q2）。
- **RS-011**: ゴルゴムの割り込みでマジチケットのオペレーションが無効になると、カードがただでコマンドに戻っていたため、割り込みが開いている間はカードを手札に残し magiTicketPending を記録するようにした（faq-card-1 RS-011）。
- **RS-216**: エグゾスがライドされていないビークルを特徴「車両」のユニットとして数えていたため、isOwnVehicleFeatureUnit を追加してユニットとして扱える状態のものだけを数えるようにした（atwiki/page-385・faq-card-5）。
- **XG5-066**: コピーベントのコスト計算が RK-043【突入】の必要パワー-3 を見ていなかったため、copyVentCost で軽減し、解決時に突入の修正を消費するようにした（atwiki XG5-066 Q1）。

- **RS-057**: コサックの名前照合が完全一致だけで別名を見ていなかったため、namesWithAliases で照合するようにした（faq-card-1 RS-057 Q2）。
- **RK-043**: XG5-076 コピーベントで入れ替えたカードにライドシューターの必要パワー-3 のルールを適用・消費していなかったため、copyVentCost と consumeRideShooterRushRule を使うようにした。
- **RS-325 / XG7-054**: XG7-054 の必要パワー-3 がフラグの数だけ重ならず、マジチケットのオペレーションにも誤って適用されていたため、フラグごとに -3 として数え、マジチケットのオペレーション中は外すようにした（page-485 Q2・page-187 Q2）。
- **RS-325 / RK-251**: マジチケットで使ったオペレーションが RK-251 ゴルゴムの仕業の選択で止まったとき、マジチケットの後処理を先に済ませてコマンドに戻していたため、後処理を選択の後まで待つ（staged）ようにした。
- **RS-296 / RS-353**: ラッシュ時に他の選択が保留中だとフォーメーション展開を飛ばしていたため、formationDeployResume に記録して選択の後に再開するようにした（faq-card-6 RS-353 Q2）。
- **RS-350 / RS-271**: 暗黒の鎧（RS-350）を重ねたユニットに対してマグリペアが起動できず、重ねた鎧もダメージにしていなかったため、起動条件に含めて先に placeDarkArmorAsDamage で鎧をダメージにするようにした。
- **R-CARD-04 / R-RUSH-03（RK-039・RK-113・RK-200）**: 敵軍ターン中に効果でライドオフさせたユニットをその場に残していたため、バトルエリアの一番右に置き直すようにした（atwiki/page-141 Q10/A10。ラッシュ扱いにはならない Q11）。
- **RK-005**: デカマスター【ディーソードベガ】の効果で撃破したユニットに RK-005 のダイナモのダメージが入っていなかったため、ディーソードベガの解決後に、敵軍捨札に移った対象ごとに 1 点を与えるようにした（faq-rider-1 RK-005 Q）。
- **RS-026**: ラッシュへのカウンターの窓（pendingRush）が開いている間は BP0 のルール撃破が止まっていたため、この窓は待たずに撃破するようにした（faq-card-1 RS-026 Q5/Q8）。
- **RS-247**: RS-026 と同じく、ラッシュへのカウンターの窓が開いている間も BP0 の敵軍ユニットが撃破されるよう、ルール撃破の待ち条件を直した。
- **RS-029**: 勇気の魔法でレッドのユニットカードをリリースした後に、アカレッド（RS-421）の【ソウル降臨】の選択が開かなかったため、リリースの後に開き直すようにした（faq-card-6 RS-421 Q）。
- **RS-363**: バルパンサーの【パンサークロー】で敵軍コマンドが場を離れても、ゴーゴーファイヤーの補充が発動していなかったため、afterCommandCardsLeft を呼ぶようにした（faq-card-6 RS-363 Q2）。
- **RK-039**: 【CHARGE】でバトルエリアのライダーをライドオフさせたとき、元の位置に残っていたため、バトルエリアの一番右に置くようにした（atwiki/page-141 Q10/A10）。
- **RK-078 (RS-072 無限連鎖カード Q1)**: 無限連鎖カードを使ったターンでも相手の常駐オペレーション（クロックアップ）が「アタックされたとき」に発動していたので、residentOps で opponentInfiniteChainBlocks を見て無効にするようにした（常駐置き場には留まる）。

- **RS-238 / RS-363 バルパンサー(2nd)**: パンサークローで置いたコマンドを捨札にしたあとコマンドゾーンの補充（ゴーゴーファイヤーの繰り返し）が起きなかったので、捨札にし終えたとき afterCommandCardsLeft を呼ぶようにした。
- **RS-241 ボウケンレッドAT (RS-005 ランドバルカン Q2)**: 複数体を効果ラッシュするとき、先に出すカードで条件を満たす AT が候補に入らなかったので、他の候補がラッシュエリアにある前提で条件を満たす候補も加えるようにした（R-RUSH-23）。
- **RS-271 マグ + RS-350 暗黒の鎧**: 起動効果のコストで自身を捨札にしたとき重ねた暗黒の鎧の後処理がされずパワーゾーンのカードを選べなかったので、settleDarkArmor を通すようにした。
- **RS-280 レッドホーク (RS-208 時間返し)**: 時間返しで phase を直接 rush に書き換えていたため『バトルフェイズを終えるとき』の効果が発動しなかったので、applyXg2BattlePhaseEnd を通すようにした。
- **RS-394 タイムロボα (RK-026 がんがんじい Q1/Q2)**: がんがんじいでバトルエリアから戻したときにチェンジフォーメーションが誘発しなかったので、戻したあと trySet6BBattleToRush を呼ぶようにした（置き換えて出たカードは戻したユニット・スモーキーで出したユニット扱いにならない）。
- **R-KW-BREAKER-03 (XG6-003 + RS-168)**: 爆竜マルチコンバインで手札から見せた RS-168 のクロスサンダー（legend3 の R の JC）が発動せず、発動してもブレイカー持ちを選べなかったので、resolveLegend3JointComboR を呼び、開いた選択に sourceNotUnit を付けてブレイカーの保護を外すようにした。

- **R-SIM-01 同時に誘発した効果の処理順（rules/triggerOrder.ts）— RK-239 / XG4-075**: ホールド状態の XG4-075 アポロガイストが出たとき、【生命の強奪】がウエイクアップ！より先に開き、順番を選べなかったため、ターンプレイヤーが処理順を選ぶ選択（simultaneous_order）を開くようにした。後に回した【生命の強奪】は開くときに候補を作り直し、リリース状態なら「リリースする」を出さない（atwiki/page-763 Q2・page-2062 Q1。Q の「RK-246」は RK-239 の誤記）。
- **R-SIM-02 止められないループ（rules/loopPriority.ts）— XG2-029 / RS-364**: 【災魔ツリー】の「BP8000以上のとき L ユニットになる」を実装し（行動の後にサイズを合わせる）、RS-364 の BP+3000 で L になると対象から外れるループでは、ターンプレイヤーが優先する効果を選ぶ選択（effectId `loop_priority`）を開くようにした。総統を優先すると BP+3000 の S、サラマンデスを優先すると BP そのままの S（atwiki/page-1798 Q1・Q2、page-576 Q7）。
- **R-SIM-02 — RS-558 / XG6-053**: ガンマジンがアークの※の L を数えて両方 L になっていた（Q の禁じる状態）ため、ループとして選ばせ、アークを優先すればアークだけ L、ガンマジンを優先すればガンマジンだけ L（BP+4000）にした（atwiki/page-1186 Q6）。RS-420・RS-454 も同じ扱い。
- **R-SIM-02 — RK-013 / XG3-029**: J パワーを重ねたウルザードに M ビークルがあるとき、ターンプレイヤーが J パワー（L）と※（M）のどちらを優先するかを選ぶようにした（M は sizeOverride "M"。atwiki/page-211 Q8）。
- **R-SIM-02 — RS-497 / XG1-078**: コピーベントで【変身の妨害】を得たユニットの制限を実装し（以前は効果名の入れ替えが誘発効果だけだった）、自分自身が制限の対象になるループでは、ターンプレイヤーが「持ち主の効果」と「【変身の妨害】の制限」のどちらを優先するかを選ぶようにした（atwiki/page-819 Q1）。
- **R-SIM-02 — RS-363 / RS-238（R-TURN-05）**: 【パンサークロー】の選択に、敵軍の【プロジェットカノン】が置き直せるときはバルパンサー自身を候補に足し、選ぶと捨札にしたまま【プロジェットカノン】を発動させずにループを止めるようにした（grnrngr/faq-card-6 RS-363 Q2）。カードを選べば今までどおり（相手が置き直すかを選ぶ）。
- **RS-421**（エンジンの変更なし。「テストにしただけで通ったもの」に数えた）: 勇気の魔法と【ソウル降臨】の順（faq-card-6 RS-421 Q4）は、既存の「リリースの後に【ソウル降臨】を開き直す」で再現できたので、テストにした。
