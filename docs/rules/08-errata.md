#### R-ERR-RS052 爆竜トリケラトプス（ユニット） [公式] `web未照合`
- 誤: 【超シールド進化】「ワイルドビースト」の自軍ユニットが撃破されるとき、**これを**かわりに捨札にしてもよい。
- 正: ※これは自軍コマンドを１つホールドしなければバトルエリアに出られない。
  【超シールド進化】「ワイルドビースト」の自軍ユニットが撃破されるとき、**このユニットを**かわりに捨札にしてもよい。
- 効果: 手札からは使えず、ユニットとして場にあるときだけ発動できる。かわりに捨札になったトリケラ自身は撃破扱いではない（R-REPL-01）。守ったユニットの「撃破された」事実は残る（R-DESTROY-02）。
- 出典: errata.html、`grnrngr/faq-card-1` RS-052 Q5「この効果は「RS-052 爆竜トリケラトプス」がユニットとして場に出ているときにだけ発動できます」、`atwiki/page-84`
- 実装: ✅ 挙動（バトルエリアのみ）。❌ テキスト未反映（E14）、撃破誘発が消える（E10）。

#### R-ERR-RS009 パワーバズーカ（オペレーション） [公式] `web未照合`
- 誤: 敵軍Ｌユニットを１体選んで撃破する。**そうしたとき**、相手はそのＬユニットの合体に必要なユニットのカードを捨札から探してバトルエリアに戻す。このとき、戻したユニットの効果は発動しない。
- 正: 敵軍Ｌユニットを１体選んで撃破する。**そうして撃破したＬユニットが捨札になったとき**、相手はそのＬユニットの合体に必要なユニットのカードを捨札から探してバトルエリアに戻す。このとき、戻したユニットの効果は発動しない。
- 効果: 置換で L ユニットが捨札にならなければ素材は戻らない。戻す素材は相手が選んで1体ずつ出す。「ホールドしなければ出られない」は有効で、ホールドできなくなった時点で終了。必要パワー・追加条件は不要。ラッシュ時の効果は発動しない。
- 出典: errata.html、`grnrngr/faq-card-1` RS-009 Q1・Q3・Q4・Q6、RS-050
- 実装: ✅ 反映済み。素材の選択は自動（05-D16、軽微）。

#### R-ERR-RS065 ボウケンイエロー（ユニット） [公式] `web未照合`

- 出典: errata.html、`grnrngr/faq-card-1` RS-065 Q2〜Q4

#### R-ERR-RS003 バトルダンス（常駐オペレーション） [公式] `web未照合`
- 誤: 自分のバトルフェイズに発動できる。自軍コマンドを2つホールド**するごとに**、自軍Sユニットを1体ラッシュエリアに戻してもよい。ただし、戻したユニットはこのターン、再びバトルエリアに出ることはできない。

  自分のバトルフェイズに発動できる。自軍コマンドを２つホールド**して**、自軍Ｓユニットを１体ラッシュエリアに戻してもよい。ただし、戻したユニットはこのターン、再びバトルエリアに出ることはできない。
- 効果: 1回の発動で2ホールドにつき1体。コマンドをホールドできる限り繰り返し発動できる。
- 出典: errata.html、`grnrngr/faq-card-1` RS-003「コマンドをホールドできる限り、繰り返し発動できます」
- 実装: ✅ 挙動。❌ テキスト未反映（E14）。

#### R-ERR-RS018 隠流忍術（カウンターオペレーション） [公式] `web未照合`

- 出典: errata.html、`grnrngr/faq-card-1` RS-018 Q11・Q13
