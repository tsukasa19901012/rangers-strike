# 08 エラッタ・テキスト読み替え

記法は [README](README.md#記法) を参照。2026-10-10 に取得したライブ版（`docs/rules/sources/web/`）で照合した。公式エラッタページ・公式カードFAQ・wikiwiki「エラッタ」・atwiki「エラッタ」(page-579) は取得済み。atwiki のカード個別ページ（§1A・§2 の Web 列、page-271 を含む）も後から本文テキストとして取得し照合した。

エンジンとカードデータは **修正後（正）** のテキストで動作しなければならない。全角／半角の数字表記の違いは意味上の差がないため無視する。

本章は3部構成。

1. **§1 公式エラッタページ記載（6件）** — ライブ版 `grnrngr/errata.html` も同じ6件のみ（スナップショットは古くなかった）。[公式]
2. **§1A 公式カードFAQ内の読み替え・訂正（10件）** — 公式エラッタページには載らず、公式カードFAQ（`faq/card_*.html`、`faq/rider_*.html`）と FAQ 索引 `faq/index.html` の回答中で「以下のように読み替え」「と解釈してください」「表記不備」等と告知されたもの。旧 §2 から7件を格上げし、3件を新規追加。[公式]
3. **§2 atwiki 記載の修正後テキスト（残り21件）** — 各カードページに「このテキストは公式HPでエラッタが発表されています／公式HPで読み替えが推奨されています／修正されています／コンプリートブックでエラッタが示されています。修正後は以下。」と書かれたもの。取得済みの公式ページ（grnrngr）に該当告知が見つからないため [wiki]。ただし11件はカードページの Q&A 欄に公式回答の転載があり、その中で同じ読み替え文が示されている（§2 の表の照合列）。

wikiwiki「エラッタ」(https://wikiwiki.jp/renst/エラッタ 、最終更新 2026-02-18) は用語解説のみでカード一覧はない（atwiki page-579 と同文）。カード別の情報は「ゲームバランス調整のためにエラッタで能力が変更されたのはデカレッドのみ」の1点（R-ERR-RS106 参照）。
