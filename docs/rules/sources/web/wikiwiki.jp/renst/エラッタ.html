これらのキーワードがハイライトされています：

    エラッタ

    • レンジャーズストライク公式サイトのＱ＆Ａにある、カードに記載された情報の正誤表。
    • 分かりづらいテキストや表記ミス、どちらとも取れるような意味のテキストに対する修正のこと。
    • 公式サイトでエラッタが出されたカードは、多くの場合、以降の再録時にエラッタ後の内容に変更される。逆に言うと再録までエラッタ内容は実際の印刷物には反映されないため、Ｑ＆Ａ更新時にはしっかりチェックして把握しておきたい。
    • ゲームバランス調整のためにエラッタで能力が変更されたのはデカレッド?のみ。ルール改正時に「～するかわりに」の処理ルールが明言された際、強力すぎるとして変更された。
