オペレーションカードを使用することができます。
オペレーションカードを使うことで、ユニットをパワーアップしたり、ゲームを有利に進めることができます。
 
自分のラッシュフェイズに手札から使用して、すぐ効果を発動します。
パワーゾーンを見てみましょう。
カードが３枚あるので、パワーが３発生しています。（カードのカテゴリやウラ・オモテに関係なく置かれているカードの枚数だけをみます）。

手札のオペレーションで、パワー３以内で使いたいカードのカテゴリを確認しましょう。

コマンドゾーンにそのカテゴリのカードがあるときホールドしましょう（カテゴリの同じカードが無いとき使用できません）。

手札のオペレーションカードを相手に見えるように出しその効果を発動させます。

使用したオペレーションは捨札にします。
他にも特殊な使いかたをするオペレーションがあります。
 
時計アイコンが付いているオペレーションカードは、場に配置してテキストの効果を常に有効にし続ける常駐オペレーションです。自分のラッシュフェイズに手札から使用して、捨札にせずに場に配置します。
パワーゾーンを見てみましょう。
カードが３枚あるので、パワーが３発生しています。（カードのカテゴリやウラ・オモテに関係なく置かれているカードの枚数だけをみます）。

手札のオペレーションで、パワー３以内で使いたいカードのカテゴリを確認しましょう。

コマンドゾーンにそのカテゴリのカードがあるときホールドしましょう（カテゴリの同じカードが無いとき使用できません）。

使用したオペレーションは場に配置します。
すでに場に常駐オペレーションが配置されているときは、それを捨札にしてから配置します。
 
ラッシュフェイズで使用するオペレーションカードではありませんが、ここで紹介します。
矢印アイコンのオペレーションカードは、相手のターンに発動できるカウンターオペレーションです。
カウンターのテキストには、必ず発動条件が書いてあります。たとえば「自軍ユニットがアタックされたとき」などがそれです。

発動条件を満たすタイミングで手札から使用して、すぐに効果を発動します。そして効果を発動したあとで捨札にします。

カウンターを使う場合にも、コマンドをホールドするので使用したいカウンターオペレーションのカテゴリと同じカードがコマンドゾーンでリリース状態で配置されていることが必要となります。


自分の手札からユニットカードを選んで場に出すことができます（これをラッシュといいます）。
 
自分の場のカードが右図のように配置されていて、手札に「マジレッド」があるとき「マジレッド」を"ラッシュ"して場に出してみましょう！
まず手札の「マジレッド」を確認しましょう。
確認するのは、必要パワーとカテゴリです。

マジレッドの必要パワーは３
カテゴリはミスティックアームズだということが分かります。

場に出ているカードがこの条件を満たしているか確認しながら進めていきます。
I パワーゾーンを見てみましょう。
カードが３枚あるので、パワーが３発生しています。（カードのカテゴリやウラ・オモテに関係なく置かれているカードの枚数だけをみます）。
II コマンドゾーンのカードを確認しましょう。黄色のカードのカテゴリがミスティックアームズでした。　このカードを、ホールドしましょう。
 
必要パワー３以内で、ホールドしたコマンドと同じカテゴリのユニットをラッシュできます。
III 「マジレッド」の必要パワー・カテゴリをそれぞれ満たすことが分かりました！
手札の「マジレッド」をラッシュエリアにリリース状態で配置します！
 
追加条件を満たして、より強力なユニットをラッシュしよう!!
必要パワーの横に「＋」のあるユニットは、場に出すための追加条件をもつユニットです。
これは「そのユニットを場に出すためには、必要パワー以外にも満たすべき条件がある」という意味です。
この場合、「５＋」となっていますので追加条件をもっています。
カードに記載された追加条件を確認しましょう。「自軍Ｓユニットを１体パワーゾーンに送る」とあるので、自分の場にあるＳユニットから１体選んでパワーゾーンに送ります。

このときも、通常のラッシュと同じく必要パワー５を満たす必要があり、さらに同じカテゴリのコマンドを１つホールドしてラッシュします。

こうして追加条件を満たすことでより強力なユニットをラッシュできます。
 
追加条件に「自軍合体ユニットを捨て札にする」とあるとき、捨札にする合体ユニットとは、テキストに書かれている「合体-」に続くユニット名を指します。

この場合「爆竜ティラノサウルス」と「爆竜トリケラトプス」と「爆竜プテラノドン」を捨札にすることで、この追加条件を満たすことができます。

あとは、通常のラッシュと同じく必要パワー７を満たす必要があり、さらに同じカテゴリのコマンドを１つホールドしてラッシュします。
それでは、「ユニット」とは何を意味するのでしょうか？

ユニットは、そのサイズごとに「Ｓユニット、Ｍユニット、Ｌユニット」と分類されているのです。

Ｓユニットはレンジャーなど、ＭユニットはマシンなどＬユニットは合体ロボットなどが分類されています。
場にでているＳユニットを手札のＭユニットに置き換えたり、場に出ているＭユニットを集めて、手札のＬユニットに合体させたりといったパワーアップの操作を「ゾードアップ」と呼びます。

レンジャーがマシンに乗り込み、そのマシンが合体してロボットに！
作品の世界観を忠実に再現したシステムです！
