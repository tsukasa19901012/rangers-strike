ラッシュエリアにあるユニットを１体選んでバトルエリアに移動させます。
カードはバトルエリアの左から順に詰めておきます。
 カードの並び方が「ナンバーコンビネーション」の発動条件になるので、よく考えて移動しよう！

バトルエリアに出すことによって、このユニットは相手のバトルエリアにあるユニットにアタックを宣言し「バトル」、またはSPポイントが1以上ならば「ストライク」を行うことが出来ます。

逆にバトルエリアにユニットを出すことで、次の相手のターンのバトルフェイズに、アタックの対象になるということも注意しておきましょう。

また、移動させなくてもかまいません。
移動させない場合は、バトルフェイズを終了しエンドフェイズに移ります。
コンビネーションナンバーをもっているユニットの効果はそのままでは発動しません。
 発動させるためには、ユニットをバトルエリアに並べる必要があります（これをコンビネーションといいます）。

カードを移動させてみましょう！
「マジグリーン」を選んでバトルエリアに出します。
バトルエリアに出したことで、このユニットは相手のバトルエリアにあるユニットにアタックすることができるようになります。

別のユニットの「コンビネーション」を発動させるためだけに出して、このユニット自身はなにもしないという選択もできます。
続いて「アバレブルー」を選んでバトルエリアに出します。
バトルエリアへは左から順に詰めて配置しますので、「マジグリーン」の右隣に置きます。
これで「アバレブルー」は「マジグリーン」からコンビネーションしたことになります。

「アバレブルー」はコンビネーションナンバー２なので、左から２番目にならべたことでコンビネーションの効果が発動します。
よってになるので、相手に「ストライク（直接攻撃）」することができるようになります。
さらに「マジイエロー」を選んで、バトルエリアに出します。これで「マジイエロー」は「アバレブルー」からコンビネーションしたことになります。

「マジイエロー」はコンビネーションによってになり、さらに「敵軍ラッシュエリアのユニットにアタックできる」能力を得ます。

この例ではSユニット同士のコンビネーションでしたが、サイズの違うユニットが、途中にあってもコンビネーションは発動します。（例：バトルエリアに左から Sユニット・Mユニット・Sユニット と並んでいる場合、右端のSユニットのコンビネーションナンバーが３であればナンバーコンビネーションが発動します。）
このように、ユニットがバトルエリアに出たときの並び順で、
ユニットの効果を発動させて戦うのが「ナンバーコンビネーション」です。

ユニット同士のBP（バトルポイント）を比べて、BPの低い方が撃破されます。
 撃破されたユニットは捨札になります。
BPが同じ値の時はお互いに撃破扱いになります。
・ 相手のどのユニットカードに対してバトルを行うかは、アタックを宣言するときに同時に指定します。
・ 相手のバトルエリアにユニットがない場合、アタックを宣言できませんのでバトルができません。
・ オペレーションカードの効果が発動している場合、常駐されている場合、そのテキスト効果が有効になります。
・ ナンバーコンビネーションが発動している場合、そのテキスト効果が有効になります。

相手はダメージ１点につきパワーゾーンのカードを１枚選び裏返しにします。
裏返しにできるカードがなければ、山札の上から１枚を裏向きのままパワーゾーンに置き１点とします。
・ 相手に７点ダメージを与えた時点（相手のパワーゾーンの裏向きのカードが７枚になった時点）で勝利となります！
・ オペレーションカードの効果が発動している場合、常駐されている場合、そのテキスト効果が有効になります。
・ ナンバーコンビネーションが発動している場合、そのテキスト効果が有効になります。
