# 色
# https://w.atwiki.jp/renst/pages/2460.html

色

カードの持つ特徴のうち、キャラクターの見た目のパーソナルカラーをあらわしたもの。「レッド」、「ブルー」、「イエロー」、「ピンク」、「グリーン」、「ブラック」、「ホワイト」「シルバー」、「バイオレット」、「ゴールド」の10種（公式用語集ver3.0より）



カードの特徴。主にスーパー戦隊シリーズ出典のSユニットが持つ。
テキスト中で「色」を参照する場合は上記10種の特徴を指す。カードのテキスト欄の色については「カテゴリ」を参照。
一部のカードを除き、該当する特徴は色つきの文字で書かれている。
これらの特徴そのものは黎明期から存在していたが、このような形で纏められたのはXG7弾になってからである。
