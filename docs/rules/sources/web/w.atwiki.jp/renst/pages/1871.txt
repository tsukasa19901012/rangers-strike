# メタルヒーローシリーズ
# https://w.atwiki.jp/renst/pages/1871.html

メタルヒーローシリーズ
このゲームの題材のひとつとなっている特撮ヒーロー番組シリーズ。スペシャルメタルエディションから正式収録。
「宇宙刑事ギャバン」から「テツワン探偵ロボタック」までの17作品を指す。ただし場合によっては作風の著しく異なる「ビーロボカブタック」「テツワン探偵ロボタック」を含めないこともある。
現在シリーズの続編は製作されていないが、いまだにファンの多い作品群である。
金属的でメカニックな外観のヒーローが多いことからこの名がついており、レンストでも多くのユニットが特徴に「メカ」を持っている。スーパーレアカードの光沢にも気が配られているそうである。
「宇宙刑事ギャバン」から「宇宙刑事シャイダー」までの3作は特に「宇宙刑事シリーズ」と呼ばれ、ゲーム中でも実質専用の能力であるチェイスを持つ。
参入が比較的最近で関連カードが少ないこともあり、各勢力のカードを10枚以上入れる必要のある「特撮ヒーロー大会」のレギュレーションでは、特にシリーズに属さない作品のキャラクターも便宜上メタルヒーローの枠として使うことができる。
カードナンバーは通常カードが[RM-○○○]、プロモーションカードが[PM-○○○]、クロスギャザーではナンバー後に[RM]が付くことで表されている。
