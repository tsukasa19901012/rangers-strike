# 軽い
# https://w.atwiki.jp/renst/pages/582.html

軽い
ラッシュするために必要なパワーが少なく、ラッシュしやすいこと。
主にサイズの小さいユニットの事を指すが、能力に対してパワーが少なくラッシュしやすい場合にも使われる。
