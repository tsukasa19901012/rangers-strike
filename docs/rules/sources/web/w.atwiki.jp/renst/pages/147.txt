# ラッシュエリア
# https://w.atwiki.jp/renst/pages/147.html

ラッシュエリア
手札からラッシュしたユニットやビークルを置けるエリア。
特殊な能力を持つカードを除いてこのエリアのユニットにアタックしたり、ここからアタックやストライクをする事は出来ない。
このエリアに置けるカードの枚数制限は無い。また、バトルエリアと違い並び順の概念は存在しない。
クロスギャザーからはラッシュエリアはカードテキスト上ではミスティックアームズのイメージカラーである黄色の文字で示されている。他の色と比べるとカテゴリと場所との繋がりは薄い。
