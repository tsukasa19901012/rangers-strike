# 撃破
# https://w.atwiki.jp/renst/pages/262.html

撃破

バトルに負けた場合や、カードの効果などによって、そのユニットがユニットであることを維持できなくなること。通常、撃破されたユニットは捨札になる。（公式用語集ver1.0より）



バトルで自分以上のBPの数値を持つユニットと戦った時や、テキストに書かれている効果などでユニットが倒されてしまうこと。
撃破されたユニットは捨札となり捨山に移動する。捨札になるのは「撃破されたとき」のタイミング。
「撃破」と「捨札になること」はイコールではない。あくまでも撃破された結果捨札になるのである。ユニットが撃破を経ずに直接捨札になることもあり、その場合は「撃破されたとき」に発動するようなユニット効果は使えない。追加条件で捨札になった場合などがこれに当たる。
