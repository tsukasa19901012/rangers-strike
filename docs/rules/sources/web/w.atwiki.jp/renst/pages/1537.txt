# ウイング（用語）
# https://w.atwiki.jp/renst/pages/1537.html

ウイング

効果：これは自軍バトルフェイズ中にラッシュエリアでホールドして、ラッシュエリアからアタックできる。そうしたターン、これはバトルエリアに出られない（原文より）




Q&A



		Q1
		「ウイング」とはどんな効果ですか？
		A1
		「ウイング」は空中からの奇襲攻撃を表現した能力です。「ウイング」を持つユニットは、ラッシュエリアでホールドすることで、バトルエリアに出さずとも、相手のユニットにアタックすることができます。「ウイング」のテキスト全文は以下の通りです。※ウイング（これは自軍バトルフェイズ中にラッシュエリアでホールドして、ラッシュエリアからアタックできる。そうしたターン、これはバトルエリアに出られない）
		Q2
		「ウイング」は、なんらかの制限を受けてユニットがバトルエリアに出られない状態でも発動することができますか？
		A2
		はい、できます。
		Q3
		「ウイング」は自軍バトルフェイズ以外のフェイズに発動することができますか？
		A3
		いいえ、できません。
		Q4
		ユニットが「ウイング」を発動した場合、発動したそのターン中にバトルエリアに出ることができますか？
		A4
		いいえ、できません。
		Q5
		「ウイング」はコマンドゾーンやパワーゾーンなどのラッシュエリア以外の場所からでも発動できますか？
		A5
		いいえ、出ることはできません。
		Q6
		ＳＰ１以上のユニットが「ウイング」を発動したとき、アタックするかわりにストライクすることができますか？
		A6
		いいえ、できません。



蒼九の翼から登場した能力。バトルエリアに出ずに、ラッシュエリアからアタックを行う。
デンジイエローのようなバトルエリアに出ることを妨害する効果や、タイガーロイドのようなバトルエリアに出ているユニットに効果を及ぼすカードの影響を受けずにアタックを行うことができる事が強み。
デメリットはユニットをホールドする点、発動したターンはバトルエリアに出られない点の２つ。ただし、ユニットが先にバトルエリアに出てからそのバトルフェイズ中に何らかの効果でラッシュエリアに戻り、その後ウイングを使うことは可能。バトルエリアに出たときとウイングで2回アタックすることができる。
また、バトルフェイズ中にユニットをリリースする手段があれば、同じユニットのウイングを1ターンに複数回使うこともできる。
作中で空を飛ぶキャラクターや飛行する動物に関する能力・モチーフを持つキャラクターのユニットが持つことが多い。
