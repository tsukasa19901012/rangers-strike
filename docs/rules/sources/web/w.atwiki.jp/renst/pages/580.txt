# 重い
# https://w.atwiki.jp/renst/pages/580.html

重い
ラッシュするために必要なパワーが多く、ラッシュしにくいという意味。
主にサイズの大きいユニットのことを指すが、能力に対してパワーが割に合っていない場合にも使われる。
