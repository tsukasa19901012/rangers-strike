# グッドスタッフ
# https://w.atwiki.jp/renst/pages/1746.html

グッドスタッフ
「良い者、優れた者」の意。元々はMTGから生まれたTCG用語。
単体でスペックの高いカードを集めて構築されたデッキ、またはそのカード自体を指す。
とにかく高性能なユニットだけで構築されたデッキの総称として使われる事が多い。コンボやシナジーを考慮していないためキーカードが存在せず、カード1枚1枚が強力なのである意味安定したデッキと言える。しかし、逆に言えばカードパワーだけで押し切る形になるのでロックなどの妨害や除去の様な搦め手には滅法弱い事が多い。
