# バニラ
# https://w.atwiki.jp/renst/pages/2032.html

バニラ
TCG全般で使われる用語。特に効果を持たないカードの通称である。
レンストでは仮面ライダー龍騎ブランク体のような全く効果を持たないユニット以外にも、シンケングリーンのようなコンビネーションでＳＰを得る効果のみを持つものなどもバニラと呼ばれる。
ストライカーであるかどうかは特に関係ない。
