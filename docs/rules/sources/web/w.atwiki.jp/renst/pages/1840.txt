# 素材
# https://w.atwiki.jp/renst/pages/1840.html

素材
ゾードアップするために必要なユニットの通称。具体的には合体が必要なユニットの追加条件に使う「合体ユニット」、パワー7-系のパワーアップユニットの元になるSユニットなどのことを指す。
かつての遊戯王OCGなどの似た概念の影響で「生贄」と呼ばれることもある。Mユニットのラッシュに必要なSユニットは特にそのイメージが近い。レンストでは多くの場合「メカに搭乗」「強化形態に２段変身」などのイメージで行われているが、中にはオロチや絶対神ン・マのように本当に生贄にしている様子を再現したものもある。
