# アタック
# https://w.atwiki.jp/renst/pages/138.html

アタック

自軍ユニットで敵軍ユニットにバトルをしかけること。（公式用語集ver1.0より）



自軍ユニットで敵軍ユニットに攻撃すること。
ユニットがバトルフェイズにのみ行うことができる行動の一つ。
ウイングなどの特殊な効果を持つ場合を除き、基本的にバトルエリアのユニットが相手のバトルエリアのユニットに対して行える。
アタックを宣言すると、敵軍ユニットとのバトルになり、バトルに負けたほうは撃破され、捨札になる。
ＳＰが1以上になる条件を満たしているユニットはストライクを行うか、アタックを行うか選ぶ事が出来る。
超力や仮面ライダーザビーMF等、「アタックするとき～」や「アタックされるとき～」と書かれた効果はアタック時のみ発動し、バトルが終了してアタックの処理が終了した時点で効果が終了する。
