# アーステクノロジー
# https://w.atwiki.jp/renst/pages/142.html

アーステクノロジー
地球の軍隊や組織に属して地球科学で戦うヒーローで構成された勢力。
イメージカラーは緑。
ライダーEXPでは、ビークルの種類とそれにライド出来るユニットが多いのが特徴。
コマンド加速・操作に長けている。
ストライク妨害・捨札回収手段を持つ。
ダークアライアンスに次いでパワーに対してBPの高いユニットが多い。
パワーが溜まりづらいのが欠点。
ストライク可能になるナンバーはＮＣ・分数・タクス共に基本的に５番、全カテゴリで最も重い。
反面、ボウケンシルバー（2nd）や仮面ライダー1号のようなナンバーに関わらずストライクが可能になるカードが非常に多く、単色での多段ストライクを得意とする側面も持つ。
参戦作品は全カテゴリ中(ダークアライアンスを除く)もっとも多い。
