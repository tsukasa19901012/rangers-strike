# PK-002 ゼクトルーパー
# https://w.atwiki.jp/renst/pages/962.html

ゼクトルーパー（プロモーション）

種類：Sユニット

カテゴリ：オーバーテクノロジー

BP：500

SP：－

必要パワー：1

追加条件：なし

CN：なし

特徴：男／戦闘員


テキスト：

※このカードはデッキに好きな枚数入れてもよい。

【フォーメーションα】これが自軍バトルエリアにある間、敵軍ターン中、カードに表記された本来のナンバーが自軍バトルエリアの「ゼクトルーパー」の数と同じ敵軍Sユニットは、バトルエリアに出られない。




フレーバーテキスト

数を頼む事が卑怯と思う甘い心は捨てろ。それが、この世界で生きる最低限の心構えだ。





イラストレーター：TSUYOSHI NOGUCHI

レアリティ：プロモーションカード

作品：仮面ライダーカブト

収録：2007年 7～9月ライダー限定大会参加賞




カード評価
史上３枚目となる元カードがノーマルのプロモ。デッキに何枚でも入れられるため使い道はある。
イラストは通常版がシャドウ所属のゼクトルーパーだったがこちらは通常のゼクトルーパーになっている。ゲーム上では特にこの２枚には違いは無い。
