# パワーゾーン
# https://w.atwiki.jp/renst/pages/109.html

パワーゾーン

Q&A



		Q1
		ダメージを受けてパワーゾーンのカードをウラ返すとき、ウラ返すカードはどのカードでも自由に選べますか？　例えば、パワーゾーンにオモテ向きのカードが5枚あるとき、真ん中の3枚目を選んでウラ返すことができますか？
		A1
		はい、自由に選ぶことができます。
		Q2
		自軍パワーゾーンのカードを、表向きのものは表向きのまま、裏向きのものは裏向きのままで並び替えることはできますか？
		A2
		ルール上は違反ではありませんので、ダメージを数えやすくするためにまとめたり、並び替えたりすることは可能ですが、なるべくはマナーとして対戦相手と了解の上で行うようにしてください。
		Q3
		パワーゾーンには何枚までカードを置けますか？
		A3
		何枚でも置くことができます。
		Q4
		パワーゾーンでダメージになっているウラ向きのカードは、自分でオモテを見て内容を確認することができますか？
		A4
		い いえ、パワーゾーンで裏返しになっているカードは、基本的にだれも見ることはできません。これは、先制攻撃をされたときにパワーが増えるというメリットが あるかわりに、山札からパワーゾーンにカードが流れてしまうというリスク＆リターンです。これを防ぎたいときは、先にパワーゾーンにチャージするほうが安 全というわけです。



パワーにするカードを置く場所。
パワーゾーンに置けるカードに枚数の制限はない。
チャージフェイズに、ここかコマンドゾーンにカードを１枚だけ置く事ができる。
ここに置かれたカードは、裏表やカテゴリに関係なく、1枚につきパワー1つ分とカウントされる。
ダメージをカウントするゲージを兼ねていて、置かれたカード枚数以上のダメージを受ければ山札からカードが置かれパワーが増える。つまりピンチになるとより高パワーの強いカードが使えるようになる仕組みになっており、序盤にあえて相手にストライクさせパワーを加速するような戦法を取ることもできる。
普通はパワーゾーンに置かれたカードはユニットやオペレーションとしては使えないが、パワーゾーンに置かれているときに効果を発揮するカードもある。
オーバーテクノロジーはパワーゾーンの操作を得意とするカテゴリであり、クロスギャザーからはパワーゾーンはカードテキスト上ではオーバーテクノロジーのイメージカラーである青色の文字で示されている。
