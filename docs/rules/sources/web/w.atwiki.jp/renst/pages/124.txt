# 圧縮
# https://w.atwiki.jp/renst/pages/124.html

圧縮
オペレーション等の効果によってデッキ（山札）を減らし戦略上必要なカードを引き当てやすくすること。
圧縮といっても方法は様々。ライダーパスやボウケンブラックのような山札の枚数を減らすもの以外にも、トライチェイサーのような山札の上を操作して擬似的な圧縮を行うものもある。また、シンケンゴールドや超変身のような手札の増えないドロー効果も圧縮と同様の効果がある。
ユニットやオペレーションによるサーチ効果は、欲しいカードが山札から手に入る上に圧縮もできるため、二重に得といえる。

圧縮冷凍の略称ではない。
