# 送る
# https://w.atwiki.jp/renst/pages/1872.html

送る
ユニット及びビークルをパワーゾーンやコマンドゾーンに置く操作を行うとき、テキスト上で用いられる表現。
主にユニットのゾードアップや、除去効果の解決の際に使われる。
パワーゾーンやコマンドゾーンに送られたユニットは、それ以降ユニットカードとして扱われる。この操作は「ユニットでなくなるとき」というタイミングにあたる。
コマンドゾーンに送られる場合、特に指定がなければカードはリリース状態で置く。パワーゾーンに送られる場合、指定がなければオモテ向きで置く。
どちらのプレイヤーのゾーンに送るのか明言されていないときは、必ずそのカードの持ち主のゾーンに送るようにする。
