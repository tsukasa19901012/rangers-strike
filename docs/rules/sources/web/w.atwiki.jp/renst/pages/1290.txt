# スクラム（用語）
# https://w.atwiki.jp/renst/pages/1290.html

スクラム

効果：これのCNより1多いCNを持つユニットがこれの次に並んでいる間、これはアタックされない（原文より）



七忍の炎陣より登場した能力。
効果はＣＮ（コンビネーションナンバー）を昇順に並べることでこの能力を持ったユニットがアタックされなくなるというもの。
「２」→「３」、「４」→「５」→「６」のように、順番良く並べていくことで付くボーナスのようなもので、撃破されたりしてナンバーが崩されると一気に能力がなくなっていくので注意。
アタック以外には無力なので能力やオペレーションなどでの撃破には当然効果が無い。
あまり積極的に頼れるほど頼もしい能力とは言い難く、使えたらラッキー程度のおまけだと割り切ったほうがいい。ただしバードニック反応炉やBSフォーメーションを使う一部のデッキにおいては非常にやっかいな能力に化ける。
