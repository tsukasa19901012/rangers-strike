# サーチ
# https://w.atwiki.jp/renst/pages/600.html

サーチ
ゲーム中、カードの効果によって山札や捨札の中から特定のカードを選び取る行為の俗称。OTやETにこの効果を持つカードが多い。
欲しいカードを手に入れることは、ゲームを有利に進めるにあたって非常に重要。特に特定のコンボやシナジーを中心に据えたデッキにとっては、キーカードが手元に来ないことは死活問題。サーチ効果を駆使しいかに早くカードを集められるかが勝負の分かれ目となる。
もっとも、早くカードを集められてもパワーやコマンドが足りなければ宝の持ち腐れ。チャージの計画を考え、ベストなタイミングを見極めて使おう。
代表的なカードはオペレーションがデネブ、Sユニットはスーパー戦隊アドレスブック、ビークルがソルインジケーター。また仮面ライダーには専用のベルトカードが存在する。
