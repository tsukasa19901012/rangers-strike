# 効果名
# https://w.atwiki.jp/renst/pages/1685.html

効果名
ユニットまたはビークルのテキスト欄にある、黒地に白抜きで書かれた名称の部分。
効果名以下の文章は「効果名を持つテキスト」または「効果名を持つ効果」とされ、ＣＮやその文章中に表記された条件を満たした時に発動する効果となる。
当wikiの各カードのページでは、太字および【】で囲んだ文で表記する。
レジストなど複数のユニットが共通して持つ能力は「効果名を持たないテキスト」に分類される。「効果名」とはあくまでも白抜きの部分のみを指す。
