# ビークルカード
# https://w.atwiki.jp/renst/pages/1505.html

ビークルカード
カード上部にビークルカード(VEHICLE CARD)と書かれたカード。
各作品でヒーロー達が使用した乗り物を表す。
ラッシュされるとエリアから離れるまでビークルとして扱われる。
マスクドライダーEXP登場と共に導入され、紅き六戦士の帰還からはメインシリーズにも登場。
