# フレーバーテキスト
# https://w.atwiki.jp/renst/pages/622.html

フレーバーテキスト
カードの下に書いてある文章のこと。レンジャーズストライクのストーリーなどが語られている。
カードを「香り付け」するから「フレーバー」テキスト。
ゲームには影響しない。
戦隊・ライダーのクロスオーバー的なことが書かれているので、ネタを知っているとにやりとできる。
動物視点で書かれたフレーバーテキストが存在することも有名。
