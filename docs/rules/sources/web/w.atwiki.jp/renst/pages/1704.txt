# 禁止カード
# https://w.atwiki.jp/renst/pages/1704.html

禁止カード
レギュレーションにおいてデッキに入れることが出来ないカード。
TCGでは、環境を支配するような強力なカードやコンボが発生した場合、公式大会で使用できないカードや枚数制限を定めてゲームバランスを修正することがある。
レンジャーズストライクでは、メタとなるカードを新発売するパックやプロモカードで登場させることで対応する傾向にあり、通常ルールの公式大会で使用できないカードはコマンダーカード以外は今のところ存在しない。
レンジャーズストライク ツアーフェスティバル’０８のガンスリンガー大会においてのみ、魔法猫スモーキーが禁止カードになった。
タッグストライクルールではドラゴンレンジャー、命の泉、メディテーションの使用が禁止されている。
