# 作品名
# https://w.atwiki.jp/renst/pages/2465.html

作品名
カード左下に書かれている、そのカードの出展となる映像作品の名称。
数は非常に少ないが、この作品名を参照するカードも存在している。
同じ作品シリーズのカードでも、本編と劇場版、ＶＳシリーズなどで出展作品が別々になっている場合がある。
XG2 ドラゴンタイガーの「仮面ライダー555」のカードは「仮面ライダーファイズ」と書かれている表記ゆれがある。
また変身一発やGOD SPEED LOVEのように、劇場版が元になっているにもかかわらず作品名が本編扱いになっているカードも存在する。変身一発は、再録の際に作品名が変更された。
