# するかわりに
# https://w.atwiki.jp/renst/pages/2395.html

するかわりに
カードの効果の処理に関してよく使われる言葉。
「ＡするかわりにＢをする」という文章で使われ、Ａの行動や効果を実行できるタイミングでＡをやらずにＢの行動や効果を実行する。
2008年10月のルール改正により「Ａが実行不可能な場合でもＢを実行することができる」ことが明言されている。
