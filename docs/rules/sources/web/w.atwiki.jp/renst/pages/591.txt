# 場
# https://w.atwiki.jp/renst/pages/591.html

場
バトルエリア、ラッシュエリア、パワーゾーン、コマンドゾーン、常駐置き場の総称。
テキストの「場を離れるとき」という表現は、場の中でそれぞれの場所から移動するときも含まれる。（ラッシュエリアからパワーゾーン、バトルエリアからラッシュエリア等）
ユニットカードの「このユニットが場にあるとき」というテキストは、そのカードがユニットとして扱われているとき、つまりラッシュエリアかバトルエリアにいるときにのみ有効。コマンドゾーンやパワーゾーンに置いても発動しないので注意。
上記のようなややこしい事例があるためか最近はテキストでは「場」という表現はあまり使われず、エリアやゾーンの名前を直接指定したり、「このカードが」「このユニットが」というテキストになっている場合が多い。
