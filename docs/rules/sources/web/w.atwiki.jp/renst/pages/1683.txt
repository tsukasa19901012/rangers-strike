# シナジー
# https://w.atwiki.jp/renst/pages/1683.html

シナジー
「相乗効果、相乗作用」の意。
直接的な繋がりのコンボとは違い、広い範囲への間接的な繋がりによる効果を指す。
反対に相性の悪い組み合わせはアンチシナジーと呼ばれる。
