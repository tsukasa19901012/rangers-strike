# 自爆
# https://w.atwiki.jp/renst/pages/1806.html

自爆
自軍ユニットをＢＰがより高い敵軍ユニットにアタックさせ、わざと撃破されることの通称。自滅・自爆特攻・玉砕など、同じ意味の通称は多数ある。
一見無駄のように見えるが、ＮＣを発動した後のユニットを自爆させることでバトルエリアから取り除き、後続のＣＮの被るユニットの効果を連続で発動させることができる。
戦略にもよるが、特にカテゴリ毎のストライクナンバーにおいてストライク不可能のユニットを使う場合は必須のテクニックであると言える。
他にもレスキューレーダーのように、自爆しては回収を繰り返してラッシュ時に発動する効果を何度も使用するような構成のデッキも存在する。
