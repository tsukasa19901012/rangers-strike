# 特徴
# https://w.atwiki.jp/renst/pages/1017.html

特徴
ユニットカードやビークルカード、及び一部のオペレーションカードの右下に記載されているそのユニット・ビークル（またはオペレーション）の持つ特徴。
原作の設定から決められる事がほとんどで、この特徴を利用した能力やオペレーションは多い。
特徴の一覧はこちらに記載。
特徴を追加する効果関連にも書いてあるが、ユニットやカードに特徴を追加する効果が適用される場合、既に持っている特徴であっても重複して追加される。また追加された特徴は一番後ろに書いてあるものとして扱う。
レッドやブルーなどの色の特徴は、色つき文字で書かれている。
