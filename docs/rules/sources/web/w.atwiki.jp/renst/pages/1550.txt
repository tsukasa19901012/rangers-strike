# ビークルサイズ
# https://w.atwiki.jp/renst/pages/1550.html

ビークルサイズ
ユニットサイズ同様、ビークルも大きさを基にしてSサイズ、Mサイズ、Lサイズに分かれている。 
Sビークルが圧倒的に多い上にサイズによる制限なども少ないので話題に上ることはあまりないが、ビークル除去カードはSビークルのみが対象のものが大半なので、それ以外のサイズのものはさらに安心。
ＲＣを持つユニットならば、特に指定がない限りどちらのサイズにも関係なくライドすることが可能。
