# https://w.atwiki.jp/renst/pages/145.html

チャージフェイズ
スタートフェイズの次のフェイズ。
自分の手札からカードを一枚選び、パワーゾーンもしくはコマンドゾーンのどちらかに置くことが出来る。
1ターンに置く事が出来るのは一枚だけ。無論、置かずに手札を維持することもできる。
このフェイズが終ると次はラッシュフェイズに移る。
