# プレイシート
# https://w.atwiki.jp/renst/pages/1424.html

プレイシート
ゲームに必要な場の配置のうち、プレイヤー１人分が表示されたA3サイズの紙。対戦時は2枚を向かい合わせて使用する。
山札・常駐置き場・コマンドゾーン・パワーゾーン・ラッシュエリア・バトルエリアの位置が指定されている。なお、捨札置き場は存在せず、捨札はプレイシートの外にまとめて置かれる。
これらの配置を覚えていればゲームは出来るので、必ずしも無くてもよい。
各弾のスターターセットに同梱される他、公式ホームページからダウンロード出来る。
