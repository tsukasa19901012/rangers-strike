# エクスパンション
# https://w.atwiki.jp/renst/pages/174.html

エクスパンション
カードの販売形態のひとつで、拡張パックのこと。自販機ブースターと手売りのパック版ブースターの2種が存在する。
英雄の再誕、マスクドライダーEXP、スペシャルメタルエディションを除くすべてのエクスパンションのタイトルには、数字が含まれている。
新シリーズクロスギャザーが登場し、戦隊ヒーロー、ライダー、メタルのエクスパンションは以降、これに集約される事となった。
パック版は初期は1パックに6枚入りだったが、リバイヴァでは12枚入りで必ずレア以上のカードが封入されていた。蒼九の翼以降ではカードフォーマットの変更に合わせてリバイヴァと同じく12枚入りとなり、レア以上とノーマルレアのカードが必ず1枚封入されている。
