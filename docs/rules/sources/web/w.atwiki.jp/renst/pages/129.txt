# オーバーテクノロジー
# https://w.atwiki.jp/renst/pages/129.html

オーバーテクノロジー
異星のテクノロジーや超未来科学で戦うヒーローで構成された勢力。正義の宇宙人などもここに属する。
イメージカラーは青。
パワーが溜まるのが早く、大型Lユニットのプレイングを得意とする。溜める以外のパワー操作も豊富。
「次の相手ターン～」で始まるNC5のロック効果や敵軍ユニットをバトルエリアに引き出す効果、山札からのサーチ効果が多いのが特徴。
デンジイエローや仮面ライダー電王LF（2nd）等、速攻デッキに対するメタカードが多い。
ダメージ回復・ダメージを与える手段を持つ。
ストライク可能になるナンバーはＮＣ・分数共に基本的に４番と比較的遅め。
アーステクノロジー程ではないが、ゴーオンブルーや仮面ライダー電王SFのような基本ナンバー以外でのストライカーも実用的なレベルで多数存在しており単色での多段ストライクも得意な方と言える。
カウンターやそれに類する効果のカードが一枚もなく、モーフ以外の奇襲攻撃は不得手。
ダークアライアンスと並んでレジストを持つユニットが少ない。
全体的に重めなのが弱点。
