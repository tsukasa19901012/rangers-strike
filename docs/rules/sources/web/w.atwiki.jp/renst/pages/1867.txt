# システムユニット
# https://w.atwiki.jp/renst/pages/1867.html

システムユニット
アタックやストライク用の戦力ではなく、常に発揮されたり自動的に発動するタイプの効果を当てにして使われるユニットの通称。
性質上撃破されると困るので、ラッシュエリアに引き籠らせて使う。中には最初からバトルエリアに出られないユニットも存在する。そういったタイプの場合BPは低く設定されていることが多い。
常駐オペレーション同様、デッキの戦略そのものに関わるものも多い。感覚的にもユニットというよりオペレーションに近いものがあるが、こちらはいざというときMユニットなどの素材にできる、比較的除去手段が豊富などの違いがあり、一概に同じようには使えない。
除去効果や、グリフォーザーを始めとするラッシュエリアにアタックできるユニットは天敵。何らかの防衛策を講じておきたい。またBPが低いタイプの場合はスカイライダー（XG4）などのBPを下げる効果にも注意。
