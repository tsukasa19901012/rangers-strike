# カウンター（用語）
# https://w.atwiki.jp/renst/pages/1295.html

カウンター

効果：これは敵軍ターン中にのみ使用できる（原文より）



オペレーションカードの種類の一つ。
テキスト左側のスペースに三角形に逆らう矢印のアイコンが表記される。
通常のオペレーションと違い、自軍ラッシュフェイズではなく敵軍ターンに使用する。逆に自軍ターン中には使用できない。
当然使用には通常のオペレーションと同様、自軍コマンドのホールドが必要。相手にリリース状態のコマンドがないならば、カウンターを心配する必要はなくなる。逆に自軍ターン終了までリリース状態のコマンドを残して相手にターンを渡すことで、カウンターを使用する可能性を相手に警戒させることができる。
使用するタイミングはカードにより様々。
シチュエーションとしては単に奇襲に徹したものの他、神秘のパワーやアイテムの発動、感情が爆発するようなシーンからのカード化が多い。特に未知の力を扱うミスティックアームズはカウンターの種類が豊富であり、一方科学に頼るせいかオーバーテクノロジーには現在１枚も存在しない。
