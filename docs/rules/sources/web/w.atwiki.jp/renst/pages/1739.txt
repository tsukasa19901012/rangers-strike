# カード名
# https://w.atwiki.jp/renst/pages/1739.html

カード名

Q&A



		Q1
		『これは「○○○○」としてつかえる。』という様なテキストが書かれたカードは、その名称のカードと同名のカードであるとして考えてよいのでしょうか？
		A1
		はい、そのとおりです。ゲーム中、同名カードとして扱えますので、追加条件などの名称を指定したテキストの対象として選ぶことができます。ですが、本来のカード名は異なりますので、デッキ構築の際は別のカードとして扱います。



カードイラストの下、必要パワーの右に書かれたカードの名前のこと。ユニットやビークルとして扱われているときはそのユニットやビークルの名前として扱う。
同じカード名を持つカードは、テキストや種類の違いに関わらず1つのデッキに3枚までしか入れられない。ただし戦闘員カードなど例外が存在する。またコマンダーカードは枚数には含まれない。
「これは○○としてつかえる」というテキストを持つカードの場合、公開情報であるときはいつでも状態にかかわらず「○○」というカード名として扱ってよい。相手プレイヤーもその名前で扱って構わない。構築のときは「○○」とは別の名前のカードなので、「○○」とは別に3枚までデッキに入れられる。
テキストでカード名が指定されている場合、通常は完全に名前が一致しているものでなければ対象にできない。例えばブレイバックルは「仮面ライダーブレイド」が対象なので「仮面ライダーブレイドKF」は対象外。一方「ディケイド ブレイド」は「これは『仮面ライダーブレイド』としてつかえる」というテキストを持つため対象になる。
サラマンデスドラゴンなどのように特定の文字列が含まれた名前を指定するカードもある。
現在最も長いカード名は「仮面ライダーディケイドCFジャンボフォーメーション」の25文字。
