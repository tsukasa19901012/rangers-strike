# 捨山
# https://w.atwiki.jp/renst/pages/1288.html

捨山（すてやま）
撃破されてしまったユニットや、使い切ったオペレーションなどのいわゆる捨札を置いておく場所。
表向きにして重ねて置き、相手側に情報を開示しておく必要がある。
普通は捨札を置く場所も一緒くたに「捨札」と呼ばれており、ほとんど使われていない単語。
