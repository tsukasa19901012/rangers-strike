# エリア

エリア
バトルエリアとラッシュエリアの総称。
エリアにオモテ向きで置かれたユニットカード・ビークルカードは、特に断り書きが無い限りユニット・ビークルとして扱う。
エリアとエリア以外の間をカードが移動した場合、つまりユニットカードがユニットになった場合やその逆が起きた場合、BPなどの数値の変動・特徴やカテゴリの追加・ホールド/リリースの状態・回数制限のある効果の使用履歴など、カード自体に本来書かれていない追加されていた情報はすべて消える。
