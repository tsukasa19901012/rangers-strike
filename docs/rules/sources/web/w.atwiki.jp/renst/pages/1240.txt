# 一角聖馬ユニゴルオン
# https://w.atwiki.jp/renst/pages/1240.html

一角聖馬ユニゴルオン

種類：Mビークル

カテゴリ：ミスティックアームズ

必要パワー：4

追加条件：なし

特徴：魔法


テキスト：

※DAを持たない特徴「人型」を持つMユニットは、ＲＣを持っていなくてもこのビークルにライドでき、それ以外のユニットはライドできない。 

※このビークルは合体ユニットとしてつかえる。 

【世界を駆ける力】これにライドしているユニットは、次の能力を得る⇒ラッシュエリアのユニットにアタックできる。 

・このテキストは公式HPで読み替えが推奨されています。修正後は以下。

【世界を駆ける力】これにライドしているユニットは、次の能力を得る⇒敵軍ラッシュエリアのユニットにアタックできる。 




フレーバーテキスト

世界すら駆け抜ける聖馬は、愛を信じ勇気を燃やす者にのみ背を許す。 





イラストレーター：Masakazu Fukuda

レアリティ：ノーマル

作品：魔法戦隊マジレンジャー

収録：究極の八神　自販：パック

再録：XG5 ザ・チケットブレイカー　スターター（カードヒーローデッキ）





Q&A



		Q1
		「RK-575 一角聖馬ユニゴルオン」のテキストには、『これにライドしているユニットは、次の能力を得る⇒ラッシュエリアのユニットにアタックできる』と書かれていますが、この「ラッシュエリア」は自軍・敵軍を問わないと考えてよろしいですか？
		A1
		「RK-575 一角聖馬ユニゴルオン」のカードのテキストが不十分なため、ご迷惑をおかけして申し訳ありません。「RK-575 一角聖馬ユニゴルオン」の効果名のテキスト『ラッシュエリアのユニットにアタックできる。』の部分については、『敵軍ラッシュエリアのユニットにアタック できる。』と読み替えてご利用いただきますよう、よろしくお願いいたします。



カード評価
ライドできるユニットの種類が非常に限られるのが残念。除去には非常に強いので、セイントカイザーへの合体自体はかなり容易である。
カードには「ラッシュエリアのユニットにアタックできる」としか書かれていないが、公式エラッタにより敵軍ラッシュエリアのユニットにしかアタックできないことが明確になっている。
