# 相打ち
# https://w.atwiki.jp/renst/pages/1826.html

相打ち
ＢＰが同じ自軍ユニットと敵軍ユニットでバトルし、お互いに撃破されること。ＢＰの値はサイズ毎に一定の範囲にあるため、案外よく発生する。
２つのユニットは同時に撃破された扱いになる。
自爆特攻と同じように後続のＣＮが被るユニットを活用できるが、敵軍ユニットの除去ができるので一般的にはこちらの方が望ましい。
無論片方がレジストを持っていた場合は、発動することで（撃破はされるが）そちらだけ生き残ることができる。
