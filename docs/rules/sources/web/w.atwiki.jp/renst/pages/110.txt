# パワー
# https://w.atwiki.jp/renst/pages/110.html

パワー
ユニットやビークルをラッシュしたり、オペレーションを使用するのに必要。
自軍のパワーは自軍パワーゾーンに置かれているカードの枚数と、敵軍コマンドゾーンに置かれているマルチカテゴリのカードの枚数で決まる。
上記の理由があるため、「パワーゾーンのカードの枚数」と「パワーの数」は必ずしも一致しない。カードの効果で参照する場合、どちらを指しているのかはよく確認する必要がある。
カードの裏表は関係ない。
