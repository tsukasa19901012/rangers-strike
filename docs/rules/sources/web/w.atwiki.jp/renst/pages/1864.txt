# 優先順位
# https://w.atwiki.jp/renst/pages/1864.html

優先順位
効果の解決をするとき、優先される順番。
「否定文の効果（～しない、できない）」が「強制的に発動する効果（～する）」「任意に発動できる効果（～してもよい）」よりも優先順位が高い。
複数の効果がぶつかった場合（「バトルエリアに出られない」ユニットが「バトルエリアに出す」効果の対象になった場合など）、優先順位の高い効果が適用される。
