# https://w.atwiki.jp/renst/pages/143.html

多色
ワイルドビースト、アーステクノロジー、オーバーテクノロジー、ミスティックアームズ、ダークアライアンスという５つあるカテゴリの内、二つ以上のカテゴリを混ぜてデッキを作ること。
各カテゴリの弱点を別のカテゴリで補うことができ、展開に幅を持たせられるのが利点。ストライクもしやすくなる。
弱点は、カテゴリを増やせば増やすほどコマンドを複数のカテゴリで割らなければならなくなり、展開が遅く不安定になること。
