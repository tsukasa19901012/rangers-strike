# 単色
# https://w.atwiki.jp/renst/pages/139.html

単色
ワイルドビースト、アーステクノロジー、オーバーテクノロジー、ミスティックアームズ、ダークアライアンスという５つあるカテゴリの内、一つのカテゴリだけでデッキを作ること。
コマンドの色を気にする必要が無いので、安定して展開を行える利点がある。
弱点は、カテゴリの傾向がそのまま展開の傾向になるため先を比較的読まれやすいこと、ストライクのナンバーが被るので打点不足になりがちなことなどが挙げられる。
