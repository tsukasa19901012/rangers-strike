# ハイランダー
# https://w.atwiki.jp/renst/pages/2252.html

ハイランダー
同名カードを1枚までしか入れずに構築されたデッキ、またはそのようなデッキのみを使用するルールを指す。
目当てのカードを引きにくいため、特定のカードを軸にしたコンボが組みづらい。より緩いシナジーをメインにするか、グッドスタッフに近い構築が求められる。
レンストには特殊レギュレーション大会として「ハイランダー大会」が存在する。コマンダーカードは使用不可。
当然カードナンバーが異なるカードでもカード名が同じならばあわせて1枚までである。
