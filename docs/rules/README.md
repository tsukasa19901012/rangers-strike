# レンジャーズストライク ルールブック

このディレクトリは、本リポジトリにおける **ゲームルールの唯一の正（single source of truth）** である。

- エンジンの挙動・テスト・UI 文言・設計文書でルールに触れるときは、このルールブックの **ルールID**（例: `R-WIN-02`）を引用する。
- ルールの追加・変更はこのディレクトリで行い、IDは変えない（廃止する場合は「廃止」と明記して残す）。
- 本書は自己完結している。旧要約ドキュメント（`docs/wiki/*.md`、glossary、cards 要約、ルート直下のレポート類、旧 architecture 文書）は参照しない。

### 1.2 出典の優先順位

1. **公式FAQ／公式エラッタ／公式ルール**（grnrngr）、および atwiki に転載された公式 Q&A・公式用語集・公式コラム
2. **atwiki の規定文**（「効果：…（原文より）」行＝カード注釈文の写し）と **atwiki 本文**

本書に載せるのは、上記の出典を実際に読んで確認できたルールだけである。出典がない、または出典同士が矛盾する事項は `[未確定]` とし、確定方法を書く。

## 2. 記法

各ルールは次の形で書く。

```
#### R-XXX-NN 見出し [信頼度] `照合状態`
規定（簡潔に）
- 出典: スナップショットの略記 ＋ 短い引用 または Q番号
- Web: 照合すべきライブURL
- [未確定] 不確かな点と、確定させる方法（任意）
- 実装: ✅ / ❌ / ?（任意）
```

**信頼度タグ**

| タグ | 意味 |
|---|---|
| `[公式]` | grnrngr の FAQ・エラッタ、または atwiki 転載の公式 Q&A・公式用語集・公式コラム・規定文（「効果：…（原文より）」） |
| `[wiki]` | atwiki 本文（編集者の解説） |
| `[Q&A]` | コミュニティ回答（page-1974 等） |
| `[未確定]` | 資料に根拠がない、または矛盾がある |

**実装状況**

- ✅ エンジンの挙動がルールと一致
- ❌ 既知の不一致（監査ID付き）
- ? 未確認／部分的

## 3. 引用のしかた

- コード: `// ルール: R-KW-BLAST-01`、`/** @rule R-WIN-02 */`
- テスト名: `it("R-START-03: 追加ドローは1ターン1回", ...)`
- 文書・PR: 「R-REPL-03 により…」。複数なら列挙する。
- ルールにない挙動を実装するときは、先にこのルールブックへルール（必要なら `[未確定]`）を追加してから ID を引用する。

## 7. 既知の矛盾・注意点（本書作成時に判明）

- **「アタックするかわりに」:** 保存済み公式カードFAQ（RS-100 Q2、RS-106 Q3・Q6）は「対象がいなければ発動不可」。atwiki 転載の公式コラム vol44 によるルール整理で「権利を失うかわりに発動可」に変更済み。本書は新しい方を採用（R-ATK-05、R-REPL-03）。デカレッドは読み替え（R-ERR-RS106）で従来の挙動を維持。
- **効果によるラッシュの条件:** 既定では必要パワー・追加条件は不要（R-RUSH-20、公式 RS-121）。ランドバルカン・シーロンの光で必要になるのはカード本文に「ただし…満たすこと」とあるから（R-RUSH-21）であり、一般則ではない。
- **エラッタの範囲:** 公式エラッタページ（保存版）は6件だが、atwiki には「公式HPでエラッタ発表／読み替え推奨／修正」の注記が付いたカードがさらに28枚ある（08章 §2）。
- **BP 計算順:** atwiki 本文（「～になる」が以降の増減を無効化）と、出典未確認の「指定値 → ＋ → －」が矛盾（R-BP-01）。
- **コマンドゾーン超過:** 公式 Q&A は「捨札」、wiki 本文は「効果ごとに異なる」（R-ZONE-08）。
