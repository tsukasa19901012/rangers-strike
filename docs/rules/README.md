# レンジャーズストライク ルールブック

このディレクトリは、本リポジトリにおける **ゲームルールの唯一の正（single source of truth）** である。

- エンジンの挙動・テスト・UI 文言・設計文書でルールに触れるときは、このルールブックの **ルールID**（例: `R-WIN-02`）を引用する。
- ルールの追加・変更はこのディレクトリで行い、IDは変えない（廃止する場合は「廃止」と明記して残す）。
- 本書は自己完結している。旧要約ドキュメント（`docs/wiki/*.md`、glossary、cards 要約、ルート直下のレポート類、旧 architecture 文書）は参照しない。

### 1.1 正となる情報源

**ライブのウェブサイトが正。** 保存スナップショットは参考資料にすぎない。

- `web相違` — ライブ版がスナップショットと異なる（本文を更新し、旧内容を注記）

### 1.2 出典の優先順位

1. **公式FAQ／公式エラッタ／公式ルール**（grnrngr）、および atwiki に転載された公式 Q&A・公式用語集・公式コラム
2. **atwiki の規定文**（「効果：…（原文より）」行＝カード注釈文の写し）と **atwiki 本文**
3. **コミュニティ Q&A**（atwiki ルール質問所 page-1974 の回答、コメント欄）

例外: **後から出た公式のルール整理は、それ以前の公式カードFAQに優先する。**

例外2: **atwiki に日付付きで記録された公式回答の後日修正（例「（2010/10/25修正）」）は、取得した公式FAQの回答より優先する。** 取得できる公式ページが修正前のまま残っているため（ユーザー決定 2026-10-10、§5.7 e）。 例: 「AするかわりにB」は公式コラム vol44（2008年10月のルール整理）が、保存済み公式カードFAQ RS-100 Q2 の旧裁定を置き換えている（R-REPL-03、R-ATK-05）。

本書に載せるのは、上記の出典を実際に読んで確認できたルールだけである。出典がない、または出典同士が矛盾する事項は `[未確定]` とし、確定方法を書く。

## 2. 記法

各ルールは次の形で書く。

```
#### R-XXX-NN 見出し [信頼度] `照合状態`
規定（簡潔に）
- 出典: スナップショットの略記 ＋ 短い引用 または Q番号
- Web: 照合すべきライブURL
- [未確定] 不確かな点と、確定させる方法（任意）
- 実装: ✅ / ❌ / ?（任意）
```

**信頼度タグ**

| タグ | 意味 |
|---|---|
| `[公式]` | grnrngr の FAQ・エラッタ、または atwiki 転載の公式 Q&A・公式用語集・公式コラム・規定文（「効果：…（原文より）」） |
| `[wiki]` | atwiki 本文（編集者の解説） |
| `[Q&A]` | コミュニティ回答（page-1974 等） |
| `[未確定]` | 資料に根拠がない、または矛盾がある |

**実装状況**

- ✅ エンジンの挙動がルールと一致
- ❌ 既知の不一致（監査ID付き）
- ? 未確認／部分的

## 3. 引用のしかた

- コード: `// ルール: R-KW-BLAST-01`、`/** @rule R-WIN-02 */`

- 文書・PR: 「R-REPL-03 により…」。複数なら列挙する。
- ルールにない挙動を実装するときは、先にこのルールブックへルール（必要なら `[未確定]`）を追加してから ID を引用する。

### 5.7 公式と atwiki の食い違い

2026-10-10 の照合で見つかった、公式（grnrngr）と atwiki が食い違う点と、本書の採否。a・b はユーザーが決定した（2026-10-10）。

- **a. スタートフェイズでリリースするもの** — R-HOLD-02, R-START-01
  - 公式: `rule/rule_phase1-2.html` は「自分の場にホールド状態（ヨコ置き）のカードがあれば、すべてリリース状態」と書き、ユニットを除外していない。
  - atwiki: `atwiki/page-157`「ホールド状態のユニットはスタートフェイズになってもリリースされず」、`atwiki/page-264`（リリースするのは「ホールド状態の自軍コマンド」）。
  - 本書: コマンドのみリリース（ユニットのホールドは持続）。**ユーザー決定（2026-10-10）**。公式ページはユニットのホールド（レジスト）登場前の基本ルールの記述と見る。E8（レジストのホールドがスタートで解除される）は不一致として修正する。
- **b. 「アタックするかわりに」の裁定** — R-ATK-05, R-REPL-03
  - 公式: ライブの公式カードFAQ（`faq/card_2.html` RS-100 Q2、RS-106 Q3・Q6、`faq/card_3.html` のデカレッドの Q）は今も旧裁定「対象がいなければ（アタックできなければ）発動できない」。
  - atwiki: `atwiki/page-318` に転載された公式コラム vol44（2008年10月のルール整理）の抜粋は「アタックする権利を失う代わりに効果を発動することができる」。
  - 本書: 攻撃対象がいなくても、アタックする権利を失うかわりに発動できる。**ユーザー決定（2026-10-10）**。後のルール整理である vol44 を採る（README §1.2 の例外）。vol44 の原文はオンラインで見つからない。
- **c. 効果の種類別の固定優先順位** — R-PRI-02
  - 公式: `faq/index.html` リファレンスに種類別の優先順位表はない（否定文優先・同時はターンプレイヤー・BP 計算順のみ）。atwiki（page-1869・1864）も「優先順位の高い効果から」と書くだけで表はない。
  - エンジン: 固定の priority を廃止した（02-D13 修正済み）。同時発動はターンプレイヤーの選択（`simultaneous_order`）、それ以外は処理の入れ子順。
- **d. デッキ枚数** — R-DECK-01
  - 公式: `rule/rule_preparation.html` は今も「40枚１組のカードのことをデッキと呼びます」。
  - atwiki: `atwiki/page-71`「クロスギャザーからはデッキ枚数の上限がなくなり、40枚以上ならば何枚でもよくなった」、`atwiki/page-604`。
  - 本書: XG 以降は 40枚以上・上限なし（atwiki のみが根拠）を採る。公式の告知文は見つかっていない。

- **e. 「可能ならバトルエリアに置く」とゼニボム** — RS-090, RS-110（R-RUSH-24 周辺）

## 7. 既知の矛盾・注意点（本書作成時に判明）

- **「アタックするかわりに」:** 保存済み公式カードFAQ（RS-100 Q2、RS-106 Q3・Q6）は「対象がいなければ発動不可」。atwiki 転載の公式コラム vol44 によるルール整理で「権利を失うかわりに発動可」に変更済み。本書は新しい方を採用（R-ATK-05、R-REPL-03）。デカレッドは読み替え（R-ERR-RS106）で従来の挙動を維持。
- **効果によるラッシュの条件:** 既定では必要パワー・追加条件は不要（R-RUSH-20、公式 RS-121）。ランドバルカン・シーロンの光で必要になるのはカード本文に「ただし…満たすこと」とあるから（R-RUSH-21）であり、一般則ではない。
- **エラッタの範囲:** 公式エラッタページは6件（ライブ版も同じ）だが、公式カードFAQの回答中にも読み替え・訂正が10件あり（08章 §1A）、atwiki には「公式HPでエラッタ発表／読み替え推奨／修正」の注記が付いたカードがさらに21枚ある（08章 §2）。
- **BP 計算順:** atwiki 本文（「～になる」が以降の増減を無効化）と、出典未確認の「指定値 → ＋ → －」が矛盾していたが、公式FAQ リファレンスで前者と確定（R-BP-01、2026-10-10）。
- **コマンドゾーン超過:** 公式 Q&A は「捨札」、wiki 本文は「効果ごとに異なる」（R-ZONE-08）。
